# Mini-Korean：規格

> 簡易韓國語　單位：word　核心層 659 ＋ 擴充層 417

## 1. 設計目標

| 目標 | 做法 |
|---|---|
| 字少 | 所有句子只由詞表內的單位組成；數字用阿拉伯數字 |
| 是真正的該語言 | 寫出來的一定是正確、自然的該語言，不是另一種語言 |
| 靠組合 | 學會詞表就能讀懂更多說法 |
| 語法固定 | 只用編號的句型規則，困難結構用固定替代說法 |
| 說不出來就換句話說 | 表外的概念用「描述 ＋ 類頭」，說不出是哪一個就用外來語 |

## 4. 語法規則

1. 語序：主語 + 助詞 + 修飾 + 場所 + 時間 + 動詞 + 賓語 + 助詞 + 句尾。韓文是 SOV，動詞在最後。　例：저는 학교에서 한국어를 공부해요.
2. 只用 해요體：現在＝해요／過去＝았어요·었어요／未來＝(으)ㄹ 거예요。　例：가요／갔어요／갈 거예요
3. 否定用「안 + 動詞」或「못 + 動詞」（放在動詞前）。　例：학교에 안 가요.
4. 助詞只有八個：은/는(이/가)、을/를、에、에서、도、의、하고、부터。　例：저는 학생이에요.
5. 助詞跟前面的詞走：有收音（받침）用 은・을，沒有收音用 이・를。　例：책을 읽어요.／친구를 만나요.
6. は/는（은/는）標示主題；이/가 標示主語。已知資訊用 은/는，新資訊用 이/가。　例：저는 학생이에요.／누가 왔어요?
7. 에 用在：目的地、時間點、對象（人）。　例：학교에 가요. 세 시에 만나요. 친구에게 줘요.
8. 에서 用在：動作發生的場所、起點。　例：집에서 쉬어요.
9. 의 用在：兩個名詞之間（屬於、修飾）。　例：친구의 책
10. 하고 用在：並列（人或物）。　例：친구하고 같이 가요.
11. 도 用在：表示「也」。　例：저도 가요.
12. 從…起（부터）與到…止（까지）用同樣的詞型。　例：9시부터 6시까지 일해요.
13. 疑問句：句尾加「요」；或者把助詞提到前面。　例：학교에 가요?
14. 原因用「-아서／어서」或「그래서」。　例：배가 아파서 병원에 가요.
15. 條件用「-면」。　例：비가 오면 집에 가요.
16. 讓步用「-아도／어도」。　例：비가 와도 가요.
17. 時間用現成的詞：오늘、어제、내일、지금、아까、오늘밤。　例：어제 갔어요.
18. 數字用阿拉伯數字。　例：3명、2개
19. 量詞只有「개、명、번、살、시간、년、원、권」等最常用幾個。　例：3명、2번
20. 動詞的名詞化用「-는」：먹는 사람 ＝吃東西的人。　例：운전하는 사람
21. 描述：表外的概念用「…하는 사람」「…하는 곳」＋ 類頭。　例：병을 보는 사람
22. 一個概念一個詞：只用「크다」，不用「엄청 크다／거대하다」。　例：큰 집
23. 「있다／없다」用於無生命，「있다」也可以表示有生命（가 있다 ＝有…）。　例：책이 있어요.／친구가 있어요.
24. 否定形容詞用「-지 않다」不合規，改用「안 + 形容詞」或反義詞。　例：안 예뻐요
25. 一個句子只說一件事；長句拆成短句。　例：저는 학생이에요. 동생은 어섯이에요.
26. 「감사합니다／반갑습니다／죄송합니다」這類固定用語直接背。　例：감사합니다.
27. 回答問題用「네／예요／아니요」。　例：네, 학생이에요.
28. 動詞的過去式是「-았어요／-었어요」，依詞幹最後母音決定。　例：먹었어요／갔어요
