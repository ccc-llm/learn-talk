# Mini-Chinese：規格

> 簡易中文　單位：char　核心層 449 ＋ 擴充層 0

## 1. 設計目標

| 目標 | 做法 |
|---|---|
| 字少 | 所有句子只由詞表內的單位組成；數字用阿拉伯數字 |
| 是真正的該語言 | 寫出來的一定是正確、自然的該語言，不是另一種語言 |
| 靠組合 | 學會詞表就能讀懂更多說法 |
| 語法固定 | 只用編號的句型規則，困難結構用固定替代說法 |
| 說不出來就換句話說 | 表外的概念用「描述 ＋ 類頭」，說不出是哪一個就用外來語 |

## 4. 語法規則

1. 主語 + 動詞 + 賓語。 中文和英文一樣，基本是「誰 + 做 + 什麼」。　例：我吃飯。 他看書。 我們學中文。
2. 時間放在動詞前面。 時間可以在主語前，也可以在主語後，但一定在動詞前。　例：我明天去。 今天晚上我在家。
3. 地點用「在 + 地方」，放在動詞前面。　例：我在學校學中文。 他住在東邊。
4. 「是」連接兩個名詞。　例：他是老師。 這是我的書。
5. 「有」表示擁有或存在。 否定一律說「沒有」，不說「不有」。　例：我有兩個朋友。 這裡有很多人。 我沒有錢。
6. 性質直接當謂語，前面加「很、太、不、真、最」等。 不加「是」：說「他很高」，不說「他是高」。　例：他很高。 今天太熱了。 這個不貴。
7. 修飾語在前，用「的」連接。 單字的性質修飾名詞時，「的」可以省略。　例：我的朋友 很好吃的菜 大車、小孩、新書
8. 數字 + 量詞 + 名詞。 本語言只用六個量詞：
9. 否定：「不」用於現在、將來、習慣與性質；「沒」用於過去與「有」。　例：我不吃肉。 他明天不來。 我昨天沒去。 我沒有手機。
10. 問句。　例：你是學生嗎？ 你叫什麼名字？ 你喝茶還是喝水？ 我很好，你呢？
11. 動作的時間狀態。
12. 能願動詞放在動詞前。
13. 比較。　例：他比我高。 這個比那個更貴。 我和你一樣大。 他是最好的老師。
14. 方向：「來」朝向說話的人，「去」離開說話的人。　例：請進來。 他回家去了。 我拿出去。
15. 「得」描述動作做得怎麼樣：動詞 + 得 + 性質。　例：你說得很好。 他走得很慢。
16. 介詞片語放在動詞前：在、和、從、給、對、到。　例：我和朋友一起吃飯。 他從中國來。 我給媽媽打電話。
17. 連接句子。 每種關係只用一組連接詞：　例：請坐。 不要說話。 我們走吧。
