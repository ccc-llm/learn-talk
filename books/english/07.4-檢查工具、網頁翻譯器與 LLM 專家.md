# 07.4 檢查工具、網頁翻譯器與 LLM 專家

本章要學習怎麼使用網頁翻譯器、句子檢查工具和 LLM（a language model tool）檢查自己的英文句子。這些工具可以找出錯字、錯的詞形和不自然的句子，但是最後仍然要自己核對。好的方法是先準備句子，再一個單位一個單位檢查，最後比較不同工具的答案。

## 句子檢查前的準備

不要直接把很長的句子交給工具。先把句子分成幾個小部分，再一個單位一個單位檢查。這樣比較容易知道錯在哪裡。

| 中文說明 | Mini-English |
|---|---|
| 把句子分成小部分。 | Split the sentence into small parts. |
| 檢查每個詞。 | Check every word. |
| 檢查每個詞形。 | Check every form. |
| 使用詞表檢查每個詞。 | Use the word list to check every word. |
| 不要使用詞表以外的詞。 | Do not use a word that is not in the list. |
| 把句子寫下來。 | Write the sentence down. |

一個實用的準備順序是：

1. **Copy my sentence into the page.**  
2. **Check every word and every form.**  
3. **Read the answer from the tool.**  
4. **Write the correct sentence again.**  

這些句子都可以使用同一個方法。每一句只做一件事，因此工具的答案會比較容易理解。

## 使用網頁翻譯器或檢查工具

網頁翻譯器可以先把句子變成另一種語言，也可以顯示句子的意思。不過，翻譯結果不一定自然。句子檢查工具可以指出可能的錯字、錯的詞形或不清楚的結構。

| 中文說明 | Mini-English |
|---|---|
| 打開網頁。 | Open the website. |
| 把句子複製到頁面。 | Copy the sentence to the page. |
| 使用翻譯工具。 | Use the translation tool. |
| 查看工具的答案。 | Look at the answer from the tool. |
| 找出錯的詞。 | Find the wrong word. |
| 這個句子有 1 個錯的詞。 | This sentence has 1 wrong word. |
| 答案會顯示錯的詞。 | The answer shows the wrong word. |
| 這個句子是正確的。 | This sentence is correct. |

可以先用簡單的方法檢查句子：

- **Every word is in the word list.**
- **The word form is correct.**
- **This sentence has 1 wrong word.**
- **The answer shows the wrong word.**
- **Please check the sentence again.**

如果工具只給一個很長的答案，可以再問一個簡單問題：

- **What is wrong with this sentence?**
- **Which word is wrong?**
- **Can you give me a correct sentence?**
- **Please show me the correct sentence.**

問題越簡單，回答越容易檢查。不要要求工具同時檢查很多件事。

## 使用 LLM 專家工具

LLM 可以像一個英文檢查專家一樣工作，但要用固定問題請它檢查句子。它可以先說明問題，再給一個新句子。

| 中文說明 | Mini-English |
|---|---|
| 這個工具可以檢查我的英文句子。 | This tool can check my English sentence. |
| 請檢查這個句子。 | Please check this sentence. |
| 這個句子的問題是什麼？ | What is the problem with this sentence? |
| 給我一個簡單的答案。 | Give me a simple answer. |
| 給我一個正確的句子。 | Give me a correct sentence. |
| 這個句子可以使用哪些詞？ | Which words can I use in this sentence? |
| 請說明每一個錯字。 | Please explain each wrong word. |
| 不要增加新的意思。 | Do not add any new meaning. |

可以先問：

- **What is wrong with this sentence?**
- **Which word is not correct?**
- **Can you give me a correct sentence?**

然後要求工具解釋：

- **Please explain the wrong word.**
- **What should I change?**
- **Use only words from the word list.**

如果想要求比較簡單的句子，可以說：

- **Please use a simple sentence.**
- **Please make the sentence shorter.**
- **Please keep the same meaning.**
- **Please do not change the meaning.**

要注意，LLM 的答案也可能錯。它可能使用詞表以外的詞，也可能改變原來的意思。因此不要直接接受答案。

## 比較答案並修改句子

最安全的方法是比較 2 個答案，再使用詞表做最後檢查。如果答案不同，不要只選比較長的答案。要選擇使用詞表內更多詞、意思更接近原句的答案。

| 中文說明 | Mini-English |
|---|---|
| 比較第一個答案和第二個答案。 | Compare the first answer and the second answer. |
| 選擇只使用詞表內詞語的答案。 | Choose the answer that uses only words from the list. |
| 用詞表檢查新句子。 | Use the word list to check the new sentence. |
| 這個工具可能是錯的。 | The tool may be wrong. |
| 我會用詞表檢查答案。 | I check the answer with the word list. |
| 我會保留簡單又清楚的答案。 | I keep the answer that is simple and clear. |
| 我會寫下最後的句子。 | I write the final sentence. |

一個完整的檢查流程是：

1. **Copy my sentence into the page.**
2. **Check every word with the word list.**
3. **Ask the tool what is wrong.**
4. **Read the answer and compare it with another answer.**
5. **Check the new sentence again.**
6. **Write the final sentence.**

最後不要只問「這句對嗎？」也可以問得更具體：

- **Is every word in the word list?**
- **Is the word form correct?**
- **Does this sentence keep the same meaning?**
- **Can you make it more simple?**

這種檢查方式可以幫助學習者同時檢查詞彙、詞形、句子結構和意思，而不是只接受工具的第一個答案。

> 答案：This sentence has 1 wrong word.

> 答案：What is wrong with this sentence?
