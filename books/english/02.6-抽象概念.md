# 02.6 抽象概念

本章學習「想法、關係、時間、社會」這類比較抽象的概念。這些詞不像 apple、house 那樣可以直接看見，但可以用來說明一個人想什麼、事情怎麼改變、大家怎麼一起生活，以及過去和未來的重要。

## 想法與計畫

想法和計畫可以幫助人做決定。它們看不見，但可以改變人的行動。

| Mini-English | 中文意思 |
|---|---|
| idea | 想法 |
| plan | 計畫 |
| choice | 選擇 |
| reason | 原因 |
| result | 結果 |
| goal | 目標 |
| decision | 決定 |
| problem | 問題 |
| answer | 答案 |
| method | 方法 |

An idea can change a person.  
一個想法可以改變一個人。

A plan can help a team.  
一個計畫可以幫助一個團隊。

The result of a choice can be difficult.  
一個選擇的結果可能很困難。

I want to know the reason for this decision.  
我想知道這個決定的原因。

We use a method to solve the problem.  
我們使用一種方法來解決問題。

### 對話

甲：What is your goal?  
乙：I want to learn a new language.  
甲：What is your plan?  
乙：I study every day and speak with my friend.

## 關係與共同生活

關係可以發生在兩個人、一群人或一個地方裡。人們透過 agreement、group、community 和 cooperation 一起生活。

| Mini-English | 中文意思 |
|---|---|
| agreement | 協議；同意 |
| group | 群組 |
| community | 社群 |
| society | 社會 |
| culture | 文化 |
| rule | 規則 |
| law | 法律 |
| choice | 選擇 |
| support | 支持 |
| together | 一起 |

An agreement can help two groups work together.  
一份協議可以幫助兩個群組一起工作。

A community is a group of people in a place.  
一個社群是一群在同一個地方的人。

The society has many kinds of people.  
這個社會有許多種人。

A rule can tell people what is right and wrong.  
一條規則可以告訴人們什麼是對的，什麼是錯的。

We support our family and our community.  
我們支持自己的家人和社群。

## 時間與變化

時間可以分成 past、present 和 future。Moment、period 和 process 說明時間中的片刻、時期和變化過程。

| Mini-English | 中文意思 |
|---|---|
| past | 過去 |
| present | 現在；目前 |
| future | 未來；將來 |
| moment | 片刻 |
| period | 時期 |
| process | 過程 |
| change | 改變 |
| happen | 發生 |
| begin | 開始 |
| continue | 繼續 |
| end | 結束 |
| progress | 進步 |
| experience | 經驗 |
| change | 改變 |

The present is important.  
現在很重要。

The past can help us understand the future.  
過去可以幫助我們理解未來。

A good experience can change a person.  
一次好的經驗可以改變一個人。

The work will begin now and continue until the end of the day.  
工作現在開始，並且持續到今天結束。

The process is slow, but the progress is real.  
這個過程很慢，但是進步是實際的。

## 社會與共同生活

society 是社會，community 是社群，government 是政府，law 是法律。這些詞可以說明大家一起生活的方式，以及人們在社會中的責任。

| Mini-English | 中文意思 |
|---|---|
| society | 社會 |
| community | 社群 |
| government | 政府 |
| law | 法律 |
| rule | 規則 |
| culture | 文化 |
| public | 公共的；公眾 |
| service | 服務 |
| safety | 安全 |
| responsibility | 責任 |
| respect | 尊重 |
| equal | 相同的；平等的 |
| fair | 公平的 |

People live together in a society.  
人們一起生活在社會中。

The government makes laws for the people.  
政府為人民制定法律。

A culture can give people a shared way of life.  
一種文化可以給人們一種共同的生活方式。

We should respect the rules and keep the place safe.  
我們應該遵守規則，並且保持地方安全。

Everyone should have an equal chance.  
每個人都應該有相同的機會。

The service is for all people in the community.  
這項服務是為社群裡的所有人提供的。
