### 自然與天氣的對話

```text
甲：Quel est le ciel ?
乙：Le ciel est gris.
甲：Il fait froid ?
乙：Oui, il fait froid.
甲：Un animal est là ?
乙：Oui, un oiseau est là.
甲：Que fait l'oiseau ?
乙：L'oiseau chante.
```

### 天氣對話

```text
甲：Il fait chaud ?
乙：Non, il fait froid.
甲：Le soleil est là ?
乙：Oui, le soleil est dans le ciel.
甲：Il va pleuvoir ?
乙：Oui, la pluie tombe.
甲：Le nuage est gris ?
乙：Oui, le nuage est gris.
```

### 讀法與寫法提醒

| 規則 | 說明 | 完整例句 |
|---|---|---|
| 動物名稱通常放在不定冠詞後面 | 使用 un 或 une | Un oiseau chante. |
| 陰性動物名稱使用 une | 名稱和冠詞保持一致 | Une abeille est sur une fleur. |
| 位置放在 être 後面 | 使用 à、dans、sur、sous、près、entre、derrière、devant | Le papillon est sur une fleur. |
| 狀態放在 être 後面 | 使用性質詞 | L'herbe est verte. |
| 動作放在主語後面 | 使用動作動詞 | Le poisson nage. |
