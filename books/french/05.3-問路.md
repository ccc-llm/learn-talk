# 05.3 問路

## 05.3 問路

### 學習目標

學習詢問目的地、詢問位置，以及回答方向。

### 常用詞語

| Mini-French | 中文 |
|---|---|
| aller | 去 |
| aller à… | 去…… |
| où | 哪裡；在……的地方 |
| comment | 怎樣；如何 |
| direction | 方向 |
| devant | 在……前面 |
| derrière | 在……後面 |
| à côté de… | 在……旁邊 |
| à droite de… | 在……右邊 |
| à gauche de… | 在……左邊 |
| entre… et… | 在……和……之間 |
| près de… | 在……附近 |
| ici | 這裡 |
| là | 那裡 |

### 基本句型

| 功能 | Mini-French | 中文 |
|---|---|---|
| 詢問地點 | Où est la gare ? | 車站在哪裡？ |
| 詢問方向 | Quelle direction ? | 哪個方向？ |
| 詢問怎麼去 | Comment aller à la gare ? | 怎麼去車站？ |
| 確認目的地 | Vous allez à la gare ? | 你要去車站嗎？ |
| 回答地點 | La gare est ici. | 車站在這裡。 |
| 回答方向 | La gare est à gauche. | 車站在左邊。 |
| 說明前進方向 | Vous allez vers la gare. | 你朝車站走。 |
| 說明下一個動作 | Ensuite, vous allez à droite. | 接著你向右走。 |

### 位置說法

| Mini-French | 中文 |
|---|---|
| La gare est devant l'hôtel. | 車站在旅館前面。 |
| La gare est derrière l'hôtel. | 車站在旅館後面。 |
| La gare est à côté du musée. | 車站在博物館旁邊。 |
| La gare est à droite du musée. | 車站在博物館右邊。 |
| La gare est à gauche du musée. | 車站在博物館左邊。 |
| Le café est entre la gare et l'hôtel. | 咖啡館在車站和旅館之間。 |
| Le musée est près de la gare. | 博物館在車站附近。 |

### 對話一：在車站問路

```text
甲：Bonjour. Je cherche la gare. Où est la gare ?
乙：La gare est devant l’hôtel.
甲：Comment aller à la gare ?
乙：Vous allez vers le musée. Ensuite, la gare est à gauche.
甲：Merci.
乙：Salut.
```

### 對話二：在旅館問路

```text
甲：Bonjour. Je veux aller à la gare.
乙：Vous allez à la gare ?
甲：Oui. Où est la gare ?
乙：La gare est à côté du parc. Elle est près du café.
甲：C’est loin ?
乙：Non. C’est à côté.
甲：Merci beaucoup.
乙：De rien.
```

### 對話三：談論語言

```text
甲：Bonjour. Vous parlez quelle langue ?
乙：Je parle français (la langue de ce pays).
甲：Vous parlez une autre langue ?
乙：Oui. Je parle une langue, un peu.
```

> 「un peu」不在詞表內，因此這句不能使用。可以改說：
>
> ```text
> Oui. Je parle une autre langue.
> ```
>
> 「français」是外來語，第一次出現時要加括號說明。

### 對話四：詢問方向

```text
甲：Bonjour. Je cherche le musée.
乙：Quelle direction ?
甲 : Je ne sais pas. Où est le musée ?
乙 : Le musée est au nord, derrière la gare.
甲 : Comment aller au musée ?
乙 : Vous allez vers la gare. Ensuite, le musée est à droite.
甲 : Merci.
乙 : Bonjour.
```

### 說不出完整句子時

| 功能 | Mini-French | 中文 |
|---|---|---|
| 只問地點 | Où ? | 哪裡？ |
| 只問方向 | Quelle direction ? | 哪個方向？ |
| 說明自己在找 | Je cherche… | 我找…… |
| 說明要去 | Je veux aller à… | 我要去…… |
| 確認理解 | C’est ici ? | 在這裡嗎？ |
| 表示距離近 | C’est à côté. | 在旁邊。 |
| 表示距離遠 | C’est loin. | 很遠。 |
| 表示完全不知道 | Je ne sais pas. | 我不知道。 |

### 練習

- [ ] 把對話中的「Je cherche la gare. Où est la gare ?」改成詢問博物館。

- [ ] 用 Mini-French 回答：「La gare est à côté du musée.」

- [ ] 用 Mini-French 說：「我不知道車站在哪裡。」

- [ ] 修正不合規則的句子：「Je parle français, un peu.」

> 答案：Je cherche le musée. Où est le musée ?

> 答案：La gare est à côté du musée.

> 答案：Je ne sais pas. Où est la gare ?

> 答案：Je parle français (la langue de ce pays). Je parle une autre langue.
