# 06.5 改寫流程：七步

本章要學習把一篇一般文章改寫成 Mini-French。文章中的每個意思都要依照固定流程處理：先找出主要資訊，再選取受限詞表內的詞，最後檢查句型、詞形與詞表範圍。七個步驟能讓改寫更準確，也能避免加入原文中不存在的新資訊。

## 步驟一：讀懂原文，決定主要資訊

改寫前，先閱讀整篇文章，決定哪些資訊最重要。主要資訊通常包括：

- 誰是文章的主題。
- 事情發生在哪裡。
- 什麼時候發生。
- 發生什麼事。
- 文章希望讀者知道什麼。

刪除次要資訊時，不能刪掉理解文章不可缺少的部分。改寫後的文章不必和原文一樣長，但必須保留主要意思。

| 原文的主要意思 | Mini-French 改寫 |
|---|---|
| 我明天要去車站。 | Je vais à la gare demain. |
| 車站附近有一個公園。 | La gare est près du parc. |
| 我在車站看見一列火車。 | Je vois un train à la gare. |

## 七個改寫步驟

| 步驟 | 操作 | 檢查問題 |
|---|---|---|
| 1. 閱讀原文 | 找出主題與主要資訊 | 最重要的事情是什麼？ |
| 2. 切分意思 | 把文章分成幾個完整意思 | 每個意思都能獨立成句嗎？ |
| 3. 選取詞彙 | 優先使用核心層詞彙 | 這個詞在詞表內嗎？ |
| 4. 選擇句型 | 套用固定的主詞、動詞、賓語句型 | 這是最簡單的表達嗎？ |
| 5. 處理困難資訊 | 使用描述、類頭或外來語 | 能否換一句話說清楚？ |
| 6. 改寫全文 | 依序重寫每一個意思 | 每句都完整而且自然嗎？ |
| 7. 檢查限制 | 檢查詞彙、冠詞、否定與時態 | 有沒有使用表外詞或錯的詞形？ |

### 步驟二：切分意思，選擇句型

先不要急著翻譯每個字。把原文分成幾個完整意思，再為每個意思選擇最簡單的句型。

Mini-French 的基本句型是：

> 主語＋動詞＋賓語

| 意思 | 句型 | Mini-French |
|---|---|---|
| 說明身分 | 主語＋être＋名詞 | Je suis étudiant. |
| 說明所在 | 主語＋être＋地點 | Je suis à la maison. |
| 說明活動 | 主語＋動詞＋賓語 | Je mange une pomme. |
| 說明所有物 | 主語＋avoir＋賓語 | Elle a une clé. |
| 說明即將發生 | aller＋動詞原文 | Je vais partir. |
| 提出選擇 | 句子＋ou＋句子 | Tu veux du thé ou du café ? |

一句話如果不能直接使用這些句型，就要先簡化內容。

### 步驟三：處理表外概念

當原文使用詞表外的概念時，可以分成兩種方法。

#### 方法一：使用描述和類頭

先說明它有什麼作用，再用類頭指出它是什麼。

| 一般概念 | Mini-French 改寫 |
|---|---|
| 一個可以閱讀的地點 | un lieu où on lit |
| 一個會唱歌的人 | une personne qui chante |
| 一個用來喝水的東西 | une chose pour boire |
| 一種做某件事的工作 | un travail de |

例如：

- Je cherche un lieu où on lit.
- Je vois une personne qui chante.
- J'ai une chose pour boire.

#### 方法二：使用外來語

如果不知道某個專有名詞的確切法文，可以使用原來的文字。第一次出現時，在括號內加上詞表內的說明。

| 外來語 | 第一次出現的寫法 |
|---|---|
| Mini-French | Mini-French (un genre de langue) |
| Kyoto | Kyoto (une ville) |
| Python | Python (un outil) |

後文再次出現時，可以直接寫：

- Je étudie Mini-French.
- Je vais à Kyoto.
- Python est utile.

## 從一般文章到 Mini-French

下面是一個簡化的改寫過程。

| 階段 | 內容 |
|---|---|
| 原文 | 我明天早上會去車站，在那裡看見一列火車。火車非常大。之後，我要回家吃蘋果。 |
| 切分意思 | 1. 去車站。2. 看見火車。3. 火車很大。4. 回家。5. 吃蘋果。 |
| 初步改寫 | Je vais à la gare demain matin. Je vois un train. Le train est grand. Je vais à la maison. Je mange une pomme. |
| 最後檢查 | 所有詞都在詞表內；時間放在動詞前；句子完整。 |

這個例子也可以保留在同一篇文章中：

- Je vais à la gare demain matin.
- Je vois un train.
- Le train est grand.
- Je vais à la maison.
- Je mange une pomme.

### 對話

甲：Je vais à la gare demain matin.  
乙：Tu vois un train ?  
甲：Oui. Le train est grand.  
乙：Je vais à la maison après.  
甲：Moi, je mange une pomme.

## 最後檢查：詞彙、語法與完整性

完成改寫後，必須從頭檢查一次。

| 檢查項目 | 檢查方法 | 合格例子 |
|---|---|---|
| 詞表限制 | 確認每個詞都在附錄詞表內 | Je lis un livre. |
| 句子完整 | 保留主語、動詞和必要賓語 | Elle mange une carotte. |
| 冠詞配合 | 依照性別和數量選冠詞 | le livre / la table / les livres |
| 動詞配合 | 依照主語改變動詞形式 | Il parle. / Nous parlons. |
| 否定形式 | 使用 ne ... pas | Je ne mange pas de pain. |
| 時間位置 | 把時間放在動詞前面 | Je viens ce soir. |
| 地點位置 | 使用 à、dans、sur 或 sous | Je suis dans le parc. |
| 困難資訊 | 使用描述、類頭或外來語 | une personne qui chante |

如果一句話需要多個補充資訊，先分成幾句，不要把所有內容塞進一個很長的句子。
