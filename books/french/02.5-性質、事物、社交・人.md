# 02.5 性質、事物、社交・人

## 02.5 性質、事物、社交・人

本章學習：

- 描述事物的性質
- 說明人與人的關係
- 介紹職業與身分
- 進行簡單的日常對話

### 一、表示性質

法文常用 `être` 描述性質。性質詞放在名詞後面。

| Mini-French | 中文 |
|---|---|
| Il est grand. | 他很高大。 |
| Elle est petite. | 她很小。 |
| Ce livre est nouveau. | 這本書是新的。 |
| Cette maison est grande. | 這棟房子很大。 |
| Cet homme est gentil. | 這位男士很友善。 |
| Cette femme est forte. | 這位女士很強壯。 |

### 二、描述一個人

描述人物時，可以使用：

- `un homme`：一個男人
- `une femme`：一個女人
- `un enfant`：一個孩子
- `un élève`：一個學生
- `un ami`：一個朋友
- `un voisin`：一個鄰居

| Mini-French | 中文 |
|---|---|
| Cet homme est courageux. | 這位男士很勇敢。 |
| Cette femme est médecin. | 這位女士是醫生。 |
| Cet enfant est heureux. | 這個孩子很快樂。 |
| Cet élève est intelligent. | 這位學生很聰明。 |
| Mon ami est calme. | 我的朋友很平靜。 |

詢問一個人的資料：

| Mini-French | 中文 |
|---|---|

| Comment tu vas ? | 你好嗎？ |
| Tu habites où ? | 你住哪裡？ |
| Tu es professeur ? | 你是教授嗎？ |
| Tu aimes la musique ? | 你喜歡音樂嗎？ |

### 七、日常對話

#### 對話一：認識一個人

```text
甲：Bonjour ! Tu habites où ?
乙：Bonjour ! J’habite à Paris.
甲：Quel est ton nom ?
乙：Mon nom est Paul.
甲：Tu es professeur ?
乙：Non, je suis étudiant.
```

#### 對話二：描述朋友

```text
甲：Qui est cet homme ?
乙：C’est mon frère.
甲 : Il est grand ?
乙 : Oui, il est grand et sportif.
甲 : Il est heureux ?
乙 : Oui, il est très heureux.
```

#### 對話三：詢問職業

```text
甲：Comment tu vas ?
乙：Très bien, merci.
甲：Tu es employé ?
乙：Non, je suis professeur.
甲 : Tu aimes ton travail ?
乙 : Oui, je l’aime beaucoup.
```

#### 對話四：詢問家庭

```text
甲：Tu as une famille ?
乙：Oui, j’ai une famille.
甲 : Tu as des frères et des sœurs ?
乙 : Oui, j’ai un frère et une sœur.
甲 : Où est ta famille ?
乙 : Elle est à la campagne.
```

### 八、句型組合

#### 句型 1：身分或職業

```text
主語 + être + 身分或職業
```

例：

```text
Je suis étudiant.
Il est professeur.
Elle est médecin.
```

#### 句型 2：描述性質

```text
主語 + être + 性質
```

例：

```text
Je suis heureux.
Le chat est noir.
La maison est grande.
```

#### 句型 3：描述一個人

```text
冠詞 + 人 + être + 性質
```

例：

```text
Cet homme est courageux.
Cette femme est calme.
Cet enfant est intelligent.
```

#### 句型 4：表示所有關係

```text
物主代詞 + 名詞
```

例：

```text
Mon ami arrive.
Ma sœur travaille.
Nos livres sont ici.
```

#### 句型 5：表示親屬關係

```text
主語 + être + 親屬
```

例：

```text
Il est mon père.
Elle est ma mère.
Nous sommes des amis.
```

#### 句型 6：詢問性質

```text
主語 + est + 性質 + ？
```

例：

```text
Tu es heureux ?
Le chat est noir ?
La maison est grande ?
```

### 九、常見替代表達

| 不直接使用 | Mini-French 替代表達 |
|---|---|
| 此人的名字 | `Mon nom est …` |
| 那個人的職業 | `Cette personne est …` |
| 一個很好的男人 | `Un homme est bon.` |
| 一位友善的女士 | `Cette personne est gentil.` |
| 他們是同事 | `Ils sont collègues.` |
| 我和我的朋友 | `Mon ami et moi.` |

> 自我介紹時，可以說：`Mon nom est …`。  
> 描述一位女性時，可以使用：`Cette personne est gentil.`
