# 03.1 形態：免費的變化

本章學習法文的「形態」：哪些形式可以按照固定規則直接組合，哪些形式需要另外記憶。重點包括名詞的性數、動詞的現在式與複合過去式、否定結構，以及「正在做」和「將要做」的簡單說法。

## 1. 名詞與冠詞：先看性，再看數

法文名詞通常有性別和數量。冠詞與形容詞必須配合名詞變化。這些變化大多是「免費的」：知道名詞的性別和數量，就可以選擇相應形式。

| 名詞 | 單數 | 複數 | 說明 |
|---|---|---|---|
| livre | le livre | les livres | 陽性 |
| table | la table | les tables | 陰性 |
| Ami | un ami | des amis | 陽性 |
| maison | une maison | des maisons | 陰性 |

完整例句：

- Je lis un livre.
- Je lis une histoire.
- Je vois des livres.
- Je vois des maisons.

這些形式可以由同一個基本單位組合出來：

- `le`、`la`、`les` 是定冠詞。
- `un`、`une`、`des` 是不定冠詞。
- 複數名詞通常使用 `les` 或 `des`。

注意：`des` 不表示「一些」以外的新概念；在本教材中，它就是複數不定冠詞。

## 2. 動詞變化：大部分是規則的

動詞的第三人稱單數現在式，通常只在原形後加上 `-s`。這個變化可以直接套用，不需要另外背完整動詞表。

| 原形 | 第三人稱單數 | 例句 |
|---|---|---|
| parler | parle | Il parle. |
| habiter | habite | Elle habite ici. |
| manger | mange | Il mange une pomme. |
| finir | finit | Il finit. |
| choisir | choisit | Il choisit un livre. |

但是，有些動詞的變化不規則。這些形式需要另外學習。

| 原形 | 需要另外學的形式 | 例句 |
|---|---|---|
| faire | fait | Il fait. |
| avoir | a | Elle a un livre. |
| aller | va | Il va à la gare. |
| pouvoir | peut | Je peux. |
| vouloir | veut | Il veut. |

`être` 的現在式變化也需要特別記憶：

| 主語 | 形式 | 例句 |
|---|---|---|
| je | suis | Je suis étudiant. |
| tu | es | Tu es élève. |
| il / elle | est | Elle est professeur. |
| nous | sommes | Nous sommes amis. |
| vous | êtes | Vous êtes là. |
| ils / elles | sont | Ils sont là. |

這些句子都可以使用同一個句型規則：

> 主語 + `être` 形式 + 其他成分。

例如：

- Je suis calmе.
- Tu es aimable.
- Il est intelligent.
- Nous sommes ensemble.
- Vous êtes bien.
- Ils sont heureux.

## 3. 同一個動詞，不同的表達方式

法文可以用不同的動詞形式表達「做某事」「正在做某事」和「將要做某事」。

### 一般現在式

一般現在式表示習慣、狀態或正在進行的動作：

- Je mange une pomme.
- Je parle bien.
- Elle travaille maintenant.

### 近將來式

`aller` 加動詞原形，表示「即將做某事」。這個結構的變化規則是固定的：

> 主語 + `vais` / `vas` / `va` / `allons` / `allez` / `vont` + 動詞原形。

| 主語 | `aller` 形式 | 例句 |
|---|---|---|
| je | vais | Je vais manger une pomme. |
| tu | vas | Tu vas partir. |
| il / elle | va | Il va arriver. |
| nous | allons | Nous allons aller. |
| vous | allez | Vous allez venir. |
| ils / elles | vont | Ils vont travailler. |

### 複合過去式

複合過去式由 `avoir` 或 `être` 加過去分詞組成。許多動詞使用 `avoir`：

- J’ai eu un billet.
- J’ai eu une idée.
- Elle a eu peur.

部分動詞使用 `être`，例如：

- aller：`allé`
- arriver：`arrivé`
- venir：`venu`
- partir：`parti`
- entrer：`entré`
- sortir：`sorti`
- monter：`monté`
- descendre：`descendu`
- rester：`resté`

例如：

- Je suis allé à la gare.
- Elle est arrivée.
- Nous sommes partis.
- Ils sont restés.

這些過去分詞不能只用一般規則猜出全部形式，因此需要和動詞一起記憶。

## 4. 否定和賓語位置：可以組合，但有一些固定點

否定使用 `ne ... pas`。這個結構是固定的：

> 主語 + `ne` + 動詞 + `pas` + 其他成分。

例如：

- Je ne mange pas de pain.
- Il ne parle pas.
- Nous ne.Partir pas demain.
- Vous ne savez pas.

有 `avoir` 時，否定使用 `n’a pas`：

- Je n’ai pas de pain.
- Elle n’a pas un billet.
- Nous n’avons pas le temps.

人稱代詞作賓語時，放在動詞前：

- Je le vois.
- Tu me vois.
- Elle le tient.
- Nous vous ecologically.

`y` 和 `en` 是例外，也可以放在動詞後：

- J’y vais.
- Il en a.
- Nous y sommes.

有些變化看起來不同，但其實是同一個固定模式的不同組合：

| 功能 | 結構 | 例句 |
|---|---|---|
| 否定 | `ne` + 動詞 + `pas` | Je ne mange pas. |
| 將來 | `aller` + 動詞原形 | Je vais manger. |
| 所有格 | `de` + 所有格形式 | le livre de mon ami |
| 地點 | `à` / `dans` / `sur` / `sous` + 場所 | Je suis à la maison. |
| 複合形容詞 | `bien` + 過去分詞 | J’ai bien mangé. |

這些形式可以互相組合：

- Je ne vais pas manger.
- Je vais aller à la gare demain.
- Je vois le livre de mon ami.
- Je ne sais pas.

所以，「免費」的意思是：掌握少量固定規則後，可以把許多詞組合起來。不規則的詞形、特殊動詞和過去分詞，則需要另外學習。

## 練習

- [ ] 將句子改成否定句：Je mange une pomme.

  > 答案：Je ne mange pas de pomme.

- [ ] 用 `aller` 表示「我將要離開」。

  > 答案：Je vais partir.

- [ ] 選擇正確形式：Tu ___ élève.（是）

  > 答案：Tu es élève.

- [ ] 將句子改成複合過去式：Je vais aller à la gare.

  > 答案：Je suis allé à la gare.

- [ ] 說出「他有一本書」。

  > 答案：Il a un livre.
