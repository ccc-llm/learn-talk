# C 練習答案

本章整理 Mini-French 核心層練習的參考答案。解題時先確認句子是否符合固定語法規則，再確認每個詞都來自核心詞表。遇到表外概念時，使用「描述 ＋ 類頭」或外來語加括號說明。

## 核心句型答案

最常見的練習集中在主語、動詞、賓語、否定、時間與地點。這些句子使用相同的基本結構，只要更換詞彙，就能組合出更多意思。

| 中文題意 | Mini-French 參考答案 |
|---|---|
| 我吃一個蘋果。 | Je mange une pomme. |
| 她喝牛奶。 | Elle boit du lait. |
| 我們在圖書館。 | Nous sommes à la bibliothèque. |
| 這個貓很小。 | Ce chat est petit. |
| 那個房子很大。 | Cette maison est grande. |
| 你去機場。 | Tu vas à l’aéroport. |
| 他們經過車站。 | Ils passent à la gare. |
| 我不喝咖啡。 | Je ne bois pas de café. |

### 常見替換

同一句型可以替換不同的人、時間、地點和事物。

| 原句 | 替換後 |
|---|---|
| Je mange une pomme. | Je mange du pain. |
| Elle boit du lait. | Elle boit du thé. |
| Nous sommes à la bibliothèque. | Nous sommes au musée. |
| Ce chat est petit. | Ce chien est grand. |
| Tu vas à l’aéroport. | Tu vas à la gare. |

## 否定、時間與地點答案

否定句使用 `ne ... pas`。時間通常放在動詞前；地點通常放在動詞後。

| 中文題意 | Mini-French 參考答案 |
|---|---|
| 我現在不看電視。 | Je ne regarde pas la télévision maintenant. |
| 她不在家。 | Elle n’est pas à la maison. |
| 他明天來。 | Il vient demain. |
| 我們昨天看見它。 | Nous l’avons vu hier. |
| 他們晚上工作。 | Ils travaillent ce soir. |
| 孩子們在公園。 | Les enfants sont au parc. |
| 咖啡在桌子上。 | Le café est sur la table. |
| 書包在桌子下面。 | Le sac est sous la table. |

否定時間句也可以使用 `ne ... plus`：

| 中文題意 | Mini-French 參考答案 |
|---|---|
| 他已經不在這裡。 | Il n’est plus là. |
| 我不再害怕。 | Je n’ai plus peur. |

## 疑問與選擇答案

特殊疑問詞放在答案原本的位置；選擇問句使用 `ou`。

| 中文題意 | Mini-French 參考答案 |
|---|---|
| 你住在哪裡？ | Tu habites où ? |
| 你叫什麼名字？ | Quel est ton nom ? |
| 你要去哪裡？ | Tu vas où ? |
| 你想要茶或咖啡嗎？ | Tu veux du thé ou du café ? |
| 有多少時間？ | Combien de temps ? |
| 他為什麼來？ | Pourquoi il vient ? |

是非問句可以把動詞放在前面：

| 中文題意 | Mini-French 參考答案 |
|---|---|
| 你來嗎？ | Tu viens ? |
| 他工作嗎？ | Il travaille ? |
| 她是學生嗎？ | Elle est élève ? |
| 這是真的嗎？ | C’est vrai ? |

## 練習

- [ ] 1. 請用 Mini-French 回答：「我明天去車站。」

> 答案：Je vais à la gare demain.

- [ ] 2. 請把「他喝咖啡」改成否定句。

> 答案：Il ne boit pas de café.

- [ ] 3. 請用 Mini-French 回答：「你住在哪裡？」

> 答案：Tu habites où ?

- [ ] 4. 請用 Mini-French 回答：「你想要牛奶或咖啡嗎？」

> 答案：Tu veux du lait ou du café ?

- [ ] 5. 請用 Mini-French 回答：「這個女孩很聰明。」

> 答案：Cette fille est intelligente.
