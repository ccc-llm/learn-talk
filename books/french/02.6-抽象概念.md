# 02.6 抽象概念

抽象概念不容易直接看見，但可以用「想法」、「關係」、「歷史」、「時間」等詞表達。本章學習如何用這些詞描述思考、 人與人之間的聯繫，以及時間與社會的變化。

## 抽象想法與資訊

抽象概念常用來表達想法、理解、選擇、差別與結果。這些詞通常放在冠詞後面，並搭配性質詞。

| Mini-French | 中文 |
|---|---|
| une idée | 一個想法 |
| un concept | 一個概念 |
| une information | 一則資訊 |
| une question | 一個問題 |
| une réponse | 一個回答 |
| un choix | 一個選擇 |
| une différence | 一個差異 |
| un résultat | 一個結果 |
| une comparaison | 一項比較 |

可把抽象概念和具體事物放在一起：

> Cette idée est claire.  
> 這個想法很清楚。

> Ce concept est important.  
> 這個概念很重要。

> Cette information est utile.  
> 這則資訊很有用。

> La question a une réponse.  
> 這個問題有一個回答。

> Le choix est difficile.  
> 這個選擇很困難。

> Je sais la différence.  
> 我知道差異。

## 關係與社會

描述抽象關係時，可以使用表示「關係」、「合作」、「群體」、「社會」和「行動」的詞。常見句型是：

> 名詞 + 關係介詞 + 名詞

| Mini-French | 中文 |
|---|---|
| une relation | 一種關係 |
| une coopération | 一種合作 |
| un groupe | 一個群體 |
| une société | 一個社會 |
| une action | 一項行動 |
| un échange | 一種交流 |
| un accord | 一個同意 |
| un respect | 一份尊重 |
| une confiance | 一份信任 |

完整例句：

> La relation entre les personnes est importante.  
> 人與人之間的關係很重要。

> La coopération est utile pour le groupe.  
> 合作對這個群體很有用。

> Je fais partie de la société.  
> 我是這個社會的一分子。

> Le groupe est une partie de la société.  
> 群體是社會的一部分。

> L’échange entre les personnes est important.  
> 人與人之間的交流很重要。

> Cette action est un exemple de coopération.  
> 這項行動是合作的一個例子。

> Je sais la différence entre l’accord et le conflit.  
> 我知道同意與衝突之間的差別。

對話：

> 甲：Tu as une idée ?  
> 乙：Oui. Cette idée est utile.  
> 甲：Quelle est la différence ?  
> 乙：La différence est l’action.

## 歷史、時間與變化

時間概念可以表達過去、現在、未來，以及某件事如何改變。「歷史」和「記憶」則用來說明已經發生的事。

| Mini-French | 中文 |
|---|---|
| le passé | 過去 |
| le présent | 現在 |
| le futur | 未來 |
| l’avenir | 未來 |
| le temps | 時間 |
| l’histoire | 歷史 |
| la mémoire | 記憶 |
| la chronologie | 時序 |
| le changement | 改變 |
| la situation | 情況 |

完整例句：

> Le passé est différent du présent.  
> 過去與現在不同。

> Je pense au futur.  
> 我想到未來。

> Le temps passe toujours.  
> 時間總是流逝。

> L’histoire de la société est longue.  
> 這個社會的歷史很長。

> La mémoire est importante.  
> 記憶很重要。

> Ce changement est très important.  
> 這個變化非常重要。

> L’avenir est incertain.  
> 未來是不確定的。

> La chronologie est claire.  
> 時序很清楚。

對話：

> 甲：Tu comprends l’histoire ?  
> 乙：Oui. Je comprends le passé.  
> 甲：Et le présent ?  
> 乙：Le présent est important aussi.  
> 甲：Le futur est certain ?  
> 乙：Non. L’avenir est incertain.
