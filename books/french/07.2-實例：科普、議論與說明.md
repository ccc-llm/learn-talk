# 07.2 實例：科普、議論與說明

本章學習如何用簡單詞彙改寫科普、議論與說明文字。重點是保留原意，並使用「描述＋類頭」、短句、因果句與選擇句，降低句子的難度。

## 科普：用自然與天氣說明

科普文字可以從觀察開始，再說明現象。以下例句使用具體名詞和簡單形容詞：

| 中文概念 | Mini-French |
|---|---|
| 天空很暗。 | Le ciel est sombre. |
| 風很大。 | Le vent est fort. |
| 雷雨要來了。 | Un orage arrive. |
| 我看見閃電。 | Je vois un éclair. |
| 太陽很熱。 | Le soleil est chaud. |
| 月亮在天空裡。 | La lune est dans le ciel. |

也可以先提出問題，再回答：

> **甲：Comment est le ciel ?**  
> **乙：Le ciel est gris.**

「Le ciel est gris.」表示「天空是灰色的」；在這裡也可以自然地表達「天色很暗」。

### 對話

> **甲：Qu’est-ce que c’est ?**  
> **乙：C’est un éclair.**  
> **甲：Le tonnerre est fort ?**  
> **乙：Oui.**

這段對話使用「描述＋類頭」的方式解釋自然現象。「Qu’est-ce que c’est ?」用來詢問眼前的事物。

## 議論：用想法與理由表達看法

.discussion 句可以先提出看法，再用「parce que」說明理由。為了讓句子更簡單，一個句子只放一個理由。

| 中文概念 | Mini-French |
|---|---|
| 我認為這個想法很重要。 | Je pense que cette idée est importante. |
| 我認為科學很有用。 | Je pense que la science est utile. |
| 這很重要，因為它很有用。 | C’est important, car c’est utile. |
| 人類應該合作。 | Les hommes doivent coopérer. |
| 我們需要更多時間。 | Nous avons besoin de plus de temps. |

「coopérer」在句中要配合第三人稱複數形式：

> Les hommes doivent coopérer.

「Je pense que ...」後面接完整的肯定句：

> Je pense que ce résultat est clair.

如果要比較兩個方法，可以使用「plus」與「que」：

> Cette solution est plus facile que cette autre solution.

如果要在兩個方法之間選擇，可以使用「ou」：

> Je choisis cette solution ou cette autre solution.

### 對話

> **甲：Tu crois que ce résultat est clair ?**  
> **乙：Oui, je pense que ce résultat est clair.**  
> **甲：Pourquoi ?**  
> **乙：Car la différence est facile à comprendre.**

「Car」和「parce que」都可以引出原因。短句中可以使用「car」；原因較長時，使用「parce que」。

## 說明：用定義與特徵解釋概念

說明一個概念時，可以先使用類頭，再提出它的特徵。常見的說明方式包括：

- 「un animal qui ...」：一個做某事的動物。
- 「une personne qui ...」：一個做某事的人。
- 「une chose pour ...」：用於某事的東西。
- 「un genre de ...」：某一類事物。
- 「le travail de ...」：某種工作。

| 中文概念 | Mini-French |
|---|---|
| 一個會唱歌的人。 | Une personne qui chante. |
| 一個在花園裡的人。 | Une personne qui travaille dans un jardin. |
| 一個用來閱讀的東西。 | Une chose pour lire. |
| 一種動物的種類。 | Un genre d’animal. |
| 照顧花園的工作。 | Le travail de s’occuper d’un jardin. |

也可以利用「être」建立簡單定義：

> Un animal est un être vivant.  
> Un chat est un animal.  
> Cet animal est petit.

這三句依序說明「動物」、「貓」和「這隻動物」的關係。

### 對話

> **甲：Qu’est-ce que c’est ?**  
> **乙：C’est une personne qui travaille avec des enfants.**  
> **甲：Elle est professeur ?**  
> **乙：Oui, elle est professeur.**

「Une personne qui travaille avec des enfants.」是「描述＋類頭」的說法，意思是「一位和兒童一起工作的人」。

## 改寫：讓長句變短

遇到較長的科普、議論或說明文字時，可以分成幾個短句。不要省略內容，也不需要使用表外詞。

| 較長的表達 | 簡易改寫 |
|---|---|
| Je pense que la coopération est nécessaire. | Je pense que la coopération est nécessaire. |
| Cet animal est un être vivant qui habite dans la forêt. | Cet animal est un être vivant. Il habite dans la forêt. |
| Ce résultat est important parce qu’il est très clair. | Ce résultat est important. Car il est très clair. |
| Cette personne travaille avec des enfants. | C’est une personne qui travaille avec des enfants. |
| Il faut choisir entre cette solution et cette autre solution. | Je choisis cette solution ou cette autre solution. |

改寫時可以使用以下順序：

1. 先寫最重要的信息。
2. 再寫原因、特徵或地點。
3. 把長句分成幾個完整句子。
4. 保留原有觀點與事實。
5. 使用詞表內的類頭代替難懂的名詞。

例如，要說明一種住在森林裡的動物，可以寫：

> C’est un animal. Il habite dans la forêt.

也可以用關係子句合併：

> C’est un animal qui habite dans la forêt.
