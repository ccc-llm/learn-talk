# 02.3 數量、時間、方位・地點

本章學習用「多少、什麼時候、在哪裡」說明數量、時間與地點。數字使用阿拉伯數字；時間放在動詞前面；地點用「在＋地方」表示。

## 數量：多少

表示數量時，可以使用阿拉伯數字、量詞和名詞。常用結構是「數字＋量詞＋名詞」。詢問數量時，可以用「幾＋量詞」。

| Mini-Chinese | 中文意思 |
|---|---|
| 我有2個朋友。 | 我有兩個朋友。 |
| 這裡有3個人。 | 這裡有三個人。 |
| 我只有2塊錢。 | 我只有兩塊錢。 |
| 你有幾個朋友？ | 你有幾個朋友？ |
| 他有3件衣服。 | 他有三件衣服。 |
| 我買了5個水果。 | 我買了五個水果。 |

## 時間：什麼時候

時間可以放在主語前面或後面，但是要在動詞前面。常見的時間包括「今天、昨天、明天、每天、每週、早、晚、現在、以前」等。

| Mini-Chinese | 中文意思 |
|---|---|
| 我明天去。 | 我明天去。 |
| 今天我在家。 | 今天我在家。 |
| 我每週學2次中文。 | 我每週學兩次中文。 |
| 他現在在學校。 | 他現在在學校。 |
| 我下午3點到公司。 | 我下午三點到公司。 |
| 我以前住在這裡。 | 我以前住在這裡。 |

## 方位・地點：在哪裡

表示某個地方存在某物時，使用「在＋地方」。也可以用「左、右、前、後、中、裡、外」等說明相對位置。

| Mini-Chinese | 中文意思 |
|---|---|
| 我在學校學中文。 | 我在學校學中文。 |
| 他住在東邊。 | 他住在東邊。 |
| 這家店在左邊。 | 這家店在左邊。 |
| 那個房間在中間。 | 那個房間在中間。 |
| 車站在公園右邊。 | 車站在公園右邊。 |
| 我從中國來。 | 我從中國來。 |

## 綜合對話

甲：你有幾個朋友？  
乙：我有2個朋友。  
甲：他們住在哪裡？  
乙：他們住在學校左邊。  
甲：他們每天來嗎？  
乙：他們每天8點來。  

## 練習

- [ ] 用「幾個」問數量：你有幾個朋友？

> 答案：你有幾個朋友？

- [ ] 把「明天3點」放在動詞前：明天3點你做什麼？

> 答案：明天3點你做什麼？

- [ ] 問對方是否會來：明天，你會來嗎？

> 答案：明天，你會來嗎？

- [ ] 用「在＋地方」說明位置：學校在車站左邊。

> 答案：學校在車站左邊。

- [ ] 說明動作、時間和地點：我明天在學校學中文。

> 答案：我明天在學校學中文。
