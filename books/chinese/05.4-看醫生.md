# 05.4 看醫生

看醫生以前，要先說明自己身體哪裡不舒服，也可以說明哪個部位有問題。這一章要學怎麼問「哪裡不好？」、怎麼回答，以及怎麼說要看醫生。

## 1. 說身體哪裡不好

醫生或朋友可以用下面的問句：

> 你今天哪裡不好？

回答時，可以先說整體情況，也可以說身體的部位。

| 情況 | Mini-Chinese |
|---|---|
| 整個身體不舒服 | 我身體不好。 |
| 頭不舒服 | 我的頭有問題。 |
| 手不舒服 | 我的手有問題。 |
| 腳不舒服 | 我的腳有問題。 |

也可以先問對方，再用完整句子回答。

甲：你今天哪裡不好？  
乙：我身體不好。  
甲：你的頭有問題嗎？  
乙：對，我的頭有問題。

## 2. 說要看醫生

不舒服的時候，可以用「去看醫生」說明自己的安排。

| 意思 | Mini-Chinese |
|---|---|
| 我要去看醫生 | 我去看醫生。 |
| 你要去看醫生嗎 | 你要看醫生嗎？ |
| 現在去看醫生 | 我現在去看醫生。 |
| 你和我一起去 | 你和我一起去。 |

「要」放在動詞前面。「我去看醫生」表示現在去看醫生；「我要去看醫生」表示自己決定要去看醫生。

甲：你哪裡不好？  
乙：我的頭有問題。  
甲：你要看醫生嗎？  
乙：好，我現在去看醫生。

## 3. 看病時的對話

看病時，先說明不舒服的部位。醫生可以請你休息、喝水。

醫生：哪裡不好？  
我：我的頭有問題。  
醫生：你休息一下。  
我：好。

醫生：你要喝水嗎？  
我：好，謝謝。

醫生：你要看醫生嗎？  
我：對，我現在去看醫生。

醫生：你和我一起去。  
我：好，謝謝醫生。

## 練習

- [ ] 1. 用 Mini-Chinese 說：「我的頭有問題。」

> 答案：我的頭有問題。

- [ ] 2. 用 Mini-Chinese 問醫生：「你今天哪裡不好？」

> 答案：你今天哪裡不好？

- [ ] 3. 用 Mini-Chinese 說：「你要看醫生嗎？」

> 答案：你要看醫生嗎？

- [ ] 4. 把「我現在去看醫生。」和「你和我一起去。」合成一段自然的對話。

> 答案：我現在去看醫生。  
> 你和我一起去。
