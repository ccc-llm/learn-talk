# 07.4 檢查工具、網頁翻譯器（看外國文字的工具）與 LLM（用文字回答問題的工具）專家

這一章要學習怎麼用句子工具、網頁翻譯器與 LLM 檢查自己的句子。先看每個字和詞是否正確，再看主詞、動詞、賓語、時間和地點的順序，最後比較工具的建議。工具可以幫忙找問題，但是自己仍要看意思是否自然。

## 1. 句子工具能做什麼？

句子工具可以檢查字詞、句子結構和語法規則。檢查以後，要自己看工具的說法，不要完全照抄。

| 檢查項目 | 工具可以找什麼 | Mini-Chinese 例句 |
|---|---|---|
| 字詞 | 有沒有字表外的字 | 「這個句子對嗎？」 |
| 詞序 | 詞的位置對不對 | 「我用工具看句子。」 |
| 時間 | 時間在動詞前或後 | 「他今天在學校學中文。」 |
| 地點 | 地點用「在」加地方 | 「我在家喝水。」 |
| 否定 | 「不」和「沒」有沒有分對 | 「我不吃肉。」 |
| 比較 | 比較詞的位置對不對 | 「他比我高。」 |
| 所有關係 | 兩個名詞中間有沒有「是」 | 「這是我的書。」 |
| 過去 | 過去的「有」前用「沒」 | 「我昨天沒去。」 |

### 給句子工具的簡單要求

| 目的 | Mini-Chinese 要求 |
|---|---|
| 找錯 | 「請找錯。」 |
| 說原因 | 「請說原因。」 |
| 改句子 | 「請改句子。」 |
| 一次完成 | 「請找錯，說原因，再改句子。」 |

不要只問「對嗎」。要求工具找錯、說原因，再改句子，會得到比較有用的結果。

## 2. 用工具檢查句子的方法

### 第一步：先找字詞問題

逐字看句子，找有沒有字表外的字。

| 原句 | 問題 | 改句 |
|---|---|---|
| 「我很高興。」 | 「興」不在字表內。 | 「我很快樂。」 |
| 「他喝可樂。」 | 「可樂」不在字表內。 | 「他喝水。」 |
| 「我喜歡音樂。」 | 「喜歡」和「樂」可以分開用。 | 「我喜歡樂。」 |

「喜歡樂」的意思比較固定，表示「enjoy music」；如果想說「我很高興」，可以用「我很快樂」。

### 第二步：再看詞的位置

先找主詞、動詞和賓語，再看時間和地點。

| 問題 | 改法 |
|---|---|
| 時間太後面 | 時間放在動詞前 |
| 地點沒有「在」 | 用「在」加地方 |
| 兩個名詞直接相連 | 中間加「是」 |
| 比較詞位置不對 | 用「比」連接兩個名詞 |

| 原句 | 改句 |
|---|---|
| 「我去明天學校。」 | 「我明天去學校。」 |
| 「我在在學校學中文。」 | 「我在學校學中文。」 |
| 「他老師。」 | 「他是老師。」 |
| 「我和你一樣大。」 | 這句正確。 |

### 第三步：問工具原因

工具說「錯」以後，要問它為什麼錯。

| 問題 | Mini-Chinese 問法 |
|---|---|
| 為什麼錯？ | 「請說原因。」 |
| 哪裡錯？ | 「請找錯。」 |
| 怎麼改？ | 「請改句子。」 |
| 兩個句子都可以嗎？ | 「這句和那句都可以嗎？」 |

「請找錯，說原因，再改句子。」是一個完整、簡單的要求。

## 3. 網頁翻譯器怎麼用？

網頁翻譯器可以幫你看意思，也可以把中文翻成另一種語言。它最適合用來理解意思，不適合決定一個句子是否真的自然。

| 用途 | 方法 | 注意 |
|---|---|---|
| 看中文意思 | 把句子放進翻譯器 | 先看意思是否正確 |
| 看外國文字 | 複製外國文字 | 不要直接相信結果 |
| 比較兩個版本 | 翻譯原句和改句 | 看兩個意思是否一樣 |
| 找不懂的字 | 看解釋 | 再用字表和語法規則確認 |

### 使用方法

| 步驟 | Mini-Chinese |
|---|---|
| 1. 準備句子 | 「請給我看句子。」 |
| 2. 放入翻譯器 | 「我不懂哪裡錯。」 |
| 3. 看意思 | 「這個可以回答問題。」 |
| 4. 比較意思 | 「請看這句和那句。」 |
| 5. 問句子工具 | 「請找錯，說原因，再改句子。」 |

例如，先把「我明天去學校。」放入翻譯器，看意思是不是「我明天會到學校」。如果意思沒有問題，再用句子工具看詞的位置。

不要只看翻譯結果。翻譯器有時會把短句翻得不自然，也可能給出字表外的說法。

## 4. 把 LLM 當句子檢查助手

LLM 可以解釋錯，也可以改句子。給它清楚的檢查規則，結果會更好。

### 簡單要求

| 目的 | Mini-Chinese |
|---|---|
| 找錯 | 「請找錯。」 |
| 說原因 | 「請說原因。」 |
| 改句子 | 「請改句子。」 |
| 不改意思 | 「請改句子，不改意思。」 |
| 只用字表 | 「只用字表裡的字。」 |
| 一次完成 | 「請找錯，說原因，再改句子，只用字表裡的字。」 |

### 完整對話

甲：大型文字語言工具可以幫我看句子。

乙：請給我看句子。

甲：請找錯，說原因，再改句子，只用字表裡的字。

乙：句子不對。時間要在動詞前。

甲：請改句子，不改意思。

乙：我明天去學校。

### 自己再做最後確認

LLM 改完以後，還要自己看：

1. 每個字是不是都在字表內。
2. 主詞、動詞和賓語是不是完整。
3. 時間是不是在動詞前。
4. 地點是不是用「在」加地方。
5. 「不」和「沒」是不是用對。
6. 句子的意思是不是自己真正想說的。

| Mini-Chinese 檢查句 |
|---|
| 「每個字都要對。」 |
| 「句子要短。」 |
| 「時間要在動詞前。」 |
| 「地點用『在』加地方。」 |
| 「有沒有錢都用『有』和『沒』。」 |

## 練習

- [ ] 檢查「他明天在學校學中文。」：句子對嗎？

> 答案：對。

- [ ] 要請句子工具找錯並說原因，應該怎麼問？

> 答案：請找錯，說原因。

- [ ] 請改句子：「我去明天學校。」

> 答案：我明天去學校。

- [ ] 請問 LLM 改完句子後，自己還要檢查什麼？

> 答案：每個字都要對。句子要短。時間要在動詞前。
