# 03.3 複合詞與量詞

複合詞是把兩個或更多詞表單位組成一個新詞，例如「學＋生」組成「學生」，「地＋方」組成「地方」。學習複合詞時，先看每個單位的意思，再看合在一起後的意思。學會複合詞以後，也可以和量詞配合，說明東西的數量。

## 1. 兩個單位怎樣組成複合詞

兩個單位組成複合詞以後，通常會有新的意思。學習時可以分成三種：

| 組成方式 | 單位 | 複合詞 | 意思 |
|---|---|---|---|
| 名詞＋名詞 | 學＋生 | 學生 | 在學校學的人 |
| 名詞＋名詞 | 朋＋友 | 朋友 | 關係很好的人 |
| 名詞＋名詞 | 衣＋服 | 衣服 | 穿在身上的東西 |
| 名詞＋名詞 | 電＋影 | 電影 | 用電影機看的故事 |
| 名詞＋名詞 | 地＋方 | 地方 | 所在的位置 |
| 名詞＋名詞 | 工＋作 | 工作 | 要做的事 |
| 名稱＋名詞 | 中＋文 | 中文 | 中國的語言 |
| 名稱＋名詞 | 生＋日 | 生日 | 出生的日期 |

有些複合詞的意思不能只看兩個單位。例如「好看」是「好＋看」，意思是美麗或令人喜歡。

### 複合詞例句

我有一個朋友。

他是一個學生。

這是一個好地方。

這是一個工作。

我學中文。

## 2. 量詞與數量

複合詞前面可以加數字和量詞。量詞要配合被數量的東西使用。

| 量詞 | 使用方法 | 例子 |
|---|---|---|
| 個 | 用於人或一般東西 | 1個學生、2個朋友 |
| 件 | 用於事情或成件的东西 | 1件事、2件衣服 |
| 塊 | 用於錢或成塊的東西 | 1塊錢、2塊肉 |
| 次 | 用於動作發生的次數 | 1次、2次 |
| 歲 | 用於年齡 | 1歲、10歲 |
| 屆 | 用於某一次或某一年的人 | 第1屆 |

數字使用阿拉伯數字。數字、量詞和名詞要放在一起，例如「3次」「2件衣服」「10歲」。

### 數量例句

我有一個朋友。

我有兩件衣服。

我今天看了3次電影。

我今年10歲。

他是第1屆學生。

這是一塊錢。

## 3. 複合詞和量詞一起用

一句完整的話可以由「誰＋做什麼」開始，再加入數字、量詞和複合詞。

| 句子 | 結構 |
|---|---|
| 我有1個朋友。 | 主語＋有＋數量＋複合詞 |
| 我有2件衣服。 | 主語＋有＋數量＋量詞＋複合詞 |
| 他做了3件事。 | 主語＋動作＋數量＋量詞＋複合詞 |
| 我看了3次電影。 | 主語＋動作＋數量＋量詞＋複合詞 |

「看電影」是複合詞加動作；「3次」說明看電影的次數。

### 對話

甲：你有幾個朋友？

乙：我有2個朋友。

甲：他是學生嗎？

乙：他是1個學生。

甲：你今天看了幾次電影？

乙：我今天看了3次電影。

## 4. 練習

- [ ] 用「朋＋友」組成一個複合詞，並寫一個完整句子。

> 答案：朋友。我有1個朋友。

- [ ] 用「電＋影」組成一個複合詞，並用「次」寫一個完整句子。

> 答案：電影。我今天看了3次電影。

- [ ] 寫一句話，用「件」和「衣服」。

> 答案：我有2件衣服。

- [ ] 「學＋生」是什麼複合詞？寫一個完整句子。

> 答案：學生。他是一個學生。

- [ ] 寫一句話，說明一個人10歲。

> 答案：他今年10歲。
