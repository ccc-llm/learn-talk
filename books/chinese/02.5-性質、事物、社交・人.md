# 02.5 性質、事物、社交・人

這一章要學習 3 種常用的中文意思：怎樣說人或東西的性質、怎樣說具體的人或事物，以及怎樣用簡單自然的話和人打招呼、表示感謝、道歉與祝福。學習以後，可以用「很＋性質」描述人或東西，也可以用「是」「有」和名詞組合，並用固定的社交話語和別人往來。

## 性質：人和東西的樣子

中文的性質詞可以直接放在主語後面，作為謂語。常用程度副詞有「很、太、不、真、最」等。

| 程度 | Mini-Chinese | 中文意思 |
|---|---|---|
| 很 | 很熱 | 很熱 |
| 太 | 太忙 | 太忙了 |
| 不 | 不高 | 不高 |
| 真 | 真好 | 真的很好 |
| 最 | 最好 | 最好 |
| 很 | 很快樂 | 很快樂 |

**Mini-Chinese 例句：**

- 他很高。
- 這個孩子很忙。
- 我的老師很好。
- 這個東西很小。
- 這個店很新。
- 今天的天气很热。
- 我家很小。
- 這件事很難。
- 這裡很熱。
- 他很快樂。

性質詞可以直接說明人或東西，不需要用「是」連接：

- 他很高。 ✓
- 他是很高。 ✗

常見的性質詞有：

| 類型 | Mini-Chinese |
|---|---|
| 大小 | 大、小、多、少 |
| 好壞 | 好、壞、優、劣、新、舊 |
| 冷熱 | 冷、熱、暖、涼 |
| 快慢 | 快、慢、早、晚 |
| 乾淨 | 淨、清、潔 |
| 輕重 | 重、輕 |
| 遠近 | 近、遠 |
| 容易與困難 | 易、難、簡、複 |
| 顏色 | 紅、黃、藍、綠、黑、白 |

## 事物：具體的人與東西

「是」可以連接兩個名詞，表示一件事物是另一件事物。「有」表示人或東西有某種東西，也可以表示某個地方存在某種人或東西。

### 用「是」說明事物

**Mini-Chinese 例句：**

- 他是老師。
- 她是朋友。
- 這是我的書。
- 那個孩子是男孩。
- 這是中國話。
- 這個房間是家裡的房間。
- 這是衣服。
- 那個東西是水果。

### 用「有」表示有或存在

**Mini-Chinese 例句：**

- 我有兩個朋友。
- 我有一件新衣服。
- 他有一本中國書。
- 這裡有很多花。
- 家裡有一個孩子。
- 我家有一個書房。
- 他有一個水杯。
- 我有一個新本子。

### 說人和人的關係

表示兩個人一起做一件事，可以用「和」：

- 我和朋友一起吃飯。
- 他和老師一起學中文。
- 我和媽媽一起看電影。
- 你和他一起去。

表示東西在哪裡，可以用「在＋地方」：

- 他在學校。
- 媽媽在家裡。
- 我在房間裡看書。
- 他們在公園裡。
- 書在桌子上。

## 社交・人：和人說話

和人往來時，可以使用簡單、固定的社交話語。這些話語可以直接用在問候、道歉、感謝和祝福的地方。

| 用途 | Mini-Chinese | 中文意思 |
|---|---|---|
| 問候 | 你好 | 你好 |
| 問候 | 早上好 | 早上好 |
| 問候 | 晚安 | 晚安 |
| 回答 | 我很好，你呢？ | 我很好，你呢？ |
| 道歉 | 對不起 | 對不起 |
| 回答 | 沒關係 | 沒關係 |
| 感謝 | 謝謝你 | 謝謝你 |
| 回答 | 不用謝 | 不用謝 |
| 邀請 | 請坐 | 請坐 |
| 邀請 | 請進 | 請進 |
| 歡迎 | 歡迎 | 歡迎 |
| 道別 | 再見 | 再見 |
| 祝福 | 祝你生日快樂 | 祝你生日快樂 |

### 打招呼

> 甲：你好。  
> 乙：你好。你今天怎麼樣？  
> 甲：我很好。你呢？  
> 乙：我也很好。

### 道歉與回答

> 甲：對不起。  
> 乙：沒關係。  
> 甲：謝謝你。  
> 乙：不用謝。

### 邀請與道別

> 甲：請坐。  
> 乙：謝謝。  
> 甲：再見。  
> 乙：再見。

### 送出禮物

- 這是給你的禮物。
- 這禮物給你。
- 謝謝你的禮物。
- 我喜歡這個禮物。

### 生日祝福

- 祝你生日快樂！
- 謝謝你。
- 我也很高興。

## 練習

- [ ] 把「他今天很忙。」翻譯成繁體中文。

> 答案：他今天很忙。

- [ ] 用 Mini-Chinese 寫一個句子，描述一個人很高。

> 答案：他很高。

- [ ] 用 Mini-Chinese 寫一個句子，說明你有一個新朋友。

> 答案：我有一個新朋友。

- [ ] 兩個人見面時，一個人先說「對不起」，另一個人可以怎麼回答？

> 答案：沒關係。

- [ ] 別人送你禮物時，你可以怎麼說？

> 答案：謝謝你。
