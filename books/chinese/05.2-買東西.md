# 05.2 買東西

這一章要學習在商店買東西、詢問商品價格，以及比較價格。Mini-Chinese 不用「價」這個字，可以用「多少錢」問價格，也可以用「很貴」「太貴了」說明價格。

## 買東西的說法

在商店買東西，常用「我要買……」。「要」表示想要，「買」表示購買。

| 中文意思 | Mini-Chinese |
|---|---|
| 我要買衣服。 | 我要買衣服。 |
| 我要買1件衣服。 | 我要買1件衣服。 |
| 我要買茶。 | 我要買茶。 |
| 我要買一些水果。 | 我要買一些水果。 |
| 我要買這個。 | 我要買這個。 |
| 我只要這個。 | 我只要這個。 |
| 我不要這個。 | 我不要這個。 |
| 我喜歡這個。 | 我喜歡這個。 |

### 商店對話

甲：你好，我要買1件衣服。  
乙：好。這件衣服多少錢？  
甲：10塊錢。  
乙：你要2件嗎？  
甲：不用，我要1件。  
乙：好。  

## 問價格和說價格

想知道商品多少錢，可以問：

> 這個多少錢？  
> 這些多少錢？  
> 這件衣服多少錢？

回答價格時，可以說：

> 10塊錢。  
> 這是2塊錢。  
> 那個是20塊錢。

「塊」可以表示錢，也可以表示一塊東西。

| 中文意思 | Mini-Chinese |
|---|---|
| 這個多少錢？ | 這個多少錢？ |
| 這些多少錢？ | 這些多少錢？ |
| 這是10塊錢。 | 這是10塊錢。 |
| 那個是20塊錢。 | 那個是20塊錢。 |
| 我給你10塊錢。 | 我給你10塊錢。 |
| 不用找了。 | 不用找了。 |

### 商店對話

甲：我要買茶。  
乙：好。這是什麼茶？  
甲：這是紅茶。  
乙：這是綠茶。  
甲：我要一些茶。  
乙：這些是5塊錢。  
甲：我給你5塊錢。  
乙：好，不用找了。  

## 說太貴和更換商品

商品太貴時，可以說「太貴了」。如果想問能不能少一點，可以說：

> 可以少一點嗎？

不想要某件商品時，可以說：

> 我不要這個。

### 商店對話

甲：我要買這個。  
乙：這個是30塊錢。  
甲：太貴了，可以少一點嗎？  
乙：20塊錢。  
甲：好，我要這個。  
乙：好。給你。  
甲：謝謝。  

## 練習

- [ ] 1. 在商店買1件衣服。

> 答案：我要買1件衣服。

- [ ] 2. 問一件衣服多少錢。

> 答案：這件衣服多少錢？

- [ ] 3. 說商品太貴了，再問能不能少一點。

> 答案：太貴了，可以少一點嗎？

- [ ] 4. 買一些水果。

> 答案：我要買一些水果。

- [ ] 5. 付10塊錢，然後不用找錢。

> 答案：我給你10塊錢。不用找了。
