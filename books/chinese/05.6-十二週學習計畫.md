# 05.6 十二週學習計畫

## 05.6 12週學中文

這12週，每週學新詞和語句。最後可以說很多話，也可以用中文和朋友說話。

## 學的東西

| 週次 | 學的東西 | 要學的話 |
|---|---|---|
| 第1週 | 我、你、他、你好、名字 | 我是學生。你叫什麼名字？ |
| 第2週 | 爸、媽、哥、姐、弟、妹 | 他是我姐姐。他是我弟弟。 |
| 第3週 | 一、兩、幾、個、塊、錢 | 我有2個哥哥。我要10塊。 |
| 第4週 | 今天、明天、昨天、早、晚、午 | 今天我很忙。明天見。 |
| 第5週 | 家、房間、學校、店、裡、前邊、後邊 | 我家在校校前邊。書在這裡。 |
| 第6週 | 飯、菜、肉、茶、水、吃、喝 | 我吃飯。我喝茶。 |
| 第7週 | 來、去、走、看、聽、說、學 | 我要回家。我和他一起走。 |
| 第8週 | 好、大、小、多、少、高、低、新、老 | 這本書很新。這間房間很大。 |
| 第9週 | 手、書、紙、刀、車、門、機 | 我要看書。這是刀。 |
| 第10週 | 老師、學生、工作、教、學校 | 你是老師嗎？我在學校工作。 |
| 第11週 | 旅行、坐車、住、看 | 你要去哪裡？我和你一起去。 |
| 第12週 | 前面學的詞和句子 | 我會說一點中文。我會看書和寫字。 |

## 每週的話

### 第1週

甲：你好！  
乙：你好！  
甲：你是學生嗎？  
乙：是。你叫什麼名字？  
甲：我叫小明。你呢？  
乙：我叫小紅。

### 第2週

甲：他是你哥哥嗎？  
乙：不是，他是我弟弟。  
甲：這是你姐姐嗎？  
乙：是。她是我姐姐。

### 第3週

甲：你有幾個哥哥？  
乙：我有2個哥哥。  
甲：你要多少錢？  
乙：我要10塊。  
甲：你要1個嗎？  
乙：要，謝謝。

### 第4週

甲：現在幾點？  
乙：現在3點。  
甲：今天你有空嗎？  
乙：今天沒空，明天有空。  
甲：好，明天見。  
乙：明天見。

### 第5週

甲：你家在哪裡？  
乙：我在學校前邊。  
甲：學校在山旁邊嗎？  
乙：對。學校在山旁邊。  
甲：你的書在裡面嗎？  
乙：不在。我的書在這裡。

### 第6週

甲：你要吃飯嗎？  
乙：要。你要喝茶嗎？  
甲：我不喝茶，我要吃飯。  
乙：好。

### 第7週

甲：你要去哪裡？  
乙：我要回家。  
甲：我也回家。  
乙：一起走。  
甲：好。

### 第8週

甲：這本書好嗎？  
乙：很好。這本書很新。  
甲：這間房間大嗎？  
乙：很大，也很乾淨。  
甲：這張桌子——

### 第8週（續）

甲：這張——  
乙：什麼？  
甲：沒事。

### 第9週

甲：你要用什麼？  
乙：我要用刀。  
甲：你要看書嗎？  
乙：要。  
甲：我也有書。  
乙：很好。

### 第10週

甲：你是老師嗎？  
乙：是。我在學校教中文。  
甲：你喜歡教書嗎？  
乙：喜歡。  
甲：我喜歡學中文。  
乙：我們一起學。

### 第11週

甲：你要坐車去哪裡？  
乙：我要去河邊。  
甲：我和你一起去。  
乙：好。  
甲：你去過那裡嗎？  
乙：去過。  
甲：我也去過。

### 第12週

甲：你好！你會說中文嗎？  
乙：會一點。  
甲：你會做飯嗎？  
乙：會。你會吃什麼？  
甲：我吃飯和菜。  
乙：我喝茶。  
甲：我們一起吃飯吧。  
乙：好！

## 學的方法

| 規則 | 說明 | 例子 |
|---|---|---|
| 1 | 人 + 動詞 + 東西 | 我吃飯。他看書。 |
| 2 | 時間在動詞前面 | 我明天去。今天我在家。 |
| 3 | 用「在」說地方 | 我在學校學中文。 |
| 4 | 用「是」連兩個名詞 | 他是老師。這是我的書。 |
| 5 | 用「有」說有什麼 | 我有2個朋友。這裡有很多人。 |
| 6 | 沒有用「沒」 | 我沒有錢。我昨天沒去。 |
| 7 | 性質放在動詞或名詞前面 | 他很高。這是一本新書。 |
| 8 | 用「的」連修飾語和名詞 | 我的朋友很好看。 |
| 9 | 數字 + 量詞 + 名詞 | 1個哥哥。2塊錢。3點。 |
| 10 | 問句可以用「嗎」 | 你是學生嗎？ |
| 11 | 問句可以用「什麼」 | 你叫什麼名字？ |
| 12 | 問句可以用「哪裡」 | 你家在哪裡？ |
| 13 | 能願動詞放在動詞前面 | 我能說中文。他會唱歌。 |
| 14 | 比較用「比」 | 他比我高。這個比那個更貴。 |
| 15 | 用「得」說動作的樣子 | 你說得很好。他走得很慢。 |
| 16 | 介詞片語放在動詞前面 | 我和朋友一起吃飯。他從中國來。 |

## 重要的話

- 你好。
- 謝謝。
- 對不起。
- 沒事。
- 請進來。
- 請坐。
- 再見。
- 不用謝。
- 我明白。
- 你會說中文嗎？
- 你叫什麼名字？
- 你家在哪裡？
- 你要喝茶還是喝水？
- 我很好，你呢？

## 學的問題

- [ ] 用「你好」和「什麼名字」說2句話。

> 答案：你好！你叫什麼名字？

- [ ] 用「他」說1句話。

> 答案：他是我哥哥。

- [ ] 用數字和量詞說1句話。

> 答案：我有2個哥哥。

- [ ] 用「在」和一個地方說1句話。

> 答案：我在學校學中文。

- [ ] 用「比」說1句話。

> 答案：他比我高。
