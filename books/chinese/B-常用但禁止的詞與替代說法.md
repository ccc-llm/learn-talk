# B 常用但禁止的詞與替代說法

本章學習幾個常用但不在 Mini-Chinese 詞表內的詞。學習者要記住替代說法，用詞表內的字組成自然句子。

## 1. 時間、程度與頻率

有些常用副詞不在詞表內。要用簡單的字表達意思，不增加新字。

| 禁止的說法 | 替代說法 | Mini-Chinese 例句 |
|---|---|---|
| 已經 | ……了、先……了 | 我吃完了飯。 |
| 剛才 | 一點時間以前 | 一點時間以前，他在這裡。 |
| 常常 | 天天、每次都 | 他每天都在這裡。 |
| 總是 | 每次都 | 他每次都.help。 |
| 突然 | 一下子 | 一下子下了雨。 |
| 終於 | 到最後 | 到最後，他來了。 |
| 非常 | 很 | 今天很熱。 |
| 大約 | 左右 | 他 30 歲左右。 |
| 幾乎 | 快……了 | 快 9 點了。 |

時間詞放在動詞前面。「已經」常用「……了」代替；「剛才」可以用「一點時間以前」代替。

## 2. 條件、轉折與選擇

中文常用的連接詞有些不在詞表內。每種關係只使用一種固定的說法。

| 禁止的說法 | 替代說法 | Mini-Chinese 例句 |
|---|---|---|
| 如果……就 | 要是……就 | 要是你來，就打電話給我。 |
| 即使……也 | 就是……也 | 就是你來了，他也會來。 |
| 但是 | 可是、是……，可是 | 今天很熱，可是我不去。 |
| 雖然……但是 | 是……，可是 | 他很高，是他不喜歡這裡。 |
| 而且 | 也、還、不只 | 他會說中文，也會說英文。 |
| 不但 | 不只 | 他不只會說中文，還會說英文。 |
| 無論 | 誰都、什麼都 | 誰都會做這件事。 |
| 除了 | ……以外 | 中文以外，他還學英文。 |
| 否則 | 要不 | 你不喜歡這個，要不換一個。 |
| 或者 | 還是（問句）、……也可以（說明句） | 你喝茶還是喝水？ |

問句可以使用「還是」。說明句要表示另一個選擇時，可以使用「……也可以」。

## 3. 動作關係與常用動詞

表外動詞不能用直接的方式表達，要用詞表內的動詞和固定結構。

| 禁止的說法 | 替代說法 | Mini-Chinese 例句 |
|---|---|---|
| 把 | 拿……V、先說東西 | 我拿書回家。 |
| 被 | 是……的、給、有人 | 這件事是媽媽做了。 |
| 讓 | 叫、給 | 媽媽叫我回家。 |
| 使 | 叫、給 | 哥哥叫我一起走。 |
| 變成 | 做了、……起來了 | 他做了老師。 |
| 著 | 在、V 在那裡 | 他在家裡。 |
| 繼續 | V 下去、不再 V 了 | 他走下去。 |
| 停止 | 不再 V 了 | 他不再走了。 |
| 越來越 | 一天比一天 | 他一天比一天高。 |
| 跟 | 和 | 我和他一起吃飯。 |

不要使用「把」和「被」。要說明動作的對象時，可以先說東西，再說動作。要表示某人受到動作時，可以使用「是……的」或「有人」。

## 4. 否定與比較

否定和比較可以使用固定句型。「不」和「沒」不能隨意交換。

| 意思 | Mini-Chinese 例句 | 說明 |
|---|---|---|
| 現在或將來不做 | 我現在不吃飯。 | 現在用「不」。 |
| 過去沒有做 | 我昨天沒吃飯。 | 過去用「沒」。 |
| 沒有某樣東西 | 我沒有手機。 | 「有」的否定是「沒有」。 |
| 比較高低 | 他比我高。 | 用「比」。 |
| 比較性質 | 這個比那個更貴。 | 用「比」和「更」。 |
| 相同 | 我和你一樣大。 | 用「一樣」。 |
| 最高程度 | 他是最好的老師。 | 用「最」。 |
