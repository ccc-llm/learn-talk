# 08.1 與既有方案的對照

## 08.1 與既有方案的對照

### 否定方式

Basic English（外國語）和 Toki Pona（外國語）的否定方式不一樣。Mini-Chinese（簡易中文）用不同的詞表示否定。

| 用法 | Mini-Chinese 句子 |
|---|---|
| 現在或將來不做某事 | 我不看書。 |
| 以前沒有做某事 | 我昨天沒看書。 |
| 沒有某物 | 我沒有書。 |
| 否定性質 | 這本書不好。 |
| 否定「有」 | 這裡沒有人。 |
| 不再做某事 | 我不看書了。 |

### 否定詞的用法

| 用法 | Mini-Chinese 句子 |
|---|---|
| 「不」放在動詞前面 | 他不來。 |
| 「不」放在性質前面 | 他不高。 |
| 「沒」放在動詞前面 | 他昨天沒來。 |
| 「沒」放在「有」前面 | 他沒有車。 |
| 「不」和「沒」都用來回答問題 | 你看書嗎？不，我沒看。 |
| 「不」和「沒」都可以放在「是」前面 | 這不是我的。 |

### 現在與將來

現在不動作，用「不 + 動詞」。

我明天不去。

現在不具有某物，用「沒有」。

我沒有錢。

將來不動作，也用「不 + 動詞」。

他明年不來。

將來不具有某物，也用「沒有」。

他不會有車。

### 過去

以前沒有做某事，用「沒 + 動詞」。

我昨天沒吃飯。

以前沒有某物，用「沒有」。

我以前沒有工作。

### 性質

否定性質，用「不 + 性質」。

這房間不乾淨。

這房間不新。

這本書不貴。

### 存在

某地方有或沒有人，用「有」或「沒有」。

這裡有很多人。

這裡沒有人。

屋裡有書。

屋裡沒有書。

### 動作不再繼續

動作不再繼續，用「不再 + 動詞 + 了」。

他不再說話了。

我不再看書了。

她不再哭了。

### 問句

問一個人做不做某事，用「嗎」。

你明天來嗎？

我今天工作嗎？

問一個人有沒有某物，用「嗎」和「有」或「沒有」。

你有車嗎？

你沒有書嗎？

問一個人要不要做某事，用「嗎」和「要」。

你要喝水嗎？

問一個人會不會做某事，用「嗎」和「會」。

你會說中文嗎？

問一個人做不做某事，也可以用「還是」。

你看書還是寫字？

你喝茶還是喝水？

### 回答

肯定回答，可以重複問題中的主要詞。

你明天來嗎？

對，我明天來。

否定回答，可以用「不」或「沒有」。

你明天來嗎？

不，我明天不來。

你有書嗎？

沒有。

### 基本規則

| 意思 | Mini-Chinese 句子 |
|---|---|
| 現在不做某事 | 我不看書。 |
| 將來不做某事 | 我明天不看書。 |
| 以前沒有做某事 | 我昨天沒看書。 |
| 現在沒有某物 | 我沒有書。 |
| 性質不好 | 這本書不好。 |
| 不再做某事 | 我不看書了。 |

「不」和「沒有」不能隨意交換。

| 句子 | 意思 |
|---|---|
| 我不吃肉。 | 我現在或將來不吃肉。 |
| 我昨天沒吃肉。 | 我以前沒有吃肉。 |
| 我沒有肉。 | 我現在手裡沒有肉。 |
| 我不吃肉了。 | 我以後不再吃肉。 |
