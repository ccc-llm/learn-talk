# 03.1 形態：免費的變化

這一章要學習 3 種中文形態變化：**屈折、派生、活用**。有些變化可以由已學的字詞直接組合，不需要另外記；有些變化會改變意思或用法，就要另外學習。

## 1. 屈折：加一個字，意思改變

屈折是在詞尾加字。Mini-Chinese 裡常用的屈折字是「了、們、的」。

| 原形 | 變化 | 作用 | Mini-Chinese |
|---|---|---|---|
| 我 | 我們 | 表示多個人 | 我們學中文。 |
| 吃 | 吃了 | 表示動作完成 | 我吃飯了。 |
| 我的 | 我的書 | 表示歸屬 | 這是我的書。 |

### 「了」

「了」可以放在動詞後面，表示動作完成。

| 形式 | Mini-Chinese |
|---|---|
| 動詞 + 了 | 我吃飯了。 |
| 動詞 + 了 + 賓語 | 我吃完了飯。 |
| 放在句末 | 老師來了。 |

「了」也可以放在句子最後，表示事情有了變化。

- 天冷了。
- 他回來了。

這些句子都用詞表內的字，因此不用另外學新詞。但是，要另外學「了」放在哪個位置，以及它表示什麼。

### 「們」和「的」

| 變化 | 說明 | Mini-Chinese |
|---|---|---|
| 人稱詞 + 們 | 表示多個人 | 他們在學校。 |
| 名詞 + 的 + 名詞 | 前面的名詞說明後面的名詞 | 這是我的中文書。 |

單字性質修飾名詞時，「的」可以省略。

| 有「的」 | 沒有「的」 |
|---|---|
| 這是新的書。 | 這是新書。 |
| 他是認真的人。 | 他是認真人。 |

「的」可以省略，是 Mini-Chinese 的免費變化。但是，它也可以用在句末。

- 這是我的。
- 他的書很好。

所以，「的」放在兩個名詞之間時可以省略，放在句末時不可以省略。

## 2. 派生：用兩個字形成新詞

派生是使用已知字組成一個新詞。新詞可以容易猜出意思，但有些要另外學習完整用法。

| 組成 | 新詞 | 意思 | Mini-Chinese |
|---|---|---|---|
| 老 + 師 | 老師 | 教人學習的人 | 老師教我們中文。 |
| 學 + 生 | 學生 | 學習的人 | 學生在學校。 |
| 中 + 文 | 中文 | 中國的語言文字 | 我學中文。 |
| 書 + 店 | 書店 | 賣書的店 | 這是書店。 |
| 工 + 作 | 工作 | 做事 | 他今天工作。 |
| 雨 + 水 | 雨水 | 下的雨 | 雨水很多。 |
| 看 + 見 | 看見 | 用眼睛看到 | 他看見朋友。 |

有些派生詞可以直接從兩個部分的意思推想。

- 「書」＋「店」＝賣書的店。
- 「看」＋「見」＝用眼睛看到。

有些派生詞不能只看字面。

- 「學」＋「生」是「學生」，不是「學生的東西」。
- 「工」＋「作」是「工作」，不是兩個詞分開使用。

這些組合要另外學習。它們不用另外記每個字，但是要記住整個詞的意思和用法。

| 類型 | 要不要另外學 |
|---|---|
| 「書店」這類意思容易推想的組合 | 知道兩個字，就可以猜出大概意思 |
| 「學生」「工作」這類固定組合 | 要另外學整個詞的意思 |
| 同一個字放在不同詞裡 | 要分別學習每個詞 |

## 3. 活用：同一個字，放在不同位置，做不同的事

活用是改變字在句子裡的工作。例如，同一個字有時是動作，有時是名稱，有時是性質。字沒有變，位置和搭配改變了。

| 類型 | Mini-Chinese | 說明 |
|---|---|---|
| 名詞 | 他在吃飯。 | 「飯」是動作的對象 |
| 動作 | 他吃飯。 | 「吃」表示做什麼 |
| 性質 | 這飯很熱。 | 「熱」說明飯的狀態 |
| 位置 | 他在家吃飯。 | 「在家」說明動作在哪裡 |
| 時間 | 他今天吃飯。 | 「今天」說明動作什麼時候 |
| 動作狀態 | 他吃完了飯。 | 「了」說明動作完成 |

### 「在」的活用

「在」放在地名或家裡的詞前面，表示地點。

- 我在家。
- 他在學校。
- 她們在東邊。

這裡用「她們」不行。Mini-Chinese 不用「她」，要說「他們」。

| 正確 | 不正確 |
|---|---|
| 他們在東邊。 | 她們在東邊。 |

「在」也可以放在動作前面，表示動作正在進行。

- 我在學中文。
- 他在吃飯。
- 她在寫字。

這裡的「她」也要改成「他」。

| 正確 | 不正確 |
|---|---|
| 他在寫字。 | 她在寫字。 |

「在」的兩種用法都要學會：放在地方前面，表示地點；放在動作前面，表示正在做。

### 「得」和「的」

「得」放在動作後面，說明動作做得怎麼樣。

| 形式 | Mini-Chinese |
|---|---|
| 動作 + 得 + 性質 | 他走得很快。 |
| 動作 + 得 + 性質 | 你說得很好。 |

「的」放在名詞前，表示歸屬或說明。

| 形式 | Mini-Chinese |
|---|---|
| 名詞 + 的 + 名詞 | 這是我的書。 |
| 名詞 + 的 | 這本書是我的。 |

這兩個字看起來很像，但是意思和位置不同。「得」要另外學；「的」可以放在兩個名詞之間，但放在句末時不可以省略。

## 4. 怎麼判斷要學到什麼程度

| 變化 | 例子 | 要另外學的內容 |
|---|---|---|
| 屈折 | 吃＋了、吃完了 | 「了」的位置和意思 |
| 屈折 | 我＋們、他們 | 「們」表示多個人 |
| 屈折 | 我的書 | 「的」連接兩個名詞 |
| 派生 | 老＋師＝老師 | 整個詞的意思 |
| 派生 | 學＋生＝學生 | 整個詞的意思和用法 |
| 派生 | 看＋見＝看見 | 整個詞的意思 |
| 活用 | 吃飯、在家、在吃飯 | 字的詞性、位置和搭配 |
| 活用 | 走得很快、我的書 | 「得」和「的」的不同用法 |

簡單來說：

- **加字以後，意思可以直接推想**：通常不用另外記新詞。
- **加字以後，形成固定的新意思**：要記住整個詞。
- **同一個字換了工作或位置**：要學它在句子裡的用法。
- **只加「了、們、的」**：字可以重複使用，但要學清楚它們的位置。
