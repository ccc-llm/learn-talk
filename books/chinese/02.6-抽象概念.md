# 02.6 抽象概念

抽象概念不容易直接看到，但可以用「想法、意思、時間、人、關係、工作、環境」等詞和句型表達。本章要學習怎麼說明一個人在想什麼、兩個人有什麼關係、事情在什麼時候發生，以及一個人和群體的關係。

## 想法和意思

「想法」是心裡的想法，「意思」是話語或事情的意思。這類詞常和「想、知道、懂、覺得」一起使用。

| Mini-Chinese | 中文意思 |
|---|---|
| 我有一個想法。 | 我心裡有一個想法。 |
| 這個想法很好。 | 這個想法不錯。 |
| 我知道你的意思。 | 我明白你想說什麼。 |
| 你懂我的意思嗎？ | 你明白我的意思嗎？ |
| 我不知道他在想什麼。 | 我不知道他心裡在想什麼。 |
| 我覺得這件事很難。 | 我覺得這件事不容易。 |

疑問句可以使用「嗎」。否定想法時，用「不知道」或「不」；否定「知道」也可以說「不知道」。

## 人和關係

人和人之間可以用「朋友、家人、師生、工作、幫助、愛」等關係來表達。最簡單的方法是說明兩個人一起做什麼，或其中一個人對另一個人怎樣。

| Mini-Chinese | 中文意思 |
|---|---|
| 他是我的朋友。 | 他是我的朋友。 |
| 我和他一起工作。 | 我和他一起做事。 |
| 他對我很好。 | 他對我很好。 |
| 我愛他。 | 我很愛他。 |
| 他比我高。 | 他比我高。 |
| 我和他一樣高。 | 我和他同樣高。 |
| 大家都是朋友。 | 大家都是朋友。 |

「一起」表示兩個人或一群人一起做事情。「比」可以比較兩個人或兩樣東西。「一樣」表示相同。

## 時間和先後

時間可以放在主語後面、動詞前面。要說明事情在什麼時候發生，也可以使用「現在、以前、每天、昨天、明天、現在、已經」等詞。

| Mini-Chinese | 中文意思 |
|---|---|
| 現在是3點。 | 現在是3點鐘。 |
| 今天下午5點半。 | 今天下午5點半。 |
| 我明天去。 | 我明天會去。 |
| 我昨天沒有去。 | 我昨天沒有去。 |
| 我每天早上7點起床。 | 我每天早上7點起床。 |
| 我以前在中國學中文。 | 我以前在中國學中文。 |
| 我等1點再來。 | 我等到1點再來。 |
| 時間到了。 | 時間到了。 |

「過」可以表示事情在過去發生。例如，「我昨天去過中國」表示去中國是以前發生的事。「了」可以放在動詞後面，表示事情已經完成。

## 群體和社會

「社會」包含很多人和不同的工作。可以用「人、大家、老師、醫生、工人、外國人、中國人、工作」等詞來說明。表外的人可以用「做什麼工作的人」來描述。

| Mini-Chinese | 中文意思 |
|---|---|
| 這裡有很多人。 | 這個地方有很多人。 |
| 每個人都有工作。 | 每一個人都有工作。 |
| 老師教學生。 | 老師教學生。 |
| 醫生看病人。 | 醫生給病人看病。 |
| 他是外國人。 | 他來自外國。 |
| 他是中國人。 | 他來自中國。 |
| 他在國外工作。 | 他在外國工作。 |
| 我想住在這裡。 | 我想住在这个地方。 |
| 大家都要休息。 | 每個人都需要休息。 |

「要」可以表示將來要做的動作。「在這裡」由「在」和「這裡」組成，用來說明事情在哪裡發生。

- [ ] 用「想法」和「好」寫一句話。

> 答案：這個想法很好。

- [ ] 用「他」「我」和「一起」寫一句話。

> 答案：他和我一起工作。

- [ ] 用「現在」和「3點」寫一句話。

> 答案：現在是3點。

- [ ] 用「每個人」和「工作」寫一句話。

> 答案：每個人都有工作。

- [ ] 用「老師」和「學生」寫一句話。

> 答案：老師教學生。
