# 02.4 自然・天氣與動作

本章學習常見的自然事物、天氣說法和日常動詞。學會這些詞後，可以描述天氣、動植物和人的動作，也可以問答別人在哪裡、正在做什麼。

## 天氣與自然

中文可以用「今天有……」和「天很……」說明天氣。自然界的東西可以用「是」和顏色連接，也可以用「在＋地方」說明位置。

| Mini-Chinese | 中文意思 |
|---|---|
| 今天有雨。 | 今天下雨。 |
| 天很熱。 | 今天很熱。 |
| 天上有白雲。 | 天空中有白雲。 |
| 風從北邊來。 | 風從北方吹來。 |
| 河水很清。 | 河水很清澈。 |
| 樹很大。 | 樹很高大。 |
| 花是紅色。 | 這朵花是紅色的。 |
| 草是綠色。 | 草是綠色的。 |

### 常用天氣詞

| 詞 | 意思 | Mini-Chinese |
|---|---|---|
| 雨 | 雨 | 今天有雨。 |
| 雪 | 雪 | 昨天有雪。 |
| 雲 | 雲 | 天上有白雲。 |
| 風 | 風 | 風很大。 |
| 天 | 天空；天氣 | 天很冷。 |
| 日 | 太陽；日子 | 日很熱。 |

### 對話

甲：今天有雨嗎？  
乙：有。今天很熱。  
甲：現在做什麼？  
乙：我在家裡看書。

## 動植物與自然的位置

描述動植物時，可以使用「在＋地方」或「從＋地方＋來」。位置詞可以放在動詞前面。

| Mini-Chinese | 中文意思 |
|---|---|
| 鳥在樹上飛。 | 鳥在樹上飛。 |
| 魚在水裡。 | 魚在水裡。 |
| 牛在草地。 | 牛在草地上。 |
| 蟲在花旁邊。 | 蟲子在花旁邊。 |
| 河邊有花。 | 河邊有花。 |
| 太陽從東邊來。 | 太陽從東方升起。 |

## 常用動詞

最常用的句型是「主語＋動詞＋賓語」。時間和地點放在動詞前面。

| 動詞 | 意思 | Mini-Chinese |
|---|---|---|
| 看 | 看；閱讀 | 他看書。 |
| 聽 | 聽 | 我聽歌。 |
| 說 | 說 | 她說話。 |
| 吃 | 吃 | 我吃飯。 |
| 喝 | 喝 | 他喝水。 |
| 走 | 走 | 我走路。 |
| 來 | 來 | 朋友來了。 |
| 去 | 去 | 我去學校。 |
| 做 | 做 | 媽媽做菜。 |
| 買 | 買 | 我買水果。 |
| 學 | 學 | 我學中文。 |
| 玩 | 玩 | 孩子玩球。 |
| 飛 | 飛 | 鳥在樹上飛。 |
| 洗 | 洗 | 我洗手。 |

## 問動作與地點

詢問某人正在做什麼，可以用「做什麼」；詢問地點，可以用「在哪裡」。回答時，常用「在＋地方＋動詞」。

| Mini-Chinese | 中文意思 |
|---|---|
| 你在做什麼？ | 你正在做什麼？ |
| 我在裡面看書。 | 我正在裡面看書。 |
| 他在哪裡？ | 他在哪裡？ |
| 他在學校。 | 他在學校裡。 |
| 我們在公園。 | 我們在公園裡。 |

> 說明：自然界的名詞和常用動詞可以組合。問動作時用「做什麼」，問地點時用「在哪裡」。

### 對話

甲：你在做什麼？  
乙：我在看書。  
甲：你的朋友在哪裡？  
乙：他在外面。  
甲：今天有雨嗎？  
乙：沒有。天很熱。
