# A 完整詞表

本章要學 Mini-Chinese 的全部 449 個核心單位。這些單位分成 9 類：代詞・指示、語法、數量、時間、方位、動作、性質、事物、社交。學會全部單位後，可以用固定句型組合出更多中文句子。

## 1. 九類單位

Mini-Chinese 的單位可以依功能分類。同類的單位放在一起，更容易學習和記憶。

| 類別 | 作用 | 單位數 |
|---|---|---:|
| 代詞・指示 | 指出人或事物 | 15 |
| 語法 | 組成句子、表達關係 | 45 |
| 數量 | 表示數字、次數、年齡等 | 18 |
| 時間 | 表示日期、時刻和時候 | 19 |
| 方位 | 表示位置和方向 | 19 |
| 動作 | 表示人的行為 | 105 |
| 性質 | 表示事物的特徵 | 59 |
| 事物 | 表示人、物、地點等 | 157 |
| 社交 | 表示問候、邀請和慶祝 | 12 |
| **合計** | 全部核心單位 | **449** |

## 3. 用完整詞表說句子

全部單位可以依固定規則組合。主語通常放在最前面，接著放時間或地點，再放動詞和賓語。

| 句子結構 | Mini-Chinese 例子 |
|---|---|
| 主語＋動詞＋賓語 | 我吃飯。 |
| 主語＋時間＋動詞＋賓語 | 我明天去中國。 |
| 主語＋地點＋動詞＋賓語 | 我在學校學中文。 |
| 主語＋是＋名詞 | 他是老師。 |
| 主語＋有＋數量＋名詞 | 她有兩本書。 |
| 主語＋很＋性質 | 他很高。 |
| 主題＋比較＋對象 | 他比我高。 |
| 動詞＋得＋性質 | 她說得很好。 |

### 完整對話

甲：你好！你是學生嗎？  
乙：是。我在學校學中文。  
甲：你叫什麼名字？  
乙：我叫小明。你呢？  
甲：我也叫小明。我明天也去學校。  
乙：好。我們一起學中文吧。
