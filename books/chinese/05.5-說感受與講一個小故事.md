# 05.5 說感受與講一個小故事

這一章要學怎麼說出自己的感受，也學怎麼用對話講一件發生的事。你會用「快樂、開心、難過、生氣、怕」表達心情，再用「昨天、今天、在、沒、有、了」說出一個小故事。

## 1. 說出自己的感受

說感受時，可以用「很」或「有點」放在感受前面。「很」表示程度很強；「有點」表示一點兒。

| 感受 | Mini-Chinese 例句 |
|---|---|
| 快樂 | 我很快樂。 |
| 開心 | 我很開心。 |
| 難過 | 我有點難過。 |
| 生氣 | 我有點生氣。 |
| 害怕 | 我有點怕。 |
| 喜歡 | 我喜歡喝茶。 |

也可以用「因為」說明原因：

| 原因 | Mini-Chinese 例句 |
|---|---|
| 開心的原因 | 因為我今天看到了花。 |
| 喜歡的原因 | 我喜歡這首歌。 |
| 難過的原因 | 因為他今天沒有來。 |
| 生氣的原因 | 因為他做錯了事。 |

問對方感受時，可以在句尾加「嗎」：

> 你今天開心嗎？  
> 我有點累。

這裡也可以說：

> 我有點難過。

### 對話：說感受

甲：你今天開心嗎？  
乙：是的，我很開心。  
甲：為什麼？  
乙：因為我今天看到了花。  
甲：我也很快樂。

## 2. 講一件發生的事

講事情時，先說時間，再說地點和動作。常見的句型是：

**時間＋在＋地方＋動作。**

| 說明 | Mini-Chinese 例句 |
|---|---|
| 昨天在家看書 | 我昨天在家看書。 |
| 今天早上吃飯 | 我今天早上吃飯。 |
| 昨天晚上睡覺 | 我昨天晚上睡覺。 |
| 今天下午做功課 | 我今天下午做功課。 |

「了」可以表示事情已經發生：

| 說明 | Mini-Chinese 例句 |
|---|---|
| 昨天下雨 | 昨天下雨了。 |
| 他來了 | 他昨天來了。 |
| 我買了水果 | 我昨天買了水果。 |
| 我很高興 | 我昨天看到朋友了，我很高興。 |

否定過去的事情時，用「沒」：

| 說明 | Mini-Chinese 例句 |
|---|---|
| 沒有出門 | 我昨天沒出門。 |
| 沒有去 | 我昨天沒去。 |
| 沒有看書 | 他昨天沒看書。 |
| 沒有來 | 她昨天沒來。 |

## 3. 用對話講一個小故事

一個小故事可以分成幾步：

1. 說時間。
2. 說人在哪裡。
3. 說做什麼。
4. 說事情怎麼樣。
5. 說自己的感受。

### 對話：昨天發生的事

甲：你昨天做什麼？  
乙：我昨天在家看書。  
甲：昨天有什麼事？  
乙：昨天下雨了，我沒出門。  
甲：今天有什麼好事？  
乙：我看到朋友了，我很高興。  
甲：我也很快樂。

另一個小故事：

甲：你好嗎？  
乙：我很好。你呢？  
甲：我今天有點累。  
乙：為什麼？  
甲：我昨天做了一件很難的事。  
乙：休息一下就好了。

「做了一件很難的事」表示完成了一件困難的事情。「休息一下就好了」表示休息一會兒就會好轉。

## 4. 說故事的固定方法

可以用下面的方法，把感受和事件連在一起：

| 功能 | Mini-Chinese 例句 |
|---|---|
| 先說事件 | 昨天下雨了。 |
| 再說反應 | 我昨天沒出門。 |
| 最後說感受 | 我有點難過。 |

也可以先說感受，再說原因：

| 功能 | Mini-Chinese 例句 |
|---|---|
| 先說感受 | 我很高興。 |
| 再說事件 | 他昨天幫我買了水果。 |
| 補充事件 | 我昨天吃了水果。 |

## 練習

- [ ] 把「我很快樂」寫成一個完整的句子。

> 答案：我今天很快樂。

- [ ] 用「有點」說明你現在的感受。

> 答案：我有點開心。

- [ ] 把「下雨了，我沒有出門」寫成 Mini-Chinese。

> 答案：昨天下雨了，我沒出門。

- [ ] 用「因為」回答：為什麼開心？

> 答案：因為我今天看到了花。

- [ ] 用對話講一件昨天發生的事。

> 答案：  
> 甲：你昨天做什麼？  
> 乙：我昨天在家看書。  
> 甲：今天有什麼好事？  
> 乙：我看到朋友了，我很高興。
