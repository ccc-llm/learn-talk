# 06.5 改寫流程：七步

本章要學習把一般文章改寫成受限語言。改寫時，先找文章的意思，再找可用的詞，調整句子結構，最後逐句檢查。這個流程可以避免文章太長、詞太難或句型超出範圍。

## 學習目標

完成本章後，你會知道如何使用以下七個步驟：

1. 找文章的主題和目的。
2. 找出必須保留的意思。
3. 找出句子之間的關係。
4. 把表外的概念換成可用的詞。
5. 使用固定句型重新寫句子。
6. 檢查所有用字和結構。
7. 比較原文和新文，修改不自然的地方。

## 改寫的七個步驟

| 步驟 | 要做的事 | 檢查問題 | Mini-Chinese 例句 |
|---|---|---|---|
| 1. 找主題 | 先知道文章要說什麼。 | 這篇文章想讓人知道什麼？ | 我現在在學校學中文。 |
| 2. 找重要意思 | 找出不能刪掉的人、時間、地点和動作。 | 誰做什麼？什麼時候？什麼地方？ | 我週日下午要去市場買水果和綠茶。 |
| 3. 找關係 | 分出說明、原因、選擇、順利和對比。 | 句子怎麼連在一起？ | 他是學生，我是老師。 |
| 4. 換概念 | 把不能說的概念換成詞表內的詞。 | 這個詞能用別的說法嗎？ | 這家店有紅茶和綠茶。 |
| 5. 重寫句子 | 用「主語＋動詞＋賓語」等固定句型。 | 句子能不能直接讀懂？ | 晚上我回家看書。 |
| 6. 逐字檢查 | 檢查字詞、否定、時間、地點和問句。 | 有沒有用到表外的字？ | 今天很熱。 |
| 7. 比較修改 | 對照原文和新文，修正意思或語氣。 | 新文有沒有漏掉重要意思？ | 他是我的老朋友。 |

### 1. 先找主題

開始改寫以前，先用一句話說明文章的主题：

- 文章在介紹什麼？
- 讀者需要做什麼？
- 文章要表達什麼結果？

例如，一般文章要介紹一個人週末的行程：

> 星期天下午，我打算去市場買一些水果，順便和朋友喝綠茶，晚上回家看書。

這篇文章的主題是「一個人的週末行程」。文章需要保留的內容有：

| 內容 | 一般說法 | 受限說法 |
|---|---|---|
| 時間 | 星期天下午 | 週日下午 |
| 動作 | 打算去 | 要去 |
| 地方 | 市場 | 市場 |
| 東西 | 水果 | 水果 |
| 喝的东西 | 綠茶 | 綠茶 |
| 其他動作 | 閱讀 | 看 |

### 2. 保留主要意思

改寫時不能只留下容易的句子。主要意思要分成幾個部分：

| 部分 | 意思 |
|---|---|
| 時間 | 週日下午 |
| 人物 | 我 |
| 動作 | 要去、買、喝、看 |
| 地方 | 市場、店裡、家裡 |
| 東西 | 水果、綠茶、書 |

可以先把意思寫成短句：

> 我週日下午去市場。  
> 我買水果和綠茶。  
> 我和朋友在店裡喝綠茶。  
> 晚上我回家看書。

這些句子都使用簡單的主語、動詞和賓語。

### 3. 固定句子關係

受限語言不需要使用很多複雜的連接詞。常用的句子關係如下：

| 關係 | 固定說法 | 例句 |
|---|---|---|
| 並列 | 和 | 我買水果和綠茶。 |
| 對比 | 比 | 他比我高。 |
| 選擇 | 還是 | 你喝茶還是喝水？ |
| 原因 | 因為 | 我home是因為天氣很熱。 |
| 承接 | 所以 | 我很熱，所以想喝水。 |
| 轉折 | 是……，可是 | 我會說中文，可是我寫得不好。 |
| 建議 | 吧 | 我們走吧。 |
| 再做一次 | 再 | 我再說一次。 |

其中有些連接方法需要調整語序：

> 一般句：我喝綠茶，因為我很喜歡茶。  
> 改寫後：我喜歡茶，所以我喝綠茶。

> 一般句：每個星期天上午，我和朋友去茶館。  
> 改寫後：每週天上午，我和朋友去店裡。

### 4. 把文章分成短句

長文章應先分成幾個短句。每個句子最好只說一個主要意思。

| 長句 | 分成短句 |
|---|---|
| 週日下午我要去市場買水果和綠茶，晚上回家後看一本書。 | 我週日下午要去市場買水果和綠茶。晚上我回家看書。 |
| 我的老朋友很喜歡喝熱茶，所以我今天給他帶了一些。 | 我的老朋友喜歡喝茶。今天我給他帶茶。 |
| 這家店有紅茶、綠茶和很多水果，你想買什麼？ | 這家店有紅茶和綠茶。這家店也有水果。你想買什麼？ |

分句以後，再檢查每個句子：

- 有主語嗎？
- 有動詞嗎？
- 有必要的賓語嗎？
- 時間在動詞前面嗎？
- 地點用「在」嗎？
- 「是」後面是名詞或類頭嗎？

例如：

> 這個東西很貴。

這個句子有主語「這個東西」、動詞「是」和性質「很貴」。它不需要改成「這是很貴的東西」。

### 5. 使用固定替代表達

當原文中的概念不能用一個可用的詞說出時，可以使用描述加類頭：

| 一般概念 | 受限說法 |
|---|---|
| 商品 | 東西 |
| 飲品 | 可以喝的水 |
| 閱讀 | 看 |
| 計程車 | 會載人的車 |
| 餐廳 | 可以吃飯的店 |
| 公園 | 可以走路的綠色地方 |
| 天氣 | 天氣 |
| 開車 | 開車 |
| 看醫生 | 去看醫生 |

例子：

> 原文章：星期天上午，我去公園和朋友一起吃午餐。  
> 改寫後：每週天上午，我和朋友去一個可以走路的綠色地方。我們在那裡吃飯。

這個版本比較長，但每個字都在詞表內，而且意思清楚。

## 完整改寫示例

下面是一般文章改成 Mini-Chinese 的完整例子。原文章不是 Mini-Chinese。

> 星期天下午，我打算去市場買一些水果，順便和朋友喝綠茶，晚上回家後閱讀一本小說。

### 第一步：找主題

文章的主題是「我週末的行程」。

### 第二步：保留重要意思

| 重要意思 | 受限詞 |
|---|---|
| 星期天下午 | 週日下午 |
| 我打算去 | 我要去 |
| 市場 | 市場 |
| 水果 | 水果 |
| 和朋友 | 和朋友 |
| 喝綠茶 | 喝綠茶 |
| 晚上 | 晚上 |
| 回家 | 回家 |
| 閱讀小說 | 看書 |

### 第三步：找出句子關係

原文有三個動作：

1. 去市場買水果和綠茶。
2. 和朋友喝綠茶。
3. 回家看書。

### 第四步：換成可用的詞

| 原文章 | 可用的說法 |
|---|---|
| 打算 | 要 |
| 一些 | 一些 |
| 順便 | 和…… |
| 閱讀 | 看 |
| 小說 | 書 |

### 第五步：重新寫句子

> 我週日下午要去市場買水果和綠茶。  
> 我和朋友在店裡喝綠茶。  
> 晚上我回家看書。

### 第六步：逐字檢查

| 檢查項目 | 結果 |
|---|---|
| 所有字都在詞表內 | 是 |
| 每句都有動詞 | 是 |
| 時間放在動詞前 | 是 |
| 地點用「在」 | 是 |
| 沒有使用「把」 | 是 |
| 沒有使用表外的連接詞 | 是 |

### 第七步：比較並修改

修改後的句子和原文意思相同，也更短。修改後的文章是：

> 我週日下午要去市場買水果和綠茶。  
> 我和朋友在店裡喝綠茶。  
> 晚上我回家看書。

這個版本可以分成四個部分：

1. 週日下午，我去市場。
2. 我買水果和綠茶。
3. 我和朋友喝綠茶。
4. 晚上，我回家看書。

## 檢查清單

完成改寫後，可以依下列順序檢查：

| 順序 | 檢查問題 |
|---|---|
| 1 | 原文的主要意思都有留下嗎？ |
| 2 | 每一句都有清楚的主語和動詞嗎？ |
| 3 | 時間放在動詞前面嗎？ |
| 4 | 地點有使用「在＋地方」嗎？ |
| 5 | 問句有使用「嗎」、「什麼」或「呢」嗎？ |
| 6 | 否定句有按照時間使用「不」或「沒」嗎？ |
| 7 | 所有字都在詞表內嗎？ |
| 8 | 有沒有太長、太多或太難的句子嗎？ |
| 9 | 新文可以讓讀者直接讀懂嗎？ |

> 答案：他很高。
