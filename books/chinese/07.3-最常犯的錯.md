# 07.3 最常犯的錯

## 最常犯的錯

學習 Mini-Chinese 時，最常犯的錯是：詞語雖然都認識，句子組合卻不合規則。這一章學習句子中時間、地點、性質、否定和問句的正確位置，也學習怎麼修正不自然的句子。

## 時間與地點的位置

時間要放在動詞前面。地點用「在＋地方」，也要放在動詞前面。

| 常犯的錯 | 正確的說法 | 說明 |
|---|---|---|
| 我看書今天。 | 我今天看書。 | 時間在動詞前面。 |
| 我學中文在學校。 | 我在學校學中文。 | 地點在動詞前面。 |
| 他在東邊住。 | 他住在東邊。 | 地點也可以放在動詞後面，但前有「在」。 |
| 今天晚上我睡覺。 | 今天晚上我睡覺。 | 這個句子正確。 |

- 我明天去。
- 我今天在家。
- 我在學校學中文。
- 他住在東邊。
- 我們明天在工作。

問地點時，要用「哪裡」：

甲：你住在哪裡？  
乙：我住在城裡。

## 不用「是」說明性質

性質詞可以直接放在主語後面。不要在性質前面加「是」。

| 常犯的錯 | 正確的說法 |
|---|---|
| 他是很高。 | 他很高。 |
| 這是很大。 | 這個很大。 |
| 今天是很好。 | 今天很好。 |
| 那個書是舊。 | 那本書很老。 |

也可以用「很」「太」「不」「真」「最」加在性質前面：

- 他很高。
- 今天太熱了。
- 這個不貴。
- 他真的會。
- 他是最好的老師。

注意：「是」用來連接兩個名詞，不說「他是高」。

| 正確的說法 | 說明 |
|---|---|
| 他是老師。 | 「是」連接「他」和「老師」。 |
| 這是我的書。 | 「是」連接兩個名詞。 |
| 我很高。 | 性質詞直接當謂語。 |

## 否定、問句與選擇

現在或將來的否定用「不」。過去的否定，或表示沒有東西時，用「沒有」。

| 常犯的錯 | 正確的說法 | 說明 |
|---|---|---|
| 我不吃肉。 | 我不吃肉。 | 這個句子正確。 |
| 他明天不吃來。 | 他明天不來。 | 「不」放在動詞前面。 |
| 我昨天沒去。 | 我昨天沒去。 | 過去的否定用「沒」。 |
| 我不有錢。 | 我沒有錢。 | 沒有東西用「沒有」。 |

問句可以用「嗎」。問名字用「什麼名字」。問選擇時，用「還是」：

- 你是學生嗎？
- 你叫什麼名字？
- 你想喝水還是喝茶？
- 你很好，是嗎？

「還是」也可以放在問句後面：

甲：你喝茶還是喝水？  
乙：我喝水。

## 不用「把」，換一種說法

不要用「把」字句。可以先說要處理的東西，再說動作：

| 常犯的錯 | 正確的說法 | 說明 |
|---|---|---|
| 我把書放在桌上。 | 我拿書放在桌上。 | 先說東西，再說動作。 |
| 他把這本書買了。 | 他買了這本書。 | 先說動作，再說東西。 |
| 她把衣服穿好。 | 他穿好了衣服。 | 不用「她」，也不加「把」。 |

「先」也常有幫助：

- 我先拿書，再看書。
- 他先吃飯，再去工作。
- 我先學中文，再看中文書。

注意：「再」表示再做一次。「先……再……」表示先做一件事，然後做另一件事。

- 我明天再來。
- 我先吃飯，再去學校。
- 你再說一次。
