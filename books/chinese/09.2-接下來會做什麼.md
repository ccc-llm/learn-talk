# 09.2 接下來會做什麼

本章要學習怎麼說後續計畫。主要使用「要」表示自己的打算，使用「會」表示以後可能發生的事，使用「再」表示完成一件事之後做下一件事。時間通常放在動詞前面。

## 計畫：用「要」

「要」可以放在動詞前面，表示自己準備做什麼。

| Mini-Chinese | 中文意思 |
|---|---|
| 我明天去學校。 | 我明天準備去學校。 |
| 我今天晚上做飯。 | 我今天晚上準備做飯。 |
| 我明年去中國。 | 我明年準備去中國。 |
| 我現在做什麼？ | 我現在準備做什麼？ |

「你 + 要 + 動詞」也可以用來詢問別人的計畫。

- 你要吃什麼？
- 你要回家嗎？
- 你要學中文嗎？

## 可能會做的事：用「會」

「會」放在動詞前面，表示對以後事情的猜測、安排或可能性。

| Mini-Chinese | 中文意思 |
|---|---|
| 他今天晚上會回來。 | 他今天晚上可能會回來。 |
| 我會在3點以前到。 | 我會在3點以前到達。 |
| 你會再來嗎？ | 你以後還會來嗎？ |
| 我會做飯。 | 我以後會做飯。 |

「會」也可以用來表示某項能力。

- 我會說中文。
- 你會唱歌嗎？
- 他會寫字。

## 完成一件事之後：用「再」

「再」表示一個動作重複發生，也可以表示完成一件事之後做下一件事。

| Mini-Chinese | 中文意思 |
|---|---|
| 你等一下再打電話給我。 | 你等一下再打電話給我。 |
| 這件事完了，我再給你看。 | 這件事完成後，我再給你看。 |
| 我寫完信，再去吃飯。 | 我寫完信後，再去吃飯。 |
| 我們吃完飯，再去海邊。 | 我們吃完飯後，再去海邊。 |

「完了」可以放在動詞後面，表示動作完成。

- 我做完了。
- 他寫完了。
- 我們吃完了。
- 你做完了嗎？

## 對話：說出後續計畫

甲：你現在要做什麼？  
乙：我現在寫信。  
甲：你寫完信後要做什麼？  
乙：我寫完信後去吃飯。  
甲：吃完飯後呢？  
乙：我們去海邊。

也可以問「等一下」的計畫。

甲：你等一下會做什麼？  
乙：我等一下會寫字。  
甲：寫完字後呢？  
乙：我寫完字後給你看。

## 練習

- [ ] 你明天要做什麼？

> 答案：我明天去學校。

- [ ] 你等一下再做什麼？

> 答案：我等一下再打電話給你。

- [ ] 這件事完了，你再做什麼？

> 答案：這件事完了，我再給你看。

- [ ] 你明年想去哪裡？

> 答案：我明年想去中國。
