# 01.2 為什麼 449 個單位就夠了

本章要學的是：用「表達力」而不是「詞頻」選詞。449 個單位不是把常用詞全部放進去，而是選擇能互相組合、形成固定句型的單位。只要學會這些單位，就能用少量詞表表達很多意思。

## 1. 選詞的重點：能不能組合

一個詞是否值得放進 Mini-Chinese，不是看它出現得多不多，而是看它能不能和別的單位組合，產生更多新的說法。

| 單位 | 可以組合的單位 | 可以形成的意思 |
|---|---|---|
| 學 | 中文、唱歌、做事、知識 | 學習不同的事情 |
| 看 | 書、電影、圖片、朋友 | 看不同的事物，也可以表示見到 |
| 說 | 話、故事、問題、謝謝 | 說話、回答、表達 |
| 做 | 飯、工作、菜、家 | 製作食物、工作或完成事情 |
| 買 | 書、菜、衣服、房子 | 購買不同的東西 |
| 去 | 學校、公司、家裡、中國 | 到不同的地方 |

例如，學會「學」，就可以和「中文」組成：

> 我學中文。

學會「唱」，就可以和「歌」組成：

> 她唱中文歌。

學會「看」，就可以和「書」組成：

> 他看書。

這些句子不是提前背好的固定句型，而是用同一個動詞和不同對象組合出來的。這就是表達力。

## 2. 一個單位可以放在很多位置

Mini-Chinese 的單位不只是單獨使用，也能放進不同的句子位置。動詞前面可以放時間、地點、人物，動詞後面可以放對象。

### 2.1 時間放在動詞前面

| Mini-Chinese | 說明 |
|---|---|
| 我今天去。 | 今天，說明動作發生的時間 |
| 我明天去。 | 明天，說明另一個時間 |
| 我昨天沒去。 | 昨天，說明過去的時間和否定 |
| 我每天學中文。 | 每天，說明經常發生的動作 |

### 2.2 地點放在動詞前面

| Mini-Chinese | 說明 |
|---|---|
| 我在家裡吃飯。 | 在家裡，說明吃飯的地點 |
| 他在學校學中文。 | 在學校，說明學中文的地點 |
| 我們在公園走路。 | 在公園，說明走路的地點 |
| 她在房間看書。 | 在房間，說明看書的地點 |

### 2.3 對象放在動詞後面

| Mini-Chinese | 說明 |
|---|---|
| 他吃飯。 | 動作和對象 |
| 他喝茶。 | 換一個對象，句型不變 |
| 他看書。 | 換一個對象，句型不變 |
| 他學中文。 | 換一個對象，句型不開 |

因此，動詞的表達力不只取決於它本身有多少意思，也取決於它可以接多少對象。

## 3. 少數單位可以組成完整意思

有些意思不需要增加很多新詞，只要把現有單位組合起來，就可以說清楚。

### 3.1 用「是」說明身分和歸屬

> 他是老師。

> 這是我的書。

> 她是中國人。

這裡的「是」把兩個名詞單位連接起來，形成一種固定關係。

### 3.2 用「有」表示擁有或存在

> 我有兩個朋友。

> 這裡有很多人。

> 我沒有手機。

這裡的「有」和「沒有」是一組，不需要另外學習「 possess 」或其他說法。

### 3.3 用「比」表示比較

> 他比我高。

> 這個比那個更貴。

> 我和你一樣大。

這裡「比」和「更」一起使用，就可以比較兩個人或兩個東西。

### 3.4 用「得」說明動作的程度

> 你說得很好。

> 他走得很慢。

> 她唱得很清楚。

「動詞 + 得 + 性質」是一個固定結構，可以把說話變得更完整。

## 4. 449 個單位怎麼配合

這 449 個單位不是彼此獨立的單字，而是分成幾個功能群組，彼此配合：

| 單位群組 | 功能 | 例子 |
|---|---|---|
| 人物單位 | 表示誰做動作 | 我、你、他、朋友、老師 |
| 動作單位 | 表示做什麼 | 看、說、吃、學、去、買 |
| 事物單位 | 表示對象或內容 | 書、飯、菜、中文、房子 |
| 性質單位 | 表示樣子或狀態 | 好、大、小、快、忙、熱 |
| 時間單位 | 表示什麼時候 | 今天、明天、每天、去年 |
| 方位單位 | 表示在哪裡 | 家裡、學校、這裡、外國 |
| 語法單位 | 把句子連接起來 | 是、有、不、嗎、和、比 |

例如：

> 我明天在學校學中文。

這句話使用了：

- 人物單位：我
- 時間單位：明天
- 方位單位：在、學校
- 動作單位：學
- 事物單位：中文

「449 個單位就夠了」的意思，不是說它們可以代替所有自然語言，而是說它們足以組成這套 Mini-Chinese 的基本句子。重點是學會組合，而不是背很多單獨的詞。
