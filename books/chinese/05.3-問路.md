# 05.3 問路

## 05.3 問路

### 1. 問路的基本說法

想知道地方在哪裡，可以用：

> 請問，X在哪裡？

| Mini-Chinese | 中文說明 |
|---|---|
| 請問，車站在哪裡？ | 詢問車站的位置。 |
| 請問，看書的地方在哪裡？ | 詢問圖書館這類地方的位置。 |
| 請問，看病的地方在哪裡？ | 詢問醫院這類地方的位置。 |
| 請問，飯店在哪裡？ | 詢問飯店的位置。 |

### 2. 回答位置

回答位置時，可以用「在」加方向或地方。

| Mini-Chinese | 中文說明 |
|---|---|
| 車站在這邊。 | 車站在說話的人這一方。 |
| 車站在那邊。 | 車站在另一方。 |
| 飯店在這邊的前方。 | 飯店在這邊的前面。 |
| 車站在右邊。 | 車站在右邊。 |
| 車站在左邊。 | 車站在左邊。 |
| 車站在旁邊。 | 車站在附近。 |
| 車站在外邊。 | 車站在外面。 |
| 車站在裡邊。 | 車站在裡面。 |
| 車站在中間。 | 車站在中央。 |

### 3. 說明走法

說明走法時，可以使用「過」、「再」和「到」。

| Mini-Chinese | 中文說明 |
|---|---|
| 過了路口，右邊就是車站。 | 走過路口，右邊是車站。 |
| 你過路口，再走就到了。 | 告訴對方先走過路口，然後再走。 |
| 你走過路口，在右邊看到一個路口，再走就到了。 | 告訴對方經過路口後，繼續走。 |
| 你走左邊，過路口就到了。 | 告訴對方從左邊走，經過路口就到。 |
| 你在這裡，過2個路口，右邊就是飯店。 | 告訴對方從這裡出發的路線。 |

### 4. 對話

```text
甲：請問，看書的地方在哪裡？
乙：在這邊的前方。
甲：要過路口嗎？
乙：對。過了路口，右邊就是。
甲：謝謝。
乙：不客氣。
```

```text
甲：請問，看病的地方在哪裡？
乙：你在那邊走，過2個路口，左邊就是。
甲：還有多遠？
乙：很近，再走就到了。
甲：好，謝謝。
乙：不用謝。
```

```text
甲：請問，車站在哪裡？
乙：在學校的右邊。
甲：就在右邊嗎？
乙：對。你走過路口，就看到了。
甲：我知道了，謝謝。
乙：不用謝。
```

### 5. 常用句型

| 句型 | Mini-Chinese |
|---|---|
| 詢問地方 | 請問，X在哪裡？ |
| 回答附近 | X在這邊。 |
| 回答遠方 | X在那邊。 |
| 回答方向 | X在左邊。 |
| 回答前方 | X在這邊的前方。 |
| 回答後方 | X在這邊的後方。 |
| 說明經過 | 過了路口，就看到了。 |
| 說明繼續走 | 再走就到了。 |

### 6. 練習

- [ ] 請問，看書的地方在哪裡？

> 答案：在這邊的前方。

- [ ] 請問，車站在哪裡？

> 答案：在學校的右邊。

- [ ] 過了路口，左邊就是飯店嗎？

> 答案：對。

- [ ] 請問，看病的地方在哪裡？

> 答案：你在那邊走，過2個路口，左邊就是。

- [ ] 車站在哪裡？

> 答案：車站在那邊。
