# 05.1 見面與自我介紹

# 05.1 說名字

見面的時候，第一句話通常是問名字。這一章的說法都用「說名字」的方式，因為「介紹」這個詞不在字表裡面。

## 1. 說自己的名字

| Mini-Chinese | 中文意思 |
|---|---|
| 我叫 Peter。 | 我叫 Peter。 |
| 我叫 Li Ming。 | 我叫李明。 |
| 我的名字是 Mei。 | 我的名字是 Mei。 |
| 你的名字是什麼？ | 你的名字是什麼？ |

名字要用外來語寫，第一次出現的時候加括號說明：

```
甲：你好！你叫什麼名字？
乙：你好！我叫 Peter（這是名字）。
```

## 2. 說自己的國

| Mini-Chinese | 中文意思 |
|---|---|
| 我是中國人。 | 我是中國人。 |
| 你是哪國人？ | 你是哪國人？ |
| 我是美國人。 | 我是美國人。 |
| 我是外國人。 | 我是外國人。 |

```
甲：你是哪國人？
乙：我是中國人。你呢？
甲：我也是中國人。
```

## 6. 說另一個人

用「這是……」來說另一個人，也可以用「他」和「我的朋友」。

| Mini-Chinese | 中文意思 |
|---|---|
| 這是我的朋友 Peter。 | 這是我的朋友 Peter。 |
| 他是我的同學。 | 他是我的同學。 |
| 他們是學生。 | 他們是學生。 |
| 這是我哥哥。 | 這是我哥哥。 |
| 這是我妹妹。 | 這是我妹妹。 |

## 7. 對話

```
甲：你好！你叫什麼名字？
乙：你好！我叫 Peter（這是名字）。你是哪國人？
甲：我是中國人。你住在哪裡？
乙：我住在城裡。你做什麼工作？
甲：我是老師。
乙：很好！我在學中文。
甲：真的嗎？你學得很好嗎？
乙：還可以。每天我都學。
甲：再見！
乙：再見！
```

## 8. 重點

| Mini-Chinese | 中文意思 |
|---|---|
| 我叫…… | 我的名字是…… |
| 這是…… | 這個人是…… |
| 你是哪國人？ | 問國籍。 |
| 我住在…… | 我住在某個地方。 |
| 我是…… | 我的工作或身分是…… |
| 我在學…… | 我正在學某件事。 |

小提醒：

- 名字不翻譯，直接用外來語，第一次出現加括號說明。
- 問名字用「你叫什麼名字？」，不要用「你叫什麼？」
- 說國用「哪國人」，不要說「你是哪個人種」這種說法。
- 學新東西用「我在學……」，學習的程度用「學得很好」。

## 9. 練習

- [ ] 2. 把「我住在城裡」改成問句，問對方住哪裡。

- [ ] 3. 把「這是我的朋友 Peter」改成問句，問對方這個人是誰。

- [ ] 4. 改正錯句：「我學中文在。」
