# 07.2 實例：科普、議論與說明

## 科普改寫：把知識說清楚

科普文章要把一個知識點說明白，讓別人容易理解。改寫時，先說最重要的東西，再補充簡單的原因或例子。一次不要放很多新說法。

| 原來的想法 | 改寫後的 Mini-Chinese |
|---|---|
| 今天很熱，我們在房間裡喝水。 | 今天很熱。我們在房間裡喝水。 |
| 水放在火上，就會變熱。 | 水放在火上，就熱了。 |
| 地球上面有很多東西。 | 地球上有山、有水，也有空氣。 |

- 一天有24小時。
- 地球很大。
- 地球上有山、有水，也有空氣。
- 火很熱，水很冷。
- 水放在火上，就熱了。

這些句子先說一個事實，再說另一個相關的事實。寫科普文章時，也可以用「因為」和「所以」說明原因。

> 因為天很熱，所以我們在房間裡喝水。

## 議論改寫：說出理由和看法

議論文章要說出自己的理由，也可以比較兩件事，再給出看法。最常用的結構是「因為……所以……」。寫的時候要清楚：原因是什麼，結果是什麼。

| 寫法 | Mini-Chinese |
|---|---|
| 說原因和結果 | 因為水很重要，所以每個人都要喝水。 |
| 說原因和決定 | 因為今天很忙，所以我不玩。 |
| 說原因和做法 | 因為下雨，所以我們在房間裡。 |
| 比較兩個事物 | 這個比那個更好。 |
| 比較兩個事物 | 他比我高。 |

- 每個人都要喝水。
- 因為水很重要，所以每個人都要喝水。
- 不是每個人都喜歡甜的水果。
- 喜歡甜的水果的人不多。
- 這個比那個更好。
- 我和他一樣高。

寫議論的句子時，可以用下面的方法：

1. 先寫理由，再寫看法。
2. 用「比」比較兩個事物。
3. 用「一樣」表示兩件事物相同。
4. 用「不是每個人都……」表示不是全部的人都這樣。

> 因為今天很熱，所以我們在房間裡喝水。  
> 他比我高。  
> 我和他一樣高。

## 說明改寫：說明步驟和方法

說明文章要告訴別人怎麼做，或說明一個過程。改寫時，把先後順序寫清楚。常用的方法是用「先」和「再」。

| 說明內容 | Mini-Chinese |
|---|---|
| 學習中文 | 先學字，再寫字。 |
| 看圖片 | 先看圖，再看文字。 |
| 吃東西 | 先喝水，再吃飯。 |
| 做東西 | 先做飯，再吃飯。 |

- 先學字，再寫字。
- 先看圖，再看文字。
- 先喝水，再吃飯。
- 我每天學中文。
- 我要每天學一點中文。

| 常用的說明方式 | Mini-Chinese |
|---|---|
| 先說第一步 | 先學字，再寫字。 |
| 說明每天做的事 | 我每天學中文。 |
| 說明一個目的 | 我想學中文。 |
| 說明遇到問題的做法 | 我不懂，所以我要問老師。 |

「先」和「再」可以放在動詞前面，表示動作的順序。「每天」可以放在動詞前面，表示這件事常常發生。

## 完整改寫實例

下面把同一個意思改寫成不同類型。

### 科普

一天有24小時。

地球上有山、有水，也有空氣。

水放在火上，就熱了。

### 議論

因為水很重要，所以每個人都要喝水。

因為今天很忙，所以我不玩。

這個比那個更好。

### 說明

先學字，再寫字。

先喝水，再吃飯。

我不懂，所以我要問老師。

---

## 練習

把下面的句子分成兩句：

因為今天很熱，所以我們在房間裡喝水。

> 答案：今天很熱。我們在房間裡喝水。

用「比」寫一個比較句。

> 答案：他比我高。

用「先」和「再」寫一個說明句。

> 答案：先喝水，再吃飯。

寫一個用「因為」和「所以」的句子。

> 答案：因為水很重要，所以每個人都要喝水。
