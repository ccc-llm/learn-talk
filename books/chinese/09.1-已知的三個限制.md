# 09.1 已知的三個限制

這一章要學習 Mini-Chinese 的三個限制：不能自由使用詞表外的新詞，不能任意改變句子結構，也不能用一個長句說出所有細節。遇到不會表達的內容時，可以使用描述加類頭、固定句型，或把長句分成幾個短句。

## 一、不能自由使用新詞

Mini-Chinese 的詞表有固定範圍。詞表外的人名、地名、物品種類和專門概念，不能直接加進句子。

不知道怎麼說時，可以使用固定方法：

| 情況 | 處理方法 | Mini-Chinese 例句 |
|---|---|---|
| 不知道物品的名稱 | 描述它的特點和用途 | 我想看有圓的特點的東西。 |
| 不知道人的身分 | 描述他做的事 | 那個做水果工作的人是我朋友。 |
| 知道是哪一個名字或地方 | 第一次出現時加括號說明 | 我住在上海（中國的一個城市）。 |
| 不必說很多細節 | 只說最重要的部分 | 我有一個新工具。 |

新名字第一次出現時，要先加括號說明。後面再說時，可以只使用那個名字。

### 常用簡單句

| Mini-Chinese | 中文意思 |
|---|---|
| 我有一個新工具。 | 我有一件以前沒有說過的工具。 |
| 那個做水果工作的人是我朋友。 | 那個賣水果的人是我的朋友。 |
| 我住在一個很大的城市。 | 我住在城市裡；城市很大。 |
| 我現在看一個有圓的特點的東西。 | 我正在看一個圓形的物體。 |

不會說名字時，不要硬造新詞。先說清楚它是什麼、有什麼用處，就可以繼續說話。

## 二、不能任意改變句型

Mini-Chinese 使用固定的語法規則。理解句子的意思，不代表可以自由移動字詞。

| 規則 | 固定方法 | Mini-Chinese 例句 |
|---|---|---|
| 基本句型 | 主語＋動詞＋賓語 | 他看書。 |
| 時間 | 放在動詞前 | 明天我會去學校。 |
| 地點 | 用「在＋地方」，放在動詞前 | 我在家裡看書。 |
| 能力 | 能願動詞放在動詞前 | 我會說中文。 |
| 所有 | 用「都」 | 每個學生都有書。 |
| 比較 | 用「比」 | 他比我高。 |

如果想說很多關係，要一個一個使用固定規則：

| 想表達的意思 | Mini-Chinese | 中文意思 |
|---|---|---|
| 原因 | 因為天冷，所以我不去。 | 因為天氣冷，所以我不出門。 |
| 同時做兩件事 | 他吃飯和看書。 | 他一邊吃飯，一邊看書。 |
| 兩件事的選擇 | 你喝茶還是喝水？ | 你要喝茶還是喝水？ |
| 喜歡和評論 | 我喜歡這首歌，因為很好聽。 | 我喜歡這首歌，因為聽起來很好。 |

固定的連接方式比自由改句型更安全。不要移動時間和地點，也不要加入詞表外的連接詞。

## 三、不能只用一個長句說完

Mini-Chinese 適合先說清楚一件簡單的事，再增加時間、地點、原因和結果。內容多時，應該分成幾個短句。

### 一個長句

我今天早上在學校的店裡和我的朋友一起吃飯和喝茶。

這個句子有很多內容，學習者不容易確認每個部分的位置。

### 分成幾個短句

我今天早上在學校的店裡吃飯。  
我和朋友一起喝茶。  
我們很開心。

### 可以使用的簡單句型

| Mini-Chinese | 中文意思 |
|---|---|
| 我今天早上吃飯。 | 我今天早上吃了飯。 |
| 我和朋友一起吃飯。 | 我和朋友一起吃飯。 |
| 我們在店裡喝茶。 | 我們在店裡喝茶。 |
| 我很開心。 | 我感到很高興。 |
| 昨天我沒吃飯。 | 我昨天沒有吃飯。 |
| 我今天會學10個字。 | 我今天將學會十個字。 |

說不出完整細節時，先說最重要的部分：

| 優先順序 | Mini-Chinese | 中文意思 |
|---|---|---|
| 1 | 我今天去學校。 | 先說時間和地點。 |
| 2 | 我今天去學校看書。 | 再說事情。 |
| 3 | 我和朋友一起去學校看書。 | 再增加人物。 |
| 4 | 我和朋友在學校的圖書館看書。 | 再增加更準確的地方。 |

如果一個句子很長，先問自己三件事：什麼時間？什麼地方？做什麼？如果三個問題都有答案，就可以分成短句說明。
