# 02.2 代詞・指示與語法（功能詞）

本章學習代詞和最常用的功能詞。代詞可以代替人、事物或地方，讓句子更簡單；功能詞可以表示肯定、否定、疑問、並列、比較和時間。學會這些詞以後，就可以用「誰 + 做 + 什麼」和「是 + 名詞」等方式造出更多句子。

## 一、代詞：代替人、物和地方

代詞用來代替句中已經知道的人、事物或地方。

| 代詞 | 意思 | Mini-Chinese 例句 |
|---|---|---|
| 我 | 說話的人 | 我是學生。 |
| 你 | 對方 | 你叫什麼名字？ |
| 他 | 對方或另一個人 | 他在學校。 |
| 們 | 表示多人 | 他們在這裡。 |
| 這 | 這個人、這個東西或這個地方 | 這是我的書。 |
| 那 | 那個人、那個東西或那個地方 | 那是他的車。 |
| 哪 | 哪一個、哪裡 | 你要去哪裡？ |
| 誰 | 哪一個人 | 那是誰？ |
| 什麼 | 什麼東西、什麼事情 | 你要說什麼？ |
| 怎麼 | 怎樣、如何 | 你怎麼學中文？ |
| 每 | 每一個 | 每個人都會說中文。 |
| 自 | 自己 | 我自己看書。 |
| 己 | 自己 | 他自己買水。 |
| 樣 | 這種、那種；怎樣 | 我和你一樣大。 |

代詞可以放在句子裡的不同位置：

- **我明天去。**
- **明天我去。**
- **你在家嗎？**
- **這是我的房間。**
- **他們每個星期都來。**

「這裡」和「那裡」要分清楚：

- **我在這裡。**
- **他在那裡。**

## 二、基本句型：是、有、在

### 「是」：表示身分、關係或所有

「是」連接兩個名詞。最基本的句型是：

> 主語 + 是 + 名詞

| Mini-Chinese | 中文意思 |
|---|---|
| 他是老師。 | 他是老師。 |
| 我是學生。 | 我是學生。 |
| 這是家。 | 這是家。 |
| 那是我的書。 | 那是我的書。 |
| 他是我朋友。 | 他是我的朋友。 |

「是」的否定形式是「不是」：

- **他不是老師。**
- **這不是我的書。**

### 「有」：表示擁有或存在

「有」後面接事物或數量：

- **我有一個朋友。**
- **她有兩個孩子。**  
  「她」要改成「他」：**他有兩個孩子。**
- **這裡有很多人。**
- **我沒有錢。**

「有」的否定一定用「沒有」：

| 肯定 | 否定 |
|---|---|
| 我有書。 | 我沒有書。 |
| 他有車。 | 他沒有車。 |
| 這裡有人。 | 這裡沒有人。 |

### 「在」：表示地方或事情正在發生

「在 + 地方」放在動詞前面：

- **我在學校學中文。**
- **他住在東邊。**
- **我們在家裡吃飯。**

「在」也可以放在動詞前，表示事情正在進行：

- **他在吃飯。**
- **她在唱歌。**  
  「她」要改成「他」：**他在唱歌。**
- **我現在看書。**

## 三、否定、疑問和連接詞

### 否定

現在、將來、習慣和性質用「不」；過去和「有」用「沒」。

| 用法 | Mini-Chinese | 說明 |
|---|---|---|
| 現在或將來 | 我明天不來。 | 「不」放在動詞前。 |
| 性質 | 這個不貴。 | 「不」放在性質詞前。 |
| 習慣 | 我不吃肉。 | 「不」放在動詞前。 |
| 過去 | 我昨天沒去。 | 「沒」放在動詞前。 |
| 擁有 | 我沒有手機。 | 「有」的否定用「沒有」。 |

### 疑問

用「嗎」提出簡單的yes/no問題：

- **你是學生嗎？**
- **他明天來嗎？**
- **你喝茶嗎？**

用「哪」和「什麼」問地點或事物：

- **你在哪裡？**
- **你要買什麼？**
- **那是誰的書？**

用「還是」提出選擇：

- **你喝茶還是喝水？**
- **他今天來還是明天來？**

### 並列和時間

- **和**連接兩個相同的成分：**我和你一起吃飯。**
- **也**表示「也」：**我也會說中文。**
- **再**表示再次：**請再說一次。**
- **了**表示事情完成或狀態改變：**我吃飯了。**、**他來了。**
- **還**表示仍然或繼續：**他還在這裡。**
- **以前**表示過去時間：**以前我在中國。**

## 四、常用功能詞和固定句型

| 功能詞 | 意思 | Mini-Chinese 例句 |
|---|---|---|
| 不 | 不 | 我不喝咖啡。 |
| 沒 | 沒有 | 我沒有咖啡。 |
| 是 | 是 | 他是醫生。 |
| 有 | 有 | 我有兩個哥哥。 |
| 在 | 在 | 我在房間。 |
| 也 | 也 | 他也會唱歌。 |
| 了 | 完成或改變 | 我找到書了。 |
| 嗎 | 問句 | 你吃飯了嗎？ |
| 和 | 和 | 我和朋友去。 |
| 還是 | 選擇 | 你要茶還是水？ |
| 更 | 更 | 他比我更高。 |
| 最 | 最 | 他是最好的老師。 |
| 很 | 很 | 這個問題很難。 |
| 太 | 太 | 今天的菜太鹹。 |
| 得 | 動作的程度 | 他說得很好。 |
| 嗎 | 問句 | 你明白嗎？ |
| 呢 | 反問 | 你呢？ |
| 吧 | 建議或確認 | 我們走吧。 |

幾個重要的固定句型：

### 「一邊 + 動詞，一邊 + 動詞」表示同時做兩件事

- **我一边听音乐，一边学习。**
- **他一边吃饭，一边说话。**

### 「比」表示比較

- **他比我高。**
- **這個比那個更貴。**
- **我和你一樣大。**

### 「從……到……」表示起點和終點

- **我從家裡到學校。**
- **他從中國到美國。**

### 「得」描述動作做得怎麼樣

- **你說得很好。**
- **他走得很慢。**
- **她唱得很清楚。**  
  「她」要改成「他」：**他唱得很清楚。**
