# 01.3 怎麼用這本書

這一章要說明每天怎麼學、怎麼做題，以及怎麼用檢查工具。先學一點新詞，再看句子、做題目；遇到不會的句子，先自己看，再問老師。每天做一點，比一次做很多更容易進步。

## 每天的進度

每天都可以用同一個方法學習。學習時間不用很多，但要每天做。讀者可以先看詞，再看句子，最後做題目。做完題目後，再讀一次。

| 步驟 | 說明 | Mini-Chinese 例句 |
|---|---|---|
| 1. 看詞 | 看今天要學的詞。 | 我先看詞。 |
| 2. 看句子 | 看詞怎麼用在句子裡。 | 我再看句子。 |
| 3. 做題目 | 用今天的詞做句子。 | 我做5題。 |
| 4. 再看 | 再讀一次句子和題目。 | 我再讀一次。 |
| 5. 問老師 | 不會的句子問老師。 | 我不會，就問老師。 |

每天的進度可以自己定。做5題、看5個詞，就可以是一天的學習。做完今天的進度，再做明天的。不要只看字，也要自己寫句子。

## 練習怎麼做

每題都先自己寫，再看答案。寫句子時，要用詞表裡的字。句子要完整，不要只寫一個詞。先問自己：「誰做什麼？」再問：「在什麼時候做？」

| 練習方法 | 怎麼做 | Mini-Chinese 例句 |
|---|---|---|
| 寫句子 | 用學過的字寫一個完整句子。 | 我寫完句子，再問老師。 |
| 改句子 | 找到不對的字，再改一次。 | 我看句子有沒有問題。 |
| 說句子 | 看著句子，慢慢說一次。 | 我今天學中文。 |
| 做問句 | 用「嗎」問一個問題。 | 你在家嗎？ |
| 用新詞 | 把今天的新詞放進句子。 | 我用新詞寫句子。 |

不會寫的時候，可以先說簡單句子。不要只寫自己知道的一兩個字。寫完後，再看每一個字是不是在詞表裡。

## 怎麼用檢查工具

寫完 Mini-Chinese 後，可以用檢查工具看句子。工具可以找不在詞表裡的字，也可以看句子有沒有錯。找到錯字後，要自己改，再檢查一次。

| 檢查結果 | 怎麼做 | Mini-Chinese 例句 |
|---|---|---|
| 找到表外的字 | 換成詞表裡的字。 | 我用工具看句子。 |
| 找到錯字 | 改正錯字。 | 我改句子。 |
| 句子不完整 | 加上缺少的主語或動詞。 | 這是完整句子。 |
| 句子是對的 | 讀一次，再做下一題。 | 這些句子是對的嗎？ |

檢查工具不是老師。工具可以幫你找問題，但是你要自己看意思對不對，也要自己改。每做完一組題目，都要再讀一次自己的句子。

## 每天怎麼安排

| 時間 | 學習工作 | Mini-Chinese 例句 |
|---|---|---|
| 一開始 | 看今天的詞。 | 我每天看詞。 |
| 中間 | 讀句子，做題目。 | 我每天做5題。 |
| 最後 | 看答案，改正句子。 | 我看答案。 |
| 有問題 | 問老師。 | 我在問老師。 |

每天做一點，學完一點。每天都做，比只在一天做很多題更好。讀完今天的学习後，可以休息，明天再來。
