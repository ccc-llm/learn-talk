# 04.5 自然度：讀起來會不會怪

寫 Mini-Chinese 時，不只要句子正確，也要讓中文母語者讀起來自然。自然度取決於詞序、固定用法、句子成分的省略，以及是否符合中文的表達習慣。本章學習如何避開「每個字都看得懂，但整句有點怪」的句子。

## 1. 先把句子成分放在自然的位置

中文常見的基本順序是「時間＋地點＋主語＋動詞＋賓語」。時間和地點可以交換，但通常都放在動詞前。

| 不太自然的說法 | 自然的說法 | 原因 |
|---|---|---|
| 我吃飯在學校。 | 我在學校吃飯。 | 地點放在動詞前。 |
| 我在吃飯今天。 | 我今天吃飯。 | 時間放在動詞前。 |
| 我看書在學校。 | 我在學校看書。 | 地點放在動詞前。 |
| 我今天在吃飯。 | 我今天吃飯。 | 「在」和「吃飯」直接連接，不自然。 |
| 我在學中文在學校。 | 我在學校學中文。 | 地點只放在動詞前一次。 |

例句：

- 我今天在學校學中文。
- 他明天在家看書。
- 我們現在在公園吃飯。
- 媽媽每天早上做飯。

寫句子時，可以先問自己：「誰」、「做什麼」、「什麼時候」、「在哪裡」。然後把時間和地點放到動詞前。

## 2. 使用固定搭配，不要逐字翻譯

Mini-Chinese 的自然度不能只看字詞，也要看詞和詞能不能自然地放在一起。有些搭配已經固定，不需要重新組合。

| 功能 | 自然搭配 | 不太自然的說法 |
|---|---|---|
| 說明年齡 | 他 10 歲。 | 他有 10 歲。 |
| 說明天氣 | 今天天氣很好。 | 今天很好天氣。 |
| 說明天氣 | 現在天氣很冷。 | 現在很冷天氣。 |
| 表示正在做 | 我在吃飯。 | 我吃飯在。 |
| 表示剛才完成 | 我吃過飯了。 | 我吃飯過了。 |
| 表示可以做 | 我會說中文。 | 我可以說中文。 |
| 表示能力 | 他會做飯。 | 他可以吃飯。 |
| 表示比較 | 他比我高。 | 他比我更高高。 |

例句：

- 這個小孩 5 歲。
- 我哥哥會做飯。
- 她在唱歌。
- 他昨天看過電影。
- 我朋友比我忙。

有些句型可以直接記住：

1. **人物＋年齡**：他 8 歲。
2. **天氣描述**：今天天氣很冷。
3. **正在做某事**：我在讀書。
4. **曾經做過某事**：我讀過這本書。
5. **能力**：他會說中文。
6. **比較**：他比我高。

這類固定句型比逐字翻譯更自然，也更符合 Mini-Chinese 的組合方式。

## 3. 省略可以讓句子更自然

中文常省去已經清楚的成分。重複說明反而可能不自然。

| 可以省略的成分 | 完整句子 | 自然句子 |
|---|---|---|
| 所有物 | 這是我的書。 | 這是書。 |
| 動作的賓語 | 我要吃飯。 | 我吃。 |
| 主語 | 他今天會來。 | 今天會來。 |
| 時間 | 我 8 點吃飯。 | 我吃飯。 |
| 地點 | 我在學校學中文。 | 我學中文。 |

例句：

- 這是我的書。
- 我想喝水。
- 他會來。
- 我在學校學中文。
- 我有一個哥哥。

省略不是刪掉重要的意思。例如，第一次說「他是我的老師」時，「我的」可以保留；後面如果只談老師，可以說「他是老師」。

## 4. 問句要符合中文的問法

問句應使用固定的問法。不要只把陳述句加上「嗎」就算完成。

| 意思 | 自然問法 |
|---|---|
| 問對方是某種人 | 你是學生嗎？ |
| 問名字 | 你叫什麼名字？ |
| 問選擇 | 你喝茶還是喝水？ |
| 問對方的狀態 | 你今天怎麼樣？ |
| 問地點 | 你住在哪裡？ |
| 問時間 | 你幾點來？ |
| 問意見 | 你喜歡嗎？ |

對話：

甲：你叫什麼名字？

乙：我叫小明。

甲：你是學生嗎？

乙：是。

甲：你今天怎麼樣？

乙：我很好，你呢？

問句的關鍵是問什麼，就用相應的固定結構。不要說「你吃飯了嗎」來表示「你吃過飯沒有」；如果要問是否吃過，可以說：「你吃過飯了嗎？」

## 練習

- [ ] 把句子改得更自然：我在房間讀書今天。

  > 答案：我今天在房間讀書。

- [ ] 在「不」和「沒」中選擇：我明天去學校。

  > 答案：我明天不去學校。

- [ ] 寫一個說明天氣很冷的句子。

  > 答案：今天天氣很冷。

- [ ] 寫一個詢問對方是否喝水的句子。

  > 答案：你喝水嗎？

- [ ] 把「他比我高」改成問句。

  > 答案：他比你高嗎？
