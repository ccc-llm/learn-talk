# 04.3 語法規則（下）

本章學習第 11–17 條語法規則，包括動作的時間狀態、能願動詞、比較、方向、動作程度、介詞片語，以及句子的連接方法。

## 第 11–12 條：動作狀態與能願動詞

動作可以用「現在」「了」「過」「將」「要」等詞，表示不同時間或狀態。

| 用法 | 說明 | Mini-Chinese |
|---|---|---|
| 動作正在進行 | 在動詞前放「現在」或「在」 | 他現在走。 |
| 動作已經完成 | 在動詞後放「了」 | 他吃飯了。 |
| 動作有過去經歷 | 在動詞後放「過」 | 我去過中國。 |
| 動作將要發生 | 在動詞前放「將」或「要」 | 他明天要來。 |

「會」「能」「可以」「要」都可以放在動詞前，說明一個人有能力、可能性或意願。

| 能願動詞 | 說明 | Mini-Chinese |
|---|---|---|
| 會 | 有能力做，或表示將來 | 我會說中文。 |
| 能 | 有能力做 | 他能來。 |
| 可以 | 對方允許或條件允許 | 你可以坐。 |
| 要 | 想要做，或將要做 | 我要喝水。 |

**對話：**

甲：你會說法文嗎？  
乙：會一點。  
甲：很好。  
乙：再見。

## 第 13–14 條：比較與方向

比較句可以用「比」和「更」。「比」後面接比較對象；「更」表示程度更高。

| 用法 | Mini-Chinese |
|---|---|
| 比較性質 | 他比我高。 |
| 比較價格 | 這個比那個更貴。 |
| 表示一樣 | 我和你一樣大。 |
| 表示最高程度 | 他是最好的老師。 |

「來」和「去」可以表示方向。「來」朝向說話的人；「去」離開說話的人。

| 用法 | Mini-Chinese |
|---|---|
| 對方進來 | 請進來。 |
| 對方出去 | 他出去了。 |
| 回家 | 他回家去了。 |
| 拿出物品 | 我拿出去。 |

## 第 15–16 條：動作程度與介詞片語

「得」放在動詞後面，說明動作做得怎麼樣。後面通常接性質詞。

| 用法 | Mini-Chinese |
|---|---|
| 說得好 | 你說得很好。 |
| 走得慢 | 他走得很慢。 |
| 唱得好 | 她唱得很好。 |
| 做得好 | 你做得好。 |

「在、和、從、給、對、到」可以放在動詞前，說明地點、方式、來源、對象或目的地。

| 介詞 | 說明 | Mini-Chinese |
|---|---|---|
| 在 | 地點或動作狀態 | 我在學校學中文。 |
| 和 | 一起做或一起存在 | 我和朋友吃飯。 |
| 從 | 來源 | 他從中國來。 |
| 給 | 接受動作的對象 | 我給媽媽打電話。 |
| 對 | 說話或動作的對象 | 他對我說。 |
| 到 | 目的地 | 我從家裡到學校。 |

介詞片語要放在主要動詞前。也可以用「一起」表示一起做：

> 我和朋友一起吃飯。

## 第 17 條：連接句子

一句話不夠時，可以使用固定的連接方法。

| 關係 | 連接方法 | Mini-Chinese |
|---|---|---|
| 因為 | 因為……所以…… | 因為今天很熱，所以我不去。 |
| 轉折 | 是……可是…… | 這件事是難，可是我不怕。 |
| 選擇 | ……還是…… | 你喝茶還是喝水？ |
| 建議 | 要不…… | 你要去嗎？要不，我和你一起去。 |
| 增加 | 也 | 我會說中文，也會說法文。 |
| 並列 | 和 | 我和他一起去。 |

連接詞可以放在句子中間，也可以放在下一句開頭：

> 我要學中文。  
> 他也要學中文。
