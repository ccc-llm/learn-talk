# 04.1 句子的骨架

這一章學習 Mini-Chinese 最基本的語序。中文句子通常先說「誰」，再說「做什麼」，最後說「對象」或補充資料。學會這個骨架，就可以用詞表組合很多句子。

## 1. 主語 + 動詞 + 賓語

最基本的句子結構是：

**主語 + 動詞 + 賓語**

- **主語**：誰做這件事
- **動詞**：做什麼
- **賓語**：對誰做、做什麼

| 句子 | 主語 | 動詞 | 賓語 |
|---|---|---|---|
| 我吃飯。 | 我 | 吃 | 飯 |
| 他看書。 | 他 | 看 | 書 |
| 我學中文。 | 我 | 學 | 中文 |
| 她喝茶。 | 他 | 喝 | 茶 |
| 我找手機。 | 我 | 找 | 手機 |

有些動詞不一定需要賓語：

| 句子 | 主語 | 動詞 | 意思 |
|---|---|---|---|
| 他來。 | 他 | 來 | 來這裡 |
| 我回。 | 我 | 回 | 回去 |
| 大家笑。 | 大家 | 笑 | 笑 |
| 孩子哭了。 | 孩子 | 哭 | 哭了 |

這個骨架也可以想成：

> **誰 + 做什麼 + 對象**

## 2. 說明人、事物和特徵

### 「是」連接兩個名詞

如果要說「A 是 B」，使用：

**A + 是 + B**

| 句子 | 說明 |
|---|---|
| 他是老師。 | 他是老師。 |
| 這是我的書。 | 這是我的書。 |
| 那是中文課。 | 那是中文課。 |
| 我是學生。 | 我是學生。 |

注意：「是」後面通常放名詞或名詞性的詞組。

### 性質直接放在主語後面

描述大小、冷熱、好壞等特徵時，通常不用「是」：

**主語 + 性質**

| 句子 | 說明 |
|---|---|
| 他很高。 | 他很高。 |
| 今天太熱了。 | 今天太熱了。 |
| 這個不貴。 | 這個不貴。 |
| 這個很好。 | 這個很好。 |

也可以在性質前加「很」「太」「不」「真」「最」：

- 很冷
- 太忙了
- 不難
- 真的好吃
- 最好的老師

完整的句子例子：

| 句子 | 結構 |
|---|---|
| 這個很甜。 | 主語 + 性質 |
| 我的朋友很好。 | 修飾語 + 主語 + 性質 |
| 他是最老師。 | 主語 + 性質 |

## 3. 加上時間和地方

### 時間放在動詞前

時間可以放在主語前，也可以放在主語後，但要在動詞前。

**時間 + 主語 + 動詞 + 賓語**

或：

**主語 + 時間 + 動詞 + 賓語**

| 句子 | 時間位置 |
|---|---|
| 我明天去。 | 時間在主語後、動詞前 |
| 明天我去。 | 時間在主語前 |
| 他今天晚上回家。 | 時間在主語後、動詞前 |
| 今天我們一起學中文。 | 時間在主語前 |
| 她昨天看書。 | 時間在主語後、動詞前 |

### 地方用「在」

要說明動作在哪裡發生，使用：

**在 + 地方 + 動詞**

完整句子可以寫成：

**主語 + 在 + 地方 + 動詞 + 賓語**

| 句子 | 結構 |
|---|---|
| 我在學校學中文。 | 主語 + 在 + 地方 + 動詞 + 賓語 |
| 他住在東邊。 | 主語 + 動詞 + 在 + 地方 |
| 我們在店裡喝茶。 | 主語 + 在 + 地方 + 動詞 + 賓語 |
| 她在房間看書。 | 主語 + 在 + 地方 + 動詞 + 賓語 |
| 他们在公園玩。 | 主語 + 在 + 地方 + 動詞 |

時間和地方一起出現時，可以把時間放在前面：

**時間 + 主語 + 在 + 地方 + 動詞 + 賓語**

例子：

- 今天我在學校學中文。
- 明天我在家休息。
- 昨天他們在公園玩。

## 4. 常見語序問題

| 問題 | 正確方法 | 例子 |
|---|---|---|
| 時間放哪裡？ | 放在動詞前 | 我明天去。 |
| 地方放哪裡？ | 用「在 + 地方」，放在動詞前 | 我在學校學中文。 |
| 性質放哪裡？ | 直接放在主語後 | 他很高。 |
| 問句怎麼問？ | 在句子後加「嗎」，或用「什麼」「誰」 | 你吃飯嗎？ |
| 「是」怎麼用？ | 連接兩個名詞 | 他是老師。 |

把不同部分組合起來：

**時間 + 主語 + 在 + 地方 + 動詞 + 賓語**

- 今天我在學校學中文。
- 明天我在家看書。
- 昨天他在店裡喝茶。

這個長結構仍然遵循基本骨架：

> **誰 + 做什麼 + 對象**

其他資料放在固定位置：

> **時間 + 誰 + 在哪裡 + 做什麼 + 對象**

## 練習

- [ ] 把句子改成正確的語序：  
  學中文 我 在學校。

  > 答案：我在學校學中文。

- [ ] 填空：他是___。  
  提示：老師

  > 答案：他是老師。

- [ ] 把「很」放到正確的位置：  
  他高。

  > 答案：他很高。

- [ ] 選擇正確的句子：  
  A. 我明天在公園玩。  
  B. 我在明天公園玩。

  > 答案：A。我明天在公園玩。

- [ ] 將這些詞組成句子：  
  他、今天、早、到、家

  > 答案：他今天早到家。
