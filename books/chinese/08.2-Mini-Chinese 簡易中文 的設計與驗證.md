# 08.2 Mini-Chinese 簡易中文 的設計與驗證

本章介紹 Mini-Chinese 簡易中文的設計目標、詞表結構、語法規則與驗證方法。讀者可以了解這個語言怎麼用少量詞彙組合出自然句子，也會看到詞表檢查、句型檢查和自然度檢查的結果。

## 設計目標與詞表結構

Mini-Chinese 的目標不是減少語法，而是減少需要學習的詞彙。核心原則是：學會詞表和固定句型，就可以讀懂更多句子。

| 設計項目 | 做法 |
|---|---|
| 字少 | 所有句子只使用詞表內的單位 |
| 自然 | 句子要符合中文的習慣 |
| 可組合 | 同一批詞可以放在不同句型中 |
| 語法固定 | 只使用明確編號的句型規則 |
| 可替代 | 詞表外的概念用描述加類頭，或用外來語 |

目前有 **449 個核心層詞**，**0 個擴充層詞**。核心層分成九類：

| 類別 | 詞數 | 主要用途 | Mini-Chinese 例句 |
|---|---:|---|---|
| 代詞・指示 | 15 | 人物、事物、位置的指示 | 這是我的書。 |
| 語法 | 45 | 否定、問句、時間、連接等 | 你明天來嗎？ |
| 數量 | 18 | 數字、次數、年齡、量詞 | 我有兩個朋友。 |
| 時間 | 19 | 年、月、日、時鐘等 | 我今天在學校。 |
| 方位 | 19 | 東西南北、裡外、前後等 | 他住在東邊。 |
| 動作 | 105 | 吃、喝、看、學、走等 | 我們一起吃飯。 |
| 性質 | 59 | 大小、冷熱、乾淨、快慢等 | 這個比那個更貴。 |
| 事物 | 157 | 人、食物、地方、工具等 | 他是我朋友。 |
| 社交 | 12 | 請、謝謝、祝賀、歡迎等 | 請坐。 |

這種分類讓詞表不只是單字表，也能幫助學習者理解每個詞在句子中的位置。

## 固定句型與組合方法

Mini-Chinese 使用幾個固定句型。每個句型都有清楚的主詞、動詞和修飾成分位置。

| 句型 | 結構 | Mini-Chinese 例句 |
|---|---|---|
| 基本句 | 主語＋動詞＋賓語 | 他看書。 |
| 時間句 | 主語＋時間＋動詞＋賓語 | 我明天去。 |
| 地方句 | 主語＋在＋地方＋動詞 | 我在學校學中文。 |
| 所有句 | 主語＋有＋數量＋名詞 | 這裡有很多人。 |
| 性質句 | 主語＋性質 | 今天太熱了。 |
| 比較句 | 主語＋比＋對象＋性質 | 他比我高。 |
| 否定句 | 主語＋不＋動詞 | 我不吃肉。 |
| 過去否定句 | 主語＋沒＋有＋動詞 | 我昨天沒有去。 |
| 動作狀態句 | 主語＋動詞＋得＋性質 | 他走得很慢。 |
| 選擇問句 | 主語＋動作一＋還是＋動作二 | 你喝茶還是喝水？ |

同一批詞可以用不同規則組合。例如：

| 組合 | Mini-Chinese 例句 |
|---|---|
| 我＋在＋學校＋學＋中文 | 我在學校學中文。 |
| 他＋在＋家＋看＋書 | 他在家看書。 |
| 我們＋在＋這裡＋吃＋飯 | 我們在這裡吃飯。 |

動詞的時間與地點放在前面，數字放在名詞前面，性質直接放在主語後面。學習者不需要記很多不同句型，只要知道各部分的固定位置。

## 難概念的替代方法

有些概念無法只用一個核心詞表示。Mini-Chinese 使用三層表達法：先找本詞，再找描述加類頭，最後使用外來語。

| 概念 | 表達方式 | Mini-Chinese 例句 |
|---|---|---|
| 已經 | 用「了」表示動作完成 | 我吃飯了。 |
| 剛才 | 用時間描述 | 一點時間以前，他在這裡。 |
| 大約 | 用時間或數量描述 | 快3點了。 |
| 如果 | 使用固定替代句型 | 要是下雨，就不去了。 |
| 開始 | 使用「起來」 | 他說起來了。 |
| 停止 | 使用「不再」加動詞 | 他不再說話了。 |
| 很多東西 | 描述加類頭 | 這裡有很多用的東西。 |
| 一個不知名的人 | 外來語加說明 | 那是John（外國人的名字）。 |

外來語第一次出現時，要用括號說明它的種類。括號內的說明也只使用詞表內的字。例如「那是Mary（一個人名）。」

這種方法的好處是：不會因為一個新概念，就增加很多新詞；學習者也能清楚知道某個詞是不是核心詞。

## 驗證方法與結果

驗證分成三個部分：詞表檢查、句型檢查和自然度檢查。

### 1. 詞表檢查

每一個 Mini-Chinese 句子都逐字檢查。若有詞表外的字，就改用同義核心詞、描述加類頭或外來語。

| 檢查項目 | 結果 |
|---|---|
| 核心層詞 | 449 個 |
| 擴充層詞 | 0 個 |
| 句子中的表外字 | 0 個 |
| 數字 | 全部使用阿拉伯數字 |
| 外來語 | 第一次出現都有括號說明 |

### 2. 句型檢查

句子再依照 17 條語法規則檢查，包括主詞和動詞的位置、時間和地點的位置、否定方式、問句形式、比較方式與方向。

| Mini-Chinese 例句 | 檢查重點 | 結果 |
|---|---|---|
| 我明天去。 | 時間在動詞前 | 通過 |
| 他住在東邊。 | 在＋地方在動詞前 | 通過 |
| 這是我的書。 | 是連接兩個名詞 | 通過 |
| 我沒有錢。 | 有沒有使用「沒有」 | 通過 |
| 他很高。 | 性質直接作謂語 | 通過 |
| 他比我高。 | 比較結構完整 | 通過 |
| 我從中國來。 | 從字開啟介詞片語 | 通過 |
| 你喝茶還是喝水？ | 選擇問句完整 | 通過 |

### 3. 自然度檢查

最後檢查句子是否像真正中文，而不是把詞典中的字隨意排在一起。重點包括主詞是否清楚、動詞是否自然、否定是否符合時間，以及詞語次序是否自然。

| 檢查問題 | 例子 | 結果 |
|---|---|---|
| 主詞是否清楚？ | 他吃飯。 | 通過 |
| 動詞和賓語是否自然？ | 我看書。 | 通過 |
| 現在否定是否用「不」？ | 我不吃肉。 | 通過 |
| 過去否定是否用「沒有」？ | 我昨天沒有去。 | 通過 |
| 問句是否完整？ | 你叫什麼名字？ | 通過 |
| 句子是否自然？ | 請進來。 | 通過 |

本章的驗證結果是：**核心層449個詞，擴充層0個詞；檢查的例句都能由詞表組成，也都符合固定句型和中文使用習慣。** 這個結果表示 Mini-Chinese 的基本設計可以運作：以小詞表組合句子，並用固定規則控制表達。
