# 06.2 描述加類頭

找不到合適的中文詞時，可以先用「描述」說明它的用途、地點、特點或所屬，再加上「類頭」。類頭就是一個概括性的名稱，例如「車」「地方」「東西」「書」。本章要學習描述的固定公式、常用類頭，以及怎麼用這些單位說出完整的句子。

## 描述的公式

基本公式是：

**描述＋的＋類頭**

描述可以說明用途、地點、特點或所屬。

| 描述方式 | 公式 | Mini-Chinese 例句 | 意思 |
|---|---|---|---|
| 說明用途 | 給人坐的＋車 | 這是給人坐的車。 | 這是供人乘坐的車。 |
| 說明地點 | 放東西的＋地方 | 這是放東西的地方。 | 這是存放物品的地方。 |
| 說明特點 | 有紅色的＋花 | 這是有紅色的花。 | 這朵花有紅色這個特點。 |
| 說明所屬 | 屬於學生的＋書 | 這是屬於學生的書。 | 這本書屬於學生。 |
| 說明用途 | 給人喝的＋水 | 這是給人喝的水。 | 這是供人飲用的水。 |
| 說明用途 | 做飯的＋器 | 這是做飯的器。 | 這是烹調食物用的器具。 |

這些例句都使用固定公式。描述放在「的」前面，類頭放在最後。

## 類頭清單

可用的類頭如下：

| 類型 | 類頭 |
|---|---|
| 人物與一般事物 | 人、東西、事、話、心 |
| 地點與時間 | 地方、時候、樣子 |
| 意義與活動 | 意思、學問、工作、病 |
| 具體事物 | 機、車、房子、書、文、國、家、店、水、氣、色、錢、路、口、頭 |

類頭不必和原詞的意思完全一樣，只要能用來說明這類東西就可以。例如：

- 說不出一種工具的名字，可以用「做什麼用的工具」說明。
- 說不出一個地方的名字，可以用「做什麼用的地方」說明。
- 說不出一個人的名字，可以先說他的特點，再用「人」作類頭。
- 說不出一種動物的名字，可以用「像什麼的動物」或「有什麼特點的動物」說明。

同一個東西可以換不同類頭說。重要的是先選一個能說清楚用途或特點的描述。

## 在句中使用

描述加類頭可以放在「是」後面，也可以放在「有」後面。

### 「是」＋描述＋類頭

| Mini-Chinese | 意思 |
|---|---|
| 這是給人坐的車。 | 這是供人乘坐的車。 |
| 這是放東西的地方。 | 這是存放物品的地方。 |
| 這是屬於孩子的書。 | 這本書屬於孩子。 |
| 這是有藍色的花。 | 這朵花有藍色這個特點。 |
| 這是做飯的器。 | 這是烹調食物用的器具。 |

### 「有」＋描述＋類頭

| Mini-Chinese | 意思 |
|---|---|
| 我家裡有一個放東西的地方。 | 我家有一個存放物品的地方。 |
| 他有一本給人看書的書。 | 他有一本供人閱讀的書。 |
| 這裡有一個給人喝水的杯子。 | 這裡有一個供人喝水的杯子。 |
| 店裡有一個給人坐的車。 | 店裡有一輛供人乘坐的車。 |

「有」後面的描述加類頭，也可以和數字、量詞一起使用：

| Mini-Chinese | 意思 |
|---|---|
| 這裡有1個放東西的地方。 | 這裡有一個存放物品的地方。 |
| 店裡有2個給人坐的車。 | 店裡有兩輛供人乘坐的車。 |
| 他有3本給人看書的書。 | 他有三本供人閱讀的書。 |

### 對話

甲：這是給人坐的車。  
乙：這是給人走的路。  
甲：這是放東西的地方。  
乙：這是給人看書的書。  
甲：這是放東西的地方。  
乙：這是給人喝的杯子。

## 選擇合適的類頭

選擇類頭時，先問自己兩個問題：

1. 這句話要說的是一個人、一個地方，還是一件東西？
2. 使用者能不能從類頭知道這是什麼？

| 要說的內容 | 適合的類頭 | Mini-Chinese |
|---|---|---|
| 一種供人坐的東西 | 車 | 這是給人坐的車。 |
| 一個存放物品的地方 | 地方 | 這是放東西的地方。 |
| 一件供人閱讀的東西 | 書 | 這是給人看書的書。 |
| 一種供人使用的工具 | 機 | 這是給人寫字的機。 |
| 一間做生意的店 | 店 | 這是做生意的店。 |
| 一種供人飲用的液體 | 水 | 這是給人喝的水。 |
| 一個人住的地方 | 房子 | 這是給人住的房子。 |
| 一種有某種特點的花 | 花 | 這是有紅色的花。 |

如果最接近的名稱是「東西」，也可以使用它。不要只為追求簡短而選不合適的類頭。

  > 答案：東西

- [ ] 用「描述＋類頭」填空：這是屬於學生的＿＿。

  > 答案：書

- [ ] 用「描述＋類頭」填空：這是做＿＿的器。

  > 答案：飯
