# C 練習答案

本章整理各章練習的參考答案，說明如何運用基本句型、時間、地點、否定、問句、比較與連接規則。答案不是唯一的；只要句子意思正確，而且使用的字都在詞表內，就可以採用不同的說法。

## 基本句型與問句

「誰 + 做什麼」是最基本的句型。表示肯定時，直接用動詞；表示否定時，現在或將來用「不」，過去用「沒」。

| 題目 | 參考答案 |
|---|---|
| 我吃飯。 | 我吃飯。 |
| 他是學生。 | 他是學生。 |
| 我有手機。 | 我沒有手機。 |
| 你喝茶還是喝水？ | 我喝茶。 |
| 你是學生嗎？ | 是，我是學生。 |

可使用的完整例句：

- 我吃飯。
- 他是老師。
- 這是我的書。
- 我沒有手機。
- 你是學生嗎？
- 你叫什麼名字？

回答「你叫什麼名字？」時，也可以說：

> 答案：我叫小明。

「小明」是人名，第一次出現時要加說明；但這個名字由詞表外的字組成，因此本練習使用「我叫王先生」的固定方式也可以。不過「王先生」同樣不是詞表內的字。嚴格來說，人名要使用外來語說法：

> 答案：我叫小明（小明是一個人名）。

## 時間、地點與狀態

時間放在動詞前面；地點用「在 + 地方」，也放在動詞前面。表示動作正在進行時，可以用「在 + 動詞」。

| 題目 | 參考答案 |
|---|---|
| 我今天去學校。 | 我今天去學校。 |
| 他在家裡看書。 | 他在家裡看書。 |
| 我現在吃飯。 | 我正在吃飯。 |
| 他明天不來。 | 他明天不來。 |
| 我昨天沒去。 | 我昨天沒有去。 |

可使用的完整例句：

- 我明天去。
- 他昨天沒有去。
- 我們每天學中文。
- 他現在工作。
- 我在學校學中文。
- 他住在東邊。

否定句的規則如下：

| 情況 | 說法 | 例句 |
|---|---|---|
| 現在或將來 | 不 + 動詞 | 我不吃肉。 |
| 過去 | 沒有 + 動詞 | 我昨天沒有去。 |
| 擁有 | 沒有 + 事物 | 我沒有錢。 |

## 比較、連接與方向

比較句用「比」連接兩個事物；相同可以用「一樣」；最高程度用「最」。連接句子時，依照意思選擇「和」「或」「可是」「所以」等詞表內的連接詞。

| 關係 | 參考答案 |
|---|---|
| 他高，我不高。 | 他比我高。 |
| 這個貴，那個不貴。 | 這個比那個更貴。 |
| 我和你一樣大。 | 我和你一樣大。 |
| 我吃飯和喝茶。 | 我吃飯和喝茶。 |
| 這很好；但是那不好。 | 這很好，可是那不好。 |

可使用的完整例句：

- 他比我高。
- 這個比那個更貴。
- 我和你一樣大。
- 他是最好的老師。
- 我和朋友一起吃飯。
- 他從中國來。
- 我給媽媽打電話。
- 你說得很好。
- 他走得很慢。

方向要分清楚：「來」是朝向說話的人，「去」是離開說話的人。

| 題目 | 參考答案 |
|---|---|
| 請進來。 | 請進來。 |
| 他離開這裡。 | 他去了。 |
| 我拿東西進來。 | 我拿進來。 |
| 我把東西拿出去。 | 我拿出去。 |

## 練習

- [ ] 1. 將「他吃飯。」改成否定句。

> 答案：他不吃飯。

- [ ] 2. 將「我昨天去。」改成問句。

> 答案：你昨天去了嗎？

- [ ] 3. 用「比」說明：小明 1.8 米，小華 1.7 米。

> 答案：小明比小華高。

- [ ] 4. 用「在」和「家裡」說明：他現在在家裡看書。

> 答案：他現在在家裡看書。

- [ ] 5. 將「我不去。」改成過去的否定句。

> 答案：我昨天沒有去。
