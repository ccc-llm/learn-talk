# 01.1 什麼是 Mini-Chinese 簡易中文

本章介紹 Mini-Chinese 簡易中文：它是甚麼、有多少單位、可以做甚麼，以及不能做甚麼。你會看到它如何使用固定句型說出完整的句子。

## 1. 核心層與單位

Mini-Chinese 是一個受限語言。它的核心層有 **449 個單位**，目前沒有擴充層。

「單位」以漢字為主。有些單位可以單獨使用，有些單位會組合起來使用。

| 類別 | 單位數 | 例子 |
|---|---:|---|
| 代詞・指示 | 15 | 我、你、他、哪 |
| 語法 | 45 | 是、不、在、嗎 |
| 數量 | 18 | 一、幾、數、點 |
| 時間 | 19 | 今、天、年、時 |
| 方位 | 19 | 上、下、中、裡 |
| 動作 | 105 | 吃、喝、看、學 |
| 性質 | 59 | 大、小、好、冷 |
| 事物 | 157 | 人、家、書、水 |
| 社交 | 12 | 請、謝、祝、禮 |
| **總數** | **449** |  |

單位的數量可以這樣表達：

> 答案：449個。

## 2. Mini-Chinese 能做甚麼

Mini-Chinese 使用固定詞序和固定句型，可以說明人們的身份、動作、狀態、位置和時間。

| 功能 | 句型 | Mini-Chinese 例句 |
|---|---|---|
| 說明身份 | 主語＋是＋名詞 | 他是老師。 |
| 說明動作 | 主語＋動詞＋賓語 | 我吃飯。 |
| 說明位置 | 主語＋在＋地方＋動詞 | 我在學校學中文。 |
| 說明性質 | 主語＋很＋性質 | 他很高。 |
| 說明否定 | 主語＋不＋動詞 | 我明天不去。 |
| 進行比較 | A＋比＋B＋性質 | 這個比那個更貴。 |
| 提問 | 主語＋動詞＋嗎 | 你是學生嗎？ |
| 回答 | 問題＋名詞 | 我是學生。 |
| 表達所有 | 主語＋都＋動詞 | 我們都學中文。 |
| 表達選擇 | A＋還是＋B | 你喝茶還是喝水？ |

這些例句使用的單位都在核心詞表內：

> 我學中文。  
> 他看書。  
> 今天太熱了。  
> 我沒有手機。  
> 我和你一樣大。

它也能使用簡短的對話：

```text
甲：你想喝什麼？
乙：我想喝水。
甲：你想喝水還是喝茶？
乙：我想喝水。
```

## 3. Mini-Chinese 不能做甚麼

受限語言不能自由使用詞表以外的字詞，也不能使用未列出的複雜句型。

| 不能直接說 | 原因 | Mini-Chinese 的方法 |
|---|---|---|
| 她很高 | 沒有「她」這個單位 | 他很高。 |
| 這個東西很好 | 「這個東西」不是固定說法 | 這個很好。 |
| 如果下雨就不去 | 沒有固定句型 | 要是下雨就不去。 |
| 把書放在桌上 | 沒有「把」句型 | 拿書放在桌上。 |
| 她們會唱歌 | 沒有「她們」這個單位 | 他們會唱歌。 |
| 這是一個外來詞 | 沒有這個概念 | 使用外來語並加說明 |

詞表以外的一般概念，可以使用「描述＋類頭」。例如，「手機的一種」可以用來描述一個外來品牌：

> iPhone（手機的一種）

外來語第一次出現時，要用括號解釋。括號中的解釋也要使用詞表內的字詞：

> iPhone（手機的一種）很好。  
> Tokyo（日本的城）很大。

Mini-Chinese 是一個可以組合的語言。學會詞表和句型後，可以使用不同單位組合出很多句子。但是，它不是完整的中文；不能表達的內容要換句話說，或使用描述＋類頭。

## 4. 使用詞表和句型

寫 Mini-Chinese 時，要先檢查字詞，再檢查句型。

| 檢查項目 | 問題 | 例子 |
|---|---|---|
| 字詞 | 每個單位都在詞表內嗎？ | 使用「他」，不用「她」。 |
| 詞序 | 動詞前面放時間和地點嗎？ | 我明天在學校學中文。 |
| 否定 | 現在用「不」，過去用「沒」嗎？ | 我不去。我昨天沒去。 |
| 數字 | 數字後面有量詞嗎？ | 3個朋友。 |
| 性質 | 性質前面不加「是」嗎？ | 他很高。 |
| 問句 | 一般問句使用「嗎」嗎？ | 你來嗎？ |

簡單來說，Mini-Chinese 的使用順序是：

1. 先選詞表內的單位。
2. 再選固定句型。
3. 把時間和地點放在動詞前面。
4. 如果缺少字詞，就換一種說法。
