# 04.4 困難結構的固定替代

本章學習 Mini-Chinese 不使用的複雜句型，以及如何用固定、簡單的說法表達相同意思。遇到表外的概念時，可以先說明意思，再用固定句型重說。

## 不用「把」和「被」

中文常有「把」字句和「被」字句。Mini-Chinese 不使用這些結構，必須改說。

| 困難結構 | 固定替代 |
|---|---|
| 把＋東西＋動詞 | 拿東西＋動詞，或先說東西 |
| 被＋人＋動詞 | 有人＋動詞，或「是……的」 |
| 把東西給人 | 拿東西給人 |

例如：

- 我拿書給你。
- 有人打他。
- 我的書看完了。

「我的書看完了」用「是……的」表示東西受到動作。

## 不用的時間和否定結構

Mini-Chinese 用「了」表示動作完成，不使用「已經」。否定也分成「不」和「沒」：「不」用於現在、將來和習慣；「沒」用於過去和「有」。

| 困難結構 | 固定替代 | 完整例句 |
|---|---|---|
| 已經＋動詞 | 動詞＋了 | 他到了。 |
| 已經＋動詞 | 動詞＋了 | 我去了。 |
| 現在、將來、習慣的否定 | 不＋動詞 | 我不吃肉。 |
| 過去的否定 | 沒＋動詞 | 我昨天沒去。 |
| 沒有某物 | 沒＋有 | 我沒有手機。 |

時間也可以放在主語後面，但要在動詞前面：

- 我明天去。
- 今天晚上我在家。
- 他下午回來。

## 用固定說法代替條件和轉折

Mini-Chinese 不使用「如果……就……」和「雖然……但是……」。這兩種意思有固定替代法。

| 困難結構 | 固定替代 | 完整例句 |
|---|---|---|
| 如果……就…… | 要是……就…… | 要是下雨，就不去了。 |
| 雖然……但是…… | 是……，可是…… | 他是老師，可是他很忙。 |
| 即使……也…… | 就是……也…… | 就是你來，他也高興。 |
| 只有……才…… | 不……就不…… | 不學就不會。 |
| 無論……都…… | 誰都……、什麼都…… | 誰都會說中文。 |

固定替代可以保留原句的重要意思，不需要說出表外的詞。

## 不用複雜的動作和比較方式

Mini-Chinese 不使用「著」「越來越」「除了」和「或者」。動作正在進行時，用「在」加動詞；比較變化時，用「一天比一天……」；選擇時，用「還是」。

| 困難結構 | 固定替代 | 完整例句 |
|---|---|---|
| 動詞＋著 | 在＋動詞 | 他在唱歌。 |
| 越來越…… | 一天比一天…… | 他一天比一天高。 |
| 除了……以外 | ……以外 | 這裡以外沒有人。 |
| 或者…… | 還是…… | 你喝茶還是喝水？ |
| 或者…… | ……也可以 | 你喝茶，也可以喝水。 |
| 必須…… | 要……、得…… | 你要學中文。 |
| 應該…… | 要……、最好…… | 你最好早點來。 |

### 對話

甲：你明天去嗎？  
乙：我要去。  
甲：好。  
乙：好。

## 練習

- [ ] 1. 把「我把書給你。」改成不用「把」的說法。

> 答案：我拿書給你。

- [ ] 2. 把「他很高興，可是他很忙。」改成「雖然……但是……」以外的固定說法。

> 答案：他是很高興，可是他很忙。

- [ ] 3. 把「如果下雨，我就不去。」改成不用「如果……就……」的說法。

> 答案：要是下雨，我就不去。

- [ ] 4. 把「他每天都在唱歌。」改成不用「著」的說法。

> 答案：他每天都在唱歌。

- [ ] 5. 把「這裡以外沒有人。」說明意思。

> 答案：這裡沒有人，那邊沒有人。
