# 09.2 接下來會做什麼

## 09.2 接下來會做什麼

### 1. future 句型：`(으)ㄹ 거예요`

`거예요` 表示「將要……」。動詞後面加上 `ㄹ 거예요` 或 `을 거예요`，說明接下來要做的事。

| 動詞 | 變化 | 完整句 |
|---|---|---|
| 가요 | 갈 거예요 | 저는 내일 카페에 갈 거예요. |
| 공부해요 | 공부할 거예요 | 저는 다음주에 한국어를 공부할 거예요. |
| 여행해요 | 여행할 거예요 | 저는 다음달에 여행할 거예요. |
| 읽어요 | 읽을 거예요 | 저는 오늘밤에 책을 읽을 거예요. |
| 만나요 | 만날 거예요 | 저는 다음 주에 친구를 만날 거예요. |
| 먹어요 | 먹을 거예요 | 저는 점심에 밥을 먹을 거예요. |

變化規則：

- 動詞最後有收音時，使用 `을 거예요`。
- 動詞最後沒有收音時，使用 `ㄹ 거예요`。

### 2. 表示時間的詞

| 詞 | 意思 |
|---|---|
| 내일 | 明天 |
| 오늘밤 | 今夜 |
| 다음주 | 下週 |
| 다음달 | 下個月 |
| 이번주 | 本週 |
| 이번달 | 本月 |

`다음주` 和 `다음 달` 是詞表裡的完整詞，不分開使用。

### 3. 否定句

否定可以放在動詞前面：

- 저는 내일 카페에 **안 갈** 거예요.
- 저는 다음 주에 한국어를 **안 공부할** 거예요.
- 저는 오늘밤에 책을 **못 읽을** 거예요.

### 4. 對話

```text
甲：내일 뭐예요?
乙：내일 카페에 갈 거예요.
甲：다음 주에 무엇을 공부할 거예요?
乙：한국어를 공부할 거예요.
甲：다음달에 어디에 갈 거예요?
乙：다음달에 여행하러 갈 거예요.
```

```text
甲：오늘밤에 뭐해요?
乙：오늘밤에 책을 읽을 거예요.
甲：내일도요?
乙：네. 내일에도 공부를 할 거예요.
```

### 5. 常用句型

| 意思 | Mini-Korean |
|---|---|
| 我將要去某個地方 | `저는 내일 카페에 갈 거예요.` |
| 我將要學習某種語言 | `저는 다음 주에 한국어를 공부할 거예요.` |
| 我將要去旅行 | `저는 다음달에 여행하겠어요.` → `저는 다음달에 여행할 거예요.` |
| 我將要在某個時間讀書 | `저는 오늘밤에 책을 읽을 거예요.` |
| 我將要和朋友見面 | `저는 다음 주에 친구를 만날 거예요.` |
| 我不會去那個地方 | `저는 내일 카페에 안 갈 거예요.` |

### 6. 練習

- [ ] 저는 내일 카페에 ________ 거예요.

- [ ] 저는 다음 주에 한국어를 ________ 거예요.

- [ ] 저는 다음달에 ________ 거예요.

- [ ] 저는 오늘밤에 책을 ________ 거예요.

> 答案：갈

> 答案：공부할

> 答案：여행할

> 答案：읽을
