# 01.2 為什麼 1076 個單位就夠了

Mini-Korean 不是把所有常用單字都塞進詞表，而是挑出「能組成很多句子」的單位。1076 個單位包含 659 個核心單位和 417 個擴充單位。數量雖然不多，但是靠助詞、動詞、形容詞和名詞的組合，就能表達日常生活的許多內容。選詞的關鍵不是「出現幾次」，而是「能表達多少意思」。

## 1. 表達力比詞頻更重要

所謂「詞頻」，是指一個詞在日常語言中使用得有多頻繁。但對初學者來說，使用頻率不一定等於學習價值。

例如，「가요」可以出現在很多句型裡：

| 例子 | 說明 |
|---|---|
| 저는 학교에 가요. | 我去學校。 |
| 친구가 와요. | 朋友來了。 |
| 기차가 역에 가요. | 火車去車站。 |

「가요」只有一個單位，卻可以和許多不同的主語、場所搭配。相反地，有些很低頻的單位，例如「흙」那樣的具體名詞，即使學會了，也只能用在很少的場合。

因此，Mini-Korean 的選詞原則是：

| 選擇方式 | 結果 |
|---|---|
| 只選最高頻的詞 | 詞彙量少，但能表達的內容也少 |
| 選能反覆組合的詞 | 詞彙量適中，但能組成更多句子 |
| 收錄很少使用的詞 | 看起來很全面，實際上學習負擔很大 |

重點不是背下很多「常常出現」的名詞，而是學會可以搭配很多句子的單位。

## 2. 一個單位可以生出很多句子

Mini-Korean 透過「名詞＋助詞＋動詞」和「名詞＋助詞＋形容詞」製造變化。

### 名詞加助詞

| 單位 | 組合例子 | 說明 |
|---|---|---|
| 학생 | 학생이에요. | 這個人是學生。 |
| 학생 | 학생이 와요. | 學生來了。 |
| 학생 | 학생과 가요. | 和學生一起去。 |
| 학생 | 학생을 만나요. | 遇見學生。 |

同一個「학생」可以出現在四個句子裡。改變的不是名詞本身，而是搭配的助詞。

### 地點加助詞

| 單位 | 組合例子 | 說明 |
|---|---|---|
| 학교 | 학교에 가요. | 去學校。 |
| 학교 | 학교에서 공부해요. | 在學校學習。 |
| 집 | 집에 있어요. | 在家裡。 |
| 집 | 집에서 밥을 먹어요. | 在家裡吃飯。 |

「에」和「에서」的意思不同，但只增加了兩個小單位，就能表現「去哪裡」和「在哪裡」。

### 形容詞加助詞

| 單位 | 組合例子 | 說明 |
|---|---|---|
| 사과 | 사과가 빨개요. | 蘋果是紅的。 |
| 사과 | 사과를 먹어요. | 吃蘋果。 |
| 방 | 방이 넓어요. | 房間很寬。 |
| 방 | 방에 가요. | 去房間。 |

動詞和形容詞也可以帶來更多變化：

- 물을 마셔요. 喝水。
- 물이 차가워요. 水是冷的。
- 이불을 씁니다. —— 「이불」不在詞表內，所以不用這個例子。
- 책이 재미있어요. 書很有趣。
- 책을 읽어요. 讀書。

也就是說，動詞、形容詞和助詞之間可以互相搭配。學會一個新單位，往往不只增加一個詞，而是增加很多可以使用的組合。

## 3. 核心單位負責「常用」，擴充單位負責「替換」

659 個核心單位先建立日常最常用的表達。417 個擴充單位則用來補充說法，讓句子可以更精確，也可以在核心單位不方便時提供替代方案。

| 類型 | 功能 | 例子 |
|---|---|---|
| 核心單位 | 建立基本會話 | 가요、먹어요、학교、친구 |
| 擴充單位 | 增加說法和選擇 | 같이、때、장소에 가까운 사람 |
| 助詞 | 改變句子關係 | 는、을、에、에서、의 |
| 動詞與形容詞 | 表達動作和狀態 | 공부해요、좋아요、작아요 |

例如只說「학교에 가요」，可以清楚表達「去學校」。但需要說明原因時，就可以增加另一個句子：

- 오늘은 비가 와요. 今天下雨。
- 그래서 집에 가요. 所以回家。

擴充單位不需要無限增加。只要遇到「常用說法可以準確表達」的情況，就不必再增加同義詞。例如「예요」和「이에요」都能表達「是」，教材可以先固定使用其中一種，避免初學者同時記憶很多形式。

這樣做有三個好處：

1. **句子更容易組合**：每個單位都有清楚的位置。
2. **學習負擔較小**：不用同時記憶很多罕用詞。
3. **仍然能表達真實生活**：核心單位可以覆蓋大部分日常對話。

1076 個單位之所以「夠用」，不是因為它們涵蓋了所有詞語，而是因為它們具有足夠的組合能力。只要學會這些單位和搭配規則，就能用同一批材料說出許多不同的句子。

## 4. 練習

- [ ] 用「물」造一句話，說明水是冷的。

> 答案：물이 차가워요.

- [ ] 用「학교」和「에서」造句，表示在學校學習。

> 答案：학교에서 공부해요.

- [ ] 用「친구」和「를」造句，表示遇見朋友。

> 答案：친구를 만나요.

- [ ] 用「어제」和「만나요」造一句完整的話。

> 答案：어제 저는 친구를 만나요.

- [ ] 說出這一章選詞時最重要的兩個重點。

> 答案：표達力, 詞頻
