# 06.2 描述加類頭

## 06.2 描述加類頭

### 1. 什麼是「描述加類頭」？

有些概念不在 Mini-Korean 詞表裡。這時可以用：

1. **描述**：說明它的行為、用途或特徵。
2. **類頭**：放在描述後面，表示這是「人」、「地方」或「事情」。

例如：

- 讀書的人 → `책을 읽는 사람이에요.`
- 做飯的人 → `요리하는 사람이에요.`
- 運動的人 → `운동하는 사람이에요.`
- 讀書的地方 → `공부하는 곳이에요.`
- 做飯的地方 → `요리하는 곳이에요.`
- 運動的事情 → `운동하는 일이에요.`

### 2. 描述人的句型

| 描述 | Mini-Korean | 意思 |
|---|---|---|
| 做某事的人 | `…하는 사람이에요.` | 某種人 |
| 讀某物的人 | `…을 읽는 사람이에요.` | 閱讀某物的人 |
| 吃某物的人 | `…을 먹는 사람이에요.` | 吃某物的人 |
| 喝某物的人 | `…을 마시는 사람이에요.` | 喝某物的人 |
| 休息的人 | `…는 사람이에요.` | 休息的人 |

例句：

- `공부하는 사람이에요.`
- `요리하는 사람이에요.`
- `운동하는 사람이에요.`
- `일하는 사람이에요.`
- `책을 읽는 사람이에요.`
- `밥을 먹는 사람이에요.`
- `물을 마시는 사람이에요.`
- `집에서 쉬는 사람이에요.`

### 3. 描述地方的句型

描述地方時，常用「做某事的地方」：

> `…하는 곳이에요.`

| 描述 | Mini-Korean | 意思 |
|---|---|---|
| 讀書的地方 | `책을 읽는 곳이에요.` | 讀書的地方 |
| 吃飯的地方 | `밥을 먹는 곳이에요.` | 吃飯的地方 |
| 做飯的地方 | `요리하는 곳이에요.` | 做飯的地方 |
| 運動的地方 | `운동하는 곳이에요.` | 運動的地方 |
| 休息的地方 | `쉬는 곳이에요.` | 休息的地方 |
| 工作的地方 | `일하는 곳이에요.` | 工作的地方 |

例句：

- `이곳은 공부하는 곳이에요.`
- `저곳은 요리하는 곳이에요.`
- `운동하는 곳이에요.`
- `책을 읽는 곳이에요.`
- `밥을 먹는 곳이에요.`
- `집에서 쉬는 곳이에요.`
- `회사에 일하는 곳이에요.`

### 4. 描述事情的句型

描述某種事情時，可以用：

> `…하는 일이에요.`

| 描述 | Mini-Korean | 意思 |
|---|---|---|
| 讀書的事情 | `책을 읽는 일이에요.` | 讀書這件事 |
| 做飯的事情 | `요리하는 일이에요.` | 做飯這件事 |
| 運動的事情 | `운동하는 일이에요.` | 運動這件事 |
| 學習的事情 | `공부하는 일이에요.` | 學習這件事 |
| 工作的事情 | `일하는 일이에요.` | 工作這件事 |
| 休息的事情 | `쉬는 일이에요.` | 休息這件事 |

例句：

- `이것은 요리하는 일이에요.`
- `그것은 공부하는 일이에요.`
- `책을 읽는 일이에요.`
- `밥을 먹는 일이에요.`
- `운동하는 일이에요.`
- `집에서 쉬는 일이에요.`
- `회사에 일하는 일이에요.`

### 5. 描述工具和材料

如果想說某個工具或材料，但名稱不在詞表裡，可以先描述它的用途：

- 用來切東西的工具 → `나이프예요.`
- 用來喝水的容器 → `컵이에요.`
- 用來裝水的瓶子 → `병이에요.`
- 做菜用的材料 → `고기예요.`
- 吃的材料 → `과일이에요.`
- 喝的材料 → `우유예요.`

也可以改成使用「地方」或「事情」的說法：

- `나이프를 쓰는 곳이에요.`
- ` 컵을 쓰는 곳이에요.`
- `병을 쓰는 곳이에요.`
- `고기를 먹는 일이에요.`
- `과일을 먹는 일이에요.`
- `우유를 마시는 일이에요.`

### 6. 描述問題

不知道某件事的名稱時，可以描述問題的內容：

- `이것은 문제예요.`
- `네, 문제예요.`
- `이 문제는 사람에 관한 문제예요.`
- `이 문제는 공부에 관한 문제예요.`
- `이 문제는 일에 관한 문제예요.`
- `이 문제는 물에 관한 문제예요.`
- `이것은 쉬운 문제예요.`

### 7. 對話

甲：`이것은 문제예요?`

乙：`네, 문제예요.`

甲：`무슨 문제예요?`

乙：`공부에 관한 문제예요.`

甲：`공부하는 사람도 있어요?`

乙：`네, 학생이에요.`

甲：`이곳은 공부하는 곳이에요?`

乙：`네, 도서관이에요.`

### 8. 常用結構

| 功能 | 結構 | Mini-Korean |
|---|---|---|
| 描述做某事的人 | 動作 + `하는` + `사람` | `요리하는 사람이에요.` |
| 描述做某事的地方 | 動作 + `하는` + `곳` | `공부하는 곳이에요.` |
| 描述某件事 | 動作 + `하는` + `일` | `운동하는 일이에요.` |
| 描述行為對象 | 動作 + `은／는` + `사람` | `물을 마시는 사람이에요.` |
| 說明問題內容 | `…에 관한` + `문제` | `공부에 관한 문제예요.` |

### 9. 練習

- [ ] 用「描述＋類頭」說「讀書的人」。

> 答案：`책을 읽는 사람이에요.`

- [ ] 用「描述＋類頭」說「做飯的地方」。

> 答案：`요리하는 곳이에요.`

- [ ] 用「描述＋類頭」說「運動這件事」。

> 答案：`운동하는 일이에요.`

- [ ] 修正錯誤的句子：`그건 문제예요?`

> 答案：`이것은 문제예요?`
