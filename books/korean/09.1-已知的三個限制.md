# 09.1 已知的三個限制

這一章要學習 Mini-Korean 的 3 個限制：詞彙範圍有限、句型比較固定、意思不會非常細緻。遇到詞表以外的內容時，可以先用描述或簡單句型說明。

## 限制一：詞彙範圍有限

Mini-Korean 不能直接說出所有名詞。遇到詞表以外的事物時，可以使用「描述 ＋ 類頭」或較簡單的名詞。

| 想表達的內容 | 替代說法 | Mini-Korean |
|---|---|---|
| 醫生 | 醫生 | 의사 |
| 不在詞表內的工具 | 工具 | 도구 |
| 某種東西 | 東西 | 것 |
| 某個地方 | 地方 | 곳 |
| 某件事情 | 事情 | 일 |

### 例句

1. 이것은 기계예요.
2. 그것은 도구예요.
3. 저는 한국어를 공부해요.
4. 이것은 물이에요.
5. 그곳은 시장이에요.

學習新單字時，可以先問對方一個簡單的問題：

> 乙：이것은 무엇이에요?  
> 甲：이것은 기계예요.

## 限制二：句型比較固定

Mini-Korean 偏好短句和簡單句型。一句話最好只說一件事，也可以把並列的內容分成幾句。

| 完整意思 | Mini-Korean |
|---|---|
| 我是學生。我也去。 | 저는 학생이에요. 저도 가요. |
| 今天是星期五。明天去圖書館。 | 오늘은 금요일이에요. 내일은 도서관에서 공부해요. |
| 我和朋友一起去。 | 친구하고 같이 가요. |
| 咖啡廳裡喝咖啡。 | 카페에서 커피를 마셔요. |

### 例句

1. 저는 학생이에요. 오늘은 학교에 가요.
2. 내일은 도서관에서 공부해요.
3. 저는 친구를 만나요. 친구와 같이 가요.
4. 저는 카페에서 커피를 마셔요.
5. 날씨가 좋아요. 그래서 공원에 가요.

遇到很長的內容時，可以分成幾個短句：

> 甲：저는 학교에 가요.  
> 乙：무엇을 공부해요?  
> 甲：저는 한국어를 공부해요.  
> 乙：왜 가요?  
> 甲：오늘은 금요일이에요. 그래서 시간이 많아요.

## 限制三：意思不會非常細緻

Mini-Korean 可以表達基本心情和簡單關係，但不能常常表達非常細微的意思。這時可以先選擇最接近的詞，再用簡單句補充。

| 意思 | 簡單說法 | Mini-Korean |
|---|---|---|
| 我很高興 | 高興 | 반가워요 |
| 我很喜歡 | 喜歡 | 좋아해요 |
| 我有一點點難過 | 難過 | 슬퍼요 |
| 我覺得有趣 | 有趣 | 재미있어요 |
| 關係很好 | 關係 | 관계가 좋아요 |

### 例句

1. 오늘은 기분이 좋아요.
2. 저는 커피를 좋아해요.
3. 이 책은 재미있어요.
4. 그 사람과 관계가 좋아요.
5. 오늘은 조금 슬퍼요.

不知道怎麼說時，也可以用固定方式回答：

> 乙：무엇이에요?  
> 甲: 아니요.

> 乙：이것은 무엇이에요?  
> 甲: 잘 모르겠어요.

> 乙：왜 가요?  
> 甲: 지금은 잘 모르겠어요.

## 練習

- [ ] 1. 用 Mini-Korean 說：「我是一個學生。今天去學校。」

> 答案：저는 학생이에요. 오늘은 학교에 가요.

- [ ] 2. 用 Mini-Korean 說：「明天在圖書館學習韓語。」

> 答案：내일은 도서관에서 한국어를 공부해요.

- [ ] 3. 用 Mini-Korean 說：「咖啡廳裡和朋友一起喝咖啡。」

> 答案：카페에서 친구하고 같이 커피를 마셔요.

- [ ] 4. 用 Mini-Korean 說：「今天心情很好，所以去公園。」

> 答案：오늘은 기분이 좋아요. 그래서 공원에 가요.

- [ ] 5. 把「我很高興見到你。」改成 Mini-Korean。

> 答案：반갑습니다.
