# 05.1 見面與自我介紹

## 1. 打招呼

第一次見面時，可以使用固定的問候語。

| 表達 | 意思 |
|---|---|
| 안녕히 가요. | 再見。 |
| 반갑습니다. | 很高興見到你。 |
| 만나요. | 見面。 |
| 만나서 반갑습니다. | 很高興見到你。 |
| 인사해요. | 打招呼。 |

對話：

```text
甲：안녕히 가요.
乙：안녕히 가요.
```

```text
甲：만나서 반갑습니다.
乙：만나서 반갑습니다.
```

## 2. 自我介紹

介紹自己的時候，可以使用「저는……」或「제……」開頭的句子。

| 表達 | 意思 |
|---|---|
| 저는 학생이에요. | 我是學生。 |
| 저는 선생님이에요. | 我是老師。 |
| 저는 회사원이에요. | 我是公司職員。 |
| 제 이름은 수진이에요. | 我的名字是秀珍。 |
| 저는 민수이에요. | 我是民秀。 |
| 저는 중국어 학생이에요. | 我是中文 student。 |
| 저는 한국어 학생이에요. | 我是韓語學生。 |

「회사원」不在核心詞表內，可以使用同義的「직장인」。

```text
甲：안녕히 가요. 저는 학생이에요.
乙：만나서 반갑습니다. 저는 선생님이에요.
```

```text
甲：제 이름은 수진이에요.
乙：반갑습니다.
```

## 3. 介紹別人

介紹身旁的人時，可以使用「그 사람은……이에요」。不要使用詞表外的「이 사람」。

| 表達 | 意思 |
|---|---|
| 그 사람은 학생이에요. | 那個人是學生。 |
| 그 사람은 선생님이에요. | 那個人是老師。 |
| 그 사람은 회사원이에요. | 那個人是公司職員。 |
| 그 사람은 친구예요. | 那個人是朋友。 |
| 그 사람은 이름이에요. | 那個人有名。 |

```text
甲：그 사람은 학생이에요.
乙：네, 학생이에요.
```

```text
甲：그 사람은 선생님이에요.
乙：아니요, 학생이에요.
```

## 4. 回答身分問題

回答問題時，可以使用「네」「예요」或「아니요」。

| 問題 | 回答 |
|---|---|
| 학생이에요? | 네, 학생이에요. |
| 선생님이에요? | 아니요, 학생이에요. |
| 회사원이에요? | 네, 직장인이에요. |
| 한국어 학생이에요? | 네, 한국어 학생이에요. |

對話：

```text
甲：학생이에요?
乙：네, 학생이에요.
```

```text
甲：선생님이에요?
乙：아니요, 학생이에요.
```

```text
甲：회사원이에요?
乙：네, 직장인이에요.
```

## 5. 表達初次見面

第一次見面時，可以先打招呼，再介紹自己。

```text
甲：안녕히 가요.
乙：만나서 반갑습니다.
甲：저는 회사원이에요.
乙：저는 학생이에요.
```

也可以使用「이름」介紹名字。

```text
甲：제 이름은 수진이에요.
乙：만나서 반갑습니다. 저는 민수이에요.
```

## 6. 常見錯誤

| 錯誤說法 | 正確說法 | 原因 |
|---|---|---|
| 안녕히 주세요. | 안녕히 가요. | 「주세요」不在詞表內。 |
| 저는 회사원이에요. | 저는 직장인이에요. | 「회사원」不在詞表內。 |
| 만나서 반갑습니다. | 만나요. 반갑습니다. | 「만나서」不在詞表內。 |
| 제 이름은 수진이에요. | 제 이름은 수진 (사람 이름)이에요. | 人名第一次出現時加上說明。 |
| 아니요, 학생이 아니에요. | 아니요, 저는 학생이 아니에요. | 完整回答需要主語。 |
| 이 사람은 학생이에요. | 그 사람은 학생이에요. | 「이」不在詞表內。 |
| 이 사람은 선생님이에요. | 그 사람은 선생님이에요. | 「이」不在詞表內。 |
| 이 사람은 회사원이에요. | 그 사람은 직장인이에요. | 「이」與「회사원」不在詞表內。 |

## 7. 課本對話

```text
甲：안녕히 가요. 저는 학생이에요.
乙：만나서 반갑습니다. 제 이름은 수진 (사람 이름)이에요.
甲：만나서 반갑습니다. 저는 민수 (사람 이름)이에요.
乙：그 사람은 선생님이에요?
甲：아니요, 저는 학생이에요.
乙：저도 학생이에요.
甲：우리도 같이 가요.
乙：네, 같이 가요.
```

## 練習

- [ ] 請把「저는 회사원이에요.」改成符合詞表規則的句子。

> 答案：저는 직장인이에요.

- [ ] 請把「이 사람은 학생이에요.」改成符合詞表規則的句子。

> 答案：그 사람은 학생이에요.

- [ ] 請用「만나요」和「반갑습니다」寫兩句打招呼的話。

> 答案：만나요. 반갑습니다.

- [ ] 請用「제 이름은」介紹自己的名字。

> 答案：제 이름은 수진 (사람 이름)이에요.
