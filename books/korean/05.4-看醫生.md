# 05.4 看醫生

## 1. 這一章會用到的詞

| Mini-Korean | 中文 |
|---|---|
| 병원 | 醫院 |
| 의사 | 醫生 |
| 약사 | 藥劑師 |
| 약 | 藥 |
| 환자 | 患者 |
| 몸 | 身體 |
| 머리 | 頭 |
| 목 | 脖子 |
| 가슴 | 胸部 |
| 허리 | 腰部 |
| 다리 | 腿 |
| 아프 | 痛 |
| 뜨거워요 | 燙、發熱 |
| 차가워요 | 冷 |
| 많이 | 很多；長時間地 |
| 몇 날 | 幾天 |
| 만나요 | 見面 |
| 도와요 | 幫助 |
| 받아요 | 收到 |
| 괜찮아요 | 沒關係 |

> 「기침해요」不能直接使用。可以描述為：「목에서 소리가 나요.」  
> 「열이 나요」不能直接使用。可以描述為：「몸이 뜨거워요.」  
> 「힘이 없어요」不能直接使用。可以改說：「몸이 안 좋아요.」

## 2. 在醫院

患者去醫院，先找醫生。

> 병원에 가요.  
> 환자가 병원에 가요.  
> 환자는 의사를 만나요.  
> 환자는 병원에서 의사에게 설명해요.  
> 의사에게 약을 받아요.

「환자는 의사를 만나요.」

- `환자는`：主題。
- `의사를`：賓語。
- `만나요`：動詞。

醫生先問哪裡不舒服。

> 어디가 아파요?  
> 머리가 아파요?  
> 목이 아파요?  
> 가슴이 아파요?  
> 허리가 아파요?  
> 다리가 아파요?

回答時，可以使用：

> 네, 머리가 아파요.  
> 아니요, 다리가 아파요.  
> 그게요, 많이 아파요.  
> 몇 날 아파요.

「그게요」不在固定詞表中，因此應避免使用。自然的固定回答是：

> 네, 많이 아파요.  
> 네, 몇 날 아파요.

## 3. 描述不舒服的狀態

詞表沒有「증상」這個詞。可以描述身體的狀態。

| 中文概念 | Mini-Korean 描述 |
|---|---|
| 咳嗽 | 목에서 소리가 나요. |
| 發燒 | 몸이 뜨거워요. |
| 發冷 | 몸이 차가워요. |
| 身體不適 | 몸이 안 좋아요. |
| 沒有精神 | 몸이 안 좋아요. |
| 頭痛 | 머리가 아파요. |
| 喉嚨痛 | 목이 아파요. |
| 胸痛 | 가슴이 아파요. |
> 腰痛 | 허리가 아파요. |
| 腿痛 | 다리가 아파요. |

也可以詢問疼痛持續多久：

> 언제부터 아파요?  
> 그게요?  
> 며칠 아파요?

應改成：

> 언제부터 아파요?  
> 네, 몇 날 아파요.

## 4. 診斷與拿藥

醫生查看患者的身體。

> 의사에게 설명해요.  
> 의사에게 보여요.  
> 의사가 몸을 봐요.  
> 의사가 다리를 봐요.  
> 의사가 머리를 봐요.

「診斷」不直接出現在 Mini-Korean 中，可以用醫生查看身體的動作描述。

> 의사에게 약을 받아요.  
> 약사가 약을 줘요.  
> 약을 먹어요.  
> 약이 좀 effect 있어요.

最後一句的 `effect` 不在詞表中，應改成：

> 약을 먹어요.  
> 약을 먹고 쉬어요.

如果沒有問題，可以回答：

> 괜찮아요?  
> 네, 괜찮아요.  
> 아니요, 아직 아파요.

## 5. 醫院對話

甲：어디가 아파요?

乙：네, 머리가 아파요. 목에서도 소리가 나요.

甲：몸이 뜨거워요?

乙：네, 조금 뜨거워요.

甲：언제부터 아파요?

乙：몇 날 아파요.

甲：의사가 몸을 봐요.

乙：네, 도와주세요.

甲：약은 이따 받아요. 약을 먹고 푹 쉬세요.

乙：감사합니다.

## 6. 常用句型

### 描述某個部位不舒服

> `[部位]`가 아파요.

例子：

> 머리가 아파요.  
> 목이 아파요.  
> 허리가 아파요.

### 詢問疼痛開始的時間

> 언제부터 아파요?

回答：

> 오늘부터 아파요.  
> 어제부터 아파요.  
> 몇 날 아파요.

### 描述發燒

> 몸이 뜨거워요.

### 描述發冷

> 몸이 차가워요.

### 描述身體不適

> 몸이 안 좋아요.

### 描述咳嗽

> 목에서 소리가 나요.

### 在醫院拿藥

> 의사에게 약을 받아요.  
> 약을 먹어요.  
> 약을 먹고 쉬어요.

## 7. 詞形替換練習

| 原句 | 替換後的句子 |
|---|---|
| 머리가 아파요. | 목이 아파요. |
| 몸이 뜨거워요. | 몸이 차가워요. |
| 오늘부터 아파요. | 어제부터 아파요. |
| 약을 먹어요. | 약을 먹고 쉬어요. |

## 練習

- [ ] 1. 「我從昨天開始頭痛。」

> 答案：어제부터 머리가 아파요.

- [ ] 2. 「患者去醫院見醫生。」

> 答案：환자가 병원에 가요. 환자는 의사를 만나요.

- [ ] 3. 「我的身體不舒服，有點發燒。」

> 答案：몸이 안 좋아요. 조금 뜨거워요.

- [ ] 4. 「我咳嗽。」

> 答案：목에서 소리가 나요.

- [ ] 5. 「我在醫院拿到藥，然後吃藥休息。」

> 答案：병원에서 약을 받아요. 약을 먹고 쉬어요.
