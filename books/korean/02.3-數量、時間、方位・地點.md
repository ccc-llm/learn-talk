## 02.3 數量、時間、方位・地點

### 數量

韓語的數字用阿拉伯數字，量詞只有少數幾個常用的。

| 韓語例句 | 中文意思 |
|---|---|
| 학생이 3명이에요. | 有 3 名學生。 |
| 과자가 2개예요. | 點心有 2 個。 |
| 저는 20살이에요. | 我 20 歲。 |
| 어제 친구를 2번 만났어요. | 昨天見了朋友 2 次。 |
| 5년 동안 한국어를 공부해요. | 學韓語 5 年。 |
| 3시간 동안 여행했어요. | 旅行了 3 小時。 |
| 이 문제는 어렵지 않아요. | 這個問題不難。 |

- 個：개（1개, 2개, 3개…）
- 名：명（1명, 2명, 3명…）
- 次：번（1번, 2번…）
- 歲：살（10살, 20살…）
- 時間：시간（1시간, 2시간…）
- 年：년（1년, 2년…）

### 時間

一週的七天各有專門的名詞；日期用「이번 주、다음 주、지난 주」這組說法。

| 韓語例句 | 中文意思 |
|---|---|
| 오늘은 월요일이에요. | 今天是星期一。 |
| 내일 학교에 가요. | 明天去學校。 |
| 모레 친구를 만나요. | 後天見朋友。 |
| 어제 친구를 만났어요. | 昨天見了朋友。 |
| 지금 밥을 먹어요. | 現在正在吃飯。 |
| 아침에 커피를 마셔요. | 早上喝咖啡。 |
| 오늘밤에 공부해요. | 今晚學習。 |
| 오후에 쇼핑해요. | 下午購物。 |
| 3시에 친구와 만나요. | 3 點和朋友見面。 |
| 이번 주에 운동해요. | 這週運動。 |
| 다음 주에 여행해요. | 下週旅行。 |
| 지난 주에는 추워요. | 上週很冷。 |
| 매일 아침에 운동해요. | 每天早上運動。 |
| 주말에 영화를 봐요. | 週末看電影。 |
| 이번 달에 한국어를 배워요. | 這個月學韓語。 |

- 昨天：어제／昨夜：어젯밤
- 今天：오늘／今夜：오늘밤
- 明天：내일／明晚：내일밤
- 前天：그저께／大前天：그글피
- 後天：모레／大後天：글피
- 本週：이번 주／下週：다음 주／上週：지난 주

### 方位・地點

地點的名詞很多，助詞要分清楚：「에」表示目的地和存在的地點，「에서」表示動作發生的場所。

| 韓語例句 | 中文意思 |
|---|---|
| 집에 가요. | 回家。 |
| 학교에서 공부해요. | 在學校學習。 |
| 도서관에서 책을 읽어요. | 在圖書館看書。 |
| 카페에서 커피를 마셔요. | 在咖啡廳喝咖啡。 |
| 학교 앞에서 기다려요. | 在學校前面等。 |
| 역에서 택시를 기다려요. | 在車站等計程車。 |
| 산에 가요. | 去山上。 |
| 바다에 가요. | 去海邊。 |
| 집 안에 있어요. → 집 안에 있어요는 「있다」說法。 | 在家裡面。 |
| 친구는 집 옆에 있어요. | 朋友在房子旁邊。 |
| 위에서 먹어요. | 從上面吃（東西）。 |
| 아래에 있어요. | 在下面。 |
| 학교에서 집까지 걸어요. | 從學校走到家。 |
| 이 길은 좁아요. | 這條路很窄。 |
| 출발지는 여기예요. | 出發地是這裡。 |
| 목적지는 거기예요. | 目的地是那裡。 |

- 方向：동쪽（東）、서쪽（西）、남쪽（南）、북쪽（北）、왼쪽（左）、오른쪽（右）
- 位置：위（上面）、아래（下面）、앞（前面）、뒤（後面）、옆（旁邊）、안（裡面）、밖（外面）
- 遠近：가까이（近）、멀리（遠）、근처（附近）

### 對話

```
甲：오늘은 무슨 요일이에요?
乙：오늘은 수요일이에요. 내일은 목요일이에요.
甲：내일 오후에 뭐 해요?
乙：내일 오후에 도서관에서 한국어를 공부해요.
甲：그럼 이번 주말에는 뭐 해요?
乙：이번 주말에 친구를 만나요. movie도 봐요.
```

（movie 是外來語，指「電影」；本課可改用「영화」：이번 주말에 친구를 만나요. 영화도 봐요.）

```
甲：학교에 언제 가요?
乙：3시에 학교에 가요.
甲：거기서 뭐 해요?
乙：거기서 공부해요. 2시간 동안 공부해요.
甲：집에는 언제 가요?
乙：5시쯤 집에 가요.
```

### 練習

- [ ] 請用韓語說：「我 20 歲。有 3 個蘋果。」

> 答案：저는 20살이에요. 사과가 3개예요.

- [ ] 請用韓語說：「明天在圖書館學韓語。」

> 答案：내일 도서관에서 한국어를 공부해요.

- [ ] 請用韓語說：「昨天見了朋友 2 次。」

> 答案：어제 친구를 2번 만났어요.

- [ ] 請用韓語說：「學校在公園前面。」

> 答案：학교는 공원 앞에 있어요. → 學校在公園前面。（也可說：공원이 학교 뒤에 있어요.）

- [ ] 請用韓語說：「從學校到地鐵站走。」

> 答案：학교에서 지하철역까지 걸어요.
