# 03.2 不規則形式

有些動詞在改成「해요體」時，不會直接加上「아요」。它們會依照自己的規則改變詞尾。這個章要學的是這些少數需要特別記憶的形式，例如 `만들어요`、`들어요`、`먹어요`、`읽어요` 等。

## 1. `만들어요`：`만들` → `만들어요`

有些動詞的原始形以 `ㄹ` 結尾。改成「해요體」時，會變成 `ㄹ어요`，不能只加上 `어요`。

| 原始形 | 說明 | 해요體 |
|---|---|---|
| 만들 | 做、製作 | 만들어요 |

例句：

- 저는 케이크를 만들어요.
- 저는 밥을 만들어요.
- 선생님은 과자를 만들어요.

這裡的 `만들어요` 是特殊形式，要特別記住。

## 2. `좋아해요`：`좋아하` → `좋아해요`

有些動詞的原始形以 `하` 結尾。改成「해요體」時，要把 `하` 改成 `해요`。

| 原始形 | 說明 | 해요體 |
|---|---|---|
| 좋아하 | 喜歡 | 좋아해요 |
| 공부하 | 學習 | 공부해요 |
| 요리하 | 做飯 | 요리해요 |
| 시작하 | 開始 | 시작해요 |
| 운동하 | 運動 | 운동해요 |
| 일하 | 工作 | 일해요 |

例句：

- 저는 한국어를 공부해요.
- 저는 사과를 좋아해요.
- 저는 운동해요.
- 저는 지금 운동을 시작해요.
- 저는 집에서 요리해요.

這些句子裡的 `해요` 不能省略。例如 `좋아해요` 不是 `좋아요`。

## 3. `들어요`：`듣` → `들어요`

有些動詞的原始形以 `ㄷ` 結尾。改成「해요體」時，ㄷ 會變成 `ㄹ`。

| 原始形 | 說明 | 해요體 |
|---|---|---|
| 듣 | 聽 | 들어요 |
| 걷 | 走路 | 걸어요 |
| 낫 | 更好 | 나아요 |

例句：

- 저는 음악을 들어요.
- 저는 학교에 걸어요.
- 저는 방에서 걸어요.
- 저는 선생님 말을 들어요.

注意：`듣` 變成 `들어요`，不是 `듣어요`。

## 4. `먹어요`、`읽어요`、`자요`：`ㄱ`、`ㄷ`、`ㅈ` 形式

有些動詞在「해요體」中，會把收音移到下一個音節。這些形式需要分開記，不要只靠加 `어요` 來猜。

| 原始形 | 說明 | 해요體 |
|---|---|---|
| 먹 | 吃 | 먹어요 |
| 읽 | 讀 | 읽어요 |
| 자 | 睡覺 | 자요 |
| 살 | 生活 | 살아요 |
| 마시 | 喝 | 마셔요 |

例句：

- 저는 밥을 먹어요.
- 저는 책을 읽어요.
- 저는 지금 자요.
- 저는 학교에서 살아요.
- 저는 커피를 마셔요.

另外，`만들어요`、`좋아해요`、`들어요` 這些都是不規則形式。它們的變化不多，但一定要特別記住。

## 對話

甲：이름이 뭐예요?

乙：저는 민수예요.

甲：무엇을 좋아해요?

乙：저는 노래를 좋아해요.

甲：무엇을 만들어요?

乙：저는 케이크를 만들어요.

甲：내일 뭐 해요?

乙：내일 책을 읽어요.

甲：어디에 가요?

乙：학교에 가요.

## 練習

- [ ] 把 `듣` 改成「해요體」。

> 答案：들어요

- [ ] 把 `좋아하` 改成「해요體」。

> 答案：좋아해요

- [ ] 把 `만들` 改成「해요體」。

> 答案：만들어요

- [ ] 把 `먹` 改成「해요體」。

> 答案：먹어요

- [ ] 選擇正確的句子：`저는 음악을 ______.`（들어요／듣어요）

> 答案：저는 음악을 들어요.
