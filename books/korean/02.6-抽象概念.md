# 02.6 抽象概念

## 02.6 抽象概念

抽象概念是表示想法、感情、規則、狀態或關係的名詞。韓語中，抽象名詞也可以像人物、動物或地點一樣，結合助詞與動詞。

### 1. 抽象概念的基本用法

| 用法 | Mini-Korean | 中文 |
|---|---|---|
| 主格 | 생각이 뭐예요? | 想法是什麼？ |
| 賓格 | 생각을 말해요. | 說出想法。 |
| 屬於 | 제 생각이에요. | 是我的想法。 |
| 描述 | 기분이 좋아요. | 心情很好。 |
| 否定 | 불안해요. | 感到不安。 |
| 原因 | 불안해서 못 가요. | 因為不安，所以不能去。 |

抽象名詞後面可以使用助詞：

- **은／는**：表示已知或說明的主題。
- **이／가**：表示新資訊或句子的主語。
- **을／를**：表示動作的受詞。
- **의**：表示兩個名詞之間的關係。

> 關係名詞和修飾語可以放在抽象名詞前：  
> **한국어의 방법** — 學韓語的方法

#### 說出自己的目標

| Mini-Korean | 中文 |
|---|---|
| 제 목표는 한국어 공부예요. | 我的目標是學習韓語。 |
| 제 생각은 이것이에요. | 我的想法是這個。 |
| 제 계획은 여기이에요. | 我的計畫在這裡。 |
| 제 방법은 이것이에요. | 我的方法是這個。 |
| 제 기준은 이것이에요. | 我的標準是這個。 |
| 목표는 뭐예요? | 目標是什麼？ |

#### 對話

甲：제 목표는 한국어 공부예요.  
乙：제 목표는 여행이에요.  
甲：그 방법이 뭐예요?  
乙：친구와 같이 가요.  
甲：좋아요. 그 결과는 좋아요.  
乙：결과가 중요해요.

#### 說明

**목표**是想要達成的結果。**계획**是準備做的步驟。**방법**是使用的方式。**기준**是判斷時使用的標準。

- **목표**：想要達成的結果。
- **계획**：準備做的步驟。
- **방법**：使用的方式。
- **기준**：判斷時使用的標準。

#### 描述心情

| Mini-Korean | 中文 |
|---|---|
| 기분이 좋아요. | 心情很好。 |
| 기분이 나빠요. | 心情不好。 |
| 오늘은 슬퍼요. | 今天很傷心。 |
| 그때는 화나요. | 那時候很生氣。 |
| 지금은 긴장돼요. | 現在很緊張。 |
| 정말 행복해요. | 真的很幸福。 |
| 사랑하는 사람이 필요해요. | 需要愛的人。 |
| 제 자신은 믿어요. | 我相信自己。 |

#### 對話

甲：오늘 기분이 어때요?  
乙：기분이 좋아요. 목표가 생겼어요.  
甲：무슨 목표예요?  
乙：한국어를 잘 배우는 목표예요.  
甲：좋아요. 그 계획도 뭐예요?  
乙：매일 한국어를 공부해요.  
甲：그 결과는 기대돼요.

#### 說明

**감정**是較廣泛的情緒。**기분**是現在的心情。**기쁨**是喜悅的感覺。**불안**是不知道會發生什麼事時的感覺。

情緒名詞也可以直接和性質動詞搭配：

- **좋아요**：好。
- **나빠요**：不好。
- **많아요**：很多。
- **커요**：大。
- **필요해요**：需要。
- **중요해요**：重要。

| 의무 | 義務 | 의무가 중요해요. |

#### 對話

甲：이 집의 규칙은 뭐예요?  
乙：규칙이 간단해요.  
甲：학교의 규범은 뭐예요?  
乙：약속을 지키는 규범이에요.  
甲：선생님의 의견이 뭐예요?  
乙：책을 읽는 것이 중요하다고 해요.  
甲：그 이유가 뭐예요?  
乙：책이 새로운 생각을 주기 때문에 중요해요.

#### 說明

**규칙**和**규범**都表示應該遵守的行為標準。**규칙**比較具體，**규범**比較概括。

- **규칙**：具體的規則。
- **규범**：概括的規範。
- **원칙**：基本原則。
- **의무**：應該做的事。
- **권리**：可以做的事。

| 경쟁 | 競爭 | 경쟁이 뭐예요? |

| 본질 | 本質 | 본질이 뭐예요? |
| 현실 | 現實 | 현실이 뭐예요? |

#### 對話

甲：학교와 집의 차이는 뭐예요?  
乙：학교는 공부하는 곳이에요.  
甲：환경은 어떤 차이가 있어요?  
乙：학교에는 친구가 있어요. 집에는 가족이 있어요.  
甲：어느 쪽이 좋아요?  
乙：사람에 따라 달라요.  
甲：그 이유는 뭐예요?  
乙：각각의 장점이 있기 때문이에요.

#### 說明

**관계**表示兩個事物或人之間的關係。**영향**表示一件事對另一件事造成的影響。

- **관계가 있다**：有關係。
- **영향을 주다**：給予影響。
- **차이가 있다**：有差異。
- **변화가 많다**：變化很多。

#### 對話

甲：Society와 사회는 어떻게 달라요?  
乙：Society는 넓은 뜻이에요. 사회는 사람들과 함께 사는 모습이에요.  
甲：그 상황은 어떤 때예요?  
乙：사람들이 함께 사는 때예요.  
甲：오늘 society의 정보는 무엇이에요?  
乙：인터넷의 정보는 많아요.  
甲：그중 어떤 정보가 중요해요?  
乙:: 건강과 관련된 정보예요.

#### 說明

**사회**是社會。**Society**也是社會，但意思更廣。**정보**是資訊，**지식**是經過學習得到的知識。

- **정보**：可以獲得的訊息。
- **지식**：學到的知識。
- **사실**：符合實際的事情。
- **진실**：真實的內容。
- **거짓**：不真實的內容。

### 7. 抽象名詞的問法

詢問抽象名詞時，可以使用 **무엇**、**뭐** 或 **어떤**。

| Mini-Korean | 中文 |
|---|---|
| 목표가 뭐예요? | 目標是什麼？ |
| 뜻이 뭐예요? | 意思是什麼？ |
| 문제가 뭐예요? | 問題是什麼？ |
| 관계가 어떤 것예요? | 是什麼關係？ |
| 기준은 어떤 것예요? | 是什麼標準？ |
| 목표는 어떤 것이에요? | 是什麼目標？ |

也可以用其他方式詢問：

| Mini-Korean | 中文 |
|---|---|
| 왜 그런가요? | 為什麼那樣？ |
| 어떻게 해요? | 怎麼做？ |
| 언제예요? | 什麼時候？ |
| 어디예요? | 在哪裡？ |
| 누구예요? | 是誰？ |

### 8. 複合抽象概念

有些抽象概念由兩個名詞組成。前面的名詞說明範圍，後面的名詞表示主要意義。

| Mini-Korean | 中文 |
|---|---|
| 한국어의 방법 | 學韓語的方法 |
| 문제의 이유 | 問題的原因 |
| 계획의 기준 | 計畫的標準 |
| 변화의 결과 | 變化的結果 |
| 감정의 문제 | 情緒的問題 |
| 사회의 변화 | 社會的變化 |
| 미래의 가능성 | 未來的可能性 |
| 학교의 규칙 | 學校的規則 |
|公司的結構 | 公司的結構 |
|人生的目的 | 人生的目的 |

使用 **의** 時，前面的名詞表示所属、範圍或關係：

> **목표의 기준**  
> 目標的標準

> **결과의 이유**  
> 結果的原因

> **감정과 생각의 관계**  
> 感情與思想的關係

連接兩個相近的抽象概念時，可以使用 **하고**：

> **방법하고 기준**  
> 方法和標準

> **계획하고 목표**  
> 計畫和目標

| Mini-Korean | 中文 |
|---|---|
| 가능성은 무엇이에요? | 可能性是什麼？ |

| 가능성은 낮아요. | 可能性低。 |

| 목표는 중요해요. | 目標很重要。 |
| 기준은 무엇이에요? | 標準是什麼？ |
| 방법도 뭐예요? | 方法也是什麼？ |
| 방식은 뭐예요? | 方式是什麼？ |
| 규칙은 무엇이에요? | 規則是什麼？ |
| 규범은 뭐예요? | 規範是什麼？ |

回答抽象概念問題時，可以使用：

- **예요**：是。
- **아니요**：不是。
- **뭐예요**：是什麼。
- **중요해요**：重要。
- **좋아요**：好。
- **높아요**：高。
- **낮아요**：低。
- **많아요**：多。
- **필요해요**：需要。
- **새로워요**：新。
- **다르다**：不同。

### 10. 短文：我的目標

오늘은 목표에 대해 생각해요.  
제 목표는 한국어 공부예요.  
한국어의 중요한 점은 말하는 방법이에요.  
매일 한국어 공부를 해요.  
그렇게 someday 좋은 결과를 얻을 거예요.

> 上方短文中的 **someday** 不在詞表內。課本中的完整版本應使用詞表內的 **언제나** 或 **지금** 改寫。

#### 短文說明

短文使用「抽象名詞＋助詞＋動詞」的固定結構：

- **목표에 대해**：關於目標。
- **목표는**：目標是。
- **중요한 점은**：重要的地方是。
- **방법이에요**：是方法。
- **공부를 해요**：進行學習。
- **결과를 얻을 거예요**：將得到結果。
