# 01.3 怎麼用這本書

## 01.3 怎麼用這本書

這一章要教你三件事：

1. 先認識 Mini-Korean 裡的單字。
2. 再用固定句型把單字組合起來。
3. 每學會一句，就大聲讀出來。

### 先看詞表的分法

Mini-Korean 的詞表分成幾類：

| 類別 | 學到的內容 | Mini-Korean 例子 |
|---|---|---|
| 代詞・指示 | 人、物和地點的說法 | 이것이 물이에요. |
| 語法（功能詞） | 句型裡的固定用法 | 저는 학생이에요. |
| 時間 | 今天、明天、星期等 | 내일 학교에 가요. |
| 方位・地點 | 家裡、學校、附近等 | 집에서 공부해요. |
| 動作 | 吃、走、學、買等 | 책을 읽어요. |
| 性質 | 大、小、好、冷等 | 방이 넓어요. |
| 事物 | 書、食物、工具等 | 사과를 먹어요. |
| 抽象概念 | 心、想法、規則等 | 저는 자신을 믿어요. |

看到新單字時，先不要急着背整篇課文。先問自己兩個問題：

- 這個單字是什麼意思？
- 它可以放在句子的哪個位置？

例如：

- **학생**：學生。
- **학교**：學校。
- **가요**：去。

用固定句型組合起來：

> 학생은 학교에 가요.

這句話只說一件事：學生去學校。

### 一個句子只說一件事

不要把很多意思放在同一個句型裡。

| 意思 | Mini-Korean |
|---|---|
| 我是學生。 | 저는 학생이에요. |
| 我去學校。 | 저는 학교에 가요. |

不要說：

> 저는 학생이고 학교에 가요.

分開說更自然，也更容易閱讀：

> 저는 학생이에요.  
> 저는 학교에 가요.

### 先學句型，再換單字

固定句型可以幫助你快速造句。

| 固定句型 | Mini-Korean |
|---|---|
| 主題＋是 | 저는 학생이에요. |
| 主題＋去＋地點 | 저는 집에 가요. |
| 主題＋在＋地點＋做 | 저는 학교에서 공부해요. |
| 賓語＋動詞 | 밥을 먹어요. |
| 對象＋動詞 | 친구에게 전화해요. |

例如，我們學會了這個句型：

> 名詞＋에 가요.

這個句型可以表示「去某個地方」。

| 單字 | Mini-Korean |
|---|---|
| 학교 | 학교에 가요. |
| 회사 | 회사에 가요. |
| 도서관 | 도서관에 가요. |
| 카페 | 카페에 가요. |
| 공원 | 공원에 가요. |

只要先記住 **에 가요**，就能組合出很多句子。

### 看見新單字時這樣做

看到不懂的單字時，可以先找相同類別的單字。

| 類別 | Mini-Korean |
|---|---|
| 水果 | 사과, 바나나 |
| 動物 | 고양이, 강아지 |
| 時間 | 오늘, 내일, 어제 |
| 地點 | 집, 학교, 회사 |
| 動作 | 먹어요, 걸어요, 읽어요 |

例如：

> 과일은 사과, 바나나예요.

意思是：水果有蘋果和香蕉。

這種方法不能知道所有意思，但可以幫助你建立清楚的關係。

### 遇到不會說的概念

不是所有概念都能用一個單字說清楚。這時不要造出詞表以外的新詞，可以先描述它。

例如：

- 說一個人的工作：  
  > 한국어를 가르치는 사람이에요.

- 說一個地方：  
  > 공원이 있는 곳이에요.

- 說一個事物：  
  > 물을 먹는 것이에요.

- 說一種種類：  
  > 꽃의 종류예요.

說明之後，再學會新的正式說法。

### 每次只學少量內容

可以按照下面的方式讀完一個單元：

1. 看單字的意思。
2. 聽自己讀單字。
3. 讀一個簡單句型。
4. 換掉句型裡的一個單字。
5. 不看課本，再讀一次。

例如：

> 저는 학생이에요.

換掉 **학생**：

> 저는 선생님이에요.

再換掉 **저는**：

> 그분은 선생님이에요.

這些句子都使用同一個簡單句型：

> 主題＋은／는＋職業＋이에요.

### 練習朗讀

第一次讀句子時，不要讀得很快。先分清楚意思，再慢慢提高速度。

> 이 말을 천천히 읽어요.  
> 나중에 다시 읽어요.

意思是：慢慢讀這段話。以後再讀一次。

### 使用固定對話

對話是學會句型的好方法。每次先聽或讀一整段，再進行交換。

甲：반갑습니다.  
乙：반갑습니다.  
甲：저는 학생이에요.  
乙：저는 선생님이에요.  
甲：이름은 무엇이에요?  
乙：이름은 민수예요.

其中 **민수** 是外來語，第一次出現時可以說：

> 민수(人名)

這個名字用韓語文字表示，意思是「民秀」。

### 每天練習

不需要每天學很多新單字。每天重複以前的內容，也會更熟悉。

> 매일 조금씩 공부해요.  
> 오늘도 다시 읽어요.

意思是：每天學一點點。今天也再讀一次。

最後，請你把學到的句子用在真實生活裡。

> 저도 한국어를 공부해요.  
> 오늘 조금 읽었어요.

意思是：我也學韓語。今天讀了一點點。

## 練習

- [ ] 把「我今天去咖啡館」寫成 Mini-Korean。

> 答案：저는 오늘 카페에 가요.

- [ ] 把「我在學校學韓語」寫成 Mini-Korean。

> 答案：저는 학교에서 한국어를 공부해요.

- [ ] 把「他是我朋友」寫成 Mini-Korean。

> 答案：그분은 제 친구예요.

- [ ] 讀一個使用「에 가요」句型的新句子。

> 答案：저는 도서관에 가요.

- [ ] 用今天的單字說一句和「水果」有關的話。

> 答案：과일은 사과예요.
