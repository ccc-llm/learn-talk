# 07.3 最常犯的錯

## 07.3 最常犯的錯

### 1. 助詞要接在名詞後面

韓語的助詞不能隨意更換。名詞有收音時，通常用「은、을」；沒有收音時，通常用「는、를」。

| 名詞 | 收音 | 主題助詞 | 賓格助詞 | 例句 |
|---|---:|---|---|---|
| 학생 | 有 | 은 | 을 | 학생은 학생이에요. |
| 책 | 有 | 은 | 을 | 책을 읽어요. |
| 친구 | 無 | 는 | 를 | 친구를 만나요. |
| 선물 | 無 | 는 | 를 | 선물을 받았어요. |
| 한국어 | 無 | 는 | 를 | 한국어를 공부해요. |

> 收音是指一個詞最後的輔音。中文母語者可以先記住幾個常見例子：「학생、책、선물」後面用「은、을」；「친구、한국어」後面用「는、를」。

### 2. 「은／는」和「을／를」不要混用

「은／는」表示主題，「을／를」表示動作的對象。

- **저는 학생이에요.**  
  我是學生。
- **저는 책을 읽어요.**  
  我讀書。
- **친구를 만나요.**  
  我見朋友。
- **선물을 받았어요.**  
  我收到禮物。

不要只看名詞的意思，還要看名詞後面有沒有收音。

### 3. 「이다」的口語形式

表示「是」時，可以使用「이에요／예요」。

| 名詞 | 形式 | 例句 |
|---|---|---|
| 학생 | 이에요 | 학생이에요. |
| 책 | 이에요 | 책이에요. |
| 한국어 | 예요 | 한국어예요. |

疑問句也要使用「是」的相應形式：

- **학생이에요?**  
  是學生嗎？
- **책이에요?**  
  是書嗎？
- **이것은 책이에요?**  
  這是書嗎？

回答時可以使用「네」或「아니요」：

- **네, 학생이에요.**  
  是的，是學生。
- **아니요, 책이에요.**  
  不是，是書。

### 4. 表外的概念要換一種說法

如果詞表裡沒有某個概念，可以使用「描述 ＋ 類頭」。

| 想要表達的概念 | Mini-Korean 說法 | 例句 |
|---|---|---|
| 語法 | 공부하는 방법 | 공부하는 방법이 어려워요. |
| 學會 | 可以說「공부해요」 | 조금 공부해요. |
| 對不對 | 可以直接問「……이에요?」 | 학생이에요? |

完整的自然說法：

- **죄송합니다. 공부하는 방법이 어려워요.**  
  不好意思，學習的方法很難。
- **아니요. 조금 공부해요.**  
  不，學一點兒。
- **학생이에요?**  
  是學生嗎？

### 5. 助詞要跟在正確的名詞後面

助詞必須直接放在名詞後面。

| 錯誤類型 | 正確例子 |
|---|---|
| 賓格助詞用錯 | 책을 읽어요. |
| 主題助詞用錯 | 학생은 학생이에요. |
| 對象助詞用錯 | 친구에게 선물을 줘요. |
| 地點助詞用錯 | 학교에 가요. |
| 動作場所助詞用錯 | 집에서 쉬어요. |

### 6. 常見助詞整理

| 助詞 | 功能 | 例句 |
|---|---|---|
| 은／는 | 主題 | 학생은 학생이에요. |
| 이／가 | 主語 | 친구가 와요. |
| 을／를 | 動作對象 | 책을 읽어요. |
| 에 | 目的地、時間點、對象 | 학교에 가요. |
| 에서 | 動作場所、起點 | 집에서 쉬어요. |
| 의 | 兩個名詞之間 | 친구의 책이에요. |
| 도 | 也 | 나도 가요. |
| 하고 | 兩個名詞並列 | 친구하고 같이 가요. |
| 부터 | 從開始 | 오늘부터 공부해요. |
| 까지 | 到結束 | 오늘까지 공부해요. |

### 對話

甲：죄송합니다. 공부하는 방법이 어려워요.  
乙：아니요. 조금 공부해요.  
甲：저것은 학생이에요?  
乙：네, 학생이에요.  
甲：이 책은 누구의 책이에요?  
乙：친구의 책이에요.

### 練習

- [ ] 1. 在「학생」後面填上正確的主題助詞：학생 ___ 학생이에요.

> 答案：은

- [ ] 2. 在「책」後面填上正確的賓格助詞：책 ___ 읽어요.

> 答案：을

- [ ] 3. 「친구」後面的賓格助詞應該用什麼？請寫出完整句子：친구 ___ 만나요.

> 答案：를。친구를 만나요.

- [ ] 4. 把「문법이 어려워요」改寫成符合 Mini-Korean 規則的句子。

> 答案：공부하는 방법이 어려워요.

- [ ] 5. 「책」後面的賓格助詞錯了。請改正：책를 읽어요.

> 答案：책을 읽어요.
