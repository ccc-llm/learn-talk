## 06.3 外來語與專有名詞

### 一、三層表達法

| 層 | 什麼時候用 | 說法 | 例句 |
|---|---|---|---|
| 本詞 | 詞表內已有的詞 | 直接用 | 저는 한국어를 공부해요. |
| 描述 | 表外的通用概念 | 描述 ＋ 類頭 | 집을 고치는 사람이에요. |
| 外來語 | 說不出是哪一個（人名、地名、品牌） | 原文 ＋（說明） | 서울(한국어 나라의 도시)에 가요. |

**規則**

1. 外來語第一次出現時，後面加括號說明；第二次以後不再加。
2. 括號裡的說明只能用詞表內的字詞。
3. 說明放在外來語後面，助詞放在說明後面：서울(한국어 나라의 도시) **은** 큰 도시예요.
4. 已經在詞表裡的外來語不用說明：커피, 케이크, 택시, 컴퓨터, 호텔.

### 二、地名的說明方式

| 外來語 | 括號說明 | 第一次出現 | 第二次以後 |
|---|---|---|---|
| 서울 | 한국어 나라의 도시 | 서울(한국어 나라의 도시)에 가요. | 저는 서울에 가요. |
| 미국 | 다른 나라 | 미국(다른 나라)에서 일해요. | 미국도 좋아요. |
| 도쿄 | 다른 나라의 도시 | 도쿄(다른 나라의 도시)에 가요. | 도쿄는 큰 도시예요. |
| 런던 | 다른 나라의 도시 | 런던(다른 나라의 도시)에 가요. | 런던에도 가요. |
| 파리 | 다른 나라의 도시 | 파리(다른 나라의 도시)에서 요리해요. | 파리는 맛있어요. |

**說明裡的常用字**

| 說明 | 用法 |
|---|---|
| 다른 나라의 도시 | 外國的城市 |
| 다른 나라의 나라 | 外國的國家 |
| 음식 | 食物 |
| 신발 | 鞋 |
| 사람의 이름 | 人的名字 |

### 三、人名與稱呼

人名沒有通用說法，所以用「原文 ＋（사람의 이름）」。

| 外來語 | 括號說明 | 例句 |
|---|---|---|
| 민수 | 사람의 이름 | 민수(사람의 이름)는 제 친구예요. |
| 수진 | 사람의 이름 | 수진(사람의 이름)은 학생이에요. |

稱呼用詞表裡的詞：

| 稱呼 | 意思 | 例句 |
|---|---|---|
| 선생님 | 老師 | 선생님은 학교에 가요. |
| 오빠 | 哥哥（女生用） | 오빠가 왔어요. |
| 누나 | 姐姐（男生用） | 누나, 사랑해요. |
| 형 | 哥哥（男生用） | 제 형은 학생이에요. |
| 동생 | 弟弟或妹妹 | 제 동생은 어리예요. |
| 님 | 敬稱 | 선생님, 반갑습니다. |

### 四、常見錯誤

| 錯誤 | 為什麼錯 | 正確 |
|---|---|---|
| 서울(首爾) | 說明用了詞表外的字 | 서울(한국어 나라의 도시) |
| 도쿄(東京) | 說明用了詞表外的字 | 도쿄(다른 나라의 도시) |
| 미국(다른 나라)에 가요. 미국(다른 나라)에 가요. | 第二次還加括號 | 미국(다른 나라)에 가요. 미국에도 가요. |
| 저는 피자(음식)를 먹어요. 저는 피자(음식)를 먹어요. | 第二次還加括號 | 저는 피자(음식)를 먹어요. 저는 피자를 먹어요. |

### 五、對話

**對話 1：說明地名**

```
甲：어디에 가요?
乙：서울(한국어 나라의 도시)에 가요.
甲：무엇을 좋아해요?
乙：도시를 좋아해요. 저는 도쿄(다른 나라의 도시)에 가요.
甲：런던(다른 나라의 도시)도 가요?
乙：아니요, 저는 미국(다른 나라)에서 일해요.
```

**對話 2：說明人名**

```
甲：그분의 이름은 뭐예요?
乙：민수(사람의 이름)예요.
甲：민수(사람의 이름)는 누구예요?
乙：제 친구예요.
甲：무슨 일을 해요?
乙：회사에서 일해요.
```

**對話 3：說明品牌與食物**

```
甲：그것은 뭐예요?
乙：피자(음식)예요.
甲：좋아요?
乙：네, 저는 피자(음식)를 먹어요. 가끔은 나이키(신발)도 사요.
```
