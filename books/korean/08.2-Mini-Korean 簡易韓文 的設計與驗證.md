# 08.2 Mini-Korean 簡易韓文 的設計與驗證

## 08.2 Mini-Korean 簡易韓文 的設計與驗證

### 1. 設計目標

Mini-Korean 的目的，是讓學習者只靠少量詞語和固定句型，就能讀懂、說出更多句子。

| 設計方式 | 做法 | 例子 |
|---|---|---|
| 詞少 | 句子只使用詞表內的單位 | 학생은 학교에 가요. |
| 自然 | 使用正確的韓語詞序和助詞 | 친구의 책이에요. |
| 可組合 | 用同一批詞語組成不同句子 | 학교에 가요. / 카페에 가요. |
| 句型固定 | 問題主要使用 `예요` 句尾 | 이름은 무엇이에요? |
| 能換說法 | 表外的概念使用描述加類頭 | 하는 사람 / 인 것 / 하는 곳 |

---

### 2. 詞語分層

核心層是學習者最先需要記住的內容。擴充層提供更多時間、描述、動作和性質詞語。

| 層級 | 學習方式 | 例子 |
|---|---|---|
| 核心層 | 先學代詞、數字、時間、人物和常用動作 | 저는 학생이에요. |
| 擴充層 | 再學完整形容詞、抽象概念和固定用語 | 이 책은 재미있어요. |

學習時先掌握核心層，再用已學會的句子組合出更多說法。

---

### 3. 句型設計

Mini-Korean 使用固定的韓語語序：

> 主語＋助詞＋修飾＋場所＋時間＋動詞＋賓語＋句尾

| 句型 | 中文說明 | 例子 |
|---|---|---|
| 身份 | 說明人或物的身分 | 학생이에요. |
| 所有 | 說明兩件事的關係 | 친구의 책이에요. |
| 地點 | 說明動作發生的地點 | 학교에 가요. |
| 存在 | 說明某處有某物 | 책이 있어요. |
| 動作 | 說明人物做什麼 | 밥을 먹어요. |
| 並列 | 連接兩個人或物 | 친구하고 같이 가요. |
| 描述 | 說明某種特徵 | 이것은 빨개요. |
| 過去 | 使用 `았어요`、`었어요` | 있어요. |

---

### 4. 助詞的正確使用

韓語助詞會跟著前面的詞走。有收音時用 `은`、`을`，沒有收音時用 `이`、`를`。

| 類型 | 有收音 | 沒有收音 | 例子 |
|---|---|---|---|
| 主題助詞 | 은 | 는 | 학생은 학생이에요. |
| 賓格助詞 | 을 | 를 | 책은 책을 읽어요. |
| 地點助詞 | 에 | 에 | 학교에 가요. |
| 場所助詞 | 에서 | 에서 | 학교에서 공부해요. |

### 主題助詞

`은` 和 `는` 用來表示說話者正在談論的主題。

- 학생은 학생이에요.
- 이 책은 재미있어요.
- 그분은 누구예요?

### 賓格助詞

`을` 和 `를` 用在動作的對象後面。

- 밥을 먹어요.
- 친구를 만나요.
- 책을 읽어요.

### 地點助詞

`에` 用在目的地、時間點和對象後面。

- 학교에 가요.
- 카페에 가요.
- 3시에 만나요.

`에서` 用在動作發生的地點和起點。

- 학교에서 공부해요.
- 집에서 출발해요.

---

### 5. 動詞的固定形式

詞表直接提供常用動詞形式。學習者先使用完整形式，再依照語法規則組合。

| 動作概念 | Mini-Korean | 例子 |
|---|---|---|
| 去 | 가요 | 학교에 가요. |
| 吃 | 먹어요 | 밥을 먹어요. |
| 見面 | 만나요 | 친구를 만나요. |
| 學習 | 공부해요 | 한국어를 공부해요. |
| 看 | 봐요 | 그림을 봐요. |
| 寫 | 써요 | 여기에 써요. |
| 讀 | 읽어요 | 책을 읽어요. |
| 聽 | 들어요 | 음악을 들어요. |
| 買物 | 쇼핑해요 | 시장에서 쇼핑해요. |
| 帮助 | 도와요 | 친구를 도와요. |

`가다`、`먹다`、`만나다` 和 `공부하다` 是說明動詞概念的形式。Mini-Korean 的例句直接使用詞表中的 `가요`、`먹어요`、`만나요` 和 `공부해요`。

---

### 6. 未知概念的處理方式

當某個概念不在詞表內時，不直接加入陌生詞，而是先描述它的功能。

| 未知概念 | 處理方式 | 例子 |
|---|---|---|
| 不在表內的人 | 描述加 `사람` | 병을 보는 사람 |
| 不在表內的物 | 描述加 `것` | 먹는 것 |
| 不在表內的地點 | 描述加 `곳` | 가는 곳 |
| 不在表內的時間 | 描述加 `때` | 가는 때 |
| 不在表內的工作 | 描述加 `일` | 하는 일 |
| 不在表內的說法 | 描述加 `말` | 하는 말 |
| 不在表內的想法 | 描述加 `생각` | 하는 생각 |
| 不在表內的區分 | 描述加 `가지` | 다른 가지 |
| 不在表內的問題 | 描述加 `문제` | 있는 문제 |
| 不在表內的名稱 | 描述加 `이름` | 있는 이름 |

### 人物描述

`사람` 可以放在描述詞後面：

- 병을 보는 사람
- 밥을 요리하는 사람
- 학생에게 가르치는 사람

### 事物描述

`것` 可以放在形容詞後面：

- 먹는 것
- 읽는 것
- 좋아하는 것

### 地點描述

`곳` 可以放在動作後面：

- 가는 곳
- 쉬는 곳
- 만나는 곳

### 名稱描述

`이름` 可以表示尚未說出的名稱：

- 사람 이름
- 학교 이름
- 나라 이름

---

### 7. 數字與數量

數字使用阿拉伯數字。常用數量單位是 `개`、`명`、`번`、`살`、`시간` 和 `년`。

| 說法 | 例子 |
|---|---|
| 數量 | 2개 |
| 人數 | 3명 |
| 次數 | 2번 |
| 年齡 | 20살 |
| 時間 | 3시간 |
| 年份 | 2년 |

例子：

- 학생은 3명이에요.
- 책은 2권이에요.
- 지금은 3시예요.
- 저는 20살이에요.

---

### 8. 時間表達

時間詞直接放在句中。

| 類型 | 詞語 | 例子 |
|---|---|---|
| 今天 | 오늘 | 오늘 학교에 가요. |
| 明天 | 내일 | 내일 학교에 가요. |
| 昨天 | 어제 | 어제 |
| 早上 | 아침 | 아침에 학교에 가요. |
| 下午 | 오후 | 오후에 공부해요. |
| 晚上 | 저녁 | 저녁에 쉬어요. |
| 現在 | 지금 | 지금 학교에 가요. |
| 每一天 | 매일 | 매일 학교에 가요. |

`어제` 可以表示昨天。表示昨天發生的事情時，要使用詞表允許的過去形式，不使用表外形式。

---

### 9. 詞彙檢查

每個例句都要分成三個部分檢查：

1. **詞語檢查**：每個詞語都在完整詞表內。
2. **助詞檢查**：主題助詞、賓格助詞、地點助詞和場所助詞正確。
3. **句型檢查**：語序符合韓語規則，句尾使用允許的 `해요體`。

| 檢查項目 | 問題 | 改正 |
|---|---|---|
| 詞語 | `학생는 학교에 가요.` | `학생은 학교에 가요.` |
| 詞語 | `이 책은 재미있어요.` | `책은 재미있어요.` |
| 詞語 | `이분은 누구예요?` | `그분은 누구예요?` |
| 動詞 | `가다` | `가요` |
| 動詞 | `먹다` | `먹어요` |
| 動詞 | `만나다` | `만나요` |
| 動詞 | `공부하다` | `공부해요` |
| 過去式 | `갔어요` | 使用詞表允許的過去形式 |

---

### 10. 對話驗證

#### 對話一：學校

甲：너는 학생이에요?  
乙：네, 학생이에요.  
甲：무엇을 공부해요?  
乙：한국어를 공부해요.  
甲：선생님은 어디에 있어요?  
乙：학교에 있어요.  

#### 對話二：朋友

甲：이름은 무엇이에요?  
乙：그분은 민수예요.  
甲：친구와 같이 가요.  
乙：네, 같이 가요.  

#### 對話三：買東西

甲：시장에 가요?  
乙：네, 시장에 가요.  
甲：사과를 3개 사요.  
乙：좋아요.  

#### 對話四：問時間

甲：언제 만나요?  
乙：내일 만나요.  
甲：어디에서 만나요?  
乙：카페에서 만나요.

| 檢查項目 | 結果 |

| 核心層詞語 | 通過 |
| 擴充層詞語 | 通過 |
| 助詞選擇 | 通過 |
| 韓語語序 | 通過 |
| `해요體` | 通過 |

通過檢查的句子不只符合形式，也能直接用於簡單會話：

- 저는 학생이에요.
- 학교에 가요.
- 친구를 만나요.
- 한국어를 공부해요.
- 책은 재미있어요.
- 그분은 누구예요?

> 答案：친구를 만나요.

> 答案：한국어를 공부해요.

- [ ] 用 `개` 回答數量：사과는 2개예요.
