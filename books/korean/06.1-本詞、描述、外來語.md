# 06.1 本詞、描述、外來語

本章要學習三層表達法：詞表內的概念直接使用「本詞」；詞表外的通用概念使用「描述＋類頭」；人名、地名、品牌等無法直接說出的名稱，使用「外來語＋第一次出現的說明」。描述時要先說明動作或特徵，再加類頭，讓句子保持簡單、自然。

## 1. 本詞：直接使用詞表內的概念

如果概念已經在詞表內，就直接使用本詞，不需要再解釋。

| 中文概念 | 本詞 | Mini-Korean 例句 |
|---|---|---|
| 學生 | 학생 | 저는 학생이에요. |
| 韓語 | 한국어 | 저는 한국어를 공부해요. |
| 圖書館 | 도서관 | 도서관에 가요. |
| 水果 | 과일 | 과일을 먹어요. |
| 醫生 | 의사 | 저는 의사예요. |
| 旅行 | 여행 | 여름에 여행해요. |
| 花 | 꽃 | 꽃이 예뻐요. |
| 電影 | 영화 | 영화를 봐요. |

「저는 학생이에요.」直接使用 `학생`，表示「我是學生」。

「저는 한국어를 공부해요.」直接使用 `한국어`，表示「我學韓語」。

## 2. 描述：描述＋類頭

詞表外的一般概念，先用可組合的說法描述，再加類頭。常用類頭有 `사람`、`것`、`곳`、`때`、`말`、`마음`、`생각`、`종류`、`문제`、`도구`、`재료`、`자연` 等。

| 描述方法 | Mini-Korean | 中文意思 |
|---|---|---|
| 動作＋사람 | 한국어를 공부하는 사람 | 學韓語的人 |
| 動作＋사람 | 병을 보는 사람 | 看病的人 |
| 動作＋사람 | 친구를 만나는 사람 | 見朋友的人 |
| 動作＋것 | 그림을 그리는 것 | 畫圖這件事 |
| 動作＋일 | 한국어를 배우는 일 | 學韓語這件事 |
| 特徵＋곳 | 조용한 곳 | 安靜的地方 |
| 特徵＋곳 | 사람이 많은 곳 | 人多的地方 |
| 修飾＋종류 | 한국어의 종류 | 韓語的種類 |
| 修飾＋도구 | 글자를 쓰는 도구 | 寫字的工具 |

描述和類頭之間通常不需要空格。`한국어를 공부하는 사람` 是由 `한국어`、`를`、`공부하`、`는`、`사람` 組合而成。

下面這個句子沒有直接說「畫家」這個詞，而是描述動作者：

> 그림을 그리는 사람은 화가예요.

意思是「畫畫的人是畫家」。

也可以描述地點：

> 조용한 곳에서 공부해요.

意思是「在安靜的地方學習」。

## 3. 外來語：第一次出現時加說明

人名、地名、品牌名稱等表外名稱，可以使用外來語。第一次出現時，在後面加上簡短說明；後面再次出現時，可以只使用名稱。

| 外來語＋說明 | Mini-Korean 例句 | 中文意思 |
|---|---|---|
| 서울(도시 이름) | 저는 서울(도시 이름)에 가요. | 我去首爾。 |
| 블랙빈(커피 가게 이름) | 블랙빈(커피 가게 이름)에서 커피를 마셔요. | 我在星巴克喝咖啡。 |
| 김민수(사람 이름) | 김민수(사람 이름)는 학생이에요. | 金民秀是學生。 |

括號中的說明也使用詞表內的詞：

- `도시 이름`：城市名稱
- `커피 가게 이름`：咖啡店名稱
- `사람 이름`：人名

第一次使用時加說明，第二次使用時可以省略：

> 저는 서울(도시 이름)에 가요.  
> 서울은 커요.

本詞、描述和外來語也可以一起出現在同一個句子裡：

> 저는 서울(도시 이름)의 커피 가게에 가요.

意思是「我去首爾的咖啡店」。

這裡的 `서울` 是外來的地名；`커피 가게` 是「描述＋類頭」，因為詞表內沒有直接表示「咖啡店」的名詞。

## 4. 練習

- [ ] 用本詞完成句子：저는 한국어를 ______.  
  提示：學習。

> 答案：저는 한국어를 공부해요.

- [ ] 用「描述＋類頭」翻譯「學韓語的人」。

> 答案：한국어를 공부하는 사람

- [ ] 用「描述＋類頭」翻譯「安靜的地方」。

> 答案：조용한 곳

- [ ] 補上外來語的第一次說明：저는 서울( ______ )에 가요.  
  提示：城市名稱。

> 答案：저는 서울(도시 이름)에 가요.

- [ ] 用本詞、描述或外來語完成句子：이것은 ______이에요. 이것은 쓰고 ______.  
  提示：第一個空格是「咖啡店名稱」；第二個空格是「寫字的工具」。

> 答案：이것은 블랙빈(커피 가게 이름)이에요. 이것은 쓰고 쓰는 도구예요.
