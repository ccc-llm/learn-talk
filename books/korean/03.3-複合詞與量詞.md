# 03.3 複合詞與量詞

本章要學的是「怎麼把兩個單位組成一個詞」。韓語裡有兩種做法：一種是直接把兩個單位黏成一個詞（中間不留空格），一種是用「의」把兩個單位連成一個短語。學會之後，你就能自己造出「火車站」「朋友的書」「桌子上面」這類說法。最後本章還要教量詞：數字後面要放對單位，書用「개」、人用「명」、次數用「번」。

## 3.1 黏成一個詞：기차역

兩個單位黏在一起，中間不留空格，就成為一個新詞。最容易分辨的是「場所 + 場所名稱」：기차(火車) + 역(車站) → 기차역（火車站）；지하철(地鐵) + 역 → 지하철역（地鐵站）。詞表裡的這些複合詞，学习時當成「一個單位」記住就好。

| 複合詞 | 兩個單位 | 意思 |
|---|---|---|
| 기차역 | 기차 + 역 | 火車站 |
| 지하철역 | 지하철 + 역 | 地鐵站 |
| 버스정류장 | 버스 + 정류장 | 公車站 |
| 기차 | 기차 + 차 | 火車 |

要注意：**複合詞裡面沒有空格**。所以「기차 역」是錯的，必須寫成「기차역」。

```text
甲：지하철역은 어디예요?
乙：지하철역은 여기예요.
甲：기차역은 멀리예요?
乙：네, 기차역은 멀리예요.
```

其他例子：

- 저는 기차역에 가요.
- 기차역 앞에 버스정류장이 있어요.
- 지하철역에서 버스를 기다려요.

## 3.2 用「의」連接兩個單位

「의」放在兩個名詞中間，表示「前者屬於後者」。前面的名詞變成修飾語，後面的名詞是主詞。用「의」時中間要有空格，和 3.1 的黏字寫法不同。

| 寫法 | 意思 |
|---|---|
| 친구 + 의 + 책 | 朋友的書 |
| 선생님 + 의 + 책 | 老師的書 |
| 그분의 + 가방 | 那位的包 |
| 나의 + 이름 | 我的名字 |
| 나무 + 의 + 줄기 | 樹的莖 |

完整例句：

- 이것은 친구의 책이에요.
- 그분의 가방은 새 가방이에요.
- 선생님의 책은 여기 있어요.
- 나무의 줄기는 길어요.
- 나무의 열매는 빨개요.

「나」的屬格形式也用同樣的原理：**나 + 의 → 나의**；他的、她的、我們的也是一樣，把「의」加在後面就成為一個新單位。

- 제 책은 여기 있어요.
- 그의 책은 새 책이에요.
- 우리의 집은 여기예요.

## 3.3 位置單位和名詞組合

表示位置的單位（앞 前面、옆 旁邊、위 上面、아래 下面、안 裡面、밖 外面、가운데 中間、사이 之間）也可以放在名詞後面，說明東西在哪裡。位置的單位要加「에」，所以常用「옆에」這個形式。

| 位置單位 | 意思 | 例句 |
|---|---|---|
| 앞 | 前面 | 학교 앞에 가요. |
| 옆에 | 旁邊 | 여기 버스정류장 옆이에요. |
| 위 | 上面 | 그릇을 책상 위에 놓아요. |
| 아래 | 下面 | 저는 집 아래로 내려가요. |
| 안 | 裡面 | 집 안은 넓어요. |
| 밖 | 外面 | 집 밖은 추워요. |
| 가운데 | 中間 | 방 가운데가 넓어요. |
| 사이 | 之間 | 의자 사이가 좁아요. |

完整例句：

- 저는 학교 앞에 가요.
- 그릇을 책상 위에 놓아요.
- 도서관 옆에 카페가 있어요.
- 저는 집 아래로 내려가요.
- 친구와 학교 앞에서 만나요.

## 3.4 量詞：數字後面要放對單位

數字不能單獨當量詞用，後面要加「단위(單位)」。書用「개」、人用「명」、次數用「번」、年齡用「살」、時間用「시간」和「분」。

| 數的對象 | 單位 | 意思 |
|---|---|---|
| 物品 | 개 | 책 3개 |
| 人 | 명 | 학생 5명 |
| 次數 | 번 | 2번 |
| 年齡 | 살 | 20살 |
| 小時 | 시간 | 3시간 |
| 分鐘 | 분 | 30분 |
| 年 | 해 | 3해 |

完整例句：

- 책 3개를 읽었어요.
- 학생 5명이 가요.
- 어제 친구를 2번 만났어요.
- 저는 20살이에요.
- 공부를 3시간 했어요.
- 3시간 30분 기다려요.
- 학생이 몇 명이에요?

兩個時間單位也可以合成一個說法：先寫小時，再寫分鐘（3시간 30분）。同樣地，人數也可以和別的單位一起用：「친구 2명이 같이 가요.」

## 練習

- [ ] 把「기차 + 역」合成一個詞，並用它寫一句話。

> 答案：기차역. 저는 기차역에 가요.

- [ ] 用「의」把「친구」和「책」連起來，寫一個完整句子。

> 答案：이것은 친구의 책이에요.

- [ ] 選對單位（개 / 명 / 번 / 살 / 시간），填空：저는 20＿＿이에요. ／ 학생 5＿＿이 가요. ／ 어제 친구를 2＿＿ 만났어요.

> 答案：저는 20살이에요. 학생 5명이 가요. 어제 친구를 2번 만났어요.

- [ ] 把「그릇을」和「책상 위에」組成一個完整句子。

> 答案：그릇을 책상 위에 놓아요.

- [ ] 用「개」和「명」各寫一句話。

> 答案：책 3개를 읽었어요. 학생 5명이 가요.
