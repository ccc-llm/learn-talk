#### 1. 描述天氣

天氣很好，可以問：

```text
甲：오늘 날씨가 좋아요?
乙：네, 오늘 날씨가 좋아요.
```

天氣不好，可以說：

```text
오늘 날씨가 나빠요.
```

有雨時：

```text
비가 와요.
```

有雪時：

```text
눈이 와요.
```

天氣的問題不一定要用「어때요」。可以根據情況，直接問天氣是「좋아요」還是「나빠요」：

```text
甲：오늘 날씨가 나빠요?
乙：네, 오늘 날씨가 나빠요.
```

#### 2. 說明天氣與季節

| Mini-Korean | 中文 |
|---|---|
| 오늘은 날씨가 좋아요. | 今天天氣很好。 |
| 어제는 날씨가 나빴어요. | 昨天天氣不好。 |
| 지금 바람이 와요. | 現在有風。 |
| 오늘밤에 비가 와요. | 今晚會下雨。 |
| 지금 하늘에 별이 보여요. | 現在天空看得見星星。 |
| 봄에는 꽃이 예뻐요. | 春天花很漂亮。 |
| 여름에는 날씨가 더워요. | 夏天天氣很熱。 |
| 가을에는 나뭇잎이 예뻐요. | 秋天樹葉很漂亮。 |
| 겨울에는 눈이 와요. | 冬天會下雪。 |

#### 3. 自然與地點

描述動物在什麼地方做什麼事：

```text
고양이가 집에서 자요.
강아리가 공원에서 뛰어요.
새가 나무 위에서 노래해요.
```

這裡的「위에서」表示「在上面」：

| Mini-Korean | 中文 |
|---|---|
| 나무 위에서 노래해요. | 在樹上唱歌。 |
| 바다에서 수영해요. | 在海裡游泳。 |
| 방에서 자요. | 在房間裡睡覺。 |
| 학교에서 공부해요. | 在學校學習。 |

#### 1. 去和來

```text
甲：학교에 가요.
乙：네, 학교에 가요.
```

```text
친구가 집에 와요.
```

「에」用在目的地：

```text
학교에 가요.
집에 와요.
회사에서 출발해요.
```

#### 2. 走和跑

```text
학교까지 걸어요.
공원에서 뛰어요.
```

問對方是否做某件事，可以問：

```text
甲：공원에서 뛰어요?
乙：네, 공원에서 뛰어요.
```

否定句用「안」：

```text
오늘은 공원에서 안 뛰어요.
```

#### 3. 看、讀和寫

```text
창밖을 봐요.
책을 읽어요.
여기에 써요.
```

「밖」是「外面」：

```text
창밖을 봐요.
```

#### 4. 吃和喝

```text
밥을 먹어요.
커피를 마셔요.
```

詢問別人是否願意一起做某件事：

```text
甲：커피를 마셔요?
乙：네, 커피를 마셔요.
```

#### 5. 睡和起床

```text
저는 밤에 자요.
아침에 일어나요.
```

「아침에」表示時間地點：

```text
아침에 일어나요.
```

#### 6. 學習、運動和做飯

```text
학교에서 한국어를 공부해요.
공원에서 운동해요.
집에서 밥을 요리해요.
```

#### 7. 給東西

「주어요」是「給」：

```text
물 주세요.
```

詢問別人是否會給東西：

```text
甲：나무에 물을 주어요?
乙：네, 나무에 물을 주어요.
```

這裡的「물」是給予的東西，「나무에」表示給的對象。

#### 8. 等待和見面

```text
친구를 기다려요.
친구를 만나요.
```

確認過去的動作：

```text
어제 친구를 만났어요.
```

#### 9. 開始

```text
지금 시작해요.
```

「지금」是「現在」：

```text
지금 공부해요.
```

### 三、描述正在做某件事的人

要說明某人在某個地方做某件事，可以使用「-는 사람」。

| Mini-Korean | 中文 |
|---|---|
| 공원에서 뛰는 사람 | 在公園跑步的人 |
| 학교에서 공부하는 사람 | 在學校學習的人 |
| 집에서 요리하는 사람 | 在家做飯的人 |
| 책을 읽는 사람 | 讀書的人 |
| 물을 마시는 사람 | 喝水的人 |

詢問某種人時，可以說：

```text
공원에서 뛰는 사람도 있어요?
```

也可以換一種問法：

```text
공원에서 뛰는 사람이 보여요?
```

回答：

```text
네, 공원에서 뛰는 사람이 보여요.
```

這裡用「보여요」表示「看得見」，不需要使用「있어요」。

### 四、多人和單人

詞表沒有「학생들」這種形式，可以用其他說法表達複數。

#### 1. 用「학생이」表示一群學生正在做某事

```text
학생이 공부해요.
```

如果要明確表示很多人，可以使用「사람이 많아요」：

```text
학교에 사람이 많아요.
```

#### 2. 用「아이」表示孩子

```text
아이가 학교에 가요.
```

#### 3. 用「우리」表示包含自己在內的多人

```text
우리는 같이 가요.
```

#### 4. 用「각각」表示各自

```text
각각의 학생이 공부해요.
```

#### 5. 用「도」表示「也」

```text
저도 공부해요.
친구도 공부해요.
```

### 五、常見的簡短回答

詞表沒有「그래요」和「그럼」，可以依情況使用下面這些回答。

| 情況 | Mini-Korean | 中文 |
|---|---|---|
| 同意 | 네. | 是。 |
| 肯定 | 예요. | 是的。 |
| 否定 | 아니요. | 不是。 |
| 道歉 | 죄송합니다. | 對不起。 |
| 感謝 | 감사합니다. | 謝謝。 |
| 問候 | 안녕히 가세요. | 再見。 |

對話中可以使用：

```text
甲：오늘 날씨가 좋아요?
乙：네, 오늘 날씨가 좋아요.
```

```text
甲：공원에서 뛰어요?
乙：아니요, 공원에서 안 뛰어요.
```

```text
甲：나무에 물을 주어요?
乙：네, 나무에 물을 주어요.
```

### 六、對話

```text
甲：오늘 날씨가 나빠요?
乙：네, 오늘 날씨가 나빠요. 비가 와요.
甲：우산을 써요.
乙：네, 우산을 써요. 같이 가요.
甲：공원에서 뛰어요?
乙：아니요, 학교에서 공부해요.
```

```text
甲：책을 읽어요?
乙：네, 책 읽어요. 너도 읽어요?
甲：저도 읽어요. 집에서 읽어요.
```

```text
甲：친구를 기다려요.
乙：네, 친구가 와요. 같이 만나요.
甲：좋아요. 공원에서 만나요.
```

### 七、句型整理

| 句型 | Mini-Korean | 中文 |
|---|---|---|
| 名詞＋助詞＋動詞 | 오늘 날씨가 좋아요. | 今天天氣很好。 |
| 否定 | 비가 안 와요. | 不下雨。 |
| 能力 | 못 가요. | 不能去。 |
| 過去 | 어제 친구를 만났어요. | 昨天見了朋友。 |
| 未來 | 내일 학교에 갈 거예요. | 明天去學校。 |
| 從某處開始 | 오늘부터 공부해요. | 從今天開始學習。 |
| 到某處為止 | 3시까지 일해요. | 工作到3點。 |
| 地點 | 집에서 밥을 먹어요. | 在家裡吃飯。 |
| 目的地 | 학교에 가요. | 去學校。 |
| 對象 | 친구에게 선물을 줘요. | 給朋友禮物。 |
| 所屬 | 친구의 책이에요. | 是朋友的書。 |
| 並列 | 친구하고 같이 가요. | 和朋友一起去。 |
