# 07.2 實例：科普、議論與說明

本章要學習如何把科普、議論與說明內容改寫成簡單、自然的 Mini-Korean。改寫時，可以把長句拆成短句，減少複雜的助詞，並使用「主題＋說明」、「事實＋但是＋觀點」等固定結構。

## 1. 科普內容：簡單說明自然與現象

科普內容可以使用「事物＋은/는＋性質」或「事物＋에서＋動作」的結構。先說明對象，再用簡單的動詞或形容詞補充資料。

| 說明方式 | Mini-Korean |
|---|---|
| 說明自然 | 자연에는 동물이 많아요. |
| 說明季節 | 여름에는 날씨가 덥고 겨울에는 날씨가 추워요. |
| 說明宇宙 | 우주는 아주 넓어요. |
| 說明植物 | 나무는 자연에서 자라요. |
| 說明天氣 | 비가 오면 날씨가 어두워요. |
| 說明動物 | 동물은 사람과 다릅니다. |
| 說明太陽 | 태양은 아주 뜨거워요. |

完整例句：

- 자연에는 동물이 많아요.
- 여름에는 날씨가 덥고 겨울에는 날씨가 추워요.
- 비가 오면 날씨가 어두워요.
- 나무는 자연에서 자라요.
- 우주는 아주 넓어요.
- 동물은 사람과 다릅니다.

這些句子使用簡單的主語和謂語，不需要使用複雜的修飾語。寫科普內容時，先說最重要的事實，再增加一項特徵或原因即可。

## 2. 議論內容：事實、觀點與相反看法

議論內容可以使用「事實＋하지만＋觀點」的固定結構。`하지만` 表示「但是」，可以讓兩個相反的意思連接起來。

| 表達功能 | Mini-Korean | 中文意思 |
|---|---|---|
| 事實 | 결과가 나왔어요. | 結果已經出來了。 |
| 相反看法 | 하지만 문제도 있어요. | 但是也有問題。 |
| 個人觀點 | 저는 이 방법을 좋아해요. | 我喜歡這個方法。 |
| 不同觀點 | 이 방법은 다른 사람에게 다릅니다. | 這個方法因人而異。 |
| 條件 | 비가 오면 집에 가요. | 如果下雨，我就回家。 |
| 原因 | 배가 아파서 병원에 가요. | 因為肚子痛，所以去醫院。 |
| 目的 | 저는 목적을 생각해요. | 我考慮目的。 |
| 重要觀點 | 계획은 중요해요. | 計畫很重要。 |

完整例句：

- 결과가 나왔어요. 하지만 문제도 있어요.
- 저는 이 방법을 좋아해요. 다른 사람에게는 다릅니다.
- 이 방법은 중요해요. 하지만 다른 방법도 있어요.
- 계획은 중요해요. 방법도 중요해요.
- 가능성이 있어요. 하지만 확신은 없어요.
- 결과는 좋아요. 하지만 원인은 어려워요.
- 비가 오면 집에 가요.
- 배가 아파서 병원에 가요.

使用 `하지만` 時，最好分成兩個短句。每個句子只說一件事，意思會更清楚。

## 3. 說明內容：重新安排資訊順序

說明同一個內容時，可以交換句子的次序。只要詞彙和意思不變，句子就可以重新組合。

| 說明順序 | Mini-Korean |
|---|---|
| 先說對象，再說資料 | 자연에는 동물이 많아요. 우리는 자연을 공부해요. |
| 先說目的，再說方法 | 목적을 생각해요. 그다음에 방법을 고릅니다. |
| 先說問題，再說結果 | 문제가 있어요. 그래서 결과가 달라요. |
| 先說原因，再說行動 | 배가 아파서 병원에 가요. |
| 先說一般情況，再說特殊情況 | 날씨가 좋아요. 비가 오면 날씨가 어두워요. |
| 先說人物，再說身分 | 나는 학생이에요. 나는 매일 한국어를 공부해요. |

完整例句：

- 자연에는 동물이 많아요. 우리는 자연을 공부해요.
- 동물을 알아요. 우리는 자연을 공부해요.
- 문금이 좋아요. 하지만 결과는 달라요.
- 문제가 있어요. 결과가 달라요.
- 비가 오면 집에 가요.
- 배가 아파서 병원에 가요.
- 나는 학생이에요. 나는 매일 한국어를 공부해요.
- 저는 회사에 가요. 저는 회사에 일을 해요.

### 用描述句代替表外的概念

遇到詞表內沒有的概念時，可以使用「……하는 사람」或「……하는 곳」。

| 概念 | Mini-Korean |
|---|---|
| 老師 | 한국어를 가르치는 사람 |
| 讀書的人 | 매일 책을 읽는 사람 |
| 學校 | 학생이 공부하는 곳 |
| 花園 | 꽃이 자라는 곳 |
| 解決問題的方法 | 문제를 해결하는 방법 |

完整例句：

- 제 선생님은 한국어를 가르치는 사람이에요.
- 동생은 매일 책을 읽는 사람이에요.
- 학교는 학생이 공부하는 곳이에요.
- 공원은 꽃이 자라는 곳이에요.
- 이것은 문제를 해결하는 방법이에요.

### 改寫練習

**原句：**

> 자연에는 동물이 많아요. 우리는 자연을 공부해요.

**改寫句：**

> 우리는 자연을 공부해요. 자연에는 동물이 많아요.

**原句：**

> 결과가 나왔어요. 하지만 문제도 있어요.

**改寫句：**

> 문제가 있어요. 결과가 나왔어요.

**原句：**

> 비가 오면 날씨가 어두워요. 저는 집에 가요.

**改寫句：**

> 저는 집에 가요. 비가 오면 날씨가 어두워요.

改寫時不要增加新的資料，也不要改變原來的意思。交換句子次序、拆開長句和簡化修飾語，都是安全的改寫方法。

## 練習

- [ ] 請把「우리는 자연을 공부해요. 자연에는 꽃이 많아요.」改成先說自然，再說學習。

> 答案：자연에는 꽃이 많아요. 우리는 자연을 공부해요.

- [ ] 請用 `하지만` 把「결과는 좋아요. 문제는 있어요.」連接成兩個短句。

> 答案：결과는 좋아요. 하지만 문제는 있어요.

- [ ] 請寫一個說明下雨天氣的完整句子，可以使用 `비` 和 `어두워요`。

> 答案：비가 오면 날씨가 어두워요.

- [ ] 請用「……하는 사람」描述「老師」。

> 答案：한국어를 가르치는 사람이에요.

- [ ] 請改寫「계획은 중요해요. 방법도 중요해요.」，交換句子次序。

> 答案：방법도 중요해요. 계획은 중요해요.
