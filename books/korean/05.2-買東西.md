# 05.2 買東西

## 05.2 買東西

### 學習目標

學習詢問價格、選擇商品、確認商品，以及使用「와／과」列舉物品。

### 購物常用詞

| Mini-Korean | 意思 |
|---|---|
| 가게 | 商店 |
| 손님 | 客人 |
| 직원 | 職員 |
| 과자 | 點心 |
| 가방 | 包 |
| 물 | 水 |
| 커피 | 咖啡 |
| 가격 | 價格 |
| 얼마 | 多少 |
| 결제하 | 付款 |
| 선택하 | 選擇 |
| 좋아해요 | 喜歡 |

### 詢問價格

使用「얼마예요?」詢問價格。

> 這 가방은 얼마예요?

| Mini-Korean | 意思 |
|---|---|
| 가방은 얼마예요? | 這個包多少錢？ |
| 과자는 얼마예요? | 這個點心多少錢？ |
| 커피는 얼마예요? | 這杯咖啡多少錢？ |
| 물은 얼마예요? | 這瓶水多少錢？ |

「얼마」前面使用名詞助詞「은」。名詞沒有收音時，使用「는」。

### 選擇商品

使用「봐요」查看或選擇想買的商品。

| Mini-Korean | 意思 |
|---|---|
| 제가 가방을 봐요. | 我看這個包。 |
| 제가 과자를 봐요. | 我看這個點心。 |
| 저는 이것을 봐요. | 我看這個。 |
| 저는 저 가방을 봐요. | 我看那個包。 |

也可以使用「좋아해요」說明自己喜歡的商品。

| Mini-Korean | 意思 |
|---|---|
| 저는 과자를 좋아해요. | 我喜歡點心。 |
| 저는 가방을 좋아해요. | 我喜歡包。 |
| 저는 커피를 좋아해요. | 我喜歡咖啡。 |

### 確認商品

使用「새로워요」說明商品是新的。

| Mini-Korean | 意思 |
|---|---|
| 가방은 새로워요. | 這個包是新的。 |
| 과자는 맛있어요. | 這個點心很好吃。 |
| 커피는 뜨거워요. | 這杯咖啡很燙。 |
| 물은 차가워요. | 這瓶水很冰。 |

### 在商店裡

使用「와요」和「주어요」說明客人來到商店，以及職員把商品交給客人。

| Mini-Korean | 意思 |
|---|---|
| 손님이 가게에 와요. | 客人來到商店。 |
| 직원이 과자를 주어요. | 職員交給客人點心。 |
| 손님은 과자를 받아요. | 客人收到點心。 |
| 손님은 가방을 받아요. | 客人收到包。 |

### 列舉商品

使用「하고」或「와／과」連接兩個名詞。

| Mini-Korean | 意思 |
|---|---|
| 과자하고 커피를 사요. | 我買點心和咖啡。 |
| 과자와 가방을 봐요. | 我看點心和包。 |
| 과자하고 가방을 봐요. | 我看點心和包。 |

「하고」可以放在兩個名詞之間。「과」和「와」要依照前面名詞是否有收音而改變：

- 有收音：과자**와** 커피
- 沒有收音：물**과** 커피

### 付款

「결제하」表示付款。

| Mini-Korean | 意思 |
|---|---|
| 결제하 | 付款 |

付款時，也可以使用下面的固定說法：

| Mini-Korean | 意思 |
|---|---|
| 네. | 是。 |
| 아니요. | 不是。 |
| 감사합니다. | 謝謝。 |

### 購物對話

```text
甲：가방은 얼마예요?
乙：가방은 새로워요.
甲：저는 가방을 봐요.
乙：네. 가방을 봐요.
甲：제가 과자를 봐요.
乙：저도 과자를 좋아해요.
甲：결제하.
乙：감사합니다.
```

### 句型整理

| 句型 | 用法 | 例句 |
|---|---|---|
| `N은/는 얼마예요?` | 詢問價格 | 과자는 얼마예요? |
| `N을/를 봐요.` | 查看或選擇商品 | 제가 가방을 봐요. |
| `N을/를 좋아해요.` | 表示喜歡商品 | 저는 과자를 좋아해요. |
| `손님이 가게에 와요.` | 客人來到商店 | 손님이 가게에 와요. |
| `직원이 N을/를 주어요.` | 職員交付商品 | 직원이 과자를 주어요. |
| `손님은 N을/를 받아요.` | 客人收到商品 | 손님은 가방을 받아요. |
| `N하고 N` | 列出兩個商品 | 과자하고 커피를 봐요. |

### 練習

- [ ] 詢問這個包多少錢。

> 答案：가방은 얼마예요?

- [ ] 說「我看那個包」。

> 答案：저는 저 가방을 봐요.

- [ ] 說「職員交給客人點心」。

> 答案：직원이 과자를 주어요.

- [ ] 說「客人收到包」。

> 答案：손님은 가방을 받아요.

- [ ] 列出「點心和咖啡」，並使用「하고」。

> 答案：과자하고 커피를 봐요.
