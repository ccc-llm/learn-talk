# 05.3 問路

## 05.3 問路

### 1. 問目的地

想知道某個地方在哪裡，可以使用：

> 目的地＋は／は＋どこですか？  
> 目的地＋에 어디예요?

| Mini-Korean | 中文 |
|---|---|
| 학교는 어디예요? | 學校在哪裡？ |
| 도서관은 어디에 있어요? | 圖書館在哪裡？ |
| 공원 근처에 있어요. | 在公園附近。 |

`어디예요?` 問「在哪裡？」，`어디에 가요?` 問「去哪裡？」。

### 2. 問怎麼走

| Mini-Korean | 中文 |
|---|---|
| 학교에 어떻게 가요? | 去學校怎麼走？ |
| 기차역에 어떻게 가요? | 去火車站怎麼走？ |
| 공원에 어떻게 가요? | 去公園怎麼走？ |

`어떻게 가요?` 表示「怎麼走？」

### 3. 回答方向

可以用 `에` 表示方向所在的位置：

| Mini-Korean | 中文 |
|---|---|
| 학교 앞에 있어요. | 在學校前面。 |
| 도서관 뒤에 있어요. | 在圖書館後面。 |
| 카페 옆에 있어요. | 在咖啡廳旁邊。 |
| 은행 왼쪽에 있어요. | 在銀行左邊。 |
| 은행 오른쪽에 있어요. | 在銀行右邊。 |
| 공원 근처에 있어요. | 在公園附近。 |
| 학교 반대쪽에 있어요. | 在學校對面。 |
| 여기서 학교까지 가요. | 從這裡走到學校。 |

### 4. 問路對話

```text
甲：실례합니다. 도서관은 어디에 있어요?
乙：학교 뒤에 있어요.
甲：학교에 어떻게 가요?
乙：이 길에서 직진해요. 그리고 교차로에서 오른쪽으로 가요.
甲：여기에서 학교까지 멀어요?
乙：아니요. 가까워요.
甲：감사합니다.
乙::아니요.
```

### 5. 校園裡問路

```text
甲：실례합니다. 책상은 어디에 있어요?
乙：교사 옆에 있어요.
甲：여기에서 교사까지 멀어요?
乙：아니요. 가까워요.
甲：감사합니다.
```

### 6. 常用句型

| Mini-Korean | 中文 |
|---|---|
| 실례합니다. | 不好意思打擾。 |
| 어디에 있어요? | 在哪裡？ |
| 어떻게 가요? | 怎麼走？ |
| 여기에서 멀어요? | 離這裡遠嗎？ |
| 가까워요. | 很近。 |
| 멀어요. | 很遠。 |
| 여기에서 학교까지 가요. | 從這裡走到學校。 |
| 이 길에서 직진해요. | 在這條路上直走。 |
| 교차로에서 오른쪽으로 가요. | 在十字路口向右走。 |
| 공원 뒤에 있어요. | 在公園後面。 |
| 집 앞에 있어요. | 在家前面。 |
| 카페 옆에 있어요. | 在咖啡廳旁邊。 |
| 은행 왼쪽에 있어요. | 在銀行左邊。 |
| 역 오른쪽에 있어요. | 在車站右邊。 |
| 감사합니다. | 謝謝。 |

### 7. 練習

- [ ] 問圖書館在哪裡。

> 答案：도서관은 어디에 있어요?

- [ ] 問去公園怎麼走。

> 答案：공원에 어떻게 가요?

- [ ] 說咖啡廳在學校後面。

> 答案：카페는 학교 뒤에 있어요.

- [ ] 問從這裡到車站遠不遠。

> 答案：여기에서 역까지 멀어요?

- [ ] 說車站在銀行右邊。

> 答案：역은 은행 오른쪽에 있어요.
