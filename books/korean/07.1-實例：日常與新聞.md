# 07.1 實例：日常與新聞

本章學習把一般文章改寫成簡單、自然的 Mini-Korean。重點是只使用詞表內的單字，刪除不必要的修飾，並讓每個句子只說一件事。日常敘述可以按照「時間 → 場所 → 動作 → 對象」排列；新聞則先說重要事實，再補充時間、地點與事件。

## 日常文章改寫

### 1. 先留下最重要的資訊

一般文章常有許多修飾語。受限語言應先保留人物、事情、時間和地點，再逐步增加資訊。

| 一般句意 | Mini-Korean |
|---|---|
| 我今天早上去了學校。 | 오늘 아침에 학교에 가요. |
| 我昨天傍晚和朋友一起去餐廳。 | 어제 저녁에 친구와 같이 식당에 가요. |
| 剛才朋友來了。 | 방금 친구가 왔어요. |
| 我明天早上去火車站。 | 내일 아침에 기차역에 가요. |
| 我現在在家休息。 | 지금 집에서 쉬어요. |

### 2. 一個句子只說一件事

長文章可以拆成幾個短句。不要在同一句放入太多動作、時間或原因。

| 一般句意 | Mini-Korean |
|---|---|
| 我早上吃麵包，然後去學校。 | 아침에 빵을 먹어요. 아침에 학교에 가요. |
| 朋友來了，我很高興。 | 친구가 왔어요. 저는 반가워요. |
| 下雨了，所以我待在家裡。 | 오늘 비가 와요. 저는 집에 있어요. |
| 妹妹在圖書館，弟弟在公園。 | 동생은 도서관에 있어요. 동생의 동생은 공원에 있어요. |

### 3. 對話實例

甲：오늘 오전에 학교에 가요?  
乙：네, 오늘 오전에 학교에 가요.  
甲：책도 가져가요?  
乙：네, 이 책을 가져가요.  
甲：그날 친구도 만났어요?  
乙：아니요, 그날 친구는 안 만났어요.

## 新聞文章改寫

### 1. 先寫主要事件

新聞句應先說清楚「什麼事情發生了」。詞表內沒有專門的新聞詞語時，可以使用普通動詞和場所名詞。

| 一般句意 | Mini-Korean |
|---|---|
| 一架飛機今天上午抵達機場。 | 오늘 오전에 비행기가 공항에 도착해요. |
| 昨天午後下了很多雨。 | 어제 오후에 비가 많이 왔어요. |
| 今天天氣不好。 | 오늘 날씨가 나빠요. |
| 老師今天上午教韓語。 | 오늘 오전에 선생님이 한국어를 가르쳐요. |
| 警察昨天來到公司。 | 어제 경찰이 회사에 왔어요. |

### 2. 按順序增加資訊

新聞可以分成兩個步驟：

1. **主要事件**：誰，在什麼地方，做什麼。
2. **補充資訊**：事件發生的時間。

| 資訊層次 | Mini-Korean |
|---|---|
| 主要事件 | 비행기가 공항에 도착해요. |
| 補充時間 | 오늘 오전에 비행기가 공항에 도착해요. |

### 3. 避免不必要的內容

| 原始內容 | 改寫結果 | 改寫理由 |
|---|---|---|
| 據說，今天機場可能會有更多飛機抵達。 | 오늘 공항에 비행기가 도착해요. | 刪除推測和重複資訊。 |
| 因為昨天下了很多雨，所以今天有很多人在家裡。 | 어제 비가 많이 왔어요. 오늘은 사람이 많아요. | 把原因和結果分開。 |
| 位於城市的機場今天上午很忙。 | 오늘 오전에 공항에 사람이 많아요. | 使用詞表內的名詞和形容詞。 |

## 寫作方法

| 一般文章常用的內容 | Mini-Korean 的處理方法 |
|---|---|
| 很長的修飾語 | 先刪除修飾語，再保留核心事件。 |
| 很多同時發生的動作 | 把動作拆成幾個短句。 |
| 推測、心想或消息來源 | 能刪除就刪除，不能刪除時使用簡單說法。 |
| 新聞專用詞 | 使用「사람、것、곳、때、일、말、마음、생각、종류、문제、도구、재료、자연」等類頭。 |
| 正式文章體 | 使用「예요」和簡單的現在、過去句型。 |

短文可以這樣寫：

오늘 오전에 비행기가 공항에 도착해요.  
어제 오후에는 비가 많이 왔어요.  
오늘 날씨가 나빠요.  
저는 오늘 학교에 안 가요.

## 練習

- [ ] 改寫成 Mini-Korean：我昨天在圖書館和朋友一起看了電影。

> 答案：어제 도서관에서 친구와 같이 영화를 봤어요.

- [ ] 改寫成 Mini-Korean：今天上午有一架飛機到達機場。

> 答案：오늘 오전에 비행기가 공항에 도착해요.

- [ ] 改寫成 Mini-Korean：因為下雨了，所以我待在家裡。

> 答案：오늘 비가 와요. 저는 집에 있어요.

- [ ] 改寫成 Mini-Korean：我下午去公司，晚上回家。

> 答案：오후에 회사에 가요. 저녁에 집에 돌아가요.
