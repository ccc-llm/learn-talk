# 08.1 與既有方案的對照

## 08.1 與既有方案的對照

### 方案名稱

- Basic English：改用詞表內的「영어」。
- Toki Pona：屬於外來語，第一次出現時標示為「Toki Pona（말의 이름）」。

| 方案 | 詞彙範圍 | 助詞 | 語序 | 學習方式 |
|---|---|---|---|---|
| Mini-Korean | 659 個核心詞和 417 個擴充詞 | 은・는、이・가、을・를、에、에서、도、의、하고、부터、까지 | 主語＋助詞＋修飾＋場所＋時間＋動詞＋賓語 | 先學核心詞，再學固定句型 |
| 영어 | 使用日常英語詞彙 | 使用英語助詞 | 英語語序 | 先學常用詞和基本句型 |
| Toki Pona（말의 이름） | 使用人造語言詞彙 | 使用固定語法詞 | 人造語言語序 | 透過小詞彙學習固定語法 |

### 詞彙的比較

Mini-Korean 的詞彙分成核心層和擴充層。學習者先學核心層，再用固定句型組合更多說法。

| 學習層 | 例子 | 意思 |
|---|---|---|
| 核心層 | 학생 | 學生 |
| 核心層 | 학교 | 學校 |
| 核心層 | 공부해요 | 學習 |
| 核心層 | 가요 | 去 |
| 核心層 | 중국어 | 中文 |
| 核心層 | 한국어 | 韓語 |
| 核心層 | 영어 | 英語 |

**對話**

甲：저는 한국어를 공부해요.  
乙：저는 영어도 공부해요.  
甲：그다음은 중국어예요.  
乙：그다음은 무엇을 공부해요?

### 助詞的比較

Mini-Korean 使用助詞表示句子的關係。助詞要放在前面的詞後面。

| 關係 | Mini-Korean | 例子 |
|---|---|---|
| 主題 | 은・는 | 학생은 학생이에요. |
| 主語 | 이・가 | 학생이 와요. |
| 賓語 | 을・를 | 책을 읽어요. |
| 場所 | 에、에서 | 학교에 가요. 학교에서 공부해요. |
| 所屬 | 의 | 친구의 책이에요. |
| 並列 | 하고 | 친구하고 같이 가요. |
| 起點 | 부터 | 9시부터 일해요. |
| 終點 | 까지 | 6시까지 일해요. |

**對話**

甲：이것은 누구의 책이에요?  
乙：그것은 친구의 책이에요.  
甲：친구를 만나요?  
乙：네, 친구를 만나요.  
甲：친구하고 같이 가요?  
乙：네, 같이 가요.

### 語序的比較

Mini-Korean 的動詞通常放在句尾。學生先學短句，再把短句組合起來。

| 說法 | Mini-Korean |
|---|---|
| 我是學生 | 저는 학생이에요. |
| 我去學校 | 저는 학교에 가요. |
| 我在學校學習韓語 | 저는 학교에서 한국어를 공부해요. |
| 今天和朋友一起去 | 오늘 친구하고 같이 가요. |

**對話**

甲：오늘 어디에 가요?  
乙：친구하고 같이 가요.  
甲：어디예요?  
乙：공원에 가요.  
甲：공원에서 무엇을 해요?  
乙：사진을 봐요.

### 否定句的比較

Mini-Korean 的否定句使用「안」或「못」。它們放在動詞前面。

| 意思 | Mini-Korean |
|---|---|
| 不去 | 안 가요. |
| 不去學校 | 학교에 안 가요. |
| 不能吃 | 못 먹어요. |
| 不能吃蘋果 | 사과를 못 먹어요. |

**對話**

甲：학교에 가요?  
乙：아니요, 오늘은 안 가요.  
甲：왜 안 가요?  
乙：아프기 때문이에요.  
甲：약은 먹어요?  
乙：네, 약을 먹어요.

### 疑問句的比較

Mini-Korean 可以用句尾的「요」表示疑問，也可以把助詞移到前面。

| 問法 | Mini-Korean |
|---|---|
| 你是學生嗎？ | 학생이에요? |
| 你要去哪裡？ | 어디에 가요? |
| 這是誰的書？ | 이것은 누구의 책이에요? |
| 你是誰？ | 당신은 누구예요? |

**對話**

甲：당신은 누구예요?  
乙：저는 학생이에요.  
甲：어디에 가요?  
乙：학교에 가요.  
甲：무엇을 공부해요?  
乙：한국어를 공부해요.

### 核心層和擴充層的比較

核心層提供大部分日常說法。擴充層增加時間、地點、性質和抽象概念等詞。

| 類型 | 核心層 | 擴充層 |
|---|---|---|
| 時間 | 오늘、내일、어제 | 간식、공휴일、기념일 |
| 地點 | 집、학교、공원 | 도시、마을、농장 |
| 性質 | 크、작、좋 | 비슷、중요、편리 |
| 動作 | 가、먹、보다 | 결정、선택、설명 |
| 抽象概念 | 기분、문제、사랑 | 가능성、경험、환경 |

**對話**

甲：오늘은 금요일이에요.  
乙：네, 오늘은 금요일이에요.  
甲：내일도 학교에 가요?  
乙：아니요, 내일은 주말이에요.  
甲：그럼 내일에는 무엇을 해요?  
乙：친구를 만나요.

### Mini-Korean 的固定學習方式

Mini-Korean 把複雜的說法拆成短句，再使用固定句型組合。這種方式讓學習者先掌握詞彙和句型，再逐步增加表達能力。

| 學習階段 | 固定方式 |
|---|---|
| 第一階段 | 學核心詞和基本助詞。 |
| 第二階段 | 學短句和問答。 |
| 第三階段 | 學地點、時間和修飾。 |
| 第四階段 | 學擴充詞和複合句。 |

**對話**

甲：한국어를 조금 공부해요.  
乙：무엇을 공부해요?  
甲：한국어를 공부해요.  
乙：매일 공부해요?  
甲: 아니요, 가끔 공부해요.  
乙：언제 공부해요?  
甲：저녁에 공부해요.

### 與其他方案的差異

Mini-Korean 不要求學習者立刻使用大量詞彙。它先建立一個可以讀懂和造句的小型系統。

| 問題 | Mini-Korean 的做法 |
|---|---|
| 詞彙太多 | 先學核心層。 |
| 語法太難 | 每次只學固定句型。 |
| 不知道怎麼說 | 用描述和類頭。 |
| 不會說名稱 | 使用外來語。 |
| 句子太長 | 拆成短句。 |
| 忘記規則 | 使用固定形式和固定問答。 |

### 綜合對話

甲：당신은 누구예요?  
乙：저는 학생이에요.  
甲：어디에 가요?  
乙：도서관에서 한국어를 공부해요.  
甲：한국어를 조금 알아요?  
乙: 아니요, 조금만 알아요.  
甲：무엇을 공부해요?  
乙：한국어와 영어를 공부해요.  
甲：언제 공부해요?  
乙：오늘 저녁에 공부해요.  
甲：오늘도 공부해요?  
乙：네, 오늘도 공부해요.

## 練習

- [ ] 1. 請用 Mini-Korean 回答：你是誰？

> 答案：저는 학생이에요.

- [ ] 2. 請把「我去圖書館」寫成 Mini-Korean。

> 答案：저는 도서관에 가요.

- [ ] 3. 請把「我在學校和朋友一起學習韓語」寫成 Mini-Korean。

> 答案：저는 학교에서 친구하고 같이 한국어를 공부해요.

- [ ] 4. 請把「今天不去學校」寫成 Mini-Korean。

> 答案：오늘은 학교에 안 가요.

- [ ] 5. 請問「이것은 누구의 책이에요?」的意思。

> 答案：這是誰的書？
