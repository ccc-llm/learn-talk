# 07.4 檢查工具、網頁翻譯器與 LLM 專家

這一章要學習使用工具檢查自己的韓語句子。先寫出 Mini-Korean，再用網頁翻譯器或 LLM 專家檢查詞語、助詞、語序和句尾。工具可以幫助我們发现问题，但最後還要自己確認意思是否正確。

## 一、先用簡單句型檢查意思

寫韓語句子時，先使用熟悉的基本句型。不要一次寫很長的句子，也不要使用詞表以外的單字。每個句子只說一件事，會比較容易檢查。

| 檢查項目 | 說明 | Mini-Korean |
|---|---|---|
| 主詞 | 先說誰做這件事 | 학생이 |
| 動作 | 再說做什麼 | 공부해요 |
| 地點 | 說明動作在哪裡發生 | 학교에서 |
| 順序 | 通常是主詞、場所、時間、動詞、賓語 | 저는 학교에서 한국어를 공부해요. |
| 否定 | 在動詞前面使用 안 或 못 | 학교에 안 가요. |
| 也 | 在名詞後面使用 도 | 저도 가요. |
| 並列 | 使用 하고 | 친구하고 같이 가요. |

下列句子可以分成幾個短句來檢查：

- 저는 학생이에요.
- 저는 한국어를 공부해요.
- 한국어는 재미있어요.
- 저는 학교에서 공부해요.

分開寫之後，可以分別確認主語、動詞和意思是否正確。確認沒有問題後，再把短句連接起來。

## 二、用網頁翻譯器檢查詞語和助詞

網頁翻譯器可以先用來檢查句子是否自然。它可以幫助我們看出一個句子是否缺少助詞，或助詞是否放錯位置。

| 常見問題 | 檢查方法 | 修正例子 |
|---|---|---|
| 缺少賓格助詞 | 檢查動詞前面的名詞 | 책 읽어요 → 책을 읽어요. |
| 缺少地點助詞 | 檢查「到哪裡」或「在哪裡」 | 학교 가요 → 학교에 가요. |
| 缺少場所助詞 | 檢查動作發生的地點 | 집에서 공부해요 |
| 也的助詞位置 | 檢查 도 是否放在名詞後面 | 나도 가요. |
| 句尾形式 | 檢查是否使用 해요 體 | 학생이에요. |
| 疑問句 | 檢查句尾是否加 요 | 학교에 가요? |

檢查以後，不要只看翻譯結果。還要看 Mini-Korean 的每個詞是否在詞表內，以及助詞是否正確。

例如：

- 학교에 가요.
- 집에서 공부해요.
- 책을 읽어요.
- 친구하고 같이 가요.
- 왜 가요?

這些句子都可以用網頁翻譯器檢查。若翻譯器給出的意思和自己的原意不同，就要把句子拆開，重新檢查主語和助詞。

## 三、用 LLM 專家檢查語序和句尾

LLM 專家可以根據本章的規則檢查句子。它可以檢查語序、詞彙範圍、否定形式和疑問句形式。

| 檢查項目 | 問題 | Mini-Korean 修正例 |
|---|---|---|
| 語序 | 動詞是否放在最後？ | 저는 학교에서 한국어를 공부해요. |
| 詞彙範圍 | 是否使用了詞表以外的詞？ | 오늘 학교에 가요. |
| 否定 | 안 或 못 是否放在動詞前？ | 오늘은 학교에 안 가요. |
| 過去時 | 是否正確使用 았어요 或 었어요？ | 어제 공부했어요. |
| 並列 | 是否使用 하고？ | 친구하고 같이 가요. |
| 所有格 | 是否使用 의？ | 친구의 책 |
| 疑問句 | 是否使用 요 或前置助詞？ | 누구예요? |

可以把句子分成三步檢查：

1. **先看詞語**：每個詞是否在詞表內？
2. **再看助詞**：은、는、이、가、을、를、에、에서、의、하고、부터、까지、도是否正確？
3. **最後看句尾**：是否使用 해요、았어요、었어요、예요 或 지요？

例如，這個句子：

> 저는 학교에서 친구 만나요.

檢查結果：

- 「친구」後面需要賓格助詞。
- 動作是「만나다」，所以應該使用「친구를」。
- 修正後是：**저는 학교에서 친구를 만나요.**

再例如：

> 오늘 날씨 좋아요.

檢查結果：

- 「날씨」是主題，後面使用「는」。
- 修正後是：**오늘 날씨는 좋아요.**

如果一句話有錯，不要一次改很多地方。先改助詞，再改詞語，最後重新讀一次意思。

## 四、自己再做最後確認

工具檢查完以後，還要自己確認三件事：

| 最後確認 | 問題 |
|---|---|
| 意思 | 這句話真的想說的事情嗎？ |
| 關係 | 誰對誰做什麼？ |
| 自然度 | 韓國人讀起來會覺得自然嗎？ |

可以使用下面的對話練習檢查：

甲：오늘 학교에 가요?  
乙：네, 학교에 가요.  
甲：책도 읽어요?  
乙：네, 책도 읽어요.

這段對話使用了：

- **네**：回答肯定問題。
- **-도**：表示「也」。
- **-에 가요**：表示去某個地方。
- **책을 읽어요**：表示讀書。

最後，自己再看一次每個句子：

- 只有詞表內的詞語嗎？
- 助詞的位置正確嗎？
- 動詞在最後嗎？
- 句尾是正確的 해요 體嗎？
- 句子的意思清楚嗎？

如果全部都是「是」，句子就可以完成了。

## 練習

- [ ] 選擇正確的句子。

  A. 책 읽어요.  
  B. 책을 읽어요.

> 答案：B. 책을 읽어요.

- [ ] 把「저는 학교에 안 가요.」改成疑問句。

> 答案：저는 학교에 안 가요?

- [ ] 將「친구 만나요.」改成正確的自然句子。

> 答案：친구를 만나요.

- [ ] 把「오늘 날씨 좋아요.」加上正確的主題助詞。

> 答案：오늘 날씨는 좋아요.

- [ ] 用 Mini-Korean 寫一句話，說明你今天不去學校。

> 答案：오늘은 학교에 안 가요.
