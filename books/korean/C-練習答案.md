# C 練習答案

這一章整理各章練習的參考答案。學習時先看問題，再自己寫一次，最後和本章答案比較。每個答案都使用詞表內的單字和固定句型。

## 1. 參考答案的寫法

回答問題時，先選擇合適的詞語，再依照「主語＋助詞＋修飾＋場所＋時間＋動詞＋賓語＋助詞＋句尾」排列。

| 問題類型 | 寫法 | Mini-Korean 例句 |
|---|---|---|
| 說明身分 | 名字／身分＋助詞＋句尾 | 저는 학생이에요. |
| 說明所在 | 地點＋에 | 학교에 가요. |
| 說明動作地點 | 地點＋에서 | 도서관에서 공부해요. |
| 說明持有物 | 所有者＋의＋物品 | 친구의 책이에요. |
| 詢問名字 | 询问词＋助詞＋句尾 | 이름이 무엇이에요? |
| 詢問地點 | 询问词＋句尾 | 어디예요? |

### 完整例句

1. 저는 학생이에요.
2. 제 친구는 선생님이에요.
3. 이 책은 한국어 책이에요.
4. 저는 학교에서 한국어를 공부해요.
5. 저는 내일 도서관에 가요.

## 2. 助詞與基本句型答案

助詞要放在前面的單字後面。有收音時使用 `은`、`을`；沒有收音時使用 `는`、`를`。

| 問題 | 參考答案 | 說明 |
|---|---|---|
| 我是學生。 | 저는 학생이에요. | `저`＋`는` 表示主題。 |
| 他是朋友。 | 그 친구가... | 不知道名字時，先用 `그 친구`。 |
| 我也去。 | 저도 가요. | `도` 表示「也」。 |
| 書和本子。 | 책하고 공책이... | `하고` 表示並列。 |
| 在學校學習。 | 학교에서 공부해요. | `에서` 表示動作發生的地點。 |
| 去圖書館。 | 도서관에 가요. | `에` 表示目的地。 |
| 讀這本書。 | 이 책을 읽어요. | `을` 表示賓語。 |
| 讀我的書。 | 제 책을 읽어요. | `제` 表示「我的」。 |

### 完整例句

1. 저는 학생이에요.
2. 저도 학교에 가요.
3. 저는 친구의 책이에요.
4. 책하고 공책이 있어요. → 這句不採用，因為 `있어요` 不在詞表內。
5. 저는 친구하고 같이 가요.
6. 저는 사진과 영상을 봐요. → 這句不採用，因為 `영상` 不在詞表內。

可使用的正確例句如下：

1. 저는 학생이에요.
2. 저도 학교에 가요.
3. 저는 친구의 책이에요.
4. 저는 친구하고 같이 가요.
5. 저는 사진과 영화를 봐요.

## 3. 詞彙與句尾答案

回答是非題時，可以使用 `네`、`아니요`。說明否定時，使用 `안` 加上動詞。

| 問題 | 參考答案 | 說明 |
|---|---|---|
| 你是老師嗎？ | 네, 학생이에요. | 用 `네` 回答肯定問題。 |
| 你去學校嗎？ | 아니요, 학교에 안 가요. | `안` 放在動詞前面。 |
| 這是什麼？ | 이것은 책이에요. | `이것` 表示「這」。 |
| 那個是什麼？ | 저것은 가방이에요. | `저것` 表示「那」。 |
| 誰去圖書館？ | 친구가 도서관에 가요. | 用 `가` 標示新資訊。 |
| 什麼時候見面？ | 내일 만나요. | 用現成的時間單字。 |
| 幾點見面？ | 3시에 만나요. | 數字使用阿拉伯數字。 |
| 今天星期幾？ | 오늘은 금요일이에요. | 星期名稱後使用 `은`。 |

### 完整例句

1. 네, 저는 학생이에요.
2. 아니요, 오늘은 금요일이에요.
3. 이것은 물이에요.
4. 저것은 가방이에요.
5. 친구가 내일 도서관에 가요.
6. 저는 3시에 친구와 만나요.

## 4. 綜合練習答案

回答較長的問題時，可以使用「背景提示＋主要內容」。例如先用 `는데` 說明情況，再用 `지만` 補充另一件事。

| 問題 | 參考答案 |
|---|---|
| 你現在做什麼？ | 지금 밥을 먹어요. |
| 你昨天做什麼？ | 어제 공부를 했어요. |
| 你明天去哪裡？ | 내일 학교에 가요. |
| 你和誰一起去？ | 친구하고 같이 가요. |
| 你為什麼去圖書館？ | 책을 읽으려고 도서관에 가요. → `으려고` 不在詞表內，改用 `책을 읽어요. 도서관에 가요.` |
| 你想喝什麼？ | 커피를 마셔요. |
| 你最喜歡什麼水果？ | 사과를 좋아해요. |
| 你每週做什麼？ | 매주 한국어를 공부해요. |
| 你現在住在哪裡？ | 여기 있어요. → `있어요` 不在詞表內，改用 `여기예요.` |
| 你要吃飯嗎？ | 지금 밥을 먹어요. |

可使用的完整答案如下：

1. 지금 밥을 먹어요.
2. 어제 공부를 했어요.
3. 내일 학교에 가요.
4. 친구하고 같이 가요.
5. 책을 읽어요. 도서관에 가요.
6. 커피를 마셔요.
7. 사과를 좋아해요.
8. 매주 한국어를 공부해요.
9. 여기예요.

## 5. 練習

- [ ] 用韓文回答：你是學生嗎？

> 答案：네, 저는 학생이에요.

- [ ] 用韓文說明：你和朋友一起去圖書館。

> 答案：저는 친구하고 같이 도서관에 가요.

- [ ] 用韓文回答：這是什麼？

> 答案：이것은 책이에요.

- [ ] 用韓文說明：你昨天讀書。

> 答案：어제 책을 읽었어요.

- [ ] 用韓文回答：明天幾點見面？

> 答案：내일 3시에 만나요.
