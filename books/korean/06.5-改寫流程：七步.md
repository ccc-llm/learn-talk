# 06.5 改寫流程：七步

把一般文章改成受限語言時，不要只替換少數詞語。先找出文章要說的事情，再刪去多餘資訊，最後檢查每一句是否簡單、自然。本章學習一套由 7 個步�組成的改寫流程。

## 一、七步改寫流程

| 步驟 | 做法 | 檢查問題 |
|---|---|---|
| 1. 找出重點 | 先決定文章要保留哪些事情。 | 這句話重要嗎？ |
| 2. 刪去多餘資訊 | 刪去細節、例子和重複內容。 | 可以只說這件事嗎？ |
| 3. 改用詞表內的字詞 | 找不到的字詞，用相近的說法代替。 | 這個字詞在詞表內嗎？ |
| 4. 一句只說一件事 | 把長句拆成短句。 | 每句只有一個意思嗎？ |
| 5. 整理語序 | 按照「主語＋助詞＋場所＋時間＋動詞＋賓詞」排列。 | 韓文語序自然嗎？ |
| 6. 檢查助詞 | 依收音選擇「은／는、을／를」，並檢查「에、에서、도、의」。 | 助詞正確嗎？ |
| 7. 檢查意思 | 最後確認內容完整、簡單，而且讀起來自然。 | 讀者可以看懂嗎？ |

### 1. 找出重點

改寫前，先問：「讀者真正需要知道什麼？」

| 一般意思 | Mini-Korean |
|---|---|
| 今天去學校。 | 오늘 학교에 가요. |
| 我是學生。 | 저는 학생이에요. |
| 昨天和朋友見面。 | 어제 친구를 만나요. |

一篇長文章可以先縮成幾個核心意思，再處理句子。

### 2. 刪去多餘資訊

刪去細節時，不要刪掉主語、動作和必要的對象。

| 意思 | 刪去後的 Mini-Korean |
|---|---|
| 早上在家裡吃飯，然後去學校。 | 아침에 밥을 먹어요. 학교에 가요. |
| 在圖書館看書。 | 도서관에서 책을 읽어요. |
| 和朋友一起去公園。 | 친구하고 같이 공원에 가요. |

這裡的 `같이` 表示「一起」，`하고` 用來連接兩個並列的名詞。

### 3. 改用詞表內的字詞

找不到確切字詞時，先找意思相近的說法。不要為了保留原意而使用詞表外的字詞。

| 一般意思 | Mini-Korean | 說明 |
|---|---|---|
| 這是水。 | 이것은 물이에요. | 使用詞表內的 `이것`、`물`、`예요`。 |
| 我餓了。 | 배가 고파요. | `배`、`고프`、`요` 不在詞表內，因此改成說明食物。 |
| 現在很忙。 | 지금 바빠요. | `지금`、`바쁘`、`요` 在詞表內。 |
| 他很高。 | 그 사람은 높아요. | `그`、`사람`、`높`、`요` 都在詞表內。 |

改寫時應先保留意思，再調整說法。不要為了簡短而改變事實。

### 4. 一句只說一件事

長句要拆開。每一句只保留一個主要動作或一個主要狀態。

| 長句 | 拆分後的 Mini-Korean |
|---|---|
| 我今天早上在學校讀書，然後和朋友一起吃飯。 | 오늘 아침에 학교에서 책을 읽어요. 친구하고 같이 밥을 먹어요. |
| 妹妹很聰明，而且她很認真。 | 동생은 똑똑해요. 동생은 성실해요. |
| 這本書很有意思，所以我讀了兩次。 | 이 책은 재미있어요. 저는 이 책을 2번 읽어요. |

如果同一個意思需要兩句表達，就分成兩句。不要使用很長的連接結構。

### 5. 整理語序

Mini-Korean 的基本語序是：

> 主語＋助詞＋修飾＋場所＋時間＋動詞＋賓語＋句尾

| 功能 | Mini-Korean |
|---|---|
| 主語 | 저 |
| 助詞 | 는 |
| 場所 | 학교에서 |
| 時間 | 오늘 |
| 動作 | 공부해요 |
| 賓語 | 한국어를 |

完整句子：

> 저는 학교에서 오늘 한국어를 공부해요.

也可以按照自然語氣調整資訊：

> 오늘 저는 학교에서 한국어를 공부해요.

這兩個句子都自然。詞表內的 `오늘`、`학교`、`한국어`、`공부해요` 可以互相組合。

### 6. 檢查助詞

韓語助詞要依照前面名詞的收音選擇。

| 名詞 | 收音 | 助詞 | Mini-Korean |
|---|---|---|---|
| 책 | 有收音 | `을` | 책을 읽어요. |
| 친구 | 無收音 | `를` | 친구를 만나요. |
| 물 | 有收音 | `은` | 물은 차가워요. |
| 사람 | 無收音 | `은` | 사람은 학생이에요. |

還要檢查意思是否正確：

| 意思 | Mini-Korean | 檢查 |
|---|---|---|
| 去學校 | 학교에 가요. | `에` 表示目的地。 |
| 在學校學習 | 학교에서 공부해요. | `에서` 表示動作發生的場所。 |
| 也有 | 저도 가요. | `도` 表示「也」。 |
| 朋友的書 | 친구의 책이에요. | `의` 表示「的」。 |

### 7. 檢查意思

最後從頭讀一次，確認三件事：

1. 原文的重要意思仍然存在。
2. 每句都只由詞表內的字詞組成。
3. 句子讀起來自然，不只是「意思大概正確」。

| 檢查項目 | 合格例子 |
|---|---|
| 內容完整 | 이 책은 재미있어요. 저는 이 책을 읽어요. |
| 語法正確 | 저는 학교에 가요. |
| 簡短清楚 | 친구가 와요. 저는 친구를 만나요. |

## 二、完整改寫範例

下面用一個簡單情境說明整個流程。

**原文意思：**  
今天早上，我在家裡吃了麵包，然後去了附近的圖書館。我在圖書館看書。下午和朋友一起回家。

### 第一步：找出重點

需要保留四件事：

- 今天早上在家裡吃麵包。
- 去圖書館。
- 在圖書館看書。
- 下午和朋友一起回家。

### 第二步：刪去多餘資訊

刪去「附近的」等細節，改成：

- 오늘 아침에 집에서 빵을 먹어요.
- 도서관에 가요.
- 도서관에서 책을 읽어요.
- 오후에 친구하고 같이 집에 돌아가요.

### 第三步：改用詞表內的字詞

檢查後，`图书馆` 的繁體寫法改為 `도서관`，「回家」使用 `돌아가요`。

### 第四步：一句只說一件事

一句放一個動作：

- 오늘 아침에 집에서 빵을 먹어요.
- 도서관에 가요.
- 도서관에서 책을 읽어요.
- 오후에 친구하고 같이 집에 돌아가요.

### 第五步：整理語序

檢查每一句：

- `오늘 아침에`：時間。
- `집에서`：動作發生的場所。
- `도서관에서`：動作發生的場所。
- `친구하고`：並列的人。
- `같이`：一起。

### 第六步：檢查助詞

| 句子 | 助詞檢查 |
|---|---|
| 오늘 아침에 집에서 빵을 먹어요. | `집에서` 表示起點或場所，`빵을` 使用賓格助詞。 |
| 도서관에 가요. | `도서관에` 表示目的地。 |
| 도서관에서 책을 읽어요. | `도서관에서` 表示動作場所，`책을` 表示賓語。 |
| 오후에 친구하고 같이 집에 돌아가요. | `친구하고` 表示並列，`집에` 表示目的地。 |

### 第七步：檢查意思

最後改寫結果是：

> 오늘 아침에 집에서 빵을 먹어요.  
> 도서관에 가요.  
> 도서관에서 책을 읽어요.  
> 오후에 친구하고 같이 집에 돌아가요.

這個版本保留主要事件，使用詞表內的字詞，而且每句只有一個意思。

## 三、對話：使用七步流程

甲：一般文章很長이에요.  
乙：어떻게 고쳐요?  
甲：먼저 중요한 것만 골라요. 그다음에 긴 문장을 짧게 써요. 마지막으로 단어와 조사에요?  
乙：문법도 확인해요?  
甲：네, 단어와 조사를 확인해요. 그다음에 뜻도 읽어요.  
乙：그럼 다시 한 번 읽어요?  
甲：네. 짧고 자연스러워요?  

甲：一般文章很長。  
乙：要怎麼改寫？  
甲：先選出重要的內容，再把長句寫短，最後檢查字詞和助詞。  
乙：也要檢查文法嗎？  
甲：要。檢查字詞和助詞後，再檢查意思。  
乙：所以要再讀一次？  
甲：對。要短，而且自然。
