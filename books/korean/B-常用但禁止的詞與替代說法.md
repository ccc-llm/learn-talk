# B 常用但禁止的詞與替代說法

本章學習幾個很常見、但不符合 Mini-Korean 詞表限制的詞。遇到這些詞時，要使用簡單的說法，或用「描述 ＋ 類頭」說明意思。重點不是完全避免表外詞，而是讓每句話都能由已學會的詞組成。

## 一、副詞與數量表達

有些副詞太長或意思太重，可以改成詞表裡更簡單的說法。

| 常見但禁止的說法 | Mini-Korean 替代說法 | 意思 |
|---|---|---|
| 매우 | 아주 | 非常 |
| 너무 많이 | 많이 | 很多 |
| 조금 | 조금 | 一點點 |
| 아주 많이 | 많이 | 很多 |
| 정말로 | 정말 | 真的 |

例句：

이 방은 아주 넓어요.

이 방은很寬敞。

저는 커피를 많이 마셔요.

我喝很多咖啡。

오늘은 정말 추워요.

今天真的很冷。

> `매우` 和 `너무 많이` 不是本課本的詞。不要疊加表示程度或數量，直接用 `아주`、`많이` 或 `조금`。

## 二、連接詞與句子關係

表示「但是」或「而且」時，只使用固定的功能詞。

| 常見但禁止的說法 | Mini-Korean 替代說法 | 意思 |
|---|---|---|
| 그러나 | 하지만 | 但是 |
| 그러므로 | 그래서 | 所以 |
| 한편 | 그리고 | 而且 |
| 그런데 | 그런데 | 不過 |
| 그러므로 | 때문 | 因為 |

例句：

친구가 왔어요. 하지만 저는 집에 가요.

朋友來了。但是我要回家。

그리고 저는 학교에 가요.

而且我要去學校。

오늘은 비가 와요. 그래서 집에 있어요.

今天下雨。所以我在家裡。

> `그리고` 可以連接兩個完整句子。不要使用 `그러나`、`한편` 等表外連接詞。

## 三、名詞的複數與並列

Mini-Korean 不用 `들` 表示複數。需要表示多人或物時，可以使用詞表裡的名詞、表示「也」的 `도`，或表示並列的 `하고`。

| 常見但禁止的說法 | Mini-Korean 替代說法 | 說明 |
|---|---|---|
| 학생들 | 학생 | 不用 `들` |
| 선생님들 | 선생님 | 不用 `들` |
| 친구들 | 친구 | 不用 `들` |
| 사람들 | 사람 | 不用 `들` |
| 아이들 | 아이 | 不用 `들` |
| 가방들 | 가방 | 不用 `들` |
| 친구와 | 친구하고 | 使用並列助詞 |
| 선생님과 | 선생님하고 | 使用並列助詞 |

例句：

친구하고 같이 가요.

我和朋友一起去。

저는 학생이에요. 제 동생도 학생이에요.

我是學生。我的弟弟也是學生。

이것은 제 가방이에요.

這是我的包。

> 句子裡需要表示多個對象時，可以分成幾個短句。不要直接在名詞後面加 `들`。

## 四、表外概念的簡單說法

遇到詞表沒有的概念時，先說明它是什麼，再用類頭。不要勉強使用不熟悉的外來語。

| 想表達的概念 | Mini-Korean 替代說法 | 類頭 |
|---|---|---|
| 東西、物品 | 이것 | 것 |
| 地方 | 이 곳 | 곳 |
| 時期 | 그 때 | 때 |
| 一件事情 | 그 일 | 일 |
| 說法 | 그 말 | 말 |
| 想法 | 그 생각 | 생각 |
| 種類 | 그 종류 | 종류 |
| 問題 | 그 문제 | 문제 |
| 名字 | 그 이름 | 이름 |
| 工具 | 그 도구 | 도구 |
| 材料 | 그 재료 | 재료 |
| 自然 | 자연 | 자연 |

例句：

이것은 방법이에요.

這是一種方法。

이것은 문제예요.

這是一個問題。

이것은 도구예요.

這是一件工具。

그 사람은 학생이에요.

那個人是學生。

> 描述具體的人時，可以使用「動作 ＋ `하는 사람`」。例如：책을 읽는 사람（讀書的人）、요리하는 사람（做菜的人）。
