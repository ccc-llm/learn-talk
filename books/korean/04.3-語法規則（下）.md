# 04.3 語法規則（下）

## 04.3 語法規則（下）

### 1. 主格助詞：가

表示新資訊或動作的主語時，使用 `가`。

| 說明 | Mini-Korean |
|---|---|
| 新的人或事物 | 사람이 와요. |
| 新的人或事物 | 고양이가 예뻐요. |
| 新的天氣資訊 | 비가 와요. |
| 新的數量資訊 | 손이 많아요. |

主語已經知道時，使用 `은` 或 `는`。

| 說明 | Mini-Korean |
|---|---|
| 已知的人或事物 | 저는 학생이에요. |
| 已知的人或事物 | 이 책은 재미있어요. |
| 已知的人或事物 | 우리 학교는 예뻐요. |

> `가` 和 `은`、`는` 要跟前面的詞一起使用。有收音時用 `은`，沒有收音時用 `는`。

---

### 2. 原因：때문에

表示原因時，可以使用 `때문에`。它放在名詞後面。

| 說明 | Mini-Korean |
|---|---|
| 因為問題 | 문제 때문에 계속해요. |
| 因為約定 | 약속 때문에 못 가요. |
| 因為天氣 | 날씨 때문에 안 가요. |
| 因為時間 | 시간 때문에 못 가요. |

也可以分成兩個短句：

> 시간이 없어요. 오늘은 안 가요.

這裡的 `없어요` 不在 Mini-Korean 詞表內，因此不採用這種說法。

---

### 3. 並列：그리고

表示「而且」、「然後」時，可以使用 `그리고`。一句話只說一件事，所以重要的事情可以分成短句。

| 說明 | Mini-Korean |
|---|---|
| 先吃飯，然後喝咖啡 | 밥을 먹어요. 그리고 커피를 마셔요. |
| 這是書，也是一本好書 | 이건 책이에요. 그리고 재미있어요. |
| 去學校，也去圖書館 | 학교에 가요. 그리고 도서관에 가요. |

`하고` 可以連接兩個名詞或人：

| 說明 | Mini-Korean |
|---|---|
| 朋友和一起去 | 친구하고 같이 가요. |
| 書和筆記本 | 책하고 공책이 있어요. |
| 媽媽和爸爸 | 어머니하고 아버지가 와요. |

---

### 4. 條件：만약

Mini-Korean 不使用附加 `-면` 的說法。條件句可以改成兩個短句，並用 `만약` 引出第一句。

| 說明 | Mini-Korean |
|---|---|
| 如果下雨，就回家 | 만약 비가 와요. 집에 가요. |
| 如果時間很多，就讀書 | 만약 시간이 많아요. 책을 읽어요. |
| 如果是星期天，就休息 | 만약 일요일이에요. 쉬어요. |
| 如果是約定日，就去 | 만약 약속이 있어요. 집에 가요. |

這種固定替代法分成兩個完整句子：

1. `만약` 引出假設情況。
2. 下一句說明結果。

---

### 5. 讓步：하지만

表示「雖然如此，但是」時，可以使用 `하지만`。它通常放在兩個短句之間。

| 說明 | Mini-Korean |
|---|---|
| 下雨了，但是還是回家 | 비가 와요. 하지만 집에 가요. |
| 有約定，但是還是去了 | 약속이 있어요. 하지만 학교에 가요. |
| 問題很多，但是繼續做 | 문제가 많아요. 하지만 계속해요. |
| 有人，但是還是一個人 | 사람이 있어요. 하지만 혼자 해요. |

`하지만` 可以連接兩個相反或相反方向的資訊：

> 어렵습니다. 하지만 계속합니다.

如果句中的形容詞或動詞沒有符合 Mini-Korean 詞表的說法，就改用詞表內的短句：

> 문제가 많아요. 하지만 계속해요.

---

### 6. 一個句子只說一件事

Mini-Korean 優先使用短句。兩個動作可以使用 `그리고` 分開。

| 長句 | Mini-Korean 改法 |
|---|---|
| 我吃飯，然後喝咖啡。 | 밥을 먹어요. 그리고 커피를 마셔요. |
| 孩子扔球，然後跑。 | 아이는 공을 봐요. 그리고 뛰어요. |
| 我讀書，然後做功課。 | 책을 읽어요. 그리고 공책에 써요. |
| 下雨了，所以回家。 | 비가 와요. 집에 가요. |

這樣做可以避免使用詞表以外的連接形式，也能讓每個句子更清楚。

---

### 7. 描述：說不出名字時

遇到詞表以外的人、事物、地點或工作時，可以使用描述加類頭。

#### 描述一個人

| 描述 | Mini-Korean |
|---|---|
| 修理東西的人 | 기계를 고치는 사람 |
| 讀書的人 | 책을 읽는 사람 |
| 買東西的人 | 물건을 사는 사람 |
| 教東西的人 | 한국어를 가르치는 사람 |

#### 描述一個地方

| 描述 | Mini-Korean |
|---|---|
| 吃東西的地方 | 밥을 먹는 곳 |
| 買東西的地方 | 물건을 사는 곳 |
| 看書的地方 | 책을 읽는 곳 |
| 工作的地方 | 일을 하는 곳 |

#### 描述一種事物

| 描述 | Mini-Korean |
|---|---|
| 吃的種類 | 먹는 종류 |
| 玩的種類 | 노는 종류 |
| 用的工具 | 쓰는 도구 |
| 用的材料 | 쓰는 재료 |

#### 描述一種工作

| 描述 | Mini-Korean |
|---|---|
| 看病的工作 | 병을 보는 일 |
| 教書的工作 | 책을 가르치는 일 |
| 做飯的工作 | 요리를 하는 일 |
| 修理的工作 | 기계를 고치는 일 |

---

### 8. 詞表的限制

有些常見的韓語說法不在 Mini-Korean 詞表內。因此，不能直接使用這些變化形式：

- 說「存在」時，改用 `있다`、`없다` 相關的固定替代說法。
- 說「下雨，所以……」時，改成 `비가 와요. 집에 가요.`
- 說「吃飯，然後……」時，改成 `밥을 먹어요. 그리고 커피를 마셔요.`
- 說「如果……」時，使用 `만약` 加兩個短句。
- 說「雖然……，但是……」時，使用 `하지만` 加兩個短句。
- 說不出事物名稱時，使用描述加類頭。

---

## 對話

甲：오늘 날씨가 좋아요. 하지만 밖에 가요.

乙：왜요? 집에 가요?

甲：약속이 있어요. 그리고 친구도 와요.

乙：친구하고 같이 가요?

甲：네. 집에서 만나요.

乙：만약 시간이 있어요. 같이 갈 거예요?

甲：네. 오늘은 조금 일찍 가요.

## 練習

- [ ] 1. 用 `가` 完成句子：비 ______ 와요.

> 答案：비가 와요.

- [ ] 2. 使用 `때 때문에` 不對；請使用 `때문에` 完成句子：문제 ______ 계속해요.

> 答案：문제 때문에 계속해요.

- [ ] 3. 把「我吃飯，然後喝咖啡」改成兩個短句，只使用詞表內的詞。

> 答案：밥을 먹어요. 그리고 커피를 마셔요.

- [ ] 4. 用 `만약` 和兩個短句完成：「如果下雨，就回家。」

> 答案：만약 비가 와요. 집에 가요.

- [ ] 5. 用 `하지만` 完成句子：비가 와요. ______ 집에 가요.

> 答案：하지만 집에 가요.
