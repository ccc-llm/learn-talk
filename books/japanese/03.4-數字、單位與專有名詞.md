# 03.4 數字、單位與專有名詞

本章要學習 2 件事：數字怎樣和單位一起使用，以及遇到外來語、專有名詞時怎樣書寫。數字統一使用阿拉伯數字；外來語第一次出現時，在括號內加上詞表內的說明，之後可以直接使用。

## 數字與單位

日文數字使用阿拉伯數字。數字後面接單位時，不需要空格。

| 說明 | Mini-Japanese |
|---|---|
| 3 個人 | 3人 |
| 1 本書 | 1本 |
| 5 杯水 | 5杯 |
| 7 點 | 7時 |
| 4 月 | 4月 |
| 7 成 | 7割 |

時間也可以把「時」和「分」放在數字後面。

| 說明 | Mini-Japanese |
|---|---|
| 3 點 10 分 | 3時10分 |
| 上午 8 點 | 午前8時 |
| 下午 2 點 | 午後2時 |

### 例句

1. 毎朝7時に起きます。  
2. 昨日は2人の友達と映画館に行きました。  
3. 昨日は3時間勉強しました。  
4. 5杯の水を飲みます。  
5. この機械の7割は新しいです。  
6. 4月10日に学校へ行きます。  

> 小提示：數字本身不表示單位。例如，「3人」是 3 個人，「3時」是 3 點。相同的數字會因後面的單位而有不同意思。

## 外來語

外來語通常使用片假名。第一次出現時，可以在後面加上括號說明；括號內也要使用詞表內的字詞。後面再次出現時，不必重複說明。

| 外來語 | 第一次出現 |
|---|---|
| 咖啡 | コーヒー（植物から作ります） |
| 拉麵 | ラーメン（料理） |
| 公共汽車 | バス（町の交通の道具） |
| 筆記型電腦 | パソコン（仕事の道具） |
| 計程車 | タクシー（町の交通の道具） |

### 例句

1. コーヒー（植物から作ります）を飲みます。  
2. ラーメン（料理）を食べます。  
3. バス（町の交通の道具）で学校へ行きます。  
4. パソコン（仕事の道具）で仕事をします。  
5. タクシー（町の交通の道具）で駅へ行きます。  

### 對話

甲：这是什么？  
乙：コーヒー（植物から作ります）です。  
甲： 좋습니다。  
乙：ありがとうございます。  
甲：ラーメン（料理）も食べますか。  
乙：はい、食べます。  

## 專有名詞

人名、地名和公司名稱等，是專有名詞。遇到詞表內沒有的專有名詞時，可以使用「外來語或原名 ＋ 類頭」的方式說明。

| 專有名詞的種類 | 寫法 | 說明 |
|---|---|---|
| 人名 | 原名（人） | 說明這是一個人 |
| 地名 | 原名（場所） | 說明這是一個地方 |
| 公司名稱 | 原名（仕事） | 說明這是一家公司或工作場所 |
| 作品名稱 | 原名（物語） | 說明這是一個故事或作品 |

「原名」要保留原來的文字。第一次出現時加上括號說明，第二次出現時可以直接使用名字。

| 第一次出現 | 第二次出現 |
|---|---|
| Paris（場所） | Paris |
| Mark（人） | Mark |
| Blue（物語） | Blue |

這種寫法可以讓讀者知道名詞的種類。說明裡可以使用「人、場所、仕事、物語」等詞表內的字詞。

## 練習

- [ ] 把「昨天 2 個人在圖書館學習 3 小時」寫成 Mini-Japanese。

> 答案：昨日は2人が図書館で3時間勉強しました。

- [ ] 寫出「明天下午 2 點 30 分」的 Mini-Japanese。

> 答案：明日は午後2時30分です。

- [ ] 在「咖啡」第一次出現時加上符合規則的括號說明。

> 答案：コーヒー（植物から作ります）です。

- [ ] 寫出「這個機械的 6 成是新的」。

> 答案：この機械の6割は新しいです。

- [ ] 用「場所」說明一個第一次出現的地名。

> 答案：Paris（場所）です。
