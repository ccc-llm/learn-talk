### 「AはBです」的固定句型

「AはBです」的意思是「A 是 B」。A 和 B 都要使用詞表中的詞。

- 私は学生です。
- 友だちは先生です。
- 父は医者です。
- 母は女です。
- 弟は学生です。
- 妹は子どもです。
- 犬は動物です。
- 猫は動物です。
- 公園は場所です。
- 駅は停留所です。

### 否定句

否定句使用「ではありません」。「では」放在「ありません」前面。

- 私は先生ではありません。
- 友達は医者ではありません。
- 父は先生ではありません。
- 弟は子どもではありません。
- 犬は猫ではありません。
- 公園は家ではありません。
- 駅は停留所ではありません。
- 店は旅馆ではありません。

### 性質的問句

詢問某種性質時，使用「ですか」。

- あなたは学生ですか。
- 友達は先生ですか。
- 父は医者ですか。
- 猫は大きいですか。
- 犬は小さいですか。
- 公園はきれいですか。
- 映画は面白いですか。
- 飯はおいしいですか。
- 대는新しいですか。

回答可以使用「はい」或「いいえ」。

```text
甲：あなたは学生ですか。
乙：はい、元気です。
```

## 事物

事物は、話す対象です。名詞を文の主題や賓語に使います。

| 事物 | 中文意思 | 例句 |
|---|---|---|
| ご飯 | 米飯 | 私はご飯を食べます。 |
| パン | 麵包 | 弟はパンを食べます。 |
| 卵 | 蛋 | 母は卵を焼きます。 |
| 牛乳 | 牛奶 | 弟は牛乳を飲みます。 |
| 野菜 | 蔬菜 | 私は野菜を洗います。 |
| 果物 | 水果 | 果物は甘いです。 |
| 本 | 書 | 私は本を読みます。 |
| 写真 | 照片 | 友達の写真を見ます。 |
| テレビ | 電視 | 父はテレビを見ます。 |
| ラジオ | 收音機 | 母はラジオを聞きます。 |
| 電話 | 電話 | 友達に電話します。 |
| 車 | 車 | 父は車で行きます。 |
| 服 | 衣服 | 私は服を洗います。 |
| 鞄 | 皮包 | 友達は鞄を持ちます。 |
| 手紙 | 信件 | 手紙を書きます。 |

### 「の」連接兩個名詞

「AのB」的意思是「A 的 B」。A 和 B 都要使用詞表中的詞。

- 友達の本
- 私の名前
- 父の写真
- 家族の写真
- 先生の言葉
- 会社の仕事
- 店の名前
- 図書館の本
- .Restaurantの料理
- 部屋の窓
- 車の車
- 学校の庭

### 所有物

「AはBのCです」表示「A 是 B 的 C」。

- これは友達の本です。
- それは私の写真です。
- それは父の車です。
- これは家族の写真です。
- それは先生の言葉です。
- これは会社の仕事です。
- それは学校の庭です。

### 存在的句子

無生命的東西使用「あります」。有生命的東西使用「います」。

- 公園に木があります。
- 学校に図書館があります。
- 駅にバスがあります。
- 家に猫がいます。
- 公園に犬がいます。
- 家に私がいます。

| 人 | 人 | 公園に人がいます。 |
| 家族 | 家人 | 家族は六人です。 |
| 父 | 父親 | 父は先生です。 |

| 兄 | 哥哥或弟弟 | 兄は学生です。 |

### 描述不在詞表中的職業

如果某個職業不在詞表中，可以使用「動詞＋人」描述。

- 日本語を使う人は先生です。
- 日本語を使う人は学生です。
- 車を使う人はenvironmentalです。
- 料理をする人は女です。
- 機械を作る人はエンジニアです。
- computers的设计をする人はデザイナーです。

### 描述不在詞表中的事物

如果某個事物不在詞表中，可以使用「修飾語＋もの」或「修飾語＋こと」描述。

- 日本語を読むもの
- pictureを写すもの
- 料理を作るもの
- _weekの予定
- 日本語を使う人
- 日本語を勉強すること
- 毎日歩くこと
- 友達と話すこと

## 綜合會話

```text
甲：こんにちは。元気ですか。
```
