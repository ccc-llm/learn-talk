# 01.2 為什麼 985 個單位就夠了

這一章要學的是：Mini-Japanese 選詞時，重點不是「哪個詞最常見」，而是「這個詞能不能和其他單位組合，產生更多意思」。985 個單位就像一套可以重複使用的組合工具。學會主要的詞、動詞和助詞，就能用固定語法說出更多句子。

## 1. 表達力比詞頻更重要

詞頻只是其中一個參考。更重要的是，一個單位能不能出現在很多句型裡。

| 單位 | 可以說明 | 可以組合的例句 |
|---|---|---|
| 学生 | 有這種身分的人 | 私は学生です。 |
| 先生 | 有這種工作的人 | 父は先生です。 |
| 仕事 | 要做的事情 | 父は仕事をします。 |
| 友達 | 朋友這個關係 | 友達に話します。 |
| 学校 | 學校這個地方 | 私は昨日学校に行きました。 |
| 猫 | 貓這種動物 | 公園に猫がいます。 |

幾個不同的單位，可以組成關係自然的新句子：

- 私は学生です。
- 父は先生です。
- 父は仕事をします。
- 友達に話します。
- 私は昨日学校に行きました。
- 公園に猫がいます。

因此，選詞時不是只看「這個詞會不會常見」，還要看它能進入多少個固定句型。

## 2. 小單位可以形成大表達力

Mini-Japanese 把語法分成固定的小單位。相同的單位可以替換不同的詞，也可以保留同一個詞，換掉其他部分。

| 句子 | 使用的單位 | 表達的意思 |
|---|---|---|
| 私は学生です。 | 私＋は＋学生＋です | 我是學生。 |
| 父は先生です。 | 父＋は＋先生＋です | 父親是老師。 |
| 友達は毎日勉強します。 | 友達＋は＋毎日＋勉強します | 朋友每天學習。 |
| 私は昨日図書館に行きました。 | 私＋は＋昨日＋図書館に＋行きました | 我昨天去了圖書館。 |
| テレビは家にあります。 | テレビ＋は＋家＋に＋あります | 電視在家裡。 |
| 公園に猫がいます。 | 公園に＋猫＋が＋います | 公園裡有貓。 |

這表示只要學會：

- **人物詞**：私、父、友達、先生
- **事物詞**：学生 先生 図書館 テレビ 猫
- **時間詞**：昨日、毎日
- **地點詞**：家、公園
- **助詞**：は、が、に、で
- **動詞**：行きます、あります、います、します
- **句尾**：です、ます、ました、ません

就可以組成很多不同意思的句子。這是「靠組合」增加表達力。

## 3. 核心單位先學，擴充單位再加入

核心單位不一定能表達所有事情，但可以先形成可用的基本句子。擴充單位則能增加人物、事物、時間和地點的種類。

| 表達需要 | 核心說法 | 擴充說法 |
|---|---|---|
| 表達一個人 | 私 | 私、私たち、あなた、俺たち |
| 表達地點 | ここ、そこ | こちら、そっち、空港、図書館 |
| 表達時間 | 今、今日 | 昨夜、来年、最近、毎朝 |
| 表達存在 | あります、います | あります、います |
| 表達有生命的人或動物 | います | います |
| 表達無生命的東西 | あります | あります |

完整例句如下：

- 私は今ここにいます。
- 猫は家にあります。
- 友達は昨日ここに来ました。
- 私は毎日学校に行きます。
- 父は図書館で本を読みます。
- テレビは家にあって、冷蔵庫は台所にあります。

最後一句把兩個短句放在同一個句型裡：

> テレビは家にあって、冷蔵庫は台所にあります。

「あって」由核心單位「あります」組合而成，用來表示「有……，而且……」。這種固定組合讓有限的單位可以表達更完整的意思。

## 4. 用固定句型限制自由變化

真正的日文有很多說法，但 Mini-Japanese 不追求所有變化。它先選擇固定的表達方式，再用同一套規則組合。

| 想表達的意思 | Mini-Japanese 固定說法 | 完整例句 |
|---|---|---|
| 數量 | いくつですか | 鳥はいくつですか。 |
| 價格 | いくらですか | カメラはいくらですか。 |
| 是否存在 | ありません | カメラがありません。 |
| 有生命的存在 | います | 教室に先生がいます。 |
| 無生命的存在 | あります | 机の上に本があります。 |
| 引用對方的話 | と言いました | 私は「はい」と言いました。 |
| 並列 | と | 水と牛乳を飲みます。 |
| 原因 | から | 雨だから、行きません。 |

這些說法不一定涵蓋日文的所有情境，但每一種都能穩定地表達一個完整意思。對初學者來說，**固定而且正確**比**很多而且複雜**更重要。

- 正確な言葉より、組み合わせしやすい言葉を選びます。  
  這句是在說：比起複雜的表達，選擇容易組合的表達。

- 少ない単位で、たくさんの意味を作れます。  
  這句是在說：用較少的單位，可以製造很多意思。

這就是 985 個單位能建立 Mini-Japanese 的原因：它不是靠收集大量同義詞，而是靠核心單位、擴充單位和固定語法共同產生表達力。
