# 06.5 改寫流程：七步

這一章要學習如何把一段普通文章，改寫成只使用 Mini-Japanese 詞表的受限語言。改寫時要保留主要意思，同時簡化句型、詞語和表達方式。完成後，每一句都應該自然、正確，而且只使用詞表內的字詞。

## 一、七個改寫步驟

| 步驟 | 要做的事 | 問題 | 改寫方法 |
|---|---|---|---|
| 1. 找主題 | 先找出文章要說什麼 | 這段文章的重點是什麼？ | 用一句簡單的日文寫出主題 |
| 2. 選概念 | 選出必須保留的意思 | 哪些資訊最重要？ | 只保留主要的時間、地點、人物和事情 |
| 3. 換詞語 | 把表外的詞換成詞表內的詞 | 這個詞在詞表內嗎？ | 改成具體的名詞、動詞或描述 |
| 4. 簡化句子 | 把長句拆成短句 | 一句話有幾個動作？ | 一個句子只說一件事 |
| 5. 整理語序 | 按照固定語序排列 | 主題、時間、地點、動詞是否正確？ | 使用「主語 → 時間 → 地方 → 動詞 → 賓語」 |
| 6. 檢查形式 | 檢查助詞、否定和疑問形式 | 句尾是否正確？ | 否定用「ません」，疑問句加「か」 |
| 7. 最後朗讀 | 檢查意思和自然程度 | 句子是否容易理解？ | 讀出來，確認每個詞都在詞表內 |

### 1. 找主題

先不要急著翻譯每一個字。先用一句簡單的日文說出文章的主要內容。

| 一般文章的意思 | Mini-Japanese |
|---|---|
| 我昨天在學校學習日語。 | 私は昨日学校で日本語を勉強しました。 |
| 這本書的價格是多少？ | これはいくらですか。 |

第一句先說明「誰、在什麼時候、在哪裡、做什麼」。第二句先保留「詢問價格」這個主要意思。

### 2. 選概念並換詞語

如果原句有很多細節，改寫時可以先刪去次要資訊，再把表外的概念換成具體的詞。

| 原來的意思 | 改寫後 |
|---|---|
| 我現在非常想喝咖啡。 | 今コーヒー（飲みもの）を飲みます。 |
| 他在那裡做什麼？ | 彼はあそこで何をしますか。 |

第一句把「咖啡」換成詞表內的「コーヒー」，並用「飲みもの」說明它的類別。第二句把「那裡做什麼」改成固定結構「であそこで何をしますか」。

「飲みもの」不是詞表內的字詞，因此上面的例句只適合用來說明外來語和類別的概念。實際改寫時，可以使用詞表內的「コーヒー」或「茶」，例如：

> 今コーヒーを飲みます。

### 3. 簡化句子並整理語序

一個句子只保留一個主要動作。句子的順序固定為：主語 → 時間 → 地方 → 動詞 → 賓語。

| 原始意思 | 簡化後 |
|---|---|
| 昨天，我和朋友在餐廳吃飯。 | 昨日友達とレストランで食べました。 |
| 明天下午三點去車站。 | 明日の午後3時に駅に行きます。 |
| 今天早上在家看書。 | 今朝家で本を読みます。 |

這三句都沒有使用複雜的修飾語。每個時間、地點和動作都可以清楚分開。

## 二、把抽象文章改成具體句子

普通文章常常使用很多抽象說法。改寫時，要問自己：「這句話要說的事情，能否用詞表內的具體詞表達？」

| 抽象的意思 | Mini-Japanese |
|---|---|
| 這個地方很安靜。 | この場所は静かです。 |
| 他的工作很重要。 | 彼の仕事は重要です。 |
| 那個方法很好。 | その方法はiativeです。 |

第三句中的「静か」和「iative」不在詞表內，因此正確的寫法應使用詞表內的詞：

> その方法はreonです。

這表示不能為了保留原句的抽象意思而使用表外詞。應該選擇詞表內最接近的詞。

| 需要表達的意思 | 可以使用的詞 | 句子 |
|---|---|---|
| 空間很寬 | 広い | この場所は広いです。 |
| 時間很短 | 短い | 時間は短いです。 |
| 數量很多 | 多い | 人は多いです。 |
| 事情很快結束 | 終まります、短い | 会は短くて終わります。 |

### 例子：改寫一段普通文章

下面是一個簡單的改寫過程：

**普通文章：**

我昨天和朋友一起在餐廳吃晚飯。餐廳很熱，食物也很好吃。我們吃飯的時間很長。

**第 1 步，找主題：**

> 昨日友達とレストランで夜ごはんを食べました。

**第 2 步，選概念：**

保留「昨天」「朋友」「餐廳」「吃晚飯」四個主要資訊。

**第 3 步，簡化句子：**

> レストランは暑いです。  
> 料理はおいしいです。  
> 時間は長かったです。

**第 4 步，整理語序：**

> 昨日友達とレストランで夜ごはんを食べました。  
> レストランは暑かったです。  
> 料理はおいしいです。  
> 時間は長かったです。

這一段最後有四個完整句子，每句只說一件事，而且每個詞都可以在詞表中找到。

## 三、最後檢查

完成初稿後，要從頭到尾檢查一次。不要只檢查詞語，也要檢查句子是否自然。

| 檢查項目 | 問題 | 修改方式 |
|---|---|---|
| 詞彙 | 有沒有詞表外的字？ | 換成具體的詞或使用描述 |
| 句型 | 有沒有複雜的結構？ | 拆成兩個短句 |
| 語序 | 主語和動詞的位置是否正確？ | 重新排列 |
| 否定 | 是否使用了正確的否定形式？ | 把「ない」改成「ありません」或「ません」 |
| 疑問 | 句尾是否有「か」？ | 加上「か」 |
| 命令 | 是否使用命令形式？ | 改成「〜てください」 |

### 否定句檢查

| 錯誤或不自然的寫法 | 正確寫法 |
|---|---|
| 机がない。 | 机がありません。 |
| 行きません。 | 行きません。 |
| 本を読みますか。 | 本を読みますか。 |

表格中的第一個例子是常見的簡體否定形式，但在本教材的規則中，否定要使用「ません」或「ありません」。所以寫成：

> 机がありません。

### 疑問句檢查

| 意思 | Mini-Japanese |
|---|---|
| 你是學生嗎？ | あなたは学生ですか。 |
| 這裡有車站嗎？ | ここに駅がありますか。 |
| 你幾點起床？ | あなたは何時に起きますか。 |

### 命令句檢查

| 意思 | Mini-Japanese |
|---|---|
| 請看這本書。 | この本を見てください。 |
| 請在這裡等待。 | ここで待ってください。 |
| 請聽我說。 | 私の話を聞てください。 |

### 朗讀檢查

朗讀時，如果一句話很難理解，通常表示句子太長，或使用的詞太難。可以按照下面的順序修改：

1. 先刪去不必要的資訊。
2. 再把長句拆成短句。
3. 然後把表外詞換成詞表內的詞。
4. 最後檢查助詞和句尾。

例如，「昨日友達とレストランで夜ごはんを食べました」可以簡化成：

> 昨日レストランで食べました。

如果「朋友」是重要資訊，再使用：

> 昨日友達とレストランで食べました。
