# B 常用但禁止的詞與替代說法

本章學習常見但不能直接使用的日文形式，以及如何用 Mini-Japanese 詞表中的詞改說。句尾的「て」形式通常要改成「ます」形式；表外的概念則改用「描述＋類頭」或外來語。

## 禁止的「て」形式與替代說法

日文的「て」形式可以表示命令、要求、進行或連續動作，但本教材只使用「ます」形式。遇到禁止的「て」形式時，要改用對應的動詞。

| 禁止形式 | 替代形式 | 中文意思 |
|---|---|---|
| して | します | 做 |
| 使って | 使います | 使用 |
| 切って | 切ります | 切 |
| 塗って | 塗ります | 塗 |
| 寝て | 寝ます | 睡覺 |
| 座って | 座ります | 坐 |
| 食べて | 食べます | 吃 |
| 飲んで | 飲みます | 喝 |
| 行って | 行きます | 去 |
| 見て | 見ます | 看 |
| 話して | 話します | 說、交谈 |
| 読んで | 読みます | 讀 |
| 聞いて | 聞きます | 聽 |

**例句：**

- 私は鉛筆で書きます。
- 私は今日日语を勉強します。
- 私は水を飲みます。
- 私は友達に話します。
- 私は図書館で本を読みます。
