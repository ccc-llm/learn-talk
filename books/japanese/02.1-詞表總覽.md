# 02.1 詞表總覽

本章要學習 Mini-Japanese 的十一大詞類、各類詞語的作用，以及由核心層到擴充層的學習順序。初學時先掌握高頻詞和固定句型，再逐步加入其他詞類；看到陌生概念時，也可以使用「描述＋類頭」或外來語來表達。

## 十一大詞類總覽

Mini-Japanese 的詞表分成十一大類。每一類都有主要用途，也可以和其他類別的詞組合。

| 詞類 | 主要用途 | 核心詞例 | Mini-Japanese |
|---|---|---|---|
| 代詞・指示 | 指出人、物或地點 | 私、あなた、ここ | 私はここです。 |
| 語法（功能詞） | 連接詞語，構成句型 | は、が、を、に、で | 私は本を読みます。 |
| 數量・比例 | 表示數量、倍數和比例 | 一、十、倍、割 | 3人がいます。 |
| 時間 | 表示日期、時間和時期 | 今、今日、昨日、明日 | 今は勉強します。 |
| 方位・地點 | 表示位置、方向和場所 | 学校、駅、北、隣 | 学校は駅の隣です。 |
| 自然・天氣 | 表示自然物和天氣 | 花、雨、風、空 | 空はきれいです。 |
| 動作 | 表示動作或行為 | 行きます、見ます、話します | 友達に話します。 |
| 性質 | 描述人或物的特徵 | 大きい、好き、きれい | 犬は大きいです。 |
| 事物 | 指出具體的人、物和食物 | 本、食物、駅、名前 | 私は本を読みます。 |
| 社交・人 | 表示人物、關係和社會生活 | 家族、友達、職業 | 友達と話します。 |
| 抽象概念 | 表示想法、感情和抽象事物 | 自由、希望、理由 | 自由は大切です。 |

### 分類的作用

同一個句子通常會使用不同類別的詞。名詞指出「什麼」，動詞表示「做什麼」，助詞把各部分連接起來。

| 句子成分 | 詞類 | 例句 |
|---|---|---|
| 誰 | 代詞・指示 | 私 |
| 什麼 | 事物 | 日本語 |
| 在哪裡 | 方位・地點 | 学校 |
| 做什麼 | 動作 | 勉強します |
| 怎樣 | 性質 | 上手いです |

完整例句：

- 私は学生です。
- 私は日本語を勉強します。
- 友達に話します。
- 猫がここにいます。
- 机があります。
- ご飯を食べます。
- 昨日、学校に行きました。

## 核心層與擴充層

核心層的詞語使用頻率高，而且可以組成許多句子。初學時應先記住核心層的名詞、動詞、性質詞和功能詞。擴充層則包含更多時間、數字、方向和具體詞彙，可以在基礎句型成熟後學習。

| 學習階段 | 主要內容 | 學習重點 | 例句 |
|---|---|---|---|
| 第一階段 | 代詞、功能詞、核心動作 | 問候、人物、位置和基本句型 | こんにちは。私は学生です。 |
| 第二階段 | 時間、性質、方位、核心事物 | 描述人物與地點，安排時間 | 今日、学校に行きます。 |
| 第三階段 | 數量、抽象概念與擴充詞彙 | 比較、原因、目的和完整敘述 | 私たちは一緒に勉強します。 |

核心層中的動詞可以很快和擴充層的名詞組合：

| 動作 | 名詞 | 完整句子 |
|---|---|---|
| 食べます | ご飯 | 私はご飯を食べます。 |
| 飲みます | 茶 | 私は茶を飲みます。 |
| 見ます | 写真 | 私は写真を見ます。 |
| 読みます | 本 | 私は本を読みます。 |
| 作ります | 絵 | 私は絵を作ります。 |
| 勉強します | 日本語 | 私は日本語を勉強します。 |

## 建議學習順序

學習時先掌握句子不可缺少的部分，再加入可以自由替換的詞語。

### 1. 學會基本句型

先學習「主語＋は／が＋動詞＋句尾」和「主語＋は＋時間＋場所＋動詞＋句尾」。

| 功能 | 說明 | Mini-Japanese |
|---|---|---|
| 肯定 | 表示某件事成立 | 私は学生です。 |
| 否定 | 使用「ません」 | 私は学生ではありません。 |
| 過去 | 使用「ました」 | 私は昨日学校に行きました。 |
| 疑問 | 句尾加「か」 | あなたは学生ですか。 |
| 存在 | 無生命用「あります」 | 公園に猫があります。 |
| 存在 | 有生命用「います」 | 公園に猫がいます。 |

### 2. 學會表達人物與地點

再學習代詞、人物、場所和方向。這個階段的重點是分清楚「あります」和「います」。

- あなたはどこですか。
- 私は駅にいます。
- 学校は公園の隣です。
- 病院は公園的前です。
- 家族と話します。

### 3. 學會時間、數量與性質

之後加入時間、數字和性質詞，就可以描述日常生活的更多細節。

- 今は何時ですか。
- 昨日、3時間勉強しました。
- 今日は寒いです。
- この店は安くておいしいです。
- 猫は白くて小さいです。

### 4. 學會原因、比較和抽象概念

最後學習複合句型。把功能詞和抽象概念加入基本句型中，就可以表達原因、目的、選擇和看法。

- 雨だから、行きません。
- 電車とバスに行きます。
- 日本語の勉強は conditioners不方便です。

<small>註：上句中的日文應讀作「日本語の勉強は不便です」。</small>

- 自由と平和は大切です。
- 時間はとても宝贵です。

> 上句中的日文應讀作「時間はとても大切ですか。」這樣的疑問句可以詢問抽象概念。

## 詞表組合與固定替代說法

學習一個新詞時，不要只背單詞。把它放進句子裡，並練習和已學過的詞組合。

| 新詞 | 類頭或說法 | 完整句子 |
|---|---|---|
| 作家 | 話をする人 | 彼は話をする人です。 |
| 博物館 | collectionsの場所 | 博物館は美術館の隣です。 |
| 料理 | 表面の thing | 料理はとてもおいしいです。 |
| 試験 | テスト | 来週、テストがあります。 |

如果無法說出表外的概念，可以先使用「描述＋類頭」：

- 日本語を話す人
- 食べ物の場所
- 勉強すること
- 道具
- 材料

表外的人名、地名、品牌或物種，可以使用外來語。第一次出現時加上解釋：

- コーヒー（飲みもの）を飲みます。
- テスト（試験）があります。
- バス（ car's thing）があります。

<small>註：上句中的日文應讀作「バス（交通の道具）があります」。</small>

這樣雖然句子會稍長，但是每一部分都來自詞表，也能清楚表達意思。

## 練習

- [ ] 把「我」和「学生」組成肯定句。

> 答案：私は学生です。

- [ ] 把「昨天去学校」組成完整的過去句。

> 答案：私は昨日学校に行きました。

- [ ] 用「あります」或「います」填空：机が___。

> 答案：あります。

- [ ] 把「你是学生吗」組成疑問句。

> 答案：あなたは学生ですか。

- [ ] 用「朋友」和「说话」組成句子。

> 答案：友達と話します。
