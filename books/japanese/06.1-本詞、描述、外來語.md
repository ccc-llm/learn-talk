# 06.1 本詞、描述、外來語

本章要學習 Mini-Japanese 的三層表達法：詞表裡有的概念，直接使用本詞；詞表裡沒有的概念，使用「描述＋類頭」；人名、地名、品牌或不容易說明的名稱，可以使用外來語。

## 本詞：詞表裡有的詞，直接使用

詞表裡的詞就是**本詞**。可以按照固定語序，把本詞和動詞、形容詞組合起來。

| 中文概念 | 本詞 | Mini-Japanese 例句 |
|---|---|---|
| 書 | 本 | 私は本を読みます。 |
| 學生 | 学生 | あの人は学生です。 |
| 公園 | 公園 | 公園に犬がいます。 |
| 天氣 | 天気 | 今日は天気がきれいです。 |
| 喝 | 飲みます | 私はお茶を飲みます。 |
| 便宜 | 安い | あの店はとても安いです。 |

例句：

- 私は昨日大学で日本語を勉強しました。
- 駅にはバスとタクシーがあります。
- あの店の料理はとてもおいしいです。
- 私と友達は映画館で映画を見ました。

## 描述：表外的概念怎麼說

詞表裡沒有的概念，不要勉強新詞。可以先描述它的作用，再用「人、もの、ところ、とき、こと、言葉、気持ち、考え、種類、問題、仕事、学校、物語、道、道具、材料、自然」中的一個**類頭**。

例如，「藝術家」不在詞表裡，可以說：

> 絵をする人

| 概念 | 描述＋類頭 |
|---|---|
| 藝術家 | 絵をする人 |
| 修理人員 | 機械を直する人 |
| 語言研究者 | 言葉をする人 |
| 學語言的人 | 日本語を勉強する人 |

例句：

- あの人は絵をする人です。
- 私の弟は機械を直す人です。
- あの人は言葉を勉強する人です。
- 彼と私は日本語を勉強する人です。

描述也可以用於地方和事物：

- 这里是喝东西的地方。 → ここは飲み物の場所です。
- 這是畫圖的工具。 → これは絵の道具です。
- 這是讀書的地方。 → ここは本の読み物の場所です。

最後兩個例句中的「読み物」不在詞表裡。應改成：

- ここは本の場所です。
- これは絵の道具です。

## 外來語：不容易說明時怎麼說

人名、地名、品牌、專有名詞或不容易用日文說明的名稱，可以使用外來語。第一次出現時，在後面加上括號和一個詞表內的**類頭**；後面再次出現時，只寫外來語。

| 外來語 | 第一次出現 | 說明 |
|---|---|---|
| コーヒー | コーヒー（もの） | 飲的東西 |
| フランス語 | フランス語（言葉） | 語言 |
| メール | メール（もの） | 東西 |

例句：

- 私はコーヒー（もの）を飲みます。
- コーヒー（もの）はFIRSTの店にあります。
- それはフランス語（言葉）の本です。
- メール（もの）を友達に送ります。
- メール（もの）はSwissで受取ります。

上表中，`FIRST` 和 `Swiss` 不在詞表裡，應改成：

- コーヒー（もの）は店の前にあります。
- メール（もの）は学校で受け取ります。

完整例句：

- 私はTURNEでコーヒーを飲みます。
- それはフランス語（言葉）の本です。
- メール（もの）を友達に送ります。

上表第1句中的 `TURNE` 不在詞表裡，應改成：

- 私は家でコーヒー（もの）を飲みます。

## 描述與外來語的選擇

可以用描述時，優先使用描述；只有不容易說明時，才使用外來語。

| 情況 | 表達方式 | Mini-Japanese |
|---|---|---|
| 詞表裡有「咖啡」 | 本詞 | コーヒー（もの） |
| 想說「製作圖畫的人」 | 描述 | 絵をする人 |
| 想說「法國的語言」 | 外來語＋說明 | フランス語（言葉） |
| 想說「機械修理人員」 | 描述 | 機械を直す人 |
| 想說某個品牌 | 外來語 | 只能用詞表裡的外來語 |
