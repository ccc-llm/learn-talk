# 02.3 數量、時間、方位・地點

本章要學習如何詢問和說明「多少、什麼時候、在哪裡」。Mini-Japanese 使用固定的語序：先說時間，再說地點，最後說動詞和賓語。數量可以配合「人、本、個」等量詞；地點則配合「に、で、の」表達所在位置、移動目的地和所屬關係。

## 數量：多少

詢問數量時，可以使用「いくつ」。回答時，數字後面接量詞。

| 說法 | 意思 |
|---|---|
| 何人ですか | 幾個人呢？ |
| 何本ですか | 幾本呢？ |
| 何個ですか | 幾個呢？ |
| いくらですか | 多少錢呢？ |

- 友達が 3人います。
- 机の上に 本が 2本あります。
- 皿に ケーキが 1個あります。
- この ケーキは いくらですか。

「几人」也可以用來問人數。「何本」用於本、筆等細長的物品。「何個」用於一般物品。

## 時間：什麼時候

表示日期時，可以使用月份和日期。表示一天中的時間時，可以使用「午前、午後、時、分」。句尾加「か」，就可以詢問「什麼時候」。

| 說法 | 意思 |
|---|---|
| 今日は何時ですか | 今天幾點呢？ |
| 明日は何時ですか | 明天幾點呢？ |
| 7月3日です | 7月3日 |
| 午後 3時です | 下午3點 |
| 午前 9時30分です | 上午9點30分 |

- 昨日 午後 3時に 学校へ 行きました。
- 明日 午前 9時に 会社へ 行きます。
- 今晩 7時に 家へ 帰ります。
- 毎日 午前 8時に 起きます。
- 会議は何時ですか。

時間也可以放在主語後面。常用的時間詞有「今日、昨日、明日、今、今朝、今晩、去年、来年」。

## 方位・地點：在哪裡

詢問地點時，可以使用「どこですか」。回答時，要說明地點和它的位置。

| 說法 | 意思 |
|---|---|
| 駅はどこですか | 車站在哪裡呢？ |
| 学校は 会社の 前です | 學校在公司的前面 |
| 銀行は 駅の 右です | 銀行在車站的右邊 |
| 公園は 病院の 近くです | 公園在醫院附近 |

- 私は 今 駅に います。
- レストランに 3人います。
- 銀行は 駅の 右に あります。
- 公園は 病院の 近くに あります。
- 入口は 店の 中に あります。

「に」可以表示人或物存在的地點，也可以表示目的地。「で」表示動作發生的地點。「の」可以表示兩個地點之間的位置關係。

- 友達は 喫茶店で 待ちます。
- 明日 公園へ 行きます。
- 家の 前に 車があります。

## 練習

- [ ] 「現在幾點？」請用 Mini-Japanese 回答。

> 答え：今 何時ですか。

- [ ] 「車站在哪裡？」請用 Mini-Japanese 回答。

> 答え：駅はどこですか。

- [ ] 「桌子上有 2本書。」請用 Mini-Japanese 寫出完整句子。

> 答え：机の上に 本が 2本あります。

- [ ] 「我明天上午9點去公司。」請用 Mini-Japanese 寫出完整句子。

> 答え：私は 明日 午前 9時に 会社へ 行きます。
