# 03.1 形態：免費的變化

本章要學習日文的「屈折、派生、活用」。有些變化只要學會一次規則，就能用在很多詞上，這些可以視為「免費的變化」；有些新詞則必須另外記住，不能只靠規則猜出意思。

## 1. 屈折與活用：學會規則就能使用

### 屈折

屈折是改變詞尾，但保留基本意思。例如，動詞的基本形式是「食べます」，改變句尾就能表示否定和過去。

| 形式 | Mini-Japanese | 意思 |
|---|---|---|
| 現在肯定 | 食べます | 吃 |
| 現在否定 | 食べません | 不吃 |
| 過去肯定 | 食べました | 吃了 |
| 過去否定 | 食べませんでした | 沒有吃 |

這些例子使用相同的事件形式：

- 私はご飯を食べます。
- 私はご飯を食べません。
- 昨日、私はご飯を食べました。
- 昨日、私はご飯を食べませんでした。

「ます」「ません」「ました」是常用的變化形式。學會這 3 個形式後，可以用在許多動詞上，不必逐句背下所有變化。

### 動詞的常用搭配

| 句子 | 說明 |
|---|---|
| 学校に行きます。 | 去學校 |
| 家で休みます。 | 在家休息 |
| 友達に話します。 | 跟朋友說話 |
| 図書館で本を読みます。 | 在圖書館看書 |

這些句型也可以搭配其他詞：

- 私は明日学校に行きます。
- 今日は家で休みます。
- 母に電話します。
- 昨日、図書館で日本語の本を読みました。

動詞、場所和對象都可以更換。這就是活用帶來的組合能力。

## 2. 名詞的變化：詞形不變，關係靠助詞

日文名詞通常不會像動詞一樣改變詞尾。名詞和別的詞之間的關係，主要由「は、が、を、に、で、と、の、も」表達。

| 助詞 | 意思 | Mini-Japanese |
|---|---|---|
| は | 主題 | 私は学生です。 |
| が | 新主語或強調 | 誰が来ましたか。 |
| を | 他動詞的賓語 | ご飯を食べます。 |
| に | 地點、時間點、對象 | 友達に話します。 |
| で | 動作地點、手段 | 鉛筆で書きます。 |
| と | 和、引用 | 友達と話します。 |
| の | 所屬、修飾 | 友達の本です。 |
| も | 也 | 私も学生です。 |

同一個名詞也可以放在不同助詞前：

- 猫がいます。
- 猫に餌をあげます。  
  - 不過「餌」不在詞表內，因此這個完整句子不能使用。
- 猫を見ます。

### 名詞與「です」的變化

| 形式 | Mini-Japanese |
|---|---|
| 肯定 | 私は学生です。 |
| 否定 | 私は学生ではありません。 |
| 疑問 | あなたは学生ですか。 |
| 過去 | 私は学生でした。 |

這些都是固定搭配。只要學會「です、ではありません、ですか、でした」，就能用於很多名詞。

## 3. 派生：形成新詞要另外記

派生是以一個詞作為材料，形成意思相關的新詞。新詞的意思可以理解，但它的完整形式仍然需要另外學。

| 材料 | 形成的詞 | 意思 |
|---|---|---|
| 医 | 医者 | 醫生 |
| 漢 | 漢字 | 漢字 |
| 英 | 英語 | 英語 |
| 日 | 日本語 | 日語 |
| 本 | 本屋 | 書店 |

其中「医者」可以清楚看出「醫」和「做醫療工作的人」的關係。但是，「日本」加上「語」所形成的「日本語」，不能只用材料的意思完全推出。因此，遇到新的派生詞時，仍然需要查看詞表或特別記憶。

以下是使用派生詞的完整句子：

- あの人は医者です。
- 私は日本語を勉強します。
- 友達は英語も勉強します。
- 昨日、本屋で新しい本を買いました。

「日本語」「英語」「本屋」和「医者」都是整個詞表中的詞。學習時可以先理解它們的關係，但應把它們當作完整的新詞來記。

## 4. 哪些是免費的，哪些要另外學？

| 變化 | 是否需要另外學 | 說明 |
|---|---|---|
| 食べます → 食べません | 少 | 學會「ません」的用法 |
| 食べます → 食べました | 少 | 學會「ました」的用法 |
| 私は学生です → 私は学生でした | 少 | 學會「でした」的用法 |
| 友達に話します → 友達に電話します | 是 | 「電話します」是另一個完整動詞 |
| 日本語 → 英語 | 是 | 這是兩個不同的詞 |
| 医者 → 医者 | 是 | 這是派生的新詞 |

簡單來說：

1. **改變句尾的活用**，通常可以使用已學的規則。
2. **更換名詞或動詞**，可以產生新的句子，但新詞本身仍須在詞表內。
3. **形成新的派生詞**，必須另外記住完整形式。
4. 句尾的變化不能隨意組合。例如，不能把任意動詞直接加上「ました」後，就當成正確的日文。

### 對話

甲：あなたは学生ですか。  
乙：はい、そうです。  
甲：私は日本語を勉強します。  
乙：私も日本語を勉強します。  
甲：何時ですか。  
乙：三時です。  
甲：じゃあ、図書館に行きます。  
乙：私も一緒に行きます。

這段對話使用了：

- 「か」構成疑問句。
- 「は」標示主題。
- 「も」表示「也」。
- 「ます」和「ました」表示動作的時間。
- 「に行きます」表示目的地。
