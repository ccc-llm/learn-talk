# 01.3 怎麼用這本書

本章要學習每天的進度、練習的完成方法，以及如何使用檢查工具檢查 Mini-Japanese 句子。每天學一點、寫一點、检查一點，會比一次學很多更容易進步。

## 每天的進度

每天先複習昨天學過的內容，再學習新的內容。學習新內容後，要寫幾個自己的句子。每個句子只說一件事，並且只使用詞表內的字詞。

| 今天的學習 | Mini-Japanese |
|---|---|
| 說明今天的計畫 | 今日は10分勉強します。 |
| 說明現在的進度 | 今日、2本読みました。 |
| 說明每天的習慣 | 毎日10分勉強します。 |
| 說明之後的安排 | 明日、30分勉強します。 |

每天不需要學很多。重要的是每天完成學習、練習和檢查。

### 每天的學習順序

1. 先讀昨天的例句。
2. 再學習今天的新內容。
3. 寫自己的完整句子。
4. 使用檢查工具檢查句子。
5. 有錯的句子，要重新寫。

| 步驟 | Mini-Japanese |
|---|---|
| 讀例句 | 昨天的文章を2回読みます。 |
| 寫句子 | 私の文章を書きます。 |
| 檢查句子 | 自分で答えを調べます。 |
| 問朋友 | 友達に答えを教えます。 |

## 練習怎麼做

練習時，先看例句，再寫自己的句子。可以替換主語、時間、地點、事物和動詞。不要一次改很多地方，這樣比較容易知道哪裡有錯。

| 例句 | 自己的練習 |
|---|---|
| 私は学生です。 | 私は先生です。 |
| 今日は学校に行きます。 | 明日、図書館に行きます。 |
| 猫がいます。 | 犬がいます。 |
| waters を飲みます。 | お茶を飲みます。 |
| 映画を見ます。 |  Consolidated 映画を見ます。 |

上面的替換例子必須保持正確的日文形式。下面是完整的練習例句：

- 私は学生です。
- 今日は学校に行きます。
- 明日、図書館に行きます。
- 犬がいます。
- お茶を飲みます。
- 友達と映画を見ます。
- 昨日は10分勉強しました。

寫完以後，要檢查每一個字詞是否在詞表內。也要檢查句子的順序：主語 → 修飾 → 時間 → 場所 → 動詞 → 賓語。

## 怎麼用檢查工具

檢查工具可以幫助你找到表外的字詞、不自然的搭配和句子的問題。使用時，先輸入完整句子，再逐項查看檢查結果。

| 檢查項目 | 要問的問題 | Mini-Japanese |
|---|---|---|
| 字詞 | 這個字詞在詞表內嗎？ | すべての言葉を調べます。 |
| 詞性 | 動詞和形容詞是平假名嗎？ | 動詞と形容詞を調べます。 |
| 助詞 | 句子的助詞正確嗎？ | 助詞を調べます。 |
| 句序 | 句子的順序正確嗎？ | 文章の順番を調べます。 |
| 意思 | 句子的意思清楚嗎？ | 文章の意味を調べます。 |

有錯時，不要只改一個字。先找出錯的地方，再重新寫完整的句子。

| 檢查結果 | 修改方法 | 修改後的句子 |
|---|---|---|
| 有表外的字詞 | 換成詞表內的字詞 | 私の文章を書きます。 |
| 動詞形式錯誤 | 使用「ます」形式 | 毎日勉強します。 |
| 句序不清楚 | 把時間、地點放在動詞前 | 昨日、学校に行きました。 |
| 意思不清楚 | 一句只說一件事 | 私は学生です。 |
| 否定形式錯誤 | 使用「ません」 | 私は行きません。 |

檢查完成後，再讀一次句子。讀起來自然，就表示句子可以使用；如果還不自然，就繼續修改。

## 今日的學習

今天的學習可以使用下面的句子記錄：

- 今日は10分勉強します。
- 私は学生です。
- 明日、図書館に行きます。
- 昨日は2本読みました。
- 友達に答えを教えます。
- 自分で答えを調べます。

每天完成學習、練習和檢查，之後就可以繼續下一課。
