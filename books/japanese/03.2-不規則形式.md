# 03.2 不規則形式

本章學習少數需要特別記憶的日文形式。重點包括：「する」變成「します」、名詞句使用「です」、形容詞不隨句尾改變，以及「あります」和「います」的用法。這些形式在日文中使用很多，必須特別記住。

## 1. 「する」變成「します」

「する」是特別的動詞。它和「ます」一起使用時，要變成「します」。

| 基本形式 | 特別形式 | 意思 |
|---|---|---|
| する | します | 做、進行 |
| 勉強する | 勉強します | 學習 |
| 電話する | 電話します | 打電話 |
| 案内する | 案内します | 引導、介紹 |

- 私は毎日日本語を勉強します。
- 私は友達に電話します。
- 駅で somebody に 길을聞きます。  
  這句不使用，因為「somebody」不在詞表內。

正確例句：

- 私は今日日本語を勉強します。
- 駅で人に道を聞きます。
- 会社の人に仕事のことを話します。
- 毎日retsunda ！  
  這句不使用，因為含有詞表外的文字。

## 2. 名詞句使用「です」

名詞可以用「です」表示「是」。疑問句只要在句尾加「か」。

| 名詞句 | 疑問句 |
|---|---|
| 私は学生です。 | あなたは学生ですか。 |
| 友だちは先生です。 | 友達は先生ですか。 |
| それは車です。 | それは車ですか。 |

- 私は学生です。
- あなたは学生ですか。
- 友だちは先生です。
- これは何ですか。
- それはいくらですか。

「です」也可以和「ではありません」以外的基本否定形式一起使用：

- 私は先生ではありません。  
  這句不使用，因為「では」和「ありません」雖然都在詞表內，但「ではありません」不是詞表中的完整單位。

符合 Mini-Japanese 的否定說法：

- 私は学生です。  
- 私は学生ではありません。  
  為了避免組合限制，課本使用「私は学生ではないです」也不自然，因此此處只說明：一般否定句應使用「ではありません」的說法，或改用其他固定句型。

自然而且安全的例子：

- 私は学生ですか。
- あなたは先生ですか。
- 猫は小さいです。
- 空は青いです。

## 3. 形容詞不隨句尾改變

日文形容詞不會像部分動詞一樣，隨著肯定、否定或過去形式改變。它可以直接放在「です」前面。

| 種類 | 例句 |
|---|---|
| 肯定的描述 | この水は冷たいです。 |
| 否定句中的描述 | この水は冷たくありません。 |
| 過去的描述 | 昨日の天気は寒かったです。 |

可記憶的基本形式：

| 意思 | 形式 |
|---|---|
| 好的 | 良い |
| 新的 | 新しい |
| 大的 | 大きい |
| 小的 | 小さい |
| 高的 | 高い |
| 低的 | 低い |
| 便宜的 | 安い |
| 喜歡的 | 好き |

正確例句：

- 新しい计算机は高いです。
- 古い计算机は安いでした。
- この进一步提高。  
  這句不使用，因為含有詞表外的文字。

使用詞表內的電腦說法：

- 新しいパソコンは高いです。
- 古いパソコンは安いでした。
- この本はとても面白いです。
- あの店の料理はおいしいです。
- 安い野菜は小さいです。

## 4. 「あります」和「います」

這兩個動詞表示「有」，但是用法不同。

| 動詞 | 使用的東西 | 否定形式 |
|---|---|---|
| あります | 沒有生命的東西 | ありません |
| います | 有生命的人或動物 | いません |

| 例子 | 意思 |
|---|---|
| 机があります。 | 桌子在這裡。 |
| 公園に猫がいます。 | 公園裡有貓。 |
| 友達がいます。 | 有朋友在。 |
| 公園に犬がいます。 | 公園裡有狗。 |

- 駅に店があります。
- 公園に_many 動物がいます。  
  這句不使用，因為含有詞表外的文字。

正確例句：

- 家に車があります。
- 庭園に猫がいます。
- 私に友達がいます。
- 学校に学生がいます。
- 公園に動物がいます。
- 冷蔵庫に野菜があります。

也可以用「ありません」表示不存在：

- 公園に猫がいません。
- 学校に学生がいません。
- 家に車がありません。

## 對話

甲：あなたは学生ですか。  
乙：はい、学生です。  
甲：日本語を勉強しますか。  
乙：はい、毎日勉強します。  
甲：学校に学生がいますか。  
乙：はい、います。  
甲：この本はおいしいですか。  
乙：いいえ、おいしくないです。
