# 05.3 問路

## 05.3 問路

### 1. 詢問地點

想知道某個地方在哪裡時，可以使用下面的句型。

| Mini-Japanese | 中文 |
|---|---|
| 駅は どこですか。 | 車站在哪裡？ |
| 公園は どこですか。 | 公園在哪裡？ |
| トイレは どこですか。 | 廁所在哪裡？ |
| 入口は どこですか。 | 入口在哪裡？ |

句型結構：

> 場所 + は + どこですか。

**は**標示要詢問的地方。**どこですか**表示「在哪裡」。

### 2. 回答地點

可以回答某個地方在這裡、在那裡，或在某條路上。

| Mini-Japanese | 中文 |
|---|---|
| 駅は ここです。 | 車站在這裡。 |
| 駅は あそこです。 | 車站在那裡。 |
| 駅は この道に あります。 | 車站在這條路上。 |
| 駅は あの 道に あります。 | 車站在那條路上。 |
| 公園は 家の 隣に あります。 | 公園在家旁邊。 |
| トイレは 入口の 隣に あります。 | 廁所在入口旁邊。 |

回答地點時，可以使用這些句型：

| Mini-Japanese | 中文 |
|---|---|
| 場所は ここです。 | 地方在這裡。 |
| 場所は あそこです。 | 地方在那裡。 |
| 場所は この道に あります。 | 地方在這條路上。 |

### 3. 問去某個地方的路線

詢問前往某個地方的道路時，可以使用：

> 行く 道は どこですか。

| Mini-Japanese | 中文 |
|---|---|
| 駅へ 行く 道は どこですか。 | 去車站的路在哪裡？ |
| 公園へ 行く 道は どこですか。 | 去公園的路在哪裡？ |
| 病院へ 行く 道は どこですか。 | 去醫院的路在哪裡？ |
| トイレへ 行く 道は どこですか。 | 去廁所的路在哪裡？ |

回答時，可以指出要走的路：

| Mini-Japanese | 中文 |
|---|---|
| この道です。 | 是這條路。 |
| あの道です。 | 是那條路。 |
| 駅へ 行く 道は この道です。 | 去車站的路是這條路。 |
| 公園へ 行く 道は あの道です。 | 去公園的路是那條路。 |

### 4. 確認方向

可以使用下面的句子，確認某個地方是不是在前面或附近。

| Mini-Japanese | 中文 |
|---|---|
| 駅は この道に あります。 | 車站在這條路上。 |
| 駅は あの道に あります。 | 車站在那條路上。 |
| 公園は 駅に 近いですか。 | 公園靠近車站嗎？ |
| トイレは 入口に 近いですか。 | 廁所靠近入口嗎？ |
| 駅は どこですか。 | 車站在哪裡？ |
| あの 交差点は どこですか。 | 那個十字路口在哪裡？ |

### 5. 實用對話

甲：すみません。駅は どこですか。  
乙：この道です。  
甲：駅へ 行く 道は どこですか。  
乙：この道です。  
甲：ありがとう。  
乙：いいえ。

甲：すみません。公園は どこですか。  
乙：あの 道に あります。  
甲：駅は どこですか。  
乙：駅は あの 交差点の 隣に あります。  
甲：ありがとうございます。  
乙：いいえ。

甲：トイレは どこですか。  
乙：入口の 隣に あります。  
甲：公園へ 行く 道は どこですか。  
乙：この道です。  
甲：ありがとう。  
乙：どういたしまして。
