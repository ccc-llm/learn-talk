# 05.1 見面與自我介紹

## 學習目標

學習以下Mini-Japanese：

- 打招呼：こんにちは
- 自我介紹：私は…
- 詢問名字：名前は何ですか
- 詢問國家：国はどこですか
- 詢問語言：日本語を勉強します
- 詢問職業：仕事は何ですか
- 詢問興趣：趣味は何ですか
- 使用這些句型：本人、友達、同事、學生、老師、醫生、家庭

## 1. 打招呼

| Mini-Japanese | 中文意思 |
|---|---|
| こんにちは | 你好 |
| こんばんは | 晚安 |
| さようなら | 再見 |
| すみません | 對不起；不好意思 |
| ありがとう | 謝謝 |

### 對話

甲：こんにちは。  
乙：こんにちは。  

甲：すみません。  
乙：いいえ。  

甲：ありがとうございます。  
乙：さようなら。  

### 說明

`こんにちは` 可以用於白天打招呼。  
`こんばんは` 可以在晚上使用。  
`さようなら` 是再見的意思。  
`すみません` 可以用來表示對不起，也可以用來打擾別人。  
`ありがとう` 表示謝謝。  
`いいえ` 是「不」或「不是」的意思。

## 2. 自我介紹

| Mini-Japanese | 中文意思 |
|---|---|
| 私は……です | 我是…… |
| 私は学生です | 我是學生 |
| 私は先生です | 我是老師 |
| 私は医者です | 我是醫生 |
| 私は友達です | 我是朋友 |
| 私は家族です | 我是家人 |
| 私は 디자인 ナーです | 我是設計師 |

### 說明

`私` 表示「我」。  
`は` 標示句子的主題。  
`です` 表示「是」。

自我介紹時，可以使用固定句型：

> 私は［職業や身份］です。

### 對話

甲：私は学生です。  
乙：私は先生です。  

甲：私は医者です。  
乙：私は家族です。  

## 3. 詢問名字

| Mini-Japanese | 中文意思 |
|---|---|
| 名前は何ですか | 你的名字是什麼？ |
| 私の名前です | 是我的名字 |
| 呼び方は何ですか | 你的稱呼方式是什麼？ |
| 名前が你知道 | 知道名字 |
| 名前の呼び方は何ですか | 名字的稱呼方式是什麼？ |

### 對話

甲：名前は何ですか。  
乙：田中です。  

甲：呼び方は何ですか。  
乙：田中です。  

甲：名前の呼び方は何ですか。  
乙：家族は田中です。  

### 說明

`何` 表示「什麼」。  
`名前` 表示「名字」。  
`呼び方` 表示「稱呼方式」。  
詢問名字時，可以使用：

> 名前は何ですか。

## 4. 詢問國家

| Mini-Japanese | 中文意思 |
|---|---|
| 国はどこですか | 你的國家是哪裡？ |
| ここです | 在這裡 |
| そこです | 在那裡 |
| あそこです | 在那邊 |
| 家族と話します | 和家人說話 |

### 對話

甲：国はどこですか。  
乙：ここです。  

甲：友達と話します。  
乙：はい。  

### 說明

`国` 表示「國家」。  
`どこ` 表示「哪裡」。  
`どこですか` 是詢問地點的固定句型。

詢問國家的時候，可以使用：

> 国はどこですか。

## 5. 詢問語言

| Mini-Japanese | 中文意思 |
|---|---|
| 日本語を勉強します | 我學習日語 |
| 日本語を話します | 我說日語 |
| 英語を勉強します | 我學習英語 |
| 中国語を勉強します | 我學習中文 |
| フランス語を勉強します | 我學習法語 |
| 韓国語を勉強します | 我學習韓語 |
| 日本語を話せます | 我能說日語 |

### 對話

甲：日本語を話せますか。  
乙：はい。日本語を話します。  

甲：英語も話せますか。  
乙：いいえ。英語は少しだけです。  

甲：フランス語を勉強します。  
乙：フランス語（言葉）です。  

### 說明

`を` 標示動作的直接賓語。  
`話します` 表示「說話、聊天」。  
`勉強します` 表示「學習、用功」。  
`話せます` 表示「能說、能講」。

外來語第一次出現時，要加上中文解釋。  
例如：

> フランス語（言葉）です。

這裡的解釋使用詞表內的`言葉`。

## 6. 詢問職業

| Mini-Japanese | 中文意思 |
|---|---|
| 仕事は何ですか | 你的工作是什麼？ |
| 仕事はgradationです | 工作是…… |
| 会社員です | 是公司職員 |
| エンジニアです | 是工程師 |
| デザイナーです | 是設計師 |
| 医者です | 是醫生 |
| 先生です | 是老師 |
| Policeです | 是警察 |

### 對話

甲：仕事は何ですか。  
乙：エンジニアです。  

甲：的设计師ですか。  
乙：いいえ。私は会社員です。  

甲：家族は何 dulce吗。  
乙：お母さんは先生です。  

### 說明

`仕事` 表示「工作」。  
`何` 表示「什麼」。  
職業的名稱可以放在句尾，使用`です`：

> 私は［職業］です。

## 7. 詢問興趣

| Mini-Japanese | 中文意思 |
|---|---|
| 趣味は何ですか | 你的興趣是什麼？ |
| 趣味は音楽です | 興趣是音樂 |
| 趣味は映画です | 興趣是電影 |
| 趣味は読書です | 興趣是讀書 |
| 趣味は旅行です | 興趣是旅行 |
| 趣味は料理です | 興趣是料理 |
| 趣味はスポーツです | 興趣是運動 |

### 對話

甲：趣味は何ですか。  
乙：音楽です。  

甲： اللغ어도話します。  
乙：(board).  

甲：趣味は旅行ですか。  
乙：はい。趣味は旅行です。  

### 說明

`趣味` 表示「興趣、喜歡的事情」。  
詢問興趣時，可以使用：

> 趣味は何ですか。

回答時，可以直接說：

> 趣味は音楽です。

## 8. 介紹家人和朋友

| Mini-Japanese | 中文意思 |
|---|---|
| 家族は何人ですか | 家裡有幾個人？ |
| 家族は3人です | 家裡有3個人 |
| 友達と話します | 和朋友說話 |
| 友達に話します | 對朋友說話 |
| 友達に説明します | 向朋友說明 |
| 家族に伝えます | 告訴家人 |
| 友達とчанします | 和朋友一起 |
| 一緒に行きます | 一起去 |

### 對話

甲：家族は何人ですか。  
乙：家族は3人です。  

甲：友達に話します。  
乙：私は家族に伝えます。  

甲：一緒に行きます。  
乙：はい。行きます。  

### 說明

`何人` 表示「幾個人」。  
`家族は3人です` 的意思是「家裡有3個人」。  
`友達` 表示「朋友」。  
`家族` 表示「家人」。  
`一緒` 表示「一起」。  
`和某人一起做某事` 可以使用`と`。

## 9. 見面時的完整對話

甲：こんにちは。  
乙：こんにちは。  

甲：名前は唐ですか。  
乙：はい、名前です。  

甲：職業は何ですか。  
乙：エンジニアです。  

甲：趣味は何ですか。  
乙：音楽です。  

甲：日本語を勉強します。  
乙：私も日本語を勉強します。  

甲：家族は何人ですか。  
乙：家族は3人です。  

甲：一緒に行きますか。  
乙：はい、行きます。  

甲：ありがとうございます。  
乙：いいえ、どうぞ。  

### 說明

`私も` 表示「我也」。  
`一緒に行きますか` 是「一起去嗎」的意思。  
`どうぞ` 不在詞表內，因此不要使用這個說法。  
表達「請」或「一起」時，可以使用：

> 一緒に行きます。  
> 行きます。
