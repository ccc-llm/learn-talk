# 02.4 自然・天氣與動作

本章學習自然界的東西，以及最常用的動作。可以用這些詞說明天氣、動植物和人的行為，並練習「あります」和「います」的差別。

## 自然界的東西

自然界的東西可以用「が」作主語。描述某個地方有什麼東西時，常用「あります」；描述有生命的動物或人時，常用「います」。

| Mini-Japanese | 中文意思 |
|---|---|
| 空があります | 有天空 |
| 風があります | 有風 |
| 山があります | 有山 |
| 犬がいます | 有狗 |
| 猫がいます | 有猫 |
| 花があります | 有花 |

### 例句

- 空に太陽があります。
- 庭に花があります。
- 森に鳥がいます。
- 川に魚がいます。
- 公園に木があります。

## 天氣與自然現象

描述天氣時，可以使用「天気」和「空」。「晴れます」表示放晴，「雨が降ります」表示下雨，「雪が降ります」表示下雪。

| Mini-Japanese | 中文意思 |
|---|---|
| 天気 | 天氣 |
| 晴れ | 晴天 |
| 曇り | 陰天 |
| 雨 | 雨 |
| 雪 | 雪 |
| 風 | 風 |
| 雷 | 雷 |
| 虹 | 彩虹 |

### 例句

- 今日はいい天気です。
- 今、晴れです。
- 午後から雨が降ります。
- 昨夜、雪が降りました。
- 強い風が吹きます。
- 空に虹があります。

## 最常用的動作

最常用的動作可以按照「什麼東西＋什麼動作」來組合。動詞要放在主語和賓語後面。過去式把「ます」變成「ました」；否定式使用「ません」。

| Mini-Japanese | 中文意思 |
|---|---|
| 降ります | 下雨、下雪、下降 |
| 吹きます | 吹 |
| 咲きます | 開花 |
| 動きます | 移動 |
| 鳴きます | 鳴叫 |
| 光ります | 發光 |
| 洗います | 洗 |
| 食べます | 吃 |
| 飲みます | 喝 |
| 見ます | 看 |

### 例句

- 犬が走ります。
- 猫が座っています。
- 鳥が空を飛 这里飛。
- 花が咲きます。
- 風で葉が動きます。
- 太陽が光ります。

## 練習

- [ ] 1. 用「あります」填空：庭に花＿＿＿。  
  > 答案：あります

- [ ] 2. 用「います」填空：森に鳥＿＿＿。  
  > 答案：います

- [ ] 3. 將句子改成過去式：雨が降ります。  
  > 答案：雨が降りました。

- [ ] 4. 將句子改成否定式：犬がいます。  
  > 答案：犬がいません。

- [ ] 5. 選擇正確的動詞：花＿＿＿。（開く／咲く）  
  > 答案：咲きます。
