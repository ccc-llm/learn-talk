# 06.4 先定義、後沿用

## 什麼是「先定義、後沿用」

第一次看到一個不熟悉的外來語時，先用括號說明它是什麼，再繼續使用。第二次以後，只寫外來語本身，不再重複說明。本章會學習如何在文章中第一次使用外來語，以及如何讓後文保持簡單。

## 第一次出現：先說明

第一次出現的外來語後面加括號。括號內用詞表中的詞說明它的類別。

| 外來語 | 第一次出現 | 說明 |
|---|---|---|
| コーヒー | コーヒー（もの） | 咖啡是一種東西 |
| ホテル | ホテル（ところ） | 酒店是一個地方 |
| テスト | テスト（もの） | 測試是一種東西 |
| レストラン | レストラン（ところ） | 餐廳是一個地方 |
| バス | バス（もの） | 公車是一種東西 |

例句：

1. 毎朝、コーヒー（もの）を飲みます。
2. ホテル（ところ）に到着します。
3. 昨日、テスト（もの）があります。
4. レストラン（ところ）で食べます。
5. バス（もの）で会社に行きます。

括號中的說明只放在第一次出現的地方。它不是新的詞，而是幫助讀者知道這個外來語的種類。

## 第二次以後：直接沿用

同一篇文章再次出現相同的外來語時，不加括號，也不重複說明。

| 第一次出現 | 後面的用法 |
|---|---|
| コーヒー（もの）を飲みます | 午後もコーヒーを飲みます |
| ホテル（ところ）に到着します | ホテルに一晩います |
| テスト（もの）があります | テストの答えを書きます |
| レストラン（ところ）で食べます | レストランで dinner をします |
| バス（もの）で会社に行きます | バスは毎日来ます |

例句：

1. 毎朝、コーヒー（もの）を飲みます。午後もコーヒーを飲みます。
2. ホテル（ところ）に到着します。ホテルに一晩います。
3. 昨日、テスト（もの）があります。テストの答えを書きます。
4. レストラン（ところ）で食べます。レストランでお茶を飲みます。
5. バス（もの）で会社に行きます。バスは毎日来ます。

「先定義、後沿用」的好處是文章只解釋一次，後面可以一直使用同一個詞。

## 在對話中使用

對話裡也可以先說明第一次出現的外來語，後面直接沿用。

甲：毎朝、コーヒー（もの）を飲みますか。  
乙：はい。午後もコーヒーを飲みます。  
甲：ホテル（ところ）に到着しましたか。  
乙：はい。ホテルに一晩います。  
甲：テスト（もの）は難しいですか。  
乙：いいえ。テストは:after，难以到しました。

## 小提醒

- 第一次出現：外來語（類別）。
- 第二次以後：只寫外來語。
- 括號內的說明要簡短。
- 外來語也可以放在句子的前面或後面。
- 如果同一個詞先出現，後文就不再加括號。
- 不要把括號裡的說明當成另一個外來語。

## 練習

- [ ] 1. 請用「先定義、後沿用」寫出完整句子：早上喝咖啡，下午也喝咖啡。

> 答案：毎朝、コーヒー（もの）を飲みます。午後もコーヒーを飲みます。

- [ ] 2. 請用「先定義、後沿用」寫出完整句子：昨天有測試，之後寫答案。

> 答案：昨日、テスト（もの）があります。テストの答えを書きます。

- [ ] 3. 請用「先定義、後沿用」寫出完整句子：在餐廳吃飯，之後喝茶。

> 答案：レストラン（ところ）で食べます。レストランでお茶を飲みます。

- [ ] 4. 請用「先定義、後沿用」寫出完整句子：搭公車去公司，公車每天來。

> 答え：バス（もの）で会社に行きます。バスは毎日来ます。
