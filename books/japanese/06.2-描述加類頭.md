# 06.2 描述加類頭

本章學習「描述 ＋ 類頭」：當要表達某個概念，但詞表內沒有直接的名詞時，先說明它的作用，再用類頭指出它屬於哪一類。「類頭」像「人」「地方」「東西」等總稱詞，可以讓句子只使用詞表內的詞。

## 描述的公式

描述通常由「修飾部分 ＋ 類頭」組成。

| 公式 | 中文意思 | 完整例句 | 中文翻譯 |
|---|---|---|---|
| …をする人 | 做某事的人 | 日本語を勉強する人は先生です。 | 學日本語的人是老師。 |
| …のもの | 某種東西 | 大きいものはこのカメラです。 | 大的東西是這台照相機。 |
| …の場所 | 做某事的地方 | 駅へ行く場所はここです。 | 去車站的地方在這裡。 |
| …のこと | 做某事這件事 | 毎日勉強することは楽しいです。 | 每天學習是很快樂的。 |
| …をする言葉 | 做某事的話 | あいさつする言葉を教えてください。 | 請教我打招呼的說法。 |
| …の気持ち | 做某事的心情 | 勉強する気持ちは強いです。 | 學習的心情很強。 |
| …の考え | 做某事的想法 | 日本語を使う考えは面白いです。 | 使用日語的想法很有趣。 |
| …の仕事 | 做某事的工作 | 日本語を教える仕事です。 | 是教日語的工作。 |
| …の道 | 通往某處的路 | 駅へ行く道はここです。 | 去車站的路在這裡。 |
| …の道具 | 做某事的工具 | 紙を切る道具は何ですか。 | 剪紙的工具是什麼？ |
| …の材料 | 做某事的材料 | 牛乳と茶を使う材料は何ですか。 | 使用牛奶和茶的材料是什麼？ |

## 類頭的固定結構

| 修飾部分 | 類頭 | 說明 |
|---|---|---|
| 日本語を勉強する | 人 | 說明「人」在做什麼。 |
| 駅へ行く | 道 | 說明「道」通往哪裡。 |
| 紙を切る | 道具 | 說明「道具」的使用方法。 |
| 牛乳と茶を使う | 材料 | 說明「材料」用在什麼地方。 |
| 日本語を使う | 考え | 說明「考え」的內容。 |
| 毎日勉強する | こと | 把動作說成一件「事情」。 |

### 完整對話

甲：駅へ行く場所はここですか。  
乙：はい、駅へ行く道はここです。

甲：日本語を勉強する場所はどこですか。  
乙：学校です。

甲：紙を切る道具は何ですか。  
乙：ナイフです。

甲：日本語を勉強する人は先生ですか。  
乙：いいえ、わたしは学生です。

甲：牛乳と茶を使う材料は何ですか。  
乙：牛乳と茶です。

## 描述的使用順序

描述放在名詞前面。

| 描述 | 名詞 | 完整句 |
|---|---|---|
| 日本語を勉強する | 場所 | 日本語を勉強する場所は学校です。 |
| 駅へ行く | 道 | 駅へ行く道はここです。 |
| 紙を切る | 道具 | 紙を切る道具はナイフです。 |
| 日本語を使う | 考え | 日本語を使う考えは面白いです。 |
| 家族について話す | 物語 | 家族について話す物語は面白いです。 |

### 注意事項

1. 類頭必須放在描述的後面：日本語を勉強する＋人。
2. 修飾部分先說明作用，再由類頭說明類別：紙を切る＋道具。
3. 類頭要選對。 describing a person use 「人」；describing a road use 「道」；describing a tool use 「道具」。
4. 句末仍要使用詞表內的句尾：です、ですか、ます、ました、ません。

### 更多完整例句

- 日本語を勉強する学校は小さいです。
- 家族について話す物語は面白いです。
- 駅に人が多いです。
- 雨が降るとき、駅に人が多いです。
- 日本語を勉強するとき、音楽を聞きます。
