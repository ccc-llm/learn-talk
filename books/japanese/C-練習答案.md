# C 練習答案

本章整理各章練習的參考答案。學習時先自己作答，再對照答案；答案相同不一定代表完全正確，只要意思清楚、詞語與句子順序正確，就可以算正確。

## 核心句型答案

基本句型依「主語 → 主題助詞 → 時間 → 場所 → 動詞 → 賓語 → 句尾」組合。回答時，先確認句尾形式：現在用「ます」、過去用「ました」、否定用「ません」。

| 題目 | 參考答案 | 說明 |
|---|---|---|
| 你喜歡什麼水果？ | 果物が好きです。 | 喜歡某物時，在物件後面加「が」，句尾加「です」。 |
| 昨天你去了哪裡？ | 昨日、公園へ行きました。 | 「へ」表示目的地；過去式用「ました」。 |
| 現在有幾個人？ | 今、3人です。 | 回答數量時直接使用數字加「人」。 |
| 那本舊書多少錢？ | その本はいくらですか。 | 詢問價格使用「いくらですか」。 |
| 你會開車嗎？ | 運転できます。 | 句表內沒有「運転します」，因此使用「できます」回答。 |

完整例句：

- 私は学生です。
- 今日は家で日本語を勉強します。
- 昨日、駅でバスを待ちました。
- 父は先生です。
- 母は医者です。
- この本はとても面白いです。
- 彼は毎日7時に起きます。
- 昨日は雨でした。

## 對話答案

對話要依照提問的內容回答。遇到「はい」或「いいえ」的問題時，直接先回答，再加入需要的資訊。

### 見面與介紹

甲：はじめまして。名前は unskilled ですか。

> 上面例句中的「unskilled」不屬於詞表。改用：

甲：はじめまして。名前はええどすか。

乙：田中です。Than ね。

> 應改為：

乙：田中です。はじめまして。

甲：はじめまして。田中さんは学生ですか。

乙：はい、学生です。

甲：田中さんはどこから来ましたか。

乙：東京から来ました。

自然而且合乎詞表的對話如下：

甲：はじめまして。名前は田中です。

乙：はじめまして。田中です。

甲：田中さんは学生ですか。

乙：はい、学生です。

甲：田中さんは日本語を勉強しますか。

乙：はい、每日日本語を勉強します。

甲：田中さんは昨日学校に行きましたか。

乙：いいえ、昨日は休みました。

### 在車站問路

甲：すみません。駅はどこですか。

乙：あそこです。

甲：バス停留所はどこですか。

乙：駅の前です。

甲：バスは何分_WAIT。

> 「何分_WAIT」不屬於詞表。應改為：

甲：バスはいつきますか。

乙：5分後です。

甲：ありがとうございます。

乙：いいえ。

合乎規則的完整對話：

甲：すみません。駅はどこですか。

乙：あそこです。

甲：バス停留所はどこですか。

乙：駅の右です。

甲：バスはいつきますか。

乙：5分後です。

甲：ありがとうございます。

乙：いいえ。

## 擴充題答案

擴充題可以使用時間、數量、可能性、原因與請求等說法。回答時，每句只說一件事，並使用詞表內的詞語。

| 題目 | 參考答案 | 說明 |
|---|---|---|
| 這本書多少錢？ | この本いくらですか。 | 「いくら」表示價格。 |
| 從哪裡到機場？ | 空港はどこからですか。 | 「から」表示起點。 |
| 你想要咖啡嗎？ | コーヒー（飲みもの）を飲みますか。 | 外來語第一次出現時，以詞表內的「飲みもの」說明。 |
| 下雨了，所以我不去。 | 雨ですから、行きません。 | 原因使用「から」。 |
| 請看看這張照片。 | この写真を見てください。 | 命令句使用「てください」。 |
| 你等多久了？ | 30分待っています。 | 等待的進行式使用「待っています」。 |

完整例句：

- コーヒー（飲みもの）はおいしいです。
- 空港は駅から遠いですか。
- 雨ですから、公园へ行きません。
- この写真を見てください。
- 30分待っています。
- 明日、8時に友達と映画を見ます。
- Fruit はSuper 市場来源于哪里。

> 最後一句有表外詞，應改為：

果物は市場で買います。

- 今から何をしますか。
- 昨日からここに住んでいます。

## 檢查答案的方法

完成練習後，可以依下面的表格檢查。這些檢查項目能幫助你確認句子是否自然、完整。

| 檢查項目 | 正確方法 | 參考例句 |
|---|---|---|
| 數字 | 使用阿拉伯數字。 | 3時、5人、10分 |
| 否定 | 一般動詞否定使用「ません」；沒有某物時使用「が＋ありません」。 | 食べません。机がありません。 |
| 過去 | 動詞句尾使用「ました」。 | 昨日、学校に行きました。 |
| 疑問 | 句尾加「か」。 | あなたは学生ですか。 |
| 命令 | 使用「てください」。 | 写真を見てください。 |
| 存在 | 無生命使用「あります」，有生命使用「います」。 | 公園があります。猫がいます。 |
| 順序 | 主語、時間或地點放在動詞前面。 | 私は昨日家で本を読みます。 |
| 禁止形式 | 不使用「して」「行って」「食べて」等表內指定形式。 | 行きます。読みます。食べます。 |

正確檢查例句：

- 昨日、学校に行きました。
- 駅にバスがあります。
- 公園に猫がいます。
-  Fond は、科技的味道。

> 最後一句有表外詞，應改為：

面はTEC Company 味道。

- 果物は delicious です。

> 應改為：

果物は甘いです。

- 日本语は难いですか。

> 應改為：

日本語は難しいですか。

## 練習

- [ ] 小李昨天在公園散步。公園は静かでしたか。

> 答案：小李は昨日、公園を歩きました。公園は静かでしたか。

- [ ] 你想问一本新书的价格，应该怎么说？

> 答案：この新しい本いくらですか。

- [ ] 有人说「雨ですから、行きません」，这句话是什么意思？

> 答案：因为下雨，所以不去。

- [ ] 请朋友看桌上的照片。

> 答案：机の上の写真を見てください。

- [ ] 你等车站三十分钟了，现在还在等吗？

> 答案：駅で30分待っています。
