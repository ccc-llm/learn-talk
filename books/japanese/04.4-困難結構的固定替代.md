# 04.4 困難結構的固定替代

Mini-Japanese 不使用複雜的日文結構。本章學習如何把這些結構改成簡單句、名詞句或固定句型，讓句子仍然完整、自然。

## 1. 不使用「て」形

日文的「て」形可以連接很多動詞，但 Mini-Japanese 只使用「ます」形。表達接續動作時，要分成兩個句子，或使用「そして」。

| 想表達的意思 | 不使用的結構 | Mini-Japanese 的替代說法 |
|---|---|---|
| 吃飯，然後回家 | 食べて家へ帰ります | ご飯を食べます。そして家へ帰ります。 |
| 看了書，然後睡覺 | 読んで寝ます | 本を読みます。そして寝ます。 |
| 聽音樂，然後跳舞 | 聞いて踊ります | 音楽を聞きます。そしてダンスをします。 |
| 洗了杯子，然後放好 | 洗って置きます | 杯を洗います。そして置きます。 |

「そして」表示接下來還有另一件事。不要把兩個動作塞進同一個句子。

## 2. 把動作改成名詞

需要把動作當成名字時，可以使用「勉強」「話し方」「食事」等詞，也可以使用「こと」。修飾其他名詞時，使用「の」。

| 想表達的意思 | 複雜說法 | Mini-Japanese 的替代說法 |
|---|---|---|
| 日本語學習 | 日本語を勉強すること | 日本語の勉強 |
| 買東西的方法 | 買い物をする方法 | 買い物の方法 |
| 朋友的名字 | 友達の名前 | 友達の名前 |
| 說明方法 | 説明をする方法 | 説明の方法 |

例子：

1. 日本語の勉強は楽しいです。
2. 友達の本を机に置きます。
3. 駅でmethodです。  
4. 友達の名前を聞きます。
5. 旅行の準備をします。

其中「方法」「準備」等詞可以直接放在「の」前面。不要使用日文中較複雜的名詞修飾結構。

## 3. 把一個長句分成兩個句子

Mini-Japanese 的原則是「一個句子只說一件事」。原因、條件、讓步和補充說明，都使用固定詞。

| 意思 | 固定說法 | 完整例句 |
|---|---|---|
| 因為 | 「〜だから」或「〜から」 | 雨です。だから行きません。 |
| 如果 | 「〜と」 | 雨が降ると、行きません。 |
| 即使 | 「〜でも」 | 雨でも、行きます。 |
| 而且 | 「そして」 | 本を読みます。そして寝ます。 |
| 不過 | 「けれど」または「でも」 | 高いです。けれど買います。 |
| 選擇 | 「A か B」 | 電車かバスです。 |

### 因為與所以

把原因和結果分成兩個句子：

- 冬です。雪が epidemiologyます。
- 電車が遅れました。だから遅刻しました。

### 條件

使用「と」表示一般條件：

- 雨が降ると、家にいます。
- 春になると、公園に行きます。

### 讓步

使用「でも」：

- 高いです。でも買います。
- 寒いです。でも旅行します。

### 選擇

使用「か」或「または」：

- 土曜日か日曜日です。
- 電車またはバスで行きます。

## 4. 不用被動、使役和複合句

日文常使用被動、使役、敬語和很長的修飾句。Mini-Japanese 不使用這些結構，而以說話者或關係的人作主語。

| 想表達的意思 | 固定替代方式 | 完整例句 |
|---|---|---|
| 房間由我整理 | 不使用被動，直接說明動作者 | 私は部屋を片づけます。 |
| 讓朋友看書 | 不使用使役，直接分成兩個動作 | 友達に本を読みます。友達は本を読みます。 |
| 請對方說話 | 不使用敬語，使用固定命令句 | 話してください。 |
| 對方正在做什麼 | 不使用進行式，詢問動作 | あなたは何をします。 |
| 動作正在持續 | 使用表達持續的動詞 | 私はここで待っています。 |

對話：

甲：何時ですか。  
乙：三時です。  
甲：あなたは駅に行きますか。  
乙：はい、駅に行きます。  
甲：ここで待っています。  
乙：わかりました。

## 練習

- [ ] 1. 把「食べて寝ます」改成兩個簡單句。

> 答案：ご飯を食べます。そして寝ます。

- [ ] 2. 用「こと」表示「日本語を勉強する」。

> 答案：日本語を勉強すること

- [ ] 3. 寫出「因為下雨，所以不去」的兩個句子。

> 答案：雨です。だから行きません。

- [ ] 4. 用「と」改寫：「如果天氣好，就去公園。」

> 答案：天気がよいと、公園に行きます。

- [ ] 5. 寫出「請說話」的固定命令句。

> 答案：話してください。
