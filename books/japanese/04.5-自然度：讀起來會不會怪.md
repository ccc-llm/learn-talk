# 04.5 自然度：讀起來會不會怪

這一章要學習怎麼讓 Mini-Japanese 讀起來自然。自然不是把很多單字接在一起，而是使用正確的語序、詞性搭配和句子節奏。學習時，先想清楚「誰、何時、何處、做什麼」，再把資訊放進固定句子裡面。

## 1. 先確認句子的基本骨架

最穩定的基本順序是：

> 主語 → 時間 → 場所 → 動作 → 賓語 → 句尾

這個順序不是絕對規則，但初学时先固定使用，句子會比較自然，也比較容易檢查。

| 句子成分 | Mini-Japanese | 中文意思 |
|---|---|---|
| 主語 | 私 | 我 |
| 時間 | 昨日 | 昨天 |
| 場所 | 学校 | 學校 |
| 動作 | 勉強します | 學習 |
| 賓語 | 日本語 | 日語 |
| 句尾 | でした | 是了 |

完整例句：

1. 私は昨日学校で日本語を勉強しました。  
   我昨天在學校學習日語。

2. 今日、図書館で本を読みます。  
   今天，我會在圖書館看書。

3. 友達は明日、喫茶店に行きます。  
   朋友明天會去咖啡店。

時間和地點都可以省略，但不要為了湊齊資訊而把句子拉得太長。

## 2. 選擇自然的詞性搭配

自然度不只取決於語序，也取決於每個詞是否能用在正確的位置。動詞、形容詞和名詞的用法不同；同一個意思也可以選擇更自然的動詞。

| 想說的意思 | 不太自然的組合 | 自然的說法 | 中文意思 |
|---|---|---|---|
| 看電影 | 映画を 見ます | 映画を 見ます | 看電影 |
| 在家休息 | 家で 休みます | 家で 休みます | 在家休息 |
| 使用電腦 | パソコンを 使います | パソコンを 使います | 使用電腦 |
| 知道名字 | 名前を 知ります | 名前を知っています | 知道名字 |
| 感到高興 | 嬉しいで あります | 嬉しいです | 感到高興 |
| 身體變大 | 成長して 大きい | 大きくなります | 長大了 |

完整例句：

4. 私は電車で学校に行きます。  
   我搭電車去學校。

5. 父は家で休みます。  
   父親在家休息。

6. あの人は嬉しそうです。  
   那個人看起來很高興。

7. 猫は大きくなりました。  
   貓長大了。

寫句子時，要問自己：「這個詞是動詞、形容詞，還是名詞？」動詞和形容詞通常放在句尾；名詞前面可以用 `の`、`を`、`に` 或 `で` 連接其他成分。

## 3. 主題和主語不要隨意交換

`は` 和 `が` 都可以表示句子裡的人物或事物，但功能不同。初学时，可以先使用下面的固定方式：

- 已知資訊、一般主題：`は`
- 回答「誰」、新出現的人或事物：`が`
- 兩個都常見，後面的資訊更重要：`は`

| 使用方式 | Mini-Japanese | 中文意思 |
|---|---|---|
| 已知主題 | 私は学生です。 | 我是學生。 |
| 回答「誰」 | 誰が来ましたか。 | 誰來了？ |
| 新出現的人 | ある女の人が入りました。 | 有一個女人進來了。 |
| 已知的人 | 友達は昨日帰りました。 | 朋友昨天回去了。 |

完整例句：

8. 昨日、PSPのゲームLinked List、およびMavenのインストールとHelloWorldプロジェクトの作成 exercice。
   （此句超出詞表，不可使用。）
9. 誰|clubloorが entrance に entrance に います。  
   （此句超出詞表，不可使用。）

正確例句：

8. 誰が来ましたか。  
   誰來了？

9. 友達が今、入口にいます。  
   朋友現在在入口。

10. 私は毎日日本語を勉強します。  
    我每天學習日語。

不要只為了避免重複 `は`，就把所有句子都改成 `が`。同一個句子裡，選擇正確的主題標記比機械替換更重要。

## 4. 簡短、清楚、只說一件事

Mini-Japanese 的自然句通常不需要很長。句子越長，越容易出現不自然的搭配，也越難確認資訊順序。

| 類型 | Mini-Japanese | 中文意思 |
|---|---|---|
| 一句一件事 | 私は毎日日本語を勉強します。 | 我每天學習日語。 |
| 補充對象 | 私は日本語と中国語を勉強します。 | 我學習日語和中文。 |
| 補充地點 | 私は図書館で本を読みます。 | 我在圖書館看書。 |
| 補充時間 | 毎朝、公園を歩きます。 | 每天早上，我會在公園散步。 |

完整例句：

11. 毎朝、公園を歩きます。  
    每天早上，我會在公園散步。

12. 私は日本語と中国語を勉強します。  
    我學習日語和中文。

13. 昨日、友達と映画を見ました。  
    昨天，我和朋友看了電影。

14. この店の料理はおいしいです。  
    這家店的料理很好吃。

自然度檢查可以分成 3 步：

1. **資訊完整嗎？** 主語、時間、場所、動作和賓語是否清楚？
2. **搭配自然嗎？** 動詞是否用對，`は`、`が`、`を`、`に`、`で` 是否合理？
3. **句子夠短嗎？** 能否分成兩個更清楚的短句？

例如，下面兩個句子意思相同：

15. 昨日、学校で友達に日本語を教えました。  
    昨天，我在學校教朋友日語。

16. 昨日、学校で友達に日本語を教えました。  
    昨天，我在學校教朋友日語。

寫完句子後，從句首讀到句尾；如果某個地方需要停很久，或需要思考「為什麼這樣說」，就應該重新檢查。
