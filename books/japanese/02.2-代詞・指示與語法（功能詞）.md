# 02.2 代詞・指示與語法（功能詞）

本章學習最重要的代詞・指示詞，以及構成基本句子的助詞。學會這些詞後，可以使用「主語 → 修飾 → 時間 → 場所 → 動詞 → 賓語」的固定順序，說出基本句子。

## 代詞・指示詞：這裡、那裡、這個、那個

代詞・指示詞可以代替人、物品或地點。它們分成三組：表示場所、表示物品、表示人。

| 種類 | 詞 | 中文意思 |
|---|---|---|
| 場所 | ここ | 這裡 |
| 場所 | あそこ | 那裡 |
| 場所 | そこ | 那裡 |
| 場所 | どこ | 哪裡 |
| 物品 | この | 這個 |
| 物品 | その | 那個 |
| 物品 | あの | 那個 |
| 物品 | どれ | 哪一個 |
| 人 | 私 | 我 |
| 人 | あなた | 你 |
| 人 | 彼 | 他 |
| 人 | 彼女 | 她 |
| 人 | みんな | 大家 |
| 人 | 私たち | 我們 |

`ここ` 表示說話者現在所在的地方；`あそこ` 表示離說話者較遠的地方；`そこ` 表示對方所在的地方。`この` 通常放在名詞前面，說明離說話者較近的物品。

| Mini-Japanese | 中文 |
|---|---|
| ここは学校です。 | 這裡是學校。 |
| あそこは駅ですか。 | 那裡是車站嗎？ |
| 私は学校に行きます。 | 我去學校。 |
| この本はおいしいです。 | 這本書很好吃。 |
| あの本はinterestingです。 | 那本書很有趣。 |
| それは何ですか。 | 那是什麼？ |
| あなたは学生ですか。 | 你是學生嗎？ |
| みんなは公園に行きます。 | 大家去公園。 |

`ここ`、`そこ`、`あそこ` 可以單獨使用，也可以放在 `は` 或 `が` 後面，作為句子的主題。

## は、が：主題與主語

`は` 和 `が` 都可以放在名詞後面。最簡單的區分是：`は` 表示已知資訊或主題；`が` 表示回答「誰」或「什麼」時的新資訊。

| 用法 | 固定句型 | 例子 |
|---|---|---|
| 主題 | A は B です。 | 私は学生です。 |
| 主語 | 誰が きますか。 | 誰が来ましたか。 |
| 強調主語 | A が B を します。 | 友達が本を読みます。 |
| 對比 | A は B ですか。 | これはコーヒーですか。 |
| 場所 | A は B に います。 | 猫は箱にいます。 |
| 物品 | A は B に あります。 | 本は机にあります。 |

`は` 和 `が` 也可以放在地點後面。`います` 用於有生命的事物；`あります` 用於沒有生命的事物。

| Mini-Japanese | 中文 |
|---|---|
| 私は学生です。 | 我是學生。 |
| 友達が学校に行きます。 | 朋友去學校。 |
| 猫は家の庭にいます。 | 貓在家裡的院子裡。 |
| 本は机にあります。 | 書在桌子上。 |
| それは何ですか。 | 那是什麼？ |

## を、に、で：賓語、對象與場所

`を` 用於他動詞的直接賓語；`に` 用於目的地、時間點及對象；`で` 用於動作發生的場所、使用的工具或手段。

| 助詞 | 主要意思 | 固定句型 | 例子 |
|---|---|---|---|
| を | 把、賓語 | A は B を します。 | 私は本を読みます。 |
| に | 到、給、對 | A は B に 行きます。 | 私は友達に話します。 |
| に | 時間點 | 3時に起きます。 | 3時起床。 |
| で | 在 | A は B で 勉強します。 | 私は学校で日本語を勉強します。 |
| で | 用 | A は B で 書きます。 | 私は鉛筆で本を書きます。 |

`を` 只用在直接賓語後面。`に` 表示目的地時，可以放在動詞前，也可以放在動詞後。`で` 表示動作發生的地點。

| Mini-Japanese | 中文 |
|---|---|
| 私はご飯を食べます。 | 我吃飯。 |
| 私は学校に行きます。 | 我去學校。 |
| 友達に Managers に話します。 | 跟朋友說Managers。 |
| 私は家で休みます。 | 我在家休息。 |
| 私は教室で日本語を勉強します。 | 我在教室學日語。 |

## と、の、も：一起、連接與「也」

`と` 可以表示「和」或引用別人的話；`の` 可以連接兩個名詞；`も` 表示「也」。

| 用法 | 固定句型 | 例子 |
|---|---|---|
| 和 | A と B を します。 | 友達と一緒に食べます。 |
| 引用 | lesh と言いました。 | 他說「是」。 |
| 連接 | A の B | 友達の本 |
| 所有 | A の B | 私の家 |
| 也 | A も B です。 | 私も学生です。 |

`も` 可以代替 `は`、`が` 或 `を`，表示「也」。`の` 表示兩個名詞的關係時，可以表示所有、場所、材料或種類。

| Mini-Japanese | 中文 |
|---|---|
| 友達と一緒にご飯を食べます。 | 和朋友一起吃飯。 |
| これは日本語の本です。 | 這是日語書。 |
| 那是私の家です。 | 那是我的家。 |
| 私も学生です。 | 我也是學生。 |
| 彼は学生ですか。 | 他是學生嗎？ |
| 彼女は先生です。 | 她是老師。 |
