# 設計 Mini-English 的提示詞

Mini-Chinese 是「用 297 個漢字說話的中文」。這份提示詞把同樣的做法反過來用在英文：請 AI 設計一個只有 n 個英文詞的受限英文（**Mini-English**），讓外國人學會這 n 個詞，就能說、能讀、能寫英文。

使用方式：把下面「提示詞」整段複製給另一個 AI。它很長，最好用能讀寫檔案、能執行程式的 AI（例如 Claude Code），分階段完成；每完成一個階段，先檢查交付物再進下一階段。

---

## 提示詞

```text
# 任務：設計 Mini-English —— 用 n 個英文詞學會英文

## 背景

我已經設計過一個叫 Mini-Chinese 的受限中文：只用 297 個漢字，就能自然地說日常生活的話；
遇到字表外的東西，用字表內的字描述（例如「醫院」→「看病的地方」），描述不出「是哪一個」的專有名詞
（人名、地名、物種）就用英文外來語，第一次出現時附上說明。所有文字都用程式檢查，確保每個字都在字表內。

現在請你反過來，為英文設計同樣的東西：Mini-English。
目標讀者：母語不是英文、剛開始學英文的人（例如只會中文的成人或中學生）。
目標：學會 n 個詞和少量語法規則以後，就能
  1. 說日常生活的話（自我介紹、買東西、問路、看醫生、說感受、講一個小故事）；
  2. 把任何一般英文文章改寫成 Mini-English，意思不變；
  3. 讀得懂別人寫的 Mini-English；
  4. 而且寫出來的 Mini-English **就是正確、自然的英文**，母語者讀起來不怪（不是另一種語言，也不是破英文）。

## 設計原則（請嚴格遵守，並在報告中說明你怎麼遵守）

1. **選詞看「表達力」與「生成力」，不看詞頻。**
   一個詞要收進來，是因為「用其他詞描述不出來」而且「加進來以後能組出、描述出很多東西」。
   詞頻只作參考。例如 red / green / blue 能描述大部分顏色，就收；purple 可以說成 red-blue color，就不收。
   反過來，能用其他詞輕鬆說出來的就不收（例如 hospital → the place where doctors help sick people）。
2. **一個概念一個詞，去掉同義詞。** big / large / huge 只留 big，large → big，huge → very big。
3. **「詞」的定義要明確。** 請決定並說明：一個詞是否包含它的屈折形式（go / goes / went / gone / going）、
   派生形式（happy / unhappy / happiness）、複合詞（bedroom）、片語動詞（give up）。
   建議：收「詞族」，屈折形式算同一個詞；派生詞只允許少數規則字尾（例如 -er 表示做某事的人、un- 表示否定），
   並明列允許的字首字尾。片語動詞與慣用語要個別列出，算在 n 之內或明列為例外。
4. **不規則形式要處理。** 英文的不規則動詞、不規則複數是學習的負擔。請列出你保留的不規則形式，
   並說明為什麼保留（Mini-English 必須是正確英文，所以不能把 went 寫成 goed）。
5. **語法盡量少、盡量規則。** 用少數句型（例如 15–20 條規則）涵蓋日常需要：
   現在、過去、將來、正在、否定、是非問句、wh- 問句、比較、因為…所以、如果…就、能力與義務等。
   困難結構（被動、完成式、關係子句、假設語氣）可以不收，改用固定的替代說法，並列出替代表。
6. **三層表達法。**
   - 本詞：在詞表內的詞，直接用；
   - 描述：詞表外的一般概念，用詞表內的詞描述（定義一個固定的「描述模板」，例如 a [類別] that/for/with …）；
   - 外來詞：描述只能說出「哪一類」、說不出「哪一個」的東西（人名、地名、物種、品牌、專門術語），
     直接用原文，第一次出現時用括號說明，例如 Paris (a big city in France)。
   「先定義、後沿用」：一篇文章中第一次用描述或外來詞時說明，之後可以直接用。
7. **數字用阿拉伯數字**（1, 2, 3, 100），不必學 one/two/three…；但說明哪些數量詞要保留（first, half, many, few…）。
8. **發音友善。** 每個詞附 IPA 音標；可以的話，避免同時收兩個發音很接近、容易混淆的詞。
9. **n 由你決定，但要有根據。** 請比較並說明你選的 n（例如 300、500、850）和以下現有方案的差別：
   Ogden 的 Basic English（850 詞）、Globish（1,500 詞）、VOA Learning English（約 1,500 詞）、
   Simple English Wikipedia、Toki Pona（約 120–140 詞，但不是英文）、
   以及詞頻表（例如 General Service List、New GSL、Oxford 3000）。
   如果適合，可以分兩層：核心 n 詞（必學）＋ 擴充層（常用但能描述的詞，學了更方便）。

## 交付物

請建立一個資料夾 mini-english/，交付以下檔案。所有說明文件用 GitHub Markdown，可以用 mermaid。

1. **mini-english.md —— 規格**
   - 設計目標與原則；
   - 詞表：依類別（代詞、語法詞、數量、時間、地點、動作、性質、事物、社交…）分表，
     每個詞一列：詞、IPA、詞性、中文意思、允許的形式（例如 go/goes/went/gone/going）、組合或描述的例子；
   - 附錄「完整詞表」放在 ```text 區塊中，一行一個詞，這是唯一的權威詞表，其他檔案都從這裡讀取；
   - 允許的字首字尾、保留的不規則形式、片語動詞清單；
   - 語法規則（編號），每條附例句；
   - 困難結構的替代表（例如被動 → 主動，完成式 → 過去式加 already/before）；
   - 範例對話與短文。
2. **check.py —— 檢查程式**
   - python check.py "some text"：檢查一段文字，列出詞表外的詞；
   - python check.py --file a.txt：逐行檢查檔案；
   - 要正確處理大小寫、標點、縮寫（don't、I'm）、屈折形式（只接受詞表中列出的形式與允許的規則字尾）、
     數字、括號內的說明（外來詞的說明也要檢查）、專有名詞（大寫開頭的詞要標記為「外來詞」，
     但是同一篇文章第一次出現時必須有括號說明）；
   - 檢查 mini-english.md 自己：詞表沒有重複、各類表格與附錄一致、所有例句都通過檢查。
3. **lexicon.tsv —— 詞典**：至少 1,000 個常用英文詞（不在詞表內的）的 Mini-English 說法。
   欄位：English、Mini-English、方式（本詞／描述／外來詞）、說明。每一條的 Mini-English 欄都要通過 check.py。
4. **examples.md —— 翻譯範例**：至少 6 段一般英文文章（新聞、說明文、故事、對話、科普、生活）改寫成 Mini-English，
   以及 2 段 Mini-English 還原成一般英文；附上每段的長度比較（改寫後變長多少）。
5. **prompts/system.md —— 給 LLM 的系統提示詞**：讓其他 LLM 讀了就能只用 Mini-English 寫作、翻譯、回答問題；
   包含完整詞表、規則、最常見的錯誤與替代說法。
6. **report.md —— 設計報告**：
   - 你選的 n 和理由，和 Basic English、Globish 等方案的比較表；
   - 每一類詞為什麼收、為什麼不收（舉出被刪掉的高頻詞與它的替代說法）；
   - 覆蓋率測試（見下）；
   - 已知的限制與還說不好的東西。

## 驗證（一定要做，並把結果寫進 report.md）

1. 所有交付物中的 Mini-English 文字都要通過 check.py，報告中附上檢查輸出。
2. **覆蓋率測試**：取 lexicon.tsv 以外的 200 個常用英文詞（例如從 Oxford 3000 隨機抽），
   統計多少個可以用本詞或描述說出來、多少個必須用外來詞、多少個說不好。
3. **改寫測試**：取 5 段沒看過的一般英文短文，自己（或請另一個 LLM 用 prompts/system.md）改寫成 Mini-English，
   記錄一次就通過 check.py 的比例、最常出錯的詞，並據此修改詞表或規則。
4. **自然度檢查**：抽 20 句 Mini-English，判斷母語者讀起來是否自然、文法正確；不自然的要修改設計。

## 進行方式

請分階段做，每個階段結束時停下來，給我看結果再繼續：
  階段 1：調查現有方案，提出 n、詞的定義、分類與選詞方法（還不用完整詞表）；
  階段 2：完整詞表與語法規則（mini-english.md）＋ check.py；
  階段 3：lexicon.tsv、examples.md、prompts/system.md；
  階段 4：驗證與 report.md，依驗證結果修改。
每個決定都要說明理由；有取捨的地方列出選項讓我決定。
```

## 備註：從 Mini-Chinese 學到、寫進提示詞的經驗

| Mini-Chinese 的經驗 | 提示詞中的對應 |
|---|---|
| 選字看表達力，不看字頻（[charset-expansion.md](charset-expansion.md)） | 原則 1 |
| 刪掉能輕易說出來的字（容易 → 不難） | 原則 1、2 |
| 三層：本詞、描述、外來語；先定義後沿用（[universal.md](../mini-chinese/universal.md)） | 原則 6 |
| 數字用阿拉伯數字 | 原則 7 |
| 字表只定義在一個地方，其他都從那裡讀（mini-chinese.md 附錄） | 交付物 1 |
| 每一行都用程式檢查（[check.py](../mini-chinese/check.py)） | 交付物 2、驗證 1 |
| LLM 寫的句子一次就全部在字表內的只有約一半（[glm-corpus.md](glm-corpus.md)） | 驗證 3：要測、要回饋到設計 |

英文和中文不同的地方，提示詞特別要求處理：**詞的形式變化**（屈折、派生、不規則形式、片語動詞），以及**寫出來必須是正確自然的英文**。這兩點在 Mini-Chinese 不存在，因為漢字沒有形態變化。
